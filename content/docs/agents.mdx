Connect your AI agent to your messenger so it can find messages, gather context and prepare replies. This page is for anyone connecting a terminal agent, a browser or phone chat, or an MCP app. It explains which connection to choose, how to set it up, where to get skills and how to check the result. By the end, you can ask your agent for your first useful task.

## What is an agent, and how does it use the tool?

An **AI agent** is a program that can use tools to carry out your request. For example, it can find messages and turn them into a summary. You describe the task; the agent chooses the actions.

A **CLI** is a command-line tool: a program controlled with text commands. An agent with terminal access runs it on your computer or server, the same way you would in a terminal. A **skill** teaches the agent the commands, so you do not need to memorise them. Apps that cannot run programs have their own route at [the end of this page](#chat-apps-and-remote-agents).

## Connect the instructions

The examples use `tg` for Telegram. For MAX, replace `tg` with `max` and the skill name `tg-cli` with `max-cli`. This applies to all examples and agent notes on this page.

### First setup

Run this once in the terminal on the computer where your agent works. Setup connects your account and adds the agent instructions:

```sh
tg personal setup --agent codex
```

Replace `codex` with `cursor`, `claude` or `gemini` for your agent. Without `--agent`, setup asks you to choose. For Hermes, OpenClaw or another agent, use `none` and follow the relevant note below.

<a id="agent-login" />

### When the agent runs the login

An agent has no terminal to draw a QR code in or to open a browser from, so each tool prints what you need as text, and the agent passes it to you in the chat. Replace `personal` with your profile name.

- **Telegram and MAX:** the agent runs `tg personal session start qr` or `max personal session start qr` in the background, because the command waits for your scan and a shell tool shows nothing until it ends. Without a terminal, the tool prints the QR code as text. The agent pastes it into the chat as a code block, exactly as printed, and you scan it with the Telegram or MAX app on your phone. When Telegram renews the code, the agent pastes the new one and says that the old one expired.
- **MAX codes expire fast:** a MAX QR code lasts about 2 minutes, so the agent pastes it at once. When it expires, the agent runs the command again for a new code.
- **Zoom:** without a terminal, `zm personal session start` prints `Open this URL to approve Zoom login:` and the URL. The agent gives you the URL as a link. Open it in a browser on the same computer, because Zoom returns to a listener there.
- **Google Drive:** `drive personal session start` always prints its Google sign-in URL, and also tries to open a browser. If no browser opens, the agent gives you the printed URL as a link to open on the same computer.
- **Google Calendar:** `gcal personal session start` always prints `Open Google sign-in:` and the URL, and also tries to open a browser. If no browser opens, the agent gives you the URL as a link to open on the same computer. It signs in through WireCat's Google app unless you give it your own client. See [Google Calendar settings](./gcal/configuration.md#your-own-google-client).

A phone-number login, a two-step verification password and the first registration of your Telegram app still need you at a terminal.

### Account already connected

`tg personal setup` with an agent chosen has already installed the skill. If your agent already sees `tg-cli`, you can skip this step. A global npm install of `tg`, `max` or `memo` adds the skill only when `TG_INSTALL_AGENT`, `MAX_INSTALL_AGENT` or `MEMO_INSTALL_AGENT` names an agent (`all`, `claude`, `codex`, `cursor` or `gemini`). The one-command Windows installer for `tg` and `max` adds it unless you pass `-Agent none`. `zm` and `drive` install a skill only when asked: run `zm skill install` or `drive skill install` after `npm install -g`. To add or update the instructions without repeating login:

```sh
tg skill install
```

The **skill** is an instruction file that teaches the agent how to use the tool. It does not contain your messenger login. Start a new agent conversation after installation.

Where each agent looks for the skill file:

- **Codex, Cursor Agent, Gemini CLI**: `~/.agents/skills/tg-cli/SKILL.md`; install only for them with `tg skill install --for agents`.
- **Claude Code**: `~/.claude/skills/tg-cli/SKILL.md`; install only for it with `tg skill install --for claude`.
- **Hermes**: `~/.hermes/skills/tg-cli/SKILL.md`; save the output of `tg skill show`, see [Hermes](#hermes).
- **OpenClaw**: `~/.agents/skills/tg-cli/SKILL.md`; `tg skill install --for agents`, see [OpenClaw](#openclaw).

`~` is your home folder, also on Windows. Without `--for`, `skill install` writes both the
`.agents` and the `.claude` copy. You can also get the skills from a skill directory, such as
ClawHub or skills.sh: [Where to get WireCat skills](#where-to-get-wirecat-skills).

**After you update the tool, run `tg skill install` again**, so the instructions match the new
version. For Hermes, or any file you saved by hand, save it from `tg skill show` again. When the agent sets
`AI_AGENT` or `CLAUDECODE`, the tool reminds it at most once a day if its copy of the skill is
missing or older than the tool. The reminder goes to stderr, so JSON output stays usable.

## Check whether you are ready

```text prompt
Use tg CLI. Read its instructions with tg skill show, show the connected account and list five recent chats. Only read: do not send anything or mark messages as read.
```

The account and chats should match yours. You can then continue to [First tasks](./first-tasks.mdx).

### If it does not work

- **The agent cannot find `tg`.** Ask it to run `tg --version`. If that fails, the agent's
  terminal does not see the installed tool. Open a new terminal, or restart the agent or editor
  after installing Node.js and the tool. On Windows, see
  [what the installer changes](./installation.mdx#what-the-windows-installer-changes). More causes:
  [Telegram troubleshooting](./tg/troubleshooting.md) ·
  [MAX troubleshooting](./max/troubleshooting.md#max-не-находится-после-установки).
- **The agent reports "no session".** The tool runs, but it finds no login. Log in with
  `tg personal setup` in the same environment and profile the agent uses: the same computer user, the same
  profile name and the same folder variables such as `TG_CONFIG_DIR`, if you set them. Details: [Telegram](./tg/troubleshooting.md#no-session-for-profile-personal--run-tg-personal-setup-in-a-local-terminal) ·
  [MAX](./max/troubleshooting.md#no-session-for-profile-personal).

### Hermes

**Install the skill.** Hermes Agent reads skills from `~/.hermes/skills`. Ask Hermes to save the exact
output of `tg skill show` into `~/.hermes/skills/tg-cli/SKILL.md`, keeping the frontmatter and UTF-8
text. On macOS or Linux you can do it yourself:

```sh
mkdir -p ~/.hermes/skills/tg-cli
tg skill show > ~/.hermes/skills/tg-cli/SKILL.md
```

Hermes can also install the skill from this site; other sources are in
[Where to get WireCat skills](#hermes-agent):

```sh
hermes skills install well-known:https://wirecat.dev/.well-known/skills/tg-cli
```

If Hermes stops at a caution from its security scan, don't force the install:
[report it](https://github.com/WireCatLabs/cli-docs/issues) with the finding. Then start a new session and try the check above. Hermes's terminal must have the tool and the
same account login.

**In one step:** `tg skill install --for hermes`. It puts the skill in `~/.agents/skills` and adds
that folder to `skills.external_dirs` in Hermes's settings; if that fails, it saves a copy in
`~/.hermes/skills` instead, and says which it did. Before you run it,
delete the copy you saved in `~/.hermes/skills/tg-cli`, or run `hermes skills uninstall tg-cli` if
you installed it from this site: Hermes prefers that folder, so an old copy would hide the new one.

**If Hermes cannot find `tg`.** Hermes runs commands with the environment of a login `bash`
(`bash -l`), saved when the session starts. That shell reads `~/.bash_profile` if you have one,
otherwise `~/.profile`. It does not read `~/.zshrc`. If you added npm's folder to `PATH` only in
`~/.zshrc`, copy that `export PATH=…` line to the file bash reads, start a new Hermes session and
ask it to run `tg --version`.

**If you talk to Hermes from a chat.** Its gateway lets you message Hermes from Telegram, Discord
and other chats. Anyone the gateway accepts can ask Hermes to run `tg` with your account: read your
chats or send as you. Keep its allowed-users list to yourself, and consider a profile that only
reads: see [Permissions](./configuration.mdx#permissions).
[Hermes skills guide](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/).

### OpenClaw

**Install the skill.** With its default state folder, OpenClaw also reads `~/.agents/skills`, so
`tg skill install --for agents` is enough. If you moved that folder with `OPENCLAW_STATE_DIR`, ask
OpenClaw to save the exact output of `tg skill show` into `skills/tg-cli/SKILL.md` inside it. Check
that the skill is available to your agent and start a new session. The tool must be installed on
the computer or server where OpenClaw runs.

**If OpenClaw cannot find `tg`.** OpenClaw's background service starts with a short `PATH`, such as
`/usr/local/bin:/usr/bin:/bin` on Linux, and npm's global folder may be missing from it. Find that
folder with `npm prefix -g`; on macOS and Linux the programs are in its `bin` folder. Stop
OpenClaw's gateway, add the folder, then start the gateway again:

```sh
openclaw config set tools.exec.pathPrepend '["/home/you/.npm-global/bin"]' --strict-json
```

Replace the path with yours. The value replaces the whole list, so include any folders you already
set there.

**If you talk to OpenClaw from a chat.** Its channels connect OpenClaw to Telegram, WhatsApp,
Discord and other chats. Anyone a channel accepts can ask OpenClaw to run `tg` with your account:
read your chats or send as you. Accept only yourself in its pairing or allowlist settings, and
consider a profile that only reads: see [Permissions](./configuration.mdx#permissions).
[OpenClaw skills guide](https://docs.openclaw.ai/tools/skills).

## For chat apps and remote agents

Everything above runs the command-line tool directly. For an agent on the same computer, that is
the faster route, and you can run the same command yourself when something looks wrong. **MCP** is
an optional connection for apps that cannot run programs:

- **ChatGPT, Claude or another chat in a browser or phone app:** follow the
  [browser/mobile connection guide](./browser-apps.mdx).
- **A desktop app with MCP settings, such as Claude Desktop:** follow [MCP setup](#cursor-and-claude-desktop).
- **An agent on another computer:** install the tool and log in there, as described in
  [Another agent](#other-agents). If it can only reach your computer over a connection, use [MCP setup](#mcp-and-skills).

Login is not an MCP tool: an agent that has only MCP asks you to run the login command yourself.

## MCP and skills

### What MCP is

**MCP (Model Context Protocol)** is an open standard for connecting AI agents to tools. It works like a
universal plug: an app that supports MCP can use a compatible MCP server without a custom integration. The
standard is published at [modelcontextprotocol.io](https://modelcontextprotocol.io/).

Two sides take part:

- The **client** is the application your agent runs in, for example Claude Desktop, ChatGPT, Cursor or Gemini CLI. It asks the
  server which tools exist and calls one when your request needs it.
- The **server** is `tg <profile> mcp serve` or `max <profile> mcp serve`, part of the command-line tool. It runs on your computer, or
  on a server that a browser chat reaches over a public HTTPS address.

Through MCP, the AI can use only the tools the server offers, and only within the profile's
[permissions](./configuration.mdx#permissions): a read-only profile cannot send. Connecting MCP does not log in to
your messenger for you; you log in once with the command-line tool. It does not download your whole
archive either.

An agent with a terminal, such as Claude Code or Codex, does not need MCP: it can run `tg` and `max`
commands directly, and a **skill** tells it how. An agent without a terminal, such as one in Claude Desktop
or a browser chat, uses MCP. The [comparison below](#cli-skill-or-mcp) helps you choose.

<Callout type="info" title="Using an AI chat in the browser or on your phone?">

ChatGPT, Claude and other web chats connect through a public HTTPS address: follow the [browser and mobile setup guide](./browser-apps.mdx).

</Callout>

### What the MCP server does

Our MCP server gives your agent access to the connected messenger: chats, messages, shared files, searches and reports. You ask for a result; the agent calls the server, which performs the action through the messenger tool.

The server is included in the command-line tool and **must be running while the agent uses it**. A local client can start it on your computer. For a browser or mobile chat, keep it running on a computer or server and connect through a public HTTPS address with authentication. Follow the [browser/mobile setup guide](./browser-apps.mdx) for that connection.

### How the agent finds and runs actions

The server exposes a small set of tools instead of making you choose from hundreds of commands. First the agent finds an action and its arguments; then it runs that action. For example, to find an agreement it discovers message search, executes it and opens the matching messages.

Examples below use Telegram names. For MAX, replace `tg` with `max`, including tool and configuration names.

| Tool | What it does |
|---|---|
| `tg_tools_search` | Finds the command for a task and tells the agent its arguments and effects. This searches available actions, not your messages. |
| `tg_read` | Runs a discovered read action: list chats, search messages, read files or build a report. |
| `tg_write` | Runs a discovered change: send a message, save extracted text or manage a group, within the profile’s permissions. |

### What the skill does

A **skill** is an instruction file for your agent: which tools to use, how to gather context, check sources and prepare a result. MCP provides access to actions; the skill explains how to use them for a task. The skill contains guidance, not your account credentials.

The installed tool includes the instructions: [add them](#connect-instructions) with the setup command, or display them with `tg skill show`. An agent with terminal access can use the instructions and run the CLI directly.

### CLI, skill or MCP?

| Connection | What it provides | Choose it when |
|---|---|---|
| CLI | Commands in a terminal, with JSON results | Your agent already has a local terminal |
| Skill + CLI | Instructions for using those commands and workflows | Your agent can run terminal commands, for example Codex, Cursor Agent, Claude Code, Gemini CLI, Hermes or OpenClaw |
| MCP | Named tools and their parameters directly inside your client | Your agent has no terminal, for example in Claude Desktop, or you prefer the client's tool interface |
| MCP over HTTP | The same tools for an AI chat in a browser, such as ChatGPT or Claude, behind your own tunnel | You chat in a browser — [ChatGPT and Claude in the browser](./browser-apps.mdx) |
| Markdown docs | A readable explanation and command reference | You want the agent to look up how something works |

For an agent with a terminal, start with [a skill](#connect-instructions). MCP is optional and follows the
same profile permissions as the CLI. It does not log in for you or download the whole archive.

### Before connecting

[Install and log in](./installation.mdx). Run `tg personal mcp config` or `max personal mcp config`
to print a configuration with the actual Node and CLI paths on your machine. This command prints
settings; it does not edit your client. Desktop clients may have a different PATH from your terminal.

The server serves the profile you name: `tg personal mcp serve`. You can serve several profiles from one server
with `tg mcp serve --profiles personal,work`, or every profile with `--profiles all`; each tool call then says which
profile it is for. max works the same way. Without a profile or `--profiles`, neither starts the server. `tg mcp` or
`max mcp` on its own only shows help.

#### Codex

In a terminal where the installed command works:

```sh
tg personal mcp add codex
codex mcp list
```

Setup uses Codex's own command and leaves other servers intact. By hand, the equivalent is `codex mcp add tg -- tg personal mcp serve`.

Connect only the messengers you use. Codex stores MCP settings in `~/.codex/config.toml`.
For Windows or an IDE with a different PATH, take `command`, `args` and `env` from `mcp config`
and put them into `[mcp_servers.tg]` or `[mcp_servers.max]`; Codex uses TOML, not `mcpServers` JSON.
[Official Codex MCP guide](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).

#### Claude Code

```sh
tg personal mcp add claude-code
claude mcp list
```

By hand, the equivalent is `claude mcp add --scope user tg -- tg personal mcp serve`. If the profile exposes write tools, setup asks you to check its [permissions](./configuration.mdx#permissions) first and then repeat with `--allow-writes`. That flag only confirms the installation; it does not change the permissions.

Use `/mcp` in a session to check status. For full paths, use the values from `mcp config`.
[Official Claude Code MCP guide](https://code.claude.com/docs/en/mcp).

#### Cursor and Claude Desktop

Copy the server entry printed by `tg personal mcp config` or `max personal mcp config` into the client's
`mcpServers` settings, preserving its full paths and environment. Merge it with existing servers.

| Client | Configuration file |
|---|---|
| Cursor, personal | `~/.cursor/mcp.json` |
| Cursor, project | `.cursor/mcp.json` |
| Claude Desktop, macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Claude Desktop, Windows | `%APPDATA%\Claude\claude_desktop_config.json` |

Restart the client and check that the server's tools are available.
[Official Cursor MCP guide](https://cursor.com/help/customization/mcp).

#### Gemini CLI

```sh
gemini mcp add --scope user tg tg personal mcp serve
gemini mcp list
```

For full paths and environment variables, merge the generated entry into `mcpServers` in
`~/.gemini/settings.json`. [Official Gemini MCP guide](https://geminicli.com/docs/tools/mcp-server/).

#### Hermes

Hermes uses `mcp_servers` in `~/.hermes/config.yaml`. Add `tg` or `max` there with the `command`,
`args` and `env` values from the generated configuration, keeping existing settings. Hermes uses
YAML; do not paste the whole `mcpServers` JSON object into it. Restart Hermes to load the server.
[Official Hermes quickstart](https://hermes-agent.nousresearch.com/docs/getting-started/quickstart/).

### Zoom, Google Drive and Memo

Each tool starts its own server. Connect it with the command your client uses for MCP servers:

- **Zoom:** `zm personal mcp serve`.
- **Google Drive:** `drive personal --read-only mcp serve`.
- **Google Calendar:** `gcal personal mcp serve`.
- **Mail:** `mail personal mcp serve`.
- **Bitrix24:** `b24 personal mcp serve`.
- **Memo:** `memo mcp serve`.

### What the agent can do

MCP covers most everyday CLI operations: read and search chats, inspect people and groups, work with message attachments, prepare reports, send replies and manage groups when permitted.

For full command syntax and MCP-specific availability, use the messenger references:

- [Telegram MCP tools and coverage](./tg/mcp.md#tools) · [Telegram command reference](./tg/commands.md).
- [MAX MCP tools and coverage](./max/mcp.md#инструменты) · [MAX command reference](./max/commands.md).

The available catalogue is determined by the messenger and profile permissions. Ask the agent to discover an action through the search tool; its result provides the supported command and arguments. A read-only profile excludes changes. The server has no confirmation step of its own: approval prompts come from your app, and the server cannot check whether a person accepted them.

After connecting, ask for five recent chats. Continue with [First tasks](./first-tasks.mdx).

## Use from web or mobile

ChatGPT, Claude, Gemini and other AI chats in a browser or phone app cannot run programs on your computer. They reach the tool through MCP and a public HTTPS address. The guide [Use from web or mobile](./browser-apps.mdx) covers the address, adding the connection to your chat, permissions, recovery and an always-on server.
