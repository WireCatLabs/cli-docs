Connect your AI agent to your messenger so it can find messages, gather context and prepare replies. This page explains which connection to choose, how to set it up and how to check the result. By the end, you can ask your agent for your first useful task.

## What is an agent, and how does it use the tool?

An **AI agent** is a program that can use tools to carry out your request. For example, it can find messages and turn them into a summary. You describe the task; the agent chooses the actions.

A **CLI** is a command-line tool: a program controlled with text commands. An agent with terminal access runs it on your computer or server, the same way you would in a terminal. A **skill** teaches the agent the commands, so you do not need to memorise them. Apps that cannot run programs have their own route at [the end of this page](#chat-apps-and-remote-agents).

## Connect the instructions

The examples use `tg` for Telegram. For MAX, replace `tg` with `max` and the skill name `tg-cli` with `max-cli`. This applies to all examples and agent notes on this page.

### First setup

Run this once in the terminal on the computer where your agent works. Setup connects your account and adds the agent instructions:

```sh
tg personal setup --agent codex
```

Replace `codex` with `cursor`, `claude` or `gemini` for your agent. Without `--agent`, setup asks you to choose. For Hermes, OpenClaw or another agent, use `none` and follow the relevant note below.

<a id="agent-login" />

### When the agent runs the login

An agent has no terminal to draw a QR code in or to open a browser from, so each tool prints what you need as text, and the agent passes it to you in the chat. Replace `personal` with your profile name.

- **Telegram and MAX:** the agent runs `tg personal session start qr` or `max personal session start qr` in the background, because the command waits for your scan and a shell tool shows nothing until it ends. Without a terminal, the tool prints the QR code as text. The agent pastes it into the chat as a code block, exactly as printed, and you scan it with the Telegram or MAX app on your phone. When Telegram renews the code, the agent pastes the new one and says that the old one expired.
- **MAX codes expire fast:** a MAX QR code lasts about 2 minutes, so the agent pastes it at once. When it expires, the agent runs the command again for a new code.
- **Zoom:** without a terminal, `zm personal session start` prints `Open this URL to approve Zoom login:` and the URL. The agent gives you the URL as a link. Open it in a browser on the same computer, because Zoom returns to a listener there.
- **Google Drive:** `drive personal session start` always prints its Google sign-in URL, and also tries to open a browser. If no browser opens, the agent gives you the printed URL as a link to open on the same computer.

A phone-number login, a two-step verification password and the first registration of your Telegram app still need you at a terminal.

### Account already connected

`tg personal setup` with an agent chosen has already installed the skill. If your agent already sees `tg-cli`, you can skip this step. A global npm install of `tg`, `max` or `memo` adds the skill only when `TG_INSTALL_AGENT`, `MAX_INSTALL_AGENT` or `MEMO_INSTALL_AGENT` names an agent (`all`, `claude`, `codex`, `cursor` or `gemini`). The one-command Windows installer for `tg` and `max` adds it unless you pass `-Agent none`. `zm` and `drive` install a skill only when asked: run `zm skill install` or `drive skill install` after `npm install -g`. To add or update the instructions without repeating login:

```sh
tg skill install
```

The **skill** is an instruction file that teaches the agent how to use the tool. It does not contain your messenger login. Start a new agent conversation after installation.

Where each agent looks for the skill file:

- **Codex, Cursor Agent, Gemini CLI**: `~/.agents/skills/tg-cli/SKILL.md`; install only for them with `tg skill install --for agents`.
- **Claude Code**: `~/.claude/skills/tg-cli/SKILL.md`; install only for it with `tg skill install --for claude`.
- **Hermes**: `~/.hermes/skills/tg-cli/SKILL.md`; save the output of `tg skill show`, see [Hermes](#hermes).
- **OpenClaw**: `~/.agents/skills/tg-cli/SKILL.md`; `tg skill install --for agents`, see [OpenClaw](#openclaw).

`~` is your home folder, also on Windows. Without `--for`, `skill install` writes both the
`.agents` and the `.claude` copy. You can also get the skills from a skill directory, such as
ClawHub or skills.sh: [Where to get WireCat skills](./skills.mdx).

**After you update the tool, run `tg skill install` again**, so the instructions match the new
version. For Hermes, or any file you saved by hand, save it from `tg skill show` again. When the agent sets
`AI_AGENT` or `CLAUDECODE`, the tool reminds it at most once a day if its copy of the skill is
missing or older than the tool. The reminder goes to stderr, so JSON output stays usable.

## Check whether you are ready

```text prompt
Use tg CLI. Read its instructions with tg skill show, show the connected account and list five recent chats. Only read: do not send anything or mark messages as read.
```

The account and chats should match yours. You can then continue to [First tasks](./first-tasks.md).

### If it does not work

- **The agent cannot find `tg`.** Ask it to run `tg --version`. If that fails, the agent's
  terminal does not see the installed tool. Open a new terminal, or restart the agent or editor
  after installing Node.js and the tool. On Windows, see
  [what the installer changes](./installation.mdx#what-the-windows-installer-changes). More causes:
  [Telegram troubleshooting](./tg/troubleshooting.md) ·
  [MAX troubleshooting](./max/troubleshooting.md#max-не-находится-после-установки).
- **The agent reports "no session".** The tool runs, but it finds no login. Log in with
  `tg personal setup` in the same environment and profile the agent uses: the same computer user, the same
  profile name and the same folder variables such as `TG_CONFIG_DIR`, if you set them. Details: [Telegram](./tg/troubleshooting.md#no-session-for-profile-personal--run-tg-personal-setup-in-a-local-terminal) ·
  [MAX](./max/troubleshooting.md#no-session-for-profile-personal).

## Notes for your agent

Use these only for the extra step your client needs. The connection command above is shared.

### Codex

Use Codex locally, in its CLI or IDE extension. Select `$tg-cli` in your conversation. If it is
missing, open a new conversation or restart Codex. [Codex skills guide](https://learn.chatgpt.com/docs/build-skills).

### Cursor

Use **Agent** with <DocTerm term="terminal" lang="en" label="terminal access" />, then ask it to use the tool. You can pick `tg-cli` through `/` in
the Agent chat. If the skill is missing, restart Cursor or ask the agent to read `tg skill show`.
[Cursor skills guide](https://cursor.com/help/customization/skills).

### Claude Code

Use `/tg-cli` in a new local session.
[Claude Code skills guide](https://code.claude.com/docs/en/skills).

### Gemini CLI

Use `gemini skills list` to see whether the skill is available. In an existing session,
`/skills reload` refreshes it. [Gemini skills guide](https://geminicli.com/docs/cli/skills/).

### Hermes

**Install the skill.** Hermes Agent reads skills from `~/.hermes/skills`. Ask Hermes to save the exact
output of `tg skill show` into `~/.hermes/skills/tg-cli/SKILL.md`, keeping the frontmatter and UTF-8
text. On macOS or Linux you can do it yourself:

```sh
mkdir -p ~/.hermes/skills/tg-cli
tg skill show > ~/.hermes/skills/tg-cli/SKILL.md
```

Hermes can also install the skill from this site; other sources are in
[Where to get WireCat skills](./skills.mdx#hermes):

```sh
hermes skills install well-known:https://wirecat.dev/.well-known/skills/tg-cli
```

If Hermes stops at a caution from its security scan, don't force the install:
[report it](https://github.com/WireCatLabs/cli-docs/issues) with the finding. Then start a new session and try the check above. Hermes's terminal must have the tool and the
same account login.

**In one step:** `tg skill install --for hermes`. It puts the skill in `~/.agents/skills` and adds
that folder to `skills.external_dirs` in Hermes's settings; if that fails, it saves a copy in
`~/.hermes/skills` instead, and says which it did. Before you run it,
delete the copy you saved in `~/.hermes/skills/tg-cli`, or run `hermes skills uninstall tg-cli` if
you installed it from this site: Hermes prefers that folder, so an old copy would hide the new one.

**If Hermes cannot find `tg`.** Hermes runs commands with the environment of a login `bash`
(`bash -l`), saved when the session starts. That shell reads `~/.bash_profile` if you have one,
otherwise `~/.profile`. It does not read `~/.zshrc`. If you added npm's folder to `PATH` only in
`~/.zshrc`, copy that `export PATH=…` line to the file bash reads, start a new Hermes session and
ask it to run `tg --version`.

**If you talk to Hermes from a chat.** Its gateway lets you message Hermes from Telegram, Discord
and other chats. Anyone the gateway accepts can ask Hermes to run `tg` with your account: read your
chats or send as you. Keep its allowed-users list to yourself, and consider a profile that only
reads: see [Permissions](./permissions.mdx).
[Hermes skills guide](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/).

### OpenClaw

**Install the skill.** With its default state folder, OpenClaw also reads `~/.agents/skills`, so
`tg skill install --for agents` is enough. If you moved that folder with `OPENCLAW_STATE_DIR`, ask
OpenClaw to save the exact output of `tg skill show` into `skills/tg-cli/SKILL.md` inside it. Check
that the skill is available to your agent and start a new session. The tool must be installed on
the computer or server where OpenClaw runs.

**If OpenClaw cannot find `tg`.** OpenClaw's background service starts with a short `PATH`, such as
`/usr/local/bin:/usr/bin:/bin` on Linux, and npm's global folder may be missing from it. Find that
folder with `npm prefix -g`; on macOS and Linux the programs are in its `bin` folder. Stop
OpenClaw's gateway, add the folder, then start the gateway again:

```sh
openclaw config set tools.exec.pathPrepend '["/home/you/.npm-global/bin"]' --strict-json
```

Replace the path with yours. The value replaces the whole list, so include any folders you already
set there.

**If you talk to OpenClaw from a chat.** Its channels connect OpenClaw to Telegram, WhatsApp,
Discord and other chats. Anyone a channel accepts can ask OpenClaw to run `tg` with your account:
read your chats or send as you. Accept only yourself in its pairing or allowlist settings, and
consider a profile that only reads: see [Permissions](./permissions.mdx).
[OpenClaw skills guide](https://docs.openclaw.ai/tools/skills).

### Another agent

The examples above are not a closed list. Any agent with command-line access can use the tool. Give it the output of `tg skill show`, or give it [the Markdown documentation](./mcp.mdx#documentation-for-your-agent). It finds what to do with `tg guide`, which lists step-by-step scenarios for common tasks, and `tg commands`, which lists every command by section and marks the ones that change something. The same scenarios are on this site, one page per tool: [Telegram](./tg/scenarios.md), [MAX](./max/scenarios.md), [Zoom](./zm/scenarios.md), [Google Drive](./drive/scenarios.md), [Google Calendar](./gcal/scenarios.md) and [Memo](./memo/scenarios.md). `--help` after a command, as in `tg chats list --help`, shows its options.

A cloud agent runs on another computer. Install the tool and log in there; your local login is not available to it.

Ready-made installation choices cover specific clients; other agents use their own instruction or tool settings.

## For chat apps and remote agents

Everything above runs the command-line tool directly. For an agent on the same computer, that is
the faster route, and you can run the same command yourself when something looks wrong. **MCP** is
an optional connection for apps that cannot run programs:

- **ChatGPT, Claude or another chat in a browser or phone app:** follow the
  [browser/mobile connection guide](./browser-apps.mdx).
- **A desktop app with MCP settings, such as Claude Desktop:** follow [MCP setup](./mcp.mdx#cursor-and-claude-desktop).
- **An agent on another computer:** install the tool and log in there, as described in
  [Another agent](#other-agents). If it can only reach your computer over a connection, use [MCP setup](./mcp.mdx).

Login is not an MCP tool: an agent that has only MCP asks you to run the login command yourself.
