Подключите ИИ-помощника к мессенджеру, чтобы он находил сообщения, собирал контекст и готовил ответы. Здесь вы выберете подходящий способ подключения, настроите его и проверите результат. После этого сможете поручить помощнику первую полезную задачу.

## Что такое агент и как он использует инструмент

**ИИ-агент** — помощник, который умеет пользоваться инструментами для выполнения вашего запроса. Например, он может найти сообщения и составить из них сводку. Вы описываете задачу, а агент выбирает действия.

**CLI** — инструмент командной строки: программа, которой управляют текстовыми командами. Агент с доступом к терминалу запускает её на вашем компьютере или сервере. Чат без такого доступа подключается через **MCP** — способ дать ассистенту доступ к инструменту через соединение. Запоминать команды не нужно.

## Подключите инструкцию

В примерах используется `tg` для Telegram. Для MAX замените `tg` на `max`, а имя инструкции `tg-cli` — на `max-cli`. Это правило действует для всех примеров и подсказок на странице.

### Первое подключение

Выполните одну команду в терминале на компьютере, где работает агент. Она подключит аккаунт и установит инструкцию для агента:

```sh
tg setup --agent codex
```

Вместо `codex` укажите `cursor`, `claude` или `gemini`. Без `--agent` программа предложит выбрать агента. Для Hermes, OpenClaw и других агентов укажите `none`, затем выполните подсказку для своего приложения ниже.

### Аккаунт уже подключён

Добавьте инструкцию без повторного входа:

```sh
tg skill install
```

**Навык (skill)** — файл с инструкцией, который объясняет агенту, как пользоваться инструментом. Команда устанавливает его в стандартные папки. После установки начните новую беседу с агентом.

## Проверьте, всё ли готово

```text prompt
Используй tg CLI. Прочитай инструкцию через tg skill show, покажи подключённый аккаунт и пять последних чатов. Только читай: ничего не отправляй и не отмечай сообщения прочитанными.
```

Аккаунт и чаты должны быть вашими. После проверки переходите к [первым задачам](./first-tasks.md).

## Подсказки для вашего агента

Здесь только дополнительные действия для конкретного приложения. Основная команда подключения общая.

### Codex

Выберите `$tg-cli` в беседе. Если навык не появился, откройте новую беседу
или перезапустите Codex. [Инструкция Codex](https://learn.chatgpt.com/docs/build-skills).

### Cursor

Используйте режим **Agent** с доступом к терминалу и попросите его воспользоваться инструмент.
Если навык не найден, попросите прочитать `skill show`.
[Инструкция Cursor](https://cursor.com/help/customization/skills).

### Claude Code

Вызовите `/tg-cli` в новой локальной сессии.
[Инструкция Claude Code](https://code.claude.com/docs/en/skills).

### Gemini CLI

Команда `gemini skills list` показывает доступные навыки. В уже открытой сессии обновите список
через `/skills reload`. [Инструкция Gemini](https://geminicli.com/docs/cli/skills/).

### Hermes

Попросите Hermes сохранить точный вывод `tg skill show` в
`~/.hermes/skills/tg-cli/SKILL.md`. Начните новую сессию и повторите проверку в начале страницы.
[Инструкция Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/).

### OpenClaw

Попросите OpenClaw сохранить точный вывод `tg skill show` в
`~/.openclaw/skills/tg-cli/SKILL.md`. Проверьте, что навык доступен вашему агенту, и начните новую
сессию. Инструмент должен быть установлен на компьютере или сервере, где работает OpenClaw.
[Инструкция OpenClaw](https://docs.openclaw.ai/tools/skills).

### Другой агент

Примеры выше — не закрытый список. Любой ассистент с доступом к командной строке может использовать инструмент. Передайте ему вывод `tg skill show` либо попросите прочитать документацию инструмента. Доступные команды он может уточнять через `--help`.

Если ассистент подключает инструменты через MCP, откройте [настройку MCP](./mcp.mdx); для чата в браузере — [подключение из браузера](./browser-apps.mdx). Готовые варианты установки предусмотрены для отдельных клиентов, остальные используют свой способ добавления инструкций или инструментов.
