Подключите ИИ-агента к мессенджеру, чтобы он находил сообщения, собирал контекст и готовил ответы. Страница для тех, кто подключает терминального агента, чат в браузере или на телефоне, либо MCP-приложение. Здесь вы выберете способ подключения, настроите его, найдёте навыки и проверите результат. После этого сможете поручить агенту первую полезную задачу.

## Что такое агент и как он использует инструмент

**ИИ-агент** — программа, которая умеет пользоваться инструментами для выполнения вашего запроса. Например, он может найти сообщения и составить из них сводку. Вы описываете задачу, а агент выбирает действия.

**CLI** — инструмент командной строки: программа, которой управляют текстовыми командами. Агент с доступом к терминалу запускает её на вашем компьютере или сервере так же, как вы в терминале. **Навык (skill)** учит агента командам, поэтому запоминать их не нужно. Для приложений, которые не умеют запускать программы, есть отдельный путь [в конце страницы](#chat-apps-and-remote-agents).

## Подключите инструкцию

В примерах используется `tg` для Telegram. Для MAX замените `tg` на `max`, а имя инструкции `tg-cli` — на `max-cli`. Это правило действует для всех примеров и подсказок на странице.

### Первое подключение

Выполните одну команду в терминале на компьютере, где работает агент. Она подключит аккаунт и установит инструкцию для агента:

```sh
tg personal setup --agent codex
```

Вместо `codex` укажите `cursor`, `claude` или `gemini`. Без `--agent` программа предложит выбрать агента. Для Hermes, OpenClaw и других агентов укажите `none`, затем выполните подсказку для своего приложения ниже.

<a id="agent-login" />

### Если вход запускает агент

У агента нет терминала, чтобы нарисовать QR-код или открыть браузер, поэтому каждый инструмент печатает нужное текстом, а агент передаёт это вам в чат. Вместо `personal` укажите имя своего профиля.

- **Telegram и MAX:** агент запускает `tg personal session start qr` или `max personal session start qr` в фоне: команда ждёт сканирования, а инструмент оболочки ничего не показывает, пока она не завершится. Без терминала инструмент печатает QR-код текстом. Агент вставляет его в чат блоком кода точно как напечатано, а вы сканируете его приложением Telegram или MAX на телефоне. Когда Telegram обновляет код, агент вставляет новый и говорит, что старый истёк.
- **Код MAX быстро истекает:** QR-код MAX действует около 2 минут, поэтому агент вставляет его сразу. Когда код истёк, агент запускает команду снова и получает новый.
- **Zoom:** без терминала `zm personal session start` печатает `Open this URL to approve Zoom login:` и ссылку. Агент передаёт вам ссылку. Откройте её в браузере на этом же компьютере: Zoom возвращает ответ на слушатель здесь.
- **Google Drive:** `drive personal session start` всегда печатает ссылку для входа в Google и пробует открыть браузер. Если браузер не открылся, агент передаёт вам напечатанную ссылку, чтобы открыть её на этом же компьютере.
- **Google Calendar:** `gcal personal session start` всегда печатает `Open Google sign-in:` и ссылку и пробует открыть браузер. Если браузер не открылся, агент передаёт вам ссылку, чтобы открыть её на этом же компьютере. Он входит через приложение Google от WireCat, если вы не дали свой клиент. См. [настройки Google Calendar](./gcal/configuration.md#your-own-google-client).

Вход по номеру телефона, пароль двухэтапной проверки и первая регистрация вашего приложения Telegram по-прежнему требуют вас у терминала.

### Аккаунт уже подключён

`tg personal setup` с выбранным агентом уже поставил навык. Если агент уже видит `tg-cli`, этот шаг можно пропустить. Глобальная установка `tg`, `max` или `memo` через npm ставит навык, только если `TG_INSTALL_AGENT`, `MAX_INSTALL_AGENT` или `MEMO_INSTALL_AGENT` называет агента (`all`, `claude`, `codex`, `cursor` или `gemini`). Установщик Windows одной командой для `tg` и `max` ставит его, если не передать `-Agent none`. `zm` и `drive` ставят навык только по запросу: после `npm install -g` выполните `zm skill install` или `drive skill install`. Чтобы добавить или обновить инструкцию без повторного входа:

```sh
tg skill install
```

**Навык (skill)** — файл с инструкцией, который объясняет агенту, как пользоваться инструментом. Вход в мессенджер в нём не хранится. После установки начните новую беседу с агентом.

Где каждый агент ищет файл навыка:

- **Codex, Cursor Agent, Gemini CLI**: `~/.agents/skills/tg-cli/SKILL.md`; только для них — `tg skill install --for agents`.
- **Claude Code**: `~/.claude/skills/tg-cli/SKILL.md`; только для него — `tg skill install --for claude`.
- **Hermes**: `~/.hermes/skills/tg-cli/SKILL.md`; сохраните вывод `tg skill show`, см. [Hermes](#hermes).
- **OpenClaw**: `~/.agents/skills/tg-cli/SKILL.md`; `tg skill install --for agents`, см. [OpenClaw](#openclaw).

`~` — ваша домашняя папка, в том числе на Windows. Без `--for` команда `skill install` записывает
обе копии: в `.agents` и в `.claude`. Навыки можно взять и из каталога навыков, например ClawHub
или skills.sh: [Где взять навыки WireCat](#где-взять-навыки-wirecat).

**После обновления инструмента снова выполните `tg skill install`**, чтобы инструкция
соответствовала новой версии. Для Hermes и любого файла, сохранённого вручную, заново сохраните его из `tg skill show`.
Если агент задаёт переменную `AI_AGENT` или `CLAUDECODE`, инструмент не чаще раза в сутки
напоминает ему, что копии навыка нет или она старше инструмента. Напоминание идёт в stderr,
поэтому JSON-вывод остаётся пригодным.

## Проверьте, всё ли готово

```text prompt
Используй tg CLI. Прочитай инструкцию через tg skill show, покажи подключённый аккаунт и пять последних чатов. Только читай: ничего не отправляй и не отмечай сообщения прочитанными.
```

Аккаунт и чаты должны быть вашими. После проверки переходите к [первым задачам](./first-tasks.mdx).

### Если не получилось

- **Агент не находит `tg`.** Попросите его выполнить `tg --version`. Если команда не работает,
  терминал агента не видит установленный инструмент. Откройте новый терминал или перезапустите
  агента или редактор после установки Node.js и инструмента. На Windows смотрите,
  [что меняет установщик](./installation.mdx#what-the-windows-installer-changes). Другие причины:
  [решение проблем Telegram](./tg/troubleshooting.md) ·
  [решение проблем MAX](./max/troubleshooting.md#max-не-находится-после-установки).
- **Агент сообщает «no session».** Инструмент запускается, но не находит вход. Войдите через
  `tg personal setup` в том же окружении и профиле, которые использует агент: тот же пользователь
  компьютера, то же имя профиля и те же переменные каталогов, например `TG_CONFIG_DIR`, если вы
  их задавали. Подробнее: [Telegram](./tg/troubleshooting.md#no-session-for-profile-personal--run-tg-personal-setup-in-a-local-terminal) ·
  [MAX](./max/troubleshooting.md#no-session-for-profile-personal).

## Подсказки для вашего агента

Здесь только дополнительные действия для конкретного приложения. Основная команда подключения общая.

### Codex

Используйте Codex локально, в CLI или расширении для IDE. Выберите `$tg-cli` в беседе. Если
навык не появился, откройте новую беседу или перезапустите Codex. [Инструкция Codex](https://learn.chatgpt.com/docs/build-skills).

### Cursor

Используйте режим **Agent** с доступом к терминалу и попросите его воспользоваться инструментом.
Навык `tg-cli` можно выбрать через `/` в чате Agent. Если его нет, перезапустите Cursor или
попросите агента прочитать `tg skill show`.
[Инструкция Cursor](https://cursor.com/help/customization/skills).

### Claude Code

Вызовите `/tg-cli` в новой локальной сессии.
[Инструкция Claude Code](https://code.claude.com/docs/en/skills).

### Gemini CLI

Команда `gemini skills list` показывает доступные навыки. В уже открытой сессии обновите список
через `/skills reload`. [Инструкция Gemini](https://geminicli.com/docs/cli/skills/).

### Hermes

**Установите навык.** Hermes Agent читает навыки из `~/.hermes/skills`. Попросите Hermes сохранить
точный вывод `tg skill show` в `~/.hermes/skills/tg-cli/SKILL.md`, сохранив frontmatter и текст в
UTF-8. На macOS или Linux это можно сделать самому:

```sh
mkdir -p ~/.hermes/skills/tg-cli
tg skill show > ~/.hermes/skills/tg-cli/SKILL.md
```

Hermes может установить навык и с этого сайта; другие источники — на странице
[Где взять навыки WireCat](#hermes-agent):

```sh
hermes skills install well-known:https://wirecat.dev/.well-known/skills/tg-cli
```

Если Hermes остановился на предупреждении своей проверки безопасности, не ставьте навык
силой: [сообщите нам](https://github.com/WireCatLabs/cli-docs/issues) находку. Затем начните новую сессию и повторите проверку выше. В терминале Hermes должны быть инструмент
и тот же вход в аккаунт.

**Одной командой:** `tg skill install --for hermes`. Она кладёт навык в `~/.agents/skills` и добавляет
эту папку в `skills.external_dirs` в настройках Hermes; если это не получается, сохраняет копию в
`~/.hermes/skills` и говорит, что сделала. Перед запуском удалите копию,
которую вы сохранили в `~/.hermes/skills/tg-cli`, или выполните `hermes skills uninstall tg-cli`, если
ставили навык с этого сайта: Hermes предпочитает эту папку, и старая копия заслонит новую.

**Если Hermes не находит `tg`.** Hermes выполняет команды в окружении login-оболочки `bash`
(`bash -l`), которое он сохраняет в начале сессии. Такая оболочка читает `~/.bash_profile`, если он
есть, иначе `~/.profile`. Файл `~/.zshrc` она не читает. Если вы добавили папку npm в `PATH` только
в `~/.zshrc`, скопируйте эту строку `export PATH=…` в файл, который читает bash, начните новую сессию
Hermes и попросите его выполнить `tg --version`.

**Если вы пишете Hermes из чата.** Его шлюз (gateway) позволяет писать Hermes из Telegram, Discord и
других чатов. Любой, кого принимает шлюз, может попросить Hermes запустить `tg` с вашим аккаунтом:
прочитать ваши чаты или написать от вашего имени. Оставьте в списке разрешённых пользователей только
себя и подумайте о профиле, который только читает: см. [Разрешения](./configuration.mdx#права).
[Инструкция Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/).

### OpenClaw

**Установите навык.** С каталогом состояния по умолчанию OpenClaw читает и `~/.agents/skills`,
поэтому достаточно `tg skill install --for agents`. Если вы перенесли этот каталог через
`OPENCLAW_STATE_DIR`, попросите OpenClaw сохранить точный вывод `tg skill show` в
`skills/tg-cli/SKILL.md` внутри него. Проверьте, что навык доступен вашему агенту, и начните новую
сессию. Инструмент должен быть установлен на компьютере или сервере, где работает OpenClaw.

**Если OpenClaw не находит `tg`.** Фоновая служба OpenClaw запускается с коротким `PATH`, например
`/usr/local/bin:/usr/bin:/bin` на Linux, и глобальной папки npm в нём может не быть. Узнайте эту
папку командой `npm prefix -g`; на macOS и Linux программы лежат в её подпапке `bin`. Остановите
шлюз OpenClaw, добавьте папку и снова запустите шлюз:

```sh
openclaw config set tools.exec.pathPrepend '["/home/you/.npm-global/bin"]' --strict-json
```

Подставьте свой путь. Значение заменяет весь список, поэтому укажите и папки, которые вы уже
добавляли туда.

**Если вы пишете OpenClaw из чата.** Его каналы (channels) подключают OpenClaw к Telegram, WhatsApp,
Discord и другим чатам. Любой, кого принимает канал, может попросить OpenClaw запустить `tg` с вашим
аккаунтом: прочитать ваши чаты или написать от вашего имени. В настройках сопряжения (pairing) или
списка разрешённых оставьте только себя и подумайте о профиле, который только читает: см.
[Разрешения](./configuration.mdx#права).
[Инструкция OpenClaw](https://docs.openclaw.ai/tools/skills).

### Другой агент

Примеры выше — не закрытый список. Любой агент с доступом к командной строке может использовать инструмент. Передайте ему вывод `tg skill show` либо [Markdown-документацию](#документация-для-агента). Что делать, он находит через `tg guide` — пошаговые сценарии для частых задач — и `tg commands` — все команды по разделам с отметкой тех, что что-то меняют. Те же сценарии есть на сайте, по странице на инструмент: [Telegram](./tg/scenarios.md), [MAX](./max/scenarios.md), [Zoom](./zm/scenarios.md), [Google Drive](./drive/scenarios.md), [Google Calendar](./gcal/scenarios.md) и [Memo](./memo/scenarios.md). `--help` после команды, например `tg chats list --help`, показывает её параметры.

Облачный агент работает на другом компьютере. Установите инструмент и войдите в аккаунт там: ваш локальный вход ему недоступен.

Готовые варианты установки предусмотрены для отдельных клиентов, остальные используют свой способ добавления инструкций или инструментов.

## Где взять навыки WireCat

**Навык (skill)** — файл с инструкцией, `SKILL.md`, который учит ИИ-агента командам одного
инструмента WireCat. Каждый инструмент сам ставит свой навык командой `skill install` (см.
[Подключите инструкцию](#connect-instructions)). В этом разделе собраны каталоги
навыков, где есть те же навыки, — на случай, если вы предпочитаете ставить и обновлять навыки так, как
это делает ваш агент. В итоге у агента будет нужный навык из выбранного вами источника.

Навык только учит. Сам инструмент всё равно должен быть установлен, и вход в аккаунт должен быть
выполнен на том компьютере, где работает агент: см. [Установку](./installation.mdx).

### Имена навыков

В примерах используется `tg` для Telegram. Для другого инструмента замените репозиторий и имя навыка:

- **Telegram** (`tg`): репозиторий `WireCatLabs/tg-cli`, навык `tg-cli`
- **MAX** (`max`): репозиторий `WireCatLabs/max-cli`, навык `max-cli`
- **WhatsApp** (`wa`): репозиторий `WireCatLabs/whatsapp-cli`, навык `whatsapp-cli`
- **Google Drive** (`drive`): репозиторий `WireCatLabs/drive-cli`, навык `drive-cli`
- **Google Calendar** (`gcal`): репозиторий `WireCatLabs/gcal-cli`, навык `gcal-cli`
- **Mail** (`mail`): репозиторий `WireCatLabs/mail-cli`, навык `mail-cli`
- **Битрикс24** (`b24`): репозиторий `WireCatLabs/bitrix24-cli`, навык `bitrix24-cli`
- **Asterisk** (`asterisk`): репозиторий `WireCatLabs/asterisk-cli`, навык `asterisk-cli`
- **Zoom** (`zm`): репозиторий `WireCatLabs/zoom-cli`, навык `zoom-cli`
- **Memo** (`memo`): репозиторий `WireCatLabs/cli-memo`, навык `cli-memo`

### Из самого инструмента

Эта копия соответствует установленной у вас версии инструмента. Она подходит для Codex, Claude Code,
Cursor, Gemini CLI и OpenClaw:

```sh
tg skill install
```

Повторите команду после обновления инструмента.

### Hermes Agent

Этот сайт публикует навык каждого инструмента — в той версии, которую описывают эти страницы, — в
каталоге навыков, который читает Hermes. Установите один навык:

```sh
hermes skills install well-known:https://wirecat.dev/.well-known/skills/tg-cli
```

Перед установкой Hermes проверяет каждый навык. Если он остановился на предупреждении (caution),
не ставьте навык силой: [сообщите нам](https://github.com/WireCatLabs/cli-docs/issues) показанную находку.
`hermes skills search https://wirecat.dev --source well-known` покажет все навыки. Hermes запоминает
источник, поэтому позже `hermes skills update` обновит навык. Клиенты нового формата каталога читают те же навыки
по адресу `https://wirecat.dev/.well-known/agent-skills/index.json`.

Можно также добавить репозиторий инструмента как постоянный источник навыков (tap):

```sh
hermes skills tap add WireCatLabs/tg-cli
```

Источник-репозиторий читает основную ветку (main), которая может опережать выпущенную версию
инструмента.
[Инструкция Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/#skills-hub).

### OpenClaw и ClawHub

ClawHub — каталог навыков OpenClaw. Навыки WireCat опубликованы там от издателя `wirecat`:
`wirecat-tg`, `wirecat-max`, `wirecat-whatsapp`, `wirecat-zoom`,
`wirecat-memo` и `wirecat-drive`. Одна команда ставит навык для всех рабочих пространств:

```sh
openclaw skills install @wirecat/wirecat-tg --global
```

Без ClawHub навык для OpenClaw ставит `tg skill install --for agents`: OpenClaw читает `~/.agents/skills`.
[Инструкция OpenClaw](https://docs.openclaw.ai/tools/skills).

### skills.sh

Команда `skills` от skills.sh ставит навык из репозитория в папки агентов, которых находит на вашем
компьютере:

```sh
npx skills add WireCatLabs/tg-cli --skill tg-cli
```

Не убирайте `--skill`: в некоторых репозиториях есть и навыки для тех, кто разрабатывает сам
инструмент. Как и источник-репозиторий Hermes, команда читает основную ветку. [skills.sh](https://skills.sh/).

### Маркетплейс плагинов Claude Code

**Скоро.** Маркетплейс WireCat для Claude Code: по плагину на инструмент, и в каждом только его
навык. Когда он будет опубликован, добавьте его в Claude Code командой:

```text
/plugin marketplace add WireCatLabs/claude-plugins
```

А пока навык для Claude Code ставит `tg skill install --for claude`.
[Инструкция по плагинам Claude Code](https://code.claude.com/docs/en/plugins).

### Проверьте результат

Начните новую сессию с агентом и выполните проверку из раздела
[Проверьте, всё ли готово](#check-connection). Если навык у агента есть, но инструмент не
запускается, смотрите подсказки для [Hermes](#hermes) и [OpenClaw](#openclaw).

## Для чат-приложений и удалённых агентов

Всё, что описано выше, напрямую запускает инструмент командной строки. Для агента на том же
компьютере это быстрее, и если что-то выглядит не так, вы можете сами выполнить ту же команду.
**MCP** — необязательный способ подключения для приложений, которые не умеют запускать программы:

- **ChatGPT, Claude или другой чат в браузере или в приложении на телефоне:** откройте
  [инструкцию подключения из браузера и мобильного приложения](./browser-apps.mdx).
- **Приложение для компьютера с настройками MCP, например Claude Desktop:** откройте [настройку MCP](#cursor-и-claude-desktop).
- **Агент на другом компьютере:** установите инструмент и войдите в аккаунт там, как описано в
  разделе [Другой агент](#other-agents). Если он может обратиться к вашему компьютеру только через соединение, откройте [настройку MCP](#mcp-и-навыки).

Вход не является инструментом MCP: агент, у которого есть только MCP, попросит вас выполнить команду входа самостоятельно.

## MCP и навыки

### Что такое MCP

**MCP (Model Context Protocol)** — открытый стандарт подключения ИИ-агентов к инструментам. Он
похож на универсальный разъём: приложение, которое поддерживает MCP, может пользоваться совместимым
MCP-сервером без отдельной интеграции. Стандарт опубликован на [modelcontextprotocol.io](https://modelcontextprotocol.io/).

В подключении две стороны:

- **Клиент** — приложение, в котором работает ваш агент, например Claude Desktop, ChatGPT, Cursor или Gemini CLI. Он
  спрашивает у сервера, какие есть инструменты, и вызывает нужный, когда этого требует запрос.
- **Сервер** — `tg <профиль> mcp serve` или `max <профиль> mcp serve`, часть инструмента командной строки. Он работает на вашем
  компьютере или на сервере, к которому чат в браузере обращается по публичному HTTPS-адресу.

Через MCP ИИ может пользоваться только инструментами, которые предлагает сервер, и только в пределах
[прав](./configuration.mdx#права) профиля: профиль только для чтения не может отправлять сообщения.
Подключение MCP не входит в мессенджер за вас: вход выполняется один раз через инструмент командной
строки. Весь архив оно тоже не скачивает.

Агенту с терминалом, например Claude Code или Codex, MCP не нужен: он может запускать команды `tg` и
`max` напрямую, а **навык** объясняет ему, как это делать. Агент без терминала, например
Claude Desktop или чат в браузере, подключается через MCP. Выбрать поможет
[сравнение ниже](#cli-skill-или-mcp).

<Callout type="info" title="Пользуетесь AI-чатом в браузере или на телефоне?">

ChatGPT, Claude и другие веб-чаты подключаются через публичный HTTPS-адрес: следуйте [инструкции для браузера и мобильного приложения](./browser-apps.mdx).

</Callout>

### Что делает MCP-сервер

Наш MCP-сервер даёт агенту доступ к подключённому мессенджеру: чатам, сообщениям, вложенным файлам, поиску и отчётам. Вы просите результат, агент вызывает инструмент сервера, а сервер выполняет действие через программу для мессенджера.

Сервер входит в инструмент командной строки и **должен работать, пока агент им пользуется**. Локальное приложение может запускать его на вашем компьютере. Для чата в браузере или на телефоне сервер работает на компьютере или отдельном сервере, а приложение подключается через публичный HTTPS-адрес с проверкой доступа. Шаги такого подключения — в [инструкции для браузера и мобильного приложения](./browser-apps.mdx).

### Как агент находит и выполняет действия

Сервер предоставляет несколько инструментов: агент сначала находит нужное действие и узнаёт его параметры, затем выполняет его. Например, чтобы найти договорённость, он находит команду поиска сообщений, запускает её и открывает найденные сообщения.

В примерах ниже используются имена Telegram. Для MAX замените `tg` на `max`, в том числе в именах инструментов и настройках.

| Инструмент | Что делает |
|---|---|
| `tg_tools_search` | Находит команду для задачи и сообщает агенту её параметры и последствия. Это поиск доступных действий, а не поиск по переписке. |
| `tg_read` | Выполняет найденное действие чтения: показывает чаты, ищет сообщения, читает файлы или строит отчёт. |
| `tg_write` | Выполняет изменение: отправляет сообщение, сохраняет текст вложения или управляет группой в пределах прав профиля. |

### Что делает навык

**Навык (skill)** — файл с инструкцией для агента: какие инструменты выбирать, как собирать контекст, проверять источники и готовить результат. MCP даёт доступ к действиям, а навык объясняет, как использовать их для задачи. В навыке нет данных входа в аккаунт.

Инструкция поставляется вместе с инструментом. [Добавьте её](#connect-instructions) командой настройки; `tg skill show` выводит её текст. Агент с терминалом может читать инструкцию и выполнять CLI-команды напрямую.

### CLI, skill или MCP?

| Способ | Что даёт | Когда выбрать |
|---|---|---|
| CLI | Команды в терминале с JSON-ответами | У агента уже есть локальный терминал |
| Skill + CLI | Инструкцию по командам и сценариям | Ваш агент умеет выполнять команды в терминале, например Codex, Cursor Agent, Claude Code, Gemini CLI, Hermes или OpenClaw |
| MCP | Инструменты и их параметры прямо в клиенте | У вашего агента нет терминала, например Claude Desktop, или вы предпочитаете интерфейс инструментов |
| MCP по HTTP | Те же инструменты для AI-чата в браузере, например ChatGPT или Claude, через публичный HTTPS-адрес | Общаетесь в браузере — [ChatGPT и Claude в браузере](./browser-apps.mdx) |
| Markdown-доки | Понятное описание и справку по командам | Агенту нужно узнать, как что-то работает |

Для агента с терминалом начните со [skill](#connect-instructions). MCP необязателен и использует те же
права профиля, что CLI. Вход и скачивание архива выполняются отдельно.

### Перед подключением

[Установите CLI и войдите](./installation.mdx). Выполните `tg personal mcp config` или
`max personal mcp config`: команда напечатает настройки с настоящими путями Node и CLI на вашей машине.
Она показывает конфигурацию, а не редактирует клиент. PATH у приложения с рабочего стола
может отличаться от PATH терминала.

Сервер работает с профилем, который вы назвали: `tg personal mcp serve`. Один сервер может работать с несколькими
профилями: `tg mcp serve --profiles personal,work`, или со всеми: `--profiles all`; тогда каждый вызов инструмента
называет свой профиль. В max так же. Без профиля или `--profiles` ни tg, ни max не запускают сервер. `tg mcp` или
`max mcp` без продолжения только показывает справку.

#### Codex

В терминале, где установленная команда уже работает:

```sh
tg personal mcp add codex
codex mcp list
```

Setup использует собственную команду Codex и не трогает другие серверы. Вручную то же делает `codex mcp add tg -- tg personal mcp serve`.

Подключите только нужные мессенджеры. Codex хранит MCP в `~/.codex/config.toml`.
Для Windows или IDE с другим PATH возьмите `command`, `args` и `env` из `mcp config`
и добавьте в `[mcp_servers.tg]` или `[mcp_servers.max]`: Codex использует TOML.
[Официальная инструкция Codex MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).

#### Claude Code

```sh
tg personal mcp add claude-code
claude mcp list
```

Вручную то же делает `claude mcp add --scope user tg -- tg personal mcp serve`. Если профиль даёт инструменты записи, setup просит сначала проверить его [разрешения](./configuration.mdx#права) и повторить с `--allow-writes`. Флаг только подтверждает установку; разрешения он не меняет.

В сессии проверьте состояние через `/mcp`. Для полных путей используйте значения из `mcp config`.
[Официальная инструкция Claude Code MCP](https://code.claude.com/docs/en/mcp).

#### Cursor и Claude Desktop

Скопируйте запись сервера из `tg personal mcp config` или `max personal mcp config` в `mcpServers` клиента,
сохранив полные пути и переменные окружения. Добавьте запись к существующим серверам.

| Клиент | Файл настроек |
|---|---|
| Cursor, личные | `~/.cursor/mcp.json` |
| Cursor, проект | `.cursor/mcp.json` |
| Claude Desktop, macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Claude Desktop, Windows | `%APPDATA%\Claude\claude_desktop_config.json` |

Перезапустите клиент и проверьте наличие инструментов сервера.
[Официальная инструкция Cursor MCP](https://cursor.com/help/customization/mcp).

#### Gemini CLI

```sh
gemini mcp add --scope user tg tg personal mcp serve
gemini mcp list
```

Для полных путей и окружения добавьте сгенерированную запись в `mcpServers` файла
`~/.gemini/settings.json`. [Официальная инструкция Gemini MCP](https://geminicli.com/docs/tools/mcp-server/).

#### Hermes

Hermes использует `mcp_servers` в `~/.hermes/config.yaml`. Добавьте туда `tg` или `max`
со значениями `command`, `args` и `env` из сгенерированной конфигурации. Сохраните существующие
настройки. Hermes использует YAML, поэтому весь объект JSON `mcpServers` туда не вставляется.
Перезапустите Hermes. [Официальный старт Hermes](https://hermes-agent.nousresearch.com/docs/getting-started/quickstart/).

<a id="что-агенту-разрешено" />

### Zoom, Google Drive и Memo

Каждый инструмент запускает свой сервер. Подключите его командой, которой ваш клиент добавляет MCP-серверы:

- **Zoom:** `zm personal mcp serve`.
- **Google Drive:** `drive personal --read-only mcp serve`.
- **Google Calendar:** `gcal personal mcp serve`.
- **Mail:** `mail personal mcp serve`.
- **Битрикс24:** `b24 personal mcp serve`.
- **Asterisk:** `asterisk office mcp serve`.
- **Memo:** `memo mcp serve`.

### Что агент может делать

Через MCP доступны большинство повседневных операций CLI: чтение и поиск переписки, сведения о людях и группах, работа с вложениями сообщений, отчёты, отправка ответов и управление группами при наличии прав.

Полный синтаксис команд и особенности доступа через MCP описаны в справочниках мессенджеров:

- [Инструменты и покрытие Telegram MCP](./tg/mcp.md#tools) · [Все команды Telegram](./tg/commands.md).
- [Инструменты и покрытие MAX MCP](./max/mcp.md#инструменты) · [Все команды MAX](./max/commands.md).

Доступный набор действий определяется мессенджером и правами профиля. Попросите агента найти действие через инструмент поиска: результат содержит поддерживаемую команду и её параметры. Профиль только для чтения исключает изменения. У сервера нет своего шага подтверждения: подтверждения показывает приложение, и сервер не может проверить, что их принял человек.

После подключения попросите показать пять последних чатов. Затем переходите к [первым задачам](./first-tasks.mdx).

### Документация для агента

MCP мессенджера обращается к вашему аккаунту. Документация доступна отдельно:

| Ресурс | Что дать агенту |
|---|---|
| [Список страниц](/llms.txt) | `https://wirecat.dev/llms.txt` — найти нужную страницу и открыть её Markdown |
| [Все страницы](/llms-full.txt) | `https://wirecat.dev/llms-full.txt` — вся справка для инструментов, поддерживающих большой документ |
| Одна страница | **Копировать Markdown** или **Открыть** вверху страницы доков |
| Сам инструмент | Агенту, который запускает инструмент: `tg guide` перечисляет пошаговые сценарии, `tg commands` — все команды по разделам |

Запрос: **«Прочитай https://wirecat.dev/llms.txt, найди документацию входящих Telegram и
используй её, чтобы разобрать мои непрочитанные сообщения».** Если агент не открывает URL,
скопируйте Markdown нужной страницы в чат.

Эти Markdown-страницы можно читать напрямую. Передайте агенту список страниц или нужный документ; дополнительный сервер документации не нужен.

Если подключение не работает, проверьте полные пути, версию Node, профиль и одинаковые каталоги
настроек в клиенте и терминале. Подробности окружения есть в справке MCP
[Telegram](./tg/mcp.md) и [MAX](./max/mcp.md).


## В браузере или на телефоне

ChatGPT, Claude, Gemini и другие AI-чаты в браузере или на телефоне не запускают программы на вашем компьютере. Они подключаются к инструменту через MCP и публичный HTTPS-адрес. Инструкция [В браузере или на телефоне](./browser-apps.mdx) описывает адрес, добавление подключения в чат, права, восстановление и постоянно работающий сервер.
