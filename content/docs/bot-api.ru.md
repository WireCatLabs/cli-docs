У бота своё имя, аккаунт и чаты. Он может публиковать отчёты, отвечать на запросы и помогать
управлять группой. Команды без `bot` работают от вашего личного аккаунта.

## Подключить бота

Создайте бота Telegram через [BotFather](https://t.me/BotFather) или следуйте
[инструкции MAX](https://business.max.ru/self). Сохраните его токен в скрытом вводе:

```sh
tg support bot auth set
max support bot auth set
```

`support` — имя профиля, которое вы выбираете. Подключайте только нужный мессенджер.
Не вставляйте токен в команду, снимок экрана или чат. Проверьте подключённого бота:

```sh
tg support bot me
max support bot me
```

## Выбрать чат

Добавьте бота в группу или канал либо начните с ним диалог из личного аккаунта. Бот получает
только разрешённые мессенджером чаты и сообщения, а не вашу личную историю переписок.
В Telegram человек должен сначала начать разговор с ботом.

Номер чата берётся из полученных обновлений или явно просмотренного чата.
Как его найти — в руководствах ботов [Telegram](./tg/bot.md) и [MAX](./max/bot.md).
Когда название сохранено, используйте его в следующих командах.

## Отправить ответ или отчёт

```sh
tg support bot messages send "Команда" "Отчёт готов"
max support bot messages send "Команда" "Отчёт готов"
```

Замените чат и текст теми, которым хотите отправить. Это настоящее сообщение от бота.
Можно также отправлять файлы, отвечать на сообщения и управлять чатами при необходимых правах.
Не выдавайте права администратора для действий, которым они не нужны.

## Автоматизация

Ассистент может готовить черновики, отчёты и использовать бота в рабочем процессе.
Выдайте нужные [права](./permissions.md) и определите разрешённых получателей.
Для важных сообщений просите проверку текста перед отправкой. Вебхуки и чтение обновлений
связывают бота с другими приложениями: изменение может прервать существующую интеграцию.

MCP даёт инструменты для обычных задач бота. Ассистент с терминалом может использовать CLI.
[Подключение ассистента](./mcp.md) объясняет выбор.

## Нужного действия нет среди обычных команд?

Нативный Bot API открывает методы, определённые мессенджером. Начните со справки:

```sh
tg support bot api --help
max support bot api --help
tg support bot api get-me --json
max support bot api get-my-info --json
```

Выберите метод и посмотрите его `--help`: поля и примеры. Telegram и MAX используют разные
имена и параметры. JSON-вход и форматы ответов нужны для интеграций; подробности — в руководстве бота.

[Официальный API Telegram](https://core.telegram.org/bots/api) · [MAX](https://dev.max.ru/docs-api)
