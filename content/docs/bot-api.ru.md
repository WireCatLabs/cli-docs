**Все методы Bot API доступны через CLI.** Полный нативный интерфейс дополняет удобные команды
для сообщений, файлов и управления чатами. Telegram покрывает все 185 методов закреплённой
схемы Bot API 10.3, MAX — все 33 операции своей официальной схемы.

Нужны Telegram CLI **0.25.0 или новее** и MAX CLI **0.25.0 или новее**. См. [установку](./installation.mdx).

## Найдите любой метод

```sh
tg sales bot api --help
max sales bot api --help
tg sales bot api get-me --json
max sales bot api get-my-info --json
```

Первое слово — профиль вашего бота. Справка `--help` каждого метода перечисляет его нативные
поля. Имена методов и параметры следуют API провайдера, поэтому в Telegram и MAX они могут отличаться.

## Нативные запросы и ответы

Параметры передаются флагами или JSON через `--body`, `--body-file` либо stdin. Нативный
`timeout` называется `--poll-timeout`, а `--timeout` ограничивает всю команду. Ответ сохраняет
структуру провайдера; целые числа вне безопасного диапазона JavaScript выводятся строками.

Некоторым методам нужны определённые права бота или возможности платформы. Записи используют
ограничения профиля, проверку получателей и журнал. Учётные данные передавайте через stdin или
защищённый JSON-файл, а не аргументы. Методы, возвращающие токен, требуют `--store-token <profile>`:
токен сохраняется только в системном хранилище ключей, stdout содержит квитанцию.

## CLI и MCP

Полный нативный API — это **интерфейс CLI**. MCP предоставляет отдельные инструменты для
типичных задач, а не инструмент на каждый метод API. Агент с доступом к терминалу может
использовать `tg bot api` и `max bot api` для остальных операций.

Подробности: [боты Telegram](https://github.com/leemour/tg-cli/blob/v0.25.0/docs/bot.md),
[боты MAX](https://github.com/leemour/max-cli/blob/v0.25.0/docs/bot.md),
[Telegram Bot API](https://core.telegram.org/bots/api), [MAX Bot API](https://dev.max.ru/docs-api).
