Эта инструкция объясняет, как WireCat добавляет почту в контекст агента: подключите ящик через
[инструмент mail](./mail/index.md), а затем находите его письма в Memo рядом с заметками и перепиской.
Она пригодится, когда нужно найти решение в почте или подготовиться к разговору.

После чтения вы сможете:

- подключить ящик и прочитать нужный период в общее хранилище;
- связать почтовый адрес со знакомым человеком;
- искать и помечать письма с указанием источников и проверять охват синхронизации;
- замечать отправителей, похожих на спам или мошенников.

Mail — собственный почтовый инструмент WireCat. Он копирует ваш ящик в общее хранилище WireCat. Memo — инструмент
на вашем компьютере, который ищет в этом хранилище, так что агент может использовать почту вместе с заметками
и скачанной историей мессенджеров. Memo не меняет ваш ящик.

## Перед началом

[Установите Mail](./mail/installation.md) и подготовьте ящик: включите IMAP и создайте пароль приложения
(отдельный пароль для одной программы, который можно отозвать). [Шаги подготовки ящика](./mail/providers.md)
описаны для каждого провайдера. Чтобы искать почту, [установите Memo по инструкции о заметках](./memo/installation.md).
Импортировать папку заметок не нужно. Используйте <DocTerm term="local-agent" lang="ru" label="локального ИИ-агента" />
на том же компьютере. История мессенджеров необязательна, но её нужно заранее скачать, если она нужна в том же ответе.

## Добавьте почту

Выберите имя профиля для ящика (здесь `ya`), затем войдите и прочитайте почту. Попросите агента помочь:

```text prompt
Помоги подключить выбранный мной почтовый аккаунт через инструмент mail.
Объясни шаги для провайдера, затем прочитай письма с выбранной мной даты.
Покажи результат синхронизации и скажи, нужен ли ещё один запуск, чтобы закончить этот период.
```

Для настройки вручную:

```sh
mail ya session start --address you@example.com
mail ya sync --since-time 2026-09-01
mail ya status
```

`session start` находит сервер, проверяет пароль приложения и сохраняет его в системной связке ключей. `sync` читает
новую почту в общее хранилище и пропускает уже сохранённую. Большой ящик не помещается в один запуск: если `sync`
отвечает `state: partial`, запустите его снова, а `mail ya status` покажет, как далеко он ушёл. Чтобы ящик оставался
актуальным, поставьте синхронизацию на таймер: `mail ya schedule command mail-ya --every 5m -- sync`. Папки, ограничения
и остальные команды описаны в разделе [повседневная работа с mail](./mail/usage.md).

Для этой почты Memo ничего настраивать не нужно. Он читает то же хранилище, поэтому `memo search mail` находит письма
сразу. Результаты поиска указывают ящик по адресу, например `you@example.com`. Адреса, которые вы затем связываете с
людьми, принадлежат отправителям и получателям: входить в их аккаунты не требуется.

Текст читаемого вложения хранится вместе с письмом и находится вместе с ним. Memo также готовит новые письма к поиску
по смыслу, поэтому их находят `tg personal search conversations` и `max personal search conversations`.

Memo всё ещё умеет импортировать почту через Himalaya — отдельную почтовую программу. Этот старый импорт оставлен для
существующих настроек и будет удалён; для новых аккаунтов используйте `mail`, а [старый импорт](./memo/mail.md)
читайте, только если уже на него полагаетесь.

## Свяжите почту с тем же человеком

<a id="link-email-to-the-same-person" />

Почтовый адрес и аккаунт Telegram или MAX остаются отдельными, пока вы явно не свяжете их.
Связь записывает, что это один **человек** в локальном хранилище; она не выполняет вход в
другой аккаунт и не объединяет ваши почтовые ящики. Сначала импортируйте почту и сохраните учётную запись человека в мессенджере, прочитав его профиль или сообщения. Добавлять его в адресную книгу не требуется. Замените имя пользователя и адрес своими:

```sh
tg personal contacts link @example_user email:rin@example.test
memo context telegram:"Rin Example" --json
```

Для MAX используйте `max personal contacts link` с ID или именем человека в MAX. Проверьте возвращённые
учётные записи и источники. Похожее имя не доказывает, что это один человек. Если сохранено
несколько аккаунтов нужного провайдера, используйте
`memo context telegram:"Rin Example" --source telegram:1 --json` со своим ID аккаунта.
См. [связь и разделение аккаунтов людей](./people.md#link-your-accounts).

## Ищите в почте

```text prompt
Используй Memo, чтобы найти договорённость о бюджете в выбранном мной почтовом аккаунте.
Покажи найденные письма, авторов и ссылки на источники. Объясни период импорта и какие данные отсутствуют.
```

Для поиска в импортированной почте:

```sh
memo search mail 'budget' --json
memo search mail 'quote subject:budget mailbox:important' --json
```

`search mail` ищет в импортированной почте. Кроме слов, он принимает `from:`, `to:`, `cc:` и `bcc:`
для человека, `subject:` для слов только из темы и `mailbox:` для папки или ярлыка Gmail. Результаты могут относиться к нескольким ящикам:
проверьте источники и попросите агента оставить результаты с выбранного вами адреса.
`search all` также ищет сообщения и заметки; `skipped` показывает, где поиск не прошёл.
Отсутствие результатов за пределами периода импорта не доказывает, что писем там нет.

## Замечайте спам и поддельных отправителей

Gmail отсеивает большую часть спама, но часть мошеннических и автоматических писем всё равно приходит. Memo
даёт каждому отправителю оценку по признакам в его письмах, чтобы агент мог указать на того, кто только
выдаёт себя за известный бренд.

```text prompt
С помощью Memo проверь, какие отправители в выбранном мной почтовом аккаунте похожи на мошенников.
Покажи каждого подозрительного отправителя с оценкой, признаками и одним письмом для примера.
Не включай отправителей, у которых оценка только из-за того, что я не открываю их рассылки.
```

Каждая синхронизация также оценивает
отправителей сохранённой почты, не чаще раза в сутки, а результат поиска в `--json` содержит `sender_score`
своего отправителя. Письма отправителя
с признаками мошенничества — например, с названием бренда с чужого домена или с доменом, зарегистрированным
меньше полугода назад, — идут после остальных результатов; домен, на который вы писали, не сдвигается никогда,
а `--plain-order` сохраняет обычный порядок. Оценка за письма, которые вы не открываете, означает лишь рассылку. Подробнее —
[что означает каждый признак](./memo/mail.md#choose-what-to-import).

## Помечайте письма и сохраняйте заметки о них

Тег помечает источник, а заметка сохраняет ваши сведения о нём. И то и другое хранится
локально. Замените полную ссылку на письмо и ID переписки и аккаунта значениями из результатов:

```sh
memo tags add follow-up --message 'msg:email/you%40example.com/12345/67890'
memo tags add work --chat 12345 --account email:you@example.com
memo tags list --source email:you@example.com --json
```

Полная ссылка на письмо содержит ящик, переписку и ID сообщения. Для метки переписки
`--account email:<адрес>` указывает, к какому ящику она относится. Эти метки не меняют
ярлыки Gmail и флаги почты. Чтобы сохранить оценку, связанную с одним письмом:

```sh
memo notes add 'Waiting for a revised quote' --subject 'msg:email/you%40example.com/12345/67890' --json
```

Полный порядок действий описан в разделах [создание, изменение и экспорт заметок](./memo/notes.md#write-your-own-notes)
и [теги для заметок, людей и сообщений](./memo/tags.md).

## Проверьте результат

Проверьте выбранный ящик, период синхронизации и нужен ли ещё один запуск. В контексте должен быть
указан связанный почтовый адрес и ссылки на нужные письма. Если их нет, проверьте связь
адреса, импорт нужного периода и выбор аккаунта. Пустой результат после частичного импорта
не доказывает, что договорённостей не было.

## Если письма не найдены

- **Нет почтового аккаунта:** выполните `mail session list` и проверьте имя профиля в команде.
- **Прочитана только часть периода:** запустите `mail <profile> sync` ещё раз; `--limit` ограничивает новые письма за запуск.
- **В результатах другой ящик:** проверьте источники и оставьте нужный адрес.
- **Письма отсутствуют в контексте человека:** проверьте точный адрес, связь и импортированную историю.

Перейдите к [заметкам и меткам источников](./memo/notes.md#write-your-own-notes), чтобы сохранить
свой контекст о найденной почте.
