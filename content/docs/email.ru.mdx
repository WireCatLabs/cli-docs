Эта инструкция объясняет, как WireCat добавляет почту в контекст агента: подключить ящик,
импортировать нужный период и находить письма вместе со сведениями о знакомых людях.
Она пригодится, когда нужно найти решение в почте или подготовиться к разговору.

После чтения вы сможете:

- подключить выбранные ящики и импортировать нужный период;
- связать почтовый адрес со знакомым человеком;
- искать и помечать письма с указанием источников и проверять охват импорта.

Для этих задач WireCat использует Memo. Memo — инструмент на вашем компьютере, который
сохраняет почту в локальном хранилище для поиска. Агент может использовать её вместе с заметками
и скачанной историей мессенджеров.

## Перед началом

[Установите Memo по инструкции о заметках](./memo.mdx#install-memo). Для почты не нужно
импортировать папку заметок. Используйте <DocTerm term="local-agent" lang="ru" label="локального ИИ-агента" />
на том же компьютере. Memo читает письма через Himalaya: настройте там ящик перед импортом.
История мессенджеров необязательна, но её нужно заранее скачать, если она нужна в том же ответе.

## Добавьте почту

Memo читает почту через [Himalaya](https://github.com/pimalaya/himalaya) — отдельную почтовую
программу. Аккаунт настраивается в ней; Memo использует его имя и адрес, и ему не нужна
отдельная копия пароля от почты. Попросите агента помочь:

```text prompt
Помоги подключить выбранный мной почтовый аккаунт через Himalaya и добавить его в Memo.
Объясни настройку аккаунта, затем импортируй письма с выбранной мной даты.
Покажи результат импорта и скажи, нужен ли ещё один запуск, чтобы закончить этот период.
```

Перед импортом в Memo аккаунт должен работать в Himalaya. Для настройки вручную:

Добавьте `mail.accounts` в конфигурацию Memo, сохранив остальные настройки. Пути к файлу по умолчанию:

| OS | Файл конфигурации |
| --- | --- |
| Linux | `~/.config/cli-memo/config.json` |
| macOS | `~/Library/Preferences/cli-memo/config.json` |
| Windows | `%APPDATA%\cli-memo\Config\config.json` |

`MEMO_CONFIG_DIR` переопределяет папку; в Linux на путь по умолчанию также влияет `XDG_CONFIG_HOME`.
В примере аккаунт Himalaya называется `gmail`; замените имя и адрес своими.

```json
{
  "mail": {
    "accounts": [{ "name": "gmail", "address": "you@example.com" }]
  }
}
```

`name` — имя аккаунта в Himalaya, а `address` — адрес вашего ящика в хранилище Memo.
Для нескольких ящиков добавьте по записи в `mail.accounts` для каждого аккаунта.
При импорте `--account` выбирает имя Himalaya, например `gmail`. Результаты поиска указывают ящик
по адресу, например `you@example.com`. Адреса, которые вы затем связываете с
людьми, принадлежат отправителям и получателям: входить в их аккаунты не требуется.

По умолчанию используется Gmail и импортируется All Mail. Для другого IMAP-провайдера
добавьте в запись аккаунта `"mode": "imap"` и `"folders": ["INBOX", "Archive"]`, указав
настоящие имена папок своего почтового ящика.

```sh
memo mail import --account gmail --since 2026-09-01 --json
```

Выберите начальную дату. По умолчанию за один запуск читается не более 200 новых писем.
Если результат сообщает о неполном импорте, повторите команду. Почтовый ящик используется
только для чтения: импорт не отправляет письма и не отмечает их прочитанными.
Импортированная почта хранится локально; повторный импорт может удалить из хранилища
текст писем, исчезнувших из источника.

## Свяжите почту с тем же человеком

<a id="link-email-to-the-same-person" />

Почтовый адрес и аккаунт Telegram или MAX остаются отдельными, пока вы явно не свяжете их.
Связь записывает, что это один **человек** в локальном хранилище; она не выполняет вход в
другой аккаунт и не объединяет ваши почтовые ящики. Сначала импортируйте почту и сохраните учётную запись человека в мессенджере, прочитав его профиль или сообщения. Добавлять его в адресную книгу не требуется. Замените имя пользователя и адрес своими:

```sh
tg contacts link @example_user email:rin@example.test
memo context telegram:"Rin Example" --json
```

Для MAX используйте `max contacts link` с ID или именем человека в MAX. Проверьте возвращённые
учётные записи и источники. Похожее имя не доказывает, что это один человек. Если сохранено
несколько аккаунтов нужного провайдера, используйте
`memo context telegram:"Rin Example" --account 1 --json` со своим ID аккаунта.
См. [связь и разделение аккаунтов людей](./people.md#link-your-accounts).

## Ищите в почте

```text prompt
Используй Memo, чтобы найти договорённость о бюджете в выбранном мной почтовом аккаунте.
Покажи найденные письма, авторов и ссылки на источники. Объясни период импорта и какие данные отсутствуют.
```

Для поиска в импортированной почте:

```sh
memo search mail 'budget' --json
```

`search mail` ищет в импортированной почте. Результаты могут относиться к нескольким ящикам:
проверьте источники и попросите агента оставить результаты с выбранного вами адреса.
`search all` также ищет сообщения и заметки; `skipped` показывает, где поиск не прошёл.
Отсутствие результатов за пределами периода импорта не доказывает, что писем там нет.

## Помечайте письма и сохраняйте заметки о них

Тег помечает источник, а заметка сохраняет ваши сведения о нём. И то и другое хранится
локально. Замените полную ссылку на письмо и ID переписки и аккаунта значениями из результатов:

```sh
memo tags add follow-up --message 'msg:email/you%40example.com/12345/67890'
memo tags add work --chat 12345 --provider email --account you@example.com
memo tags list --provider email --account you@example.com --json
```

Полная ссылка на письмо содержит ящик, переписку и ID сообщения. Для метки переписки
`--provider` и `--account` вместе указывают, к какому ящику она относится. Эти метки не меняют
ярлыки Gmail и флаги почты. Чтобы сохранить оценку, связанную с одним письмом:

```sh
memo notes add 'Waiting for a revised quote' --about 'msg:email/you%40example.com/12345/67890' --json
```

Полный порядок действий описан в разделах [создание, изменение и экспорт заметок](./memo.mdx#create-your-own-notes)
и [теги для заметок, людей и сообщений](./memo.mdx#tag-your-sources).

## Проверьте результат

Проверьте выбранный ящик, период импорта и нужен ли ещё один запуск. В контексте должен быть
указан связанный почтовый адрес и ссылки на нужные письма. Если их нет, проверьте связь
адреса, импорт нужного периода и выбор аккаунта. Пустой результат после частичного импорта
не доказывает, что договорённостей не было.

## Если письма не найдены

- **Нет почтового аккаунта:** проверьте имя аккаунта Himalaya и запись в `mail.accounts`.
- **Импортирована только часть периода:** повторите импорт; `--max` ограничивает новые письма за запуск.
- **В результатах другой ящик:** проверьте источники и оставьте нужный адрес.
- **Письма отсутствуют в контексте человека:** проверьте точный адрес, связь и импортированную историю.

Перейдите к [заметкам и меткам источников](./memo.mdx#create-your-own-notes), чтобы сохранить
свой контекст о найденной почте.
