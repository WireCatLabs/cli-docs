The Telegram and MAX tools install through npm and work on **Windows, macOS and Linux**.
Ask a <DocTerm term="local-agent" label="local agent" /> to help with installation and login, or run the terminal commands yourself.

## 1. Choose your messenger

Expand **Telegram** or **MAX** and copy the prompt to your agent.

<InstallationGuide />

## 2. Log in on your computer

Open the guide for your messenger. Keep your phone nearby: you authorize account access while your agent helps you through the steps.

- **[Log in to Telegram](./tg/sessions.md)** — the cli first obtains <DocTerm term="telegram-app" label="Telegram application credentials" />; you then approve login with a QR code or a code from Telegram. The guide explains both steps, [my.telegram.org](https://my.telegram.org/apps) and scanning the QR.
- **[Log in to MAX](./max/sessions.md)** — scan the QR code in the MAX app on your phone and approve the connection. Bots use a separate [token-based connection](./max/bot.md).

Allow about five minutes for setup. Enter codes and passwords in your local terminal when the cli asks. Downloading chat history is a separate step after login.

## 3. Connect your agent and try a first task

An <DocTerm term="skill" label="agent skill" /> teaches your agent to use the cli. See [Connect your agent](./agents.md) to check its installation and connect your agent. For Claude Desktop, use [MCP](./mcp.md).

Try this request:

```text prompt
Review unread messages by chat and tell me who needs a reply.
```

[First tasks](./first-tasks.md) covers finding agreements, preparing for a call and drafting a reply.

## Install in a terminal

You need <DocTerm term="nodejs" label="Node.js" /> **22.16+ (22.x) or 24+** with <DocTerm term="npm" label="npm" />. Your agent will check these programs before installation.

### Node.js

If a suitable version is missing, copy this prompt to your agent. It will choose an installation method for your computer and check the result.

<NodeSetupPrompt />

### Telegram

```sh
npm install -g @leemour/tg-cli
tg setup
```

### MAX commands

```sh
npm install -g @leemour/max-cli
max setup
```

`setup` guides login and offers to connect a skill for your agent.
After setup, run `tg doctor` or `max doctor` and follow the suggested steps.

### Windows

Command launch problems, updates and file locations are covered in each cli's reference: [Telegram installation](./tg/installation.md) and [MAX installation](./max/installation.md). These include Windows-specific help if the command does not launch after installation.
