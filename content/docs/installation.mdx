Connect your Telegram or MAX to an AI agent so it can find messages, gather context and help with replies. This page takes you through installing the command-line tool, logging into your account and checking the chat list.

Login authorises the tool to use your account as a separate device. You confirm it on your phone; history for finding older messages can be downloaded later.

You need:

- a computer with Windows, macOS or Linux;
- your phone, with Telegram or MAX open on the account you want to connect.

Pick your system and messenger on the tabs below. The page remembers your choice.

### Log in with your phone

Logging in adds your computer as a new device on your account, the same way Telegram Desktop or
MAX on the web does. Your phone approves it. The CLI asks its questions in a terminal window, so
even when your agent leads the setup, it usually asks you to run this command and answer the
questions yourself.

<Tabs groupId="messenger" persist items={["Telegram", "MAX"]}>
<Tab value="Telegram">

```sh
tg setup
```

The terminal asks you, in this order:

1. **Phone number** — in international format, for example `+34600111222`.
2. **Code from Telegram for my.telegram.org** — Telegram sends it as a message in the Telegram
   app (from the chat called *Telegram*), not by SMS. Type it in the terminal. The CLI uses it to
   register itself with Telegram for you; this happens only on the first login.

   <Screenshot src="/screenshots/telegram/code-message.jpg" alt="the Telegram app showing the message with the my.telegram.org login code" width={360} />

3. **QR code** — the terminal shows a QR code. On your phone, open
   **Settings → Devices → Add Device** (in older apps: *Link Desktop Device*) and scan it with that scanner (not the camera app).

   <Screenshot alt="the terminal showing the Telegram login QR code" />
   <Screenshot src="/screenshots/telegram/add-device.jpg" alt="Telegram on the phone: Settings → Devices, with the Add Device button" width={360} />

4. **Two-step verification password** — only if you set one in Telegram. The characters stay
   hidden while you type.
5. **Which agent you use** — setup teaches it the commands. Then it shows
   `Logged in as <your name>` and checks five of your chats.

<Accordions>
<Accordion title="Why does Telegram need a code for my.telegram.org?">

Telegram asks every program that connects to an account to be registered first. The registration
gives the program two values: <DocTerm term="telegram-app" lang="en" label="app ID and app hash" />. They only identify the program;
they give no access to your messages on their own. Telegram allows one registration per phone
number, so if you have one already, the CLI reuses it.

The code in step 2 lets the CLI fill in that registration form on
[my.telegram.org](https://my.telegram.org) for you. The QR scan in step 3 is the actual login.

</Accordion>
<Accordion title="Why scan a QR code?">

The QR code links the CLI to your account as a new device, like Telegram Desktop. Your phone
proves it is you. If two-step verification is enabled, the terminal also asks for that password. After login the CLI shows up in
**Settings → Devices**, where you can remove it at any time.

</Accordion>

   <Screenshot src="/screenshots/telegram/my-telegram-api-tools.png" alt="my.telegram.org menu with API development tools highlighted" />

   <Screenshot src="/screenshots/telegram/my-telegram-credentials.png" alt="my.telegram.org App configuration page with api_id and api_hash highlighted" />

### Check that it works

Setup checks this for you, and an agent that installed the CLI checks it too. Run it yourself if
your agent says it cannot find the command, your chats or your messages:

<Tabs groupId="messenger" persist items={["Telegram", "MAX"]}>
<Tab value="Telegram">

```sh
tg chats list --limit 5
```

</Tab>
<Tab value="MAX">

```sh
max chats list --limit 5
```

</Tab>
</Tabs>

You should see five of your recent chats.

- **"Not logged in"** — run the setup command again.
- **Command not found** — open a new terminal, or restart your agent; on Windows, see
  [what the installer changes](#what-the-windows-installer-changes).
- **A chat or older messages are missing** — logging in does not download history. Ask your agent
  to fetch that chat's history first.

## What the CLI and your agent can do with this login

The login gives the CLI **the same access you have in the app**: read your chats, send, edit and
delete messages, manage groups and contacts. Your agent gets that access when it runs `tg` or
`max` commands.

- **It acts only when a command asks.** Reading does not mark messages as read, and nothing is sent
  unless a command sends it.
- **By default, sending is allowed**, up to 30 messages per hour. Deleting messages needs an extra
  confirmation.
- **You decide what an agent may do.** Each account connection (a *profile*) has its own rules:

| You want | Set up | Read more |
|---|---|---|
| The agent only reads, never changes anything | a read-only profile | [Telegram](./tg/configuration.md#what-a-profile-may-do) · [MAX](./max/security.md#preventing-sends-to-the-wrong-place) |
| A question before each send | the `ask` level for sending | [Telegram](./tg/configuration.md#a-question-before-a-change) |
| Sends only to chats you chose | a recipient list | [Telegram](./tg/security.md#the-send-guard) · [MAX](./max/security.md#preventing-sends-to-the-wrong-place) |
| Fewer messages per hour | `sendsPerHour` | [Telegram](./tg/security.md#the-send-guard) · [MAX](./max/security.md#preventing-sends-to-the-wrong-place) |

These controls help prevent unwanted actions. An assistant with full access to your terminal or
settings files can change them; a profile is not a separate secure computer.
[Understand the limits](./security.mdx#what-the-guard-cannot-hold).

**Your login is saved on this computer.** Treat the saved session like a password: whoever copies
it can use your account. To log out, run `tg session end` or `max session end`, or remove the device
in **Settings → Devices** on your phone. What is stored where:
[Telegram security](./tg/security.md) · [MAX security](./max/security.md).

## Troubleshooting

### What the Windows installer changes

The npm commands above allow the packages’ installation scripts. They add npm’s command folder to your Windows user PATH, preserve existing entries, keep a working `.cmd` launcher and install the agent skill. A new terminal finds `tg` or `max` by name.

An already-running terminal or agent must refresh its environment: an npm child process cannot update its parent’s PATH. Your agent should do this itself, without asking you to edit PATH. PowerShell’s execution policy stays unchanged.

<Accordions>
<Accordion title="npm skipped the installation script or the command is not found">

Follow the package’s repair instructions: [Telegram installation](./tg/installation.md) or [MAX installation](./max/installation.md). They use files in the installed package and preserve existing PATH entries.

The optional PowerShell helper also updates the terminal running it, even when npm skips package scripts. For Telegram:

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://wirecat.dev/install.ps1'))) -Tool tg -Agent all
```

Use `-Tool max` for MAX. Before login, your agent should read `tg skill show` or `max skill show` and check that the installed skill is loaded.
