## Where the tools run

**On your own computer** is the simplest starting point. Use Windows, macOS or Linux. A <DocTerm term="local-agent" lang="en" label="AI agent" /> with terminal access runs the tools there, alongside the saved history and files you choose.

**On a server you control** is useful for background sync or recurring work. Install and connect the tools on that server. Its disk holds the sessions and local data; it needs access to the folders you want to import. A path on your laptop does not automatically refer to a file on the server.

**From a browser or phone**, your agent can connect to a tool running on your computer or server. The browser does not install or run the CLI. Follow [Use from web or mobile](./browser-apps.mdx) for the remote connection. Keep the machine running when you need access to it.

You do not need to run both your laptop and a server. Choose one place to start. A tool installed in one environment is not automatically available in another terminal, account, container or remote workspace.

## What setup involves

1. **Prepare the runtime.** Node.js runs the tools; npm installs their packages and command launchers.
2. **Install the tool you need.** A command-line tool, or CLI, is a program your agent can run through a terminal. Installing it makes its command available; it does not connect your account or import all your data.
3. **Connect a source.** Messenger tools need an account session or a bot token. Memo starts with folders you choose; email requires a configured mail account.
4. **Connect your agent.** Give it command-line access and the tool's instructions, or configure an MCP connection for a compatible app.
5. **Prepare the useful data.** Download the chat history or import the folders and mail you need. Check the period covered and any files that could not be read.
6. **Check a small result.** Ask the agent to list a few chats or find a word in an imported note. Check its sources before allowing changes or background work.

### Ask your agent to help

Copy this request into the agent you use, such as Claude Code, Codex, Cursor, Gemini CLI or Hermes. Tell it which tool and source you chose above.

```text prompt
Help me set up the WireCat tool I choose on this computer.
Check Node.js and npm and explain any changes before installing.
Follow its installation guide; connect only the account or folder I choose.
Teach my AI agent the tool's commands and test a read-only task.
Explain where its data stays and how to stop background work.
```

You approve account login yourself. Follow the tool's instructions for entering codes, scanning a QR code or providing a bot token. Keep these credentials out of an ordinary agent chat.

## Node.js, npm and finding the command

The messenger tools require <DocTerm term="nodejs" lang="en" label="Node.js" /> **22.16+ in the 22.x series, or 24+**, with npm. Follow your tool's guide for its supported runtime and platform instructions. Check your terminal with:

```sh
node --version
npm --version
```

If Node.js is missing or needs an update, ask your agent to prepare it:

<NodeSetupPrompt lang="en" />

Global installation makes a command such as `tg`, `max` or `memo` available through your environment's PATH: the list of folders the terminal searches for programs. After installation, check that the agent can run the command too. An already-running agent may need to refresh its environment or restart.

<a id="what-the-windows-installer-changes" />

### Windows and command visibility

Use the Windows commands in the tool guide. PowerShell may need npm's `.cmd` launcher, and package installation scripts may need explicit permission. The messenger installers can add npm's command folder to your user PATH without changing PowerShell's execution policy. See the repairs for [Telegram](./tg/installation.md) and [MAX](./max/installation.md).

## Connecting is not importing

A messenger login authorises that machine as a device on your account. It gives the tool access to what the service and your account permit, but does not make your entire history available locally. Download the chats and periods you need: [Telegram archive](./tg/archive.md) · [MAX archive](./max/archive.md).

Memo does not need a messenger login of its own. Register selected folders and import their readable contents; configure mail separately. To include messenger history, download it with the corresponding messenger tool first. See [notes and files](./memo.mdx) and [email](./email.mdx).

For a local agent, a skill teaches it how to use the commands. For an app connecting remotely, MCP exposes the tool's capabilities. Neither step by itself grants an account session or downloads history. [Connect your agent](./agents.mdx).

## Data, permissions and background work

Saved sessions and the local archive stay on the computer or server where you run the tool. Treat sessions as credentials and protect that machine and its backups. Local storage does not prevent your agent from sending retrieved content to its AI provider; check [security and data flow](./security.mdx).

The messenger tools allow sending by default. Set [permissions](./permissions.mdx) before letting an agent perform changes or unattended tasks; choose a read-only profile when you only want it to read. Reading, saving a note, drafting a reply and sending a message are different actions.

Installation does not start continuous syncing, moderation or auto-replies. Those need the relevant process or schedule to run, and the machine must stay on. A closed agent chat does not necessarily stop a separate background process. Ask the agent to show what it started and how to stop it. [Recurring tasks](./prompting.mdx#recurring-tasks).

## Check and maintain the setup

A working setup has an available command, a connected source, useful data and an agent that can reach it. If a command works in your terminal but not in your agent, check the agent's environment. If search is empty, check imports and history coverage before reinstalling.

Use each tool's guide for updates, file locations and removal: [Memo](./memo.mdx#install-memo), [Telegram](./tg/installation.md) and [MAX](./max/installation.md). Removing a package and revoking a connected account session are separate steps; follow the session guide when you want to remove account access.

Once a small read-only task works, try [your first message task](./first-tasks.md) or [search your notes and files](./memo.mdx).
