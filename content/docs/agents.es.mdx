Conecta tu asistente al mensajero para encontrar mensajes, reunir contexto y preparar respuestas. Aquí elegirás cómo conectarlo, configurarás la conexión y comprobarás el resultado. Después podrás pedir tu primera tarea útil.

## Qué es un agente y cómo usa la herramienta

Un **agente de IA** es un asistente que utiliza herramientas para realizar una petición. Puede encontrar mensajes y resumirlos. Tú describes la tarea; el agente elige las acciones.

Una **CLI** es una herramienta de línea de comandos: se controla con instrucciones de texto. Un agente con terminal puede ejecutarla en tu ordenador o servidor. Un chat sin terminal se conecta mediante **MCP**, que permite al asistente utilizar la herramienta a través de una conexión. No necesitas memorizar comandos.

## Dónde quieres usar el asistente

- **[En ChatGPT, Claude u otro chat de IA en el navegador o móvil](./browser-apps.mdx)** — Sigue la guía de navegador y móvil.
- **[En Codex, Claude Code, Cursor, Gemini CLI, Hermes u OpenClaw con terminal](#connect-instructions)** — Conecta la herramienta abajo.
- **[En una aplicación con ajustes MCP, como Claude Desktop](./mcp.mdx)** — Sigue la guía MCP.
- **[Quiero comprobar una conexión existente](#check-connection)** — Pide la cuenta y los chats.
- **[La herramienta o cuenta no están configuradas](./installation.mdx)** — Empieza por instalación e inicio de sesión.

## Conecta las instrucciones

Los ejemplos usan `tg` para Telegram. Para MAX cambia `tg` por `max` y el nombre del skill `tg-cli` por `max-cli`. Se aplica a todos los ejemplos y notas.

### Primera conexión

Ejecuta un comando en el terminal del ordenador donde trabaja el agente. Conecta la cuenta e instala las instrucciones:

```sh
tg setup --agent codex
```

Cambia `codex` por `cursor`, `claude` o `gemini`. Sin `--agent`, la configuración te permite elegir. Para Hermes, OpenClaw u otro agente, usa `none` y sigue la nota correspondiente abajo.

### La cuenta ya está conectada

Añade las instrucciones sin repetir el inicio de sesión:

```sh
tg skill install
```

Un **skill** es un archivo que enseña al agente a usar la herramienta. El comando lo instala en las carpetas estándar. Inicia una conversación nueva después.

## Comprueba si está todo listo

```text prompt
Usa tg CLI. Lee las instrucciones con tg skill show, muestra la cuenta conectada y cinco chats recientes. Solo lee: no envíes nada ni marques mensajes como leídos.
```

La cuenta y los chats deben ser tuyos. Después sigue con [Primeras tareas](./first-tasks.md).

## Notas para tu agente

Aquí solo se explican pasos adicionales de cada aplicación. El comando principal es común.

### Codex

Selecciona `$tg-cli` en la conversación. Si no aparece, abre una nueva conversación
o reinicia Codex. [Guía de Codex](https://learn.chatgpt.com/docs/build-skills).

### Cursor

Usa **Agent** con acceso a la terminal y pídele que use la herramienta. Si no encuentra el skill,
pídele que lea `skill show`. [Guía de Cursor](https://cursor.com/help/customization/skills).

### Claude Code

Usa `/tg-cli` en una nueva sesión local.
[Guía de Claude Code](https://code.claude.com/docs/en/skills).

### Gemini CLI

Comprueba los skills disponibles con `gemini skills list`. En una sesión abierta,
`/skills reload` actualiza la lista. [Guía de Gemini](https://geminicli.com/docs/cli/skills/).

### Hermes

Pide a Hermes que guarde la salida exacta de `tg skill show` en
`~/.hermes/skills/tg-cli/SKILL.md`. Abre una nueva sesión y repite la comprobación del principio.
[Guía de Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/).

### OpenClaw

Pide a OpenClaw que guarde la salida exacta de `tg skill show` en
`~/.openclaw/skills/tg-cli/SKILL.md`. Comprueba que el skill esté disponible para tu agente y abre
una nueva sesión. La herramienta debe estar instalada en el ordenador o servidor donde se ejecuta OpenClaw.
[Guía de OpenClaw](https://docs.openclaw.ai/tools/skills).

### Otro agente

Los ejemplos anteriores no son una lista cerrada. Cualquier asistente con acceso a la línea de comandos puede usar la herramienta. Dale la salida de `tg skill show`, o pídele que lea la documentación. Puede consultar los comandos con `--help`.

Si usa MCP, sigue la [configuración MCP](./mcp.mdx); para un chat del navegador, usa la [conexión desde el navegador](./browser-apps.mdx). Las opciones de instalación preparadas cubren clientes concretos; los demás usan sus propios ajustes de instrucciones o herramientas.

## Empieza tu primera tarea

Pide encontrar un acuerdo, resumir conversaciones o preparar un borrador: [Primeras tareas](./first-tasks.md). Si no encuentra la herramienta, comprueba la instalación y que el agente trabaja en el mismo ordenador. Para otro dispositivo, sigue la [guía de navegador y móvil](./browser-apps.mdx).
