WireCat хранит ваши сообщения, почту, заметки и файлы на вашем компьютере. Некоторые функции еще и отправляют текст
или картинки модели ИИ, и по умолчанию это может быть облачный сервис. Эта страница показывает, как направить каждую
такую функцию на модель, которая работает на вашем компьютере, чтобы то, что она читает, никуда не уходило. Нужен
локальный сервер моделей, например Ollama или другой сервер, который говорит на языке OpenAI. Сейчас для этого нужно
несколько настроек в разных местах, а несколько функций все еще уходят наружу. И то и другое перечислено ниже. WireCat
работает над одним переключателем «только локально» для всего этого.

## Что уже работает локально

**Поиск по смыслу** и **поиск по картинкам** по умолчанию работают на вашем компьютере и ничего не отправляют.

## Модель ИИ в настройках

Эта модель читает текст на картинках, которые вы добавляете в память, и может читать источники для фактов. В WireCat
Desktop откройте **Настройки**, **Модель ИИ**.

**С Ollama:**

1. Установите Ollama и скачайте модель, которая умеет читать картинки, например `llava`. Ollama должен слушать свой
   обычный адрес, `127.0.0.1:11434`.
2. В поле **Провайдер** выберите **Ollama на этом компьютере (бета)** и выберите модель.
3. Отметьте **Распознавать картинки этой моделью**, сохраните и нажмите **Проверить**.

То же из терминала: `memo models ai set ollama --model llava`.

**С другим сервером на вашем компьютере**, который говорит на языке OpenAI:

1. В поле **Провайдер** выберите **OpenAI или совместимый**.
2. В **Адрес (base URL)** впишите адрес сервера на этом компьютере, например `http://127.0.0.1:8080/v1`. Укажите
   порт, который слушает ваш сервер.
3. Впишите название модели. В **API-ключ** впишите любое значение: сейчас WireCat нужен ключ даже для сервера на
   вашем компьютере.
4. Сохраните и нажмите **Проверить**.

## Чтение фактов

В **Настройки**, **Чтение фактов** выберите **Модель ИИ**, которая теперь ваша локальная, или **Ollama**. Нажмите
**Использовать этого читателя**. После этого [Добавить в память](./memory.mdx#добавить-в-память) предлагает факты с
помощью этой модели.

## Поиск получше

Два помощника поиска находятся в подробностях Memo: на странице Инструменты нажмите **Управление** в строке Memo.

- **Переписывать записи для лучшего поиска:** в WireCat Desktop оставьте выключенным, там для него есть только
  облачные модели. Из терминала его можно направить на локальный сервер:

  ```sh
  memo models consents set openai --model <model> --base-url http://127.0.0.1:11434/v1 --yes
  ```

- **Искать тщательнее:** выберите OpenAI с адресом `http://127.0.0.1:11434/v1`. Ответ он ждет только 5 секунд,
  поэтому модель, которая работает на процессоре без видеокарты, скорее всего не успеет. Тогда поиск оставляет свой
  порядок.

## Голосовые сообщения

Голосовое сообщение сначала расшифровывает речевой сервис самого мессенджера, если он есть. Чтобы звук остался на
вашем компьютере, добавьте `--local` к команде инструмента `messages transcribe`, например в Telegram. Тогда
используется скачанная модель.

## Что все еще уходит наружу

Эти части используют ИИ-агента, а не модель выше. Они работают локально, только если вы направите этого агента на
локальную модель в его собственных настройках:

- **Сводки** пишет Claude Code.
- **Почтовый агент** в WireCat Desktop запускает Claude Code. Агент по расписанию, запущенный из терминала, может
  работать через Codex.
- **Каждый агент, подключенный через MCP**, например ChatGPT, Claude или Codex, читает все через WireCat своей
  собственной моделью.

WireCat работает над одним переключателем «только локально», который оставит каждую функцию на вашем компьютере и
покажет, что локально, а что нет.
