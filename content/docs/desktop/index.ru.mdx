WireCat Desktop — приложение для тех, кто хочет, чтобы ИИ-агент работал с их сообщениями, встречами,
документами и заметками, но не хочет сам устанавливать и обслуживать инструменты командной строки. Оно
устанавливает инструменты WireCat, даёт ИИ-агентам инструкции для работы с ними, открывает вход в аккаунт для
каждого инструмента и показывает, что инструменты хранят на вашем компьютере. Эта страница идёт по приложению
в том порядке, в каком вы с ним знакомитесь: установка, первый запуск, затем каждая страница окна.
Приложение не обязательно: каждый инструмент по-прежнему устанавливается и работает из терминала и без него.

## Скачать и установить

[Скачайте WireCat Desktop](/ru/download) для macOS (Apple silicon и Intel), Windows (64-битной) или
Linux (AppImage, .deb или .rpm). Страница загрузки сама предложит файл для вашего компьютера. Приложение
для macOS подписано и проверено Apple. Установщик для Windows подписан сертификатом Open Source Developer
от Certum, и Windows показывает издателя Open Source Developer Viacheslav Ptsarev. Первый запуск Windows всё ещё
может попросить подтвердить; [шаги первого запуска](/ru/download#first-launch) показывают, где нажать.

Самому приложению больше ничего не нужно. Инструменты работают на
<DocTerm term="nodejs" lang="ru" label="Node.js" /> 22.16 и новее в линейке 22.x или 24 и новее, вместе с
npm. Если Node.js нет, он слишком старый или npm требует для установки прав администратора, приложение
предложит поставить собственную копию Node.js в вашу папку пользователя. Права администратора для этого не
нужны, а ваш Node.js остаётся как есть.

## Первый запуск

При первом запуске в окне приложения открывается настройка. Её шаги перечислены слева: **Начало**,
**Компьютер**, **Выбор**, **Установка**, **Агенты**, **Вход** и **Готово**. **Продолжить** ведёт к следующему
шагу, **Назад** — к предыдущему. **Настроить позже** закрывает настройку, а **Завершить настройку** в боковой
панели открывает её снова на том шаге, до которого вы дошли.

1. **Начало:** короткий рассказ о том, что делает WireCat. Инструменты хранят ваши сообщения, почту, встречи и
   файлы в хранилище на этом компьютере, а не в облаке WireCat. Каждый инструмент — открытый инструмент
   командной строки из npm; приложение устанавливает его и запускает его собственные команды. **Начать**
   запускает настройку.
2. **Компьютер:** приложение проверяет систему, Node.js и npm. **Проверить снова** повторяет проверку после
   того, как вы что-то исправили.
3. **Выбор:** отметьте сервисы, к которым агент должен получить доступ: Telegram, MAX, WhatsApp, Zoom,
   Google Drive, Memo или почту. Добавить или убрать инструменты можно и позже на странице **Инструменты**.
4. **Установка:** каждый инструмент ставится из npm, и приложение проверяет, что он запускается. Установки идут
   по одной. Полоса показывает ход: поиск пакетов, скачивание, распаковку, установку на компьютер и проверку
   запуска, а также прошедшее время и оценку остатка. На инструмент обычно уходит минута-две, при медленном
   интернете дольше. Пока вы ждёте, короткие подсказки объясняют, зачем нужен каждый инструмент. Установка
   продолжится, если вы перейдёте дальше, и каждую из них также видно на странице **Инструменты** вместе с
   полным журналом. Перед каждой установкой идёт та же проверка хранилища, что и на странице
   [Инструменты](#инструменты), и предупреждение ждёт вашего ответа в строке инструмента.
5. **Агенты:** каждому найденному ИИ-агенту приложение даёт
   <DocTerm term="skill" lang="ru" label="навык" /> инструмента — короткое руководство по его командам.
   Оно знает, откуда читают навыки Claude Code, Codex, Cursor, Gemini CLI, OpenCode, Hermes Agent и
   OpenClaw. С навыком вы просите агента обычными словами, например «Что вчера прислала Анна?», и агент
   знает, какой инструмент ответит.
6. **Вход:** вход связывает инструмент с вашим аккаунтом, и агент получает к нему доступ. Приложение проводит
   его в своём окне для Telegram (QR-код или номер телефона), MAX и WhatsApp (QR-код), а для Zoom и Google
   Drive открывает браузер. Если у инструмента нет входа в окне, **Войти в терминале** открывает терминал,
   где запускается собственная настройка инструмента. Почта спрашивает адрес в своём окне. Для учётной записи
   Microsoft она затем открывает вход Microsoft в браузере. Для Gmail и других почтовых серверов она просит пароль
   приложения — пароль, созданный только для этой программы; [Подготовка почтового ящика](../mail/providers.md) показывает,
   как его получить у каждого сервиса. Memo не требует входа.
7. **Готово:** приложение показывает, что установлено, и предлагает три следующих шага: дать ChatGPT или
   Claude доступ к инструменту, посмотреть, какие агенты их используют, или попробовать первый рецепт.
   **Появится в следующем выпуске WireCat Desktop:** у каждого настроенного инструмента будет свёрнутая карточка «Что
   можно сделать с» этим инструментом. Раскройте её, чтобы увидеть следующие шаги; каждый открывает нужное место в
   приложении: **Добавить ещё один аккаунт**, **Запустить синхронизацию**, **Оставить работать в фоне**, **Дать агентам
   навык**, **Подключить ChatGPT или Claude в браузере**, **Посмотреть, что он запускал** и **Открыть документацию**.
   В карточке только то, что умеет её инструмент.

## Что можно делать в приложении

Боковая панель перечисляет страницы в таком порядке: **Инструменты**, **Агенты**, **Поиск**, **Задачи**,
**Рецепты**, **Память** и **Аналитика**. Ниже, отдельно, стоят **Хранилище**, **Журнал** и **Настройки**: они о
данных и о самом приложении. Вверху окна есть **Сообщить о проблеме**, **Уведомления** (исправления
безопасности, обновления и новости от WireCat) и **Помощь**; когда готова новая версия, рядом появляется
кнопка обновления. В **Помощи** также есть **Конфиденциальность**, **О WireCat** и настройки Node.js, который
поставил WireCat.

### Инструменты

Здесь вы устанавливаете инструменты и подключаете каждый к своему аккаунту. У каждого инструмента есть
индикатор состояния. Зелёный значит «установлен и актуален», янтарный — «есть обновление», красный —
«установлен, но не запускается», пустое кольцо — «не установлен». В каждой строке одна кнопка:
**Установить**, **Обновить до** версии, **Исправить** или **Управление**.

Все инструменты хранят сообщения и заметки в одном общем хранилище, и новая версия инструмента может перевести
его в более новый формат. Перед **Установить** или **Обновить до** приложение это проверяет. Если другому
установленному инструменту нужна своя новая версия, чтобы и дальше читать хранилище, приложение обновит и его,
сразу после выбранного, и скажет об этом в строке хода установки. Предупреждение появляется, только когда у
другого инструмента такой версии ещё нет или когда новая версия не может открыть ваше хранилище. Тогда вы
выбираете **Не сейчас** или **Всё равно обновить**. Инструмент, который не сообщает, какой формат он читает,
например Zoom, в проверку не входит.

**Управление** открывает подробности инструмента:

- **Аккаунты:** добавьте аккаунт под именем, например `personal` или `work`, и войдите через **Войти здесь**
  или **Открыть терминал**. Приложение никогда не выбирает аккаунт за вас.
- **Проверить состояние:** запускает собственную проверку инструмента для профиля и простыми словами объясняет
  каждую проблему. Если файл настроек инструмента испорчен, например пропущена запятая, **Исправить файл**
  просит инструмент починить его. Инструмент сохраняет файл в прежнем виде и не меняет того, что не может
  исправить безопасно.
- **Синхронизировать:** копирует новые сообщения, файлы или встречи профиля на этот компьютер.
- **Разрешения:** что агентам можно делать с каждой группой команд, отдельно для каждого профиля:
  **Разрешить**, **Спрашивать**, **Только чтение** или **Запретить**.
- **Фоновая служба** (Telegram, MAX и WhatsApp): инструмент получает новые сообщения, только пока работает его
  служба. Для каждого аккаунта видно, работает ли она и запускается ли при входе в систему. **Запустить и оставить
  работать** запускает её и включает запуск при входе, **Остановить** останавливает, **Не запускать при входе**
  убирает её из автозапуска. Если что-то не так, одна фраза объясняет причину и предлагает одно действие, например
  **Войти**. WhatsApp ещё нужен телефон в сети.
- **MCP-сервер (или подключить веб):** даёт ChatGPT или Claude в браузере доступ к инструменту. Руководство
  по [Tailscale Funnel](./tailscale-funnel.mdx) публикует сервер, или можно взять туннель Cloudflare.
- **Запускать по расписанию** (только Email): включает почтового агента Memo. Он читает новую почту каждые
  5 минут и предлагает задачи, счета, заказы и факты, которые вы принимаете сами, и никогда ничего не
  отправляет. Нужны Memo и Claude Code.
- **Удалить:** убирает инструмент. Его данные остаются на этом компьютере, пока вы их не удалите, а в диалоге
  есть **Удалить вместе с данными**.

### Агенты

Здесь видно, какие ИИ-агенты есть на компьютере и какие навыки у каждого. **Подключить** даёт агенту навыки
выбранных инструментов. Приложение находит отсутствующий или старый навык, инструмент, которого новый терминал
не видит в PATH, и команды, запрещённые разрешениями профиля, и исправляет или объясняет каждую проблему.
Если проблема требует больше одного щелчка, **Исправить** может также открыть вашего агента (Claude Code, Codex
или Gemini CLI) в терминале с описанием проблемы. Агент объясняет, что нашёл, и спрашивает, прежде чем что-либо
менять.

### Поиск

Здесь вы ищете в том, что один инструмент хранит на этом компьютере. Выберите **Инструмент** и **Профиль**, затем
введите, что искать. Поиск читает только локальную копию и никогда не обращается к сервису, поэтому то, что не
синхронизировано, не найдётся. Откройте результат, чтобы увидеть сообщения вокруг него, всю переписку по письму
или расшифровку встречи.

### Задачи

Что вы и ваши агенты собираетесь сделать. Агенты читают и меняют тот же список, поэтому задача, о которой вы
попросили в чате с агентом, появляется здесь. Переключайте вид: **Таблица** или **Доска**. Добавляйте
задачу кнопкой **Новая задача** и ищите с фильтрами, например `project:HRB priority:high when:overdue`. Колонка
доски — это состояние: **Новые**, **К выполнению**, **В работе**, **Готово** или **Отклонено**. Задачи хранит
Memo; если Memo не установлен, страница так и скажет.

### Рецепты

Готовые запросы: сводка каждое утро, подготовка к каждому звонку, задачи из того, о чём вас просили. Они собраны по
целям: **Наверстать**, **Подготовиться**, **Собрать**, **Проанализировать**, **Проверить**, **Запомнить**,
**Спланировать** и **Запланировать**. Рецепт показывает, что ему нужно. **Скопировать промпт** копирует запрос для
вашего агента, а **Открыть в** агенте запускает этого агента в терминале с ним. Рецепты, которые пришли с
приложением, работают без интернета, а новые появляются, когда он есть.

### Память

Здесь вы решаете, что агенты могут помнить о вас и о людях, с которыми вы общаетесь. Агент, подключённый к
WireCat, сохраняет то, что узнал, например «Кай предпочитает звонки по пятницам», вместе с сообщениями, которые
это показывают. Ничто из написанного им не считается, и ничто из предложенного не происходит, пока вы это не
одобрите. Память хранит Memo.

Вкладки: **На проверку**, **В работе**, **Отклонено** и **Все**. У каждой записи видны сообщения и заметки, на
которых она основана. С записью можно сделать следующее:

- **Одобрить** или **Отклонить** её.
- **Изменить** её карандашом или из **Ещё**. Ваше исправление сохраняется как ваше и одобренное; версия
  агента остаётся во вкладке **Отклонено**.
- Отменить своё решение. В **Ещё** есть подходящая отмена: **Отклонить**, **Больше не верно** или **Отменить
  одобрение**. **Отменить одобрение** есть у решения и у факта, который записал агент: он возвращается во вкладку
  **На проверку**. У факта, который вы записали сами, вместо этого есть **Изменить** и **Стереть…**.
- **Стереть…** её, тоже из **Ещё**. WireCat стирает запись с этого компьютера, и агенты перестают её находить.
  Сообщения, заметки и встречи, на которых она основана, остаются, а резервная копия, сделанная раньше, всё ещё
  хранит её.

Что WireCat хранит и как этим пользуются. Страница только для чтения. Выберите период (**7 дней**, **30 дней**,

### Хранилище

Здесь видно, сколько места занимают инструменты, и можно навести порядок. Страница показывает папки каждого
инструмента — **Настройки**, **Данные** и **Кеш** — **Общее хранилище** (файл `wirecat.db`, где инструменты
хранят сообщения, почту, документы и заметки) с подсчётами и просмотр **Таблиц** внутри него.

- **Резервные копии:** **Сделать копию** копирует всё хранилище, и копию можно защитить паролем. Страница
  показывает, как восстановить копию.
- **Очистить хранилище…:** удаляет все сообщения, чаты, письма, документы и встречи в общем хранилище.
  Настройки и входы остаются. Диалог сначала делает копию, если вы не сняли галочку.
- **Удалить:** убирает папки инструмента, когда их не использует ни один установленный инструмент. **Удалить

## Добавить свой инструмент

**Появится в следующем выпуске WireCat Desktop:** всё, что описано в этом разделе. Текущий выпуск показывает только
инструменты WireCat.

Так вы добавляете инструмент, который WireCat не делает: свой, коллеги или из закрытого репозитория. Страница
«Инструменты» может показывать три вида инструментов:

| Вид | Откуда он | Метка |
| --- | --- | --- |
| Инструменты WireCat | Встроены в приложение | нет |
| Инструменты сообщества | Список, который WireCat проверяет и подписывает | **Сообщество** |
| Ваши | Добавлены вами по имени в npm | **Не проверен** |

Второй и третий виды по умолчанию выключены. В настройках для каждого свой переключатель, в широком окне они стоят
рядом: **Включить инструменты сообщества** и **Разрешить инструменты, которые WireCat не проверял**. **Включить
инструменты сообщества** действует со следующего запуска, и страница предлагает **Перезапустить**. **Разрешить
инструменты, которые WireCat не проверял** действует сразу.

### Инструменты сообщества

Включите **Включить инструменты сообщества**. Приложение прочитает список, который подписывает WireCat, и покажет его
инструменты с меткой **Сообщество**. Устанавливается такой инструмент кнопкой **Установить**, как любой другой.
Приложение ставит выпуск, только если npm собрал его из собственного репозитория инструмента. Проверка смотрит, как
инструмент собран и выпущен, а не всё, что он делает. Пока в списке нет ни одного инструмента. Как авторам попасть в
список, сказано на странице [Добавьте свой инструмент в WireCat](../build-list-tool.md).

Подписанный список действует 30 дней, и приложение загружает новый каждый день. Если загрузить не получается, за семь
дней до конца срока уведомление вверху приложения говорит, когда список истекает. Когда список устарел, уведомление
пишет: «Список инструментов сообщества устарел, поэтому инструменты сообщества нельзя установить или обновить.
Установленные продолжают работать». Пока не придёт новый список, строка инструмента сообщества объясняет, почему
**Установить** или **Обновить** не работает. Удалить его можно. Ваши инструменты и инструменты WireCat список не
используют. Уведомление видно, только пока инструменты сообщества включены.

### Добавить инструмент по имени в npm

1. В настройках включите **Разрешить инструменты, которые WireCat не проверял**. Откроется предупреждение:
   инструмент, добавленный так, работает от вашего имени на этом компьютере и может прочитать всё, что хранит
   WireCat; добавляйте только инструменты авторов, которым полностью доверяете; WireCat не отвечает за то, что они
   делают. Подтвердите кнопкой **Разрешить**.
2. На странице «Инструменты» нажмите **Добавить свой инструмент**, вверху рядом с **Проверить снова**. Введите имя в
   npm, например `@scope/name`, и нажмите **Проверить пакет**. WireCat только читает npm. Ничего не ставится, и код
   пакета не запускается.
3. Прочитайте экран проверки (ниже) и нажмите **Добавить**.
4. WireCat спрашивает «Проверить `@scope/name` перед установкой?» и первым делом предлагает вашего ИИ-агента. Для
   каждого агента, которого он может открыть, есть своя кнопка, например **Проверить через Claude Code** или
   **Проверить через Codex**. Агент открывается в терминале с готовым заданием: скачать именно тот файл пакета, который
   вы проверяли, сверить его sha512, прочитать код, сравнить его с репозиторием на коммите выпуска и сообщить, с
   какими серверами он связывается, что читает и пишет на этом компьютере и что в нём подозрительного. Агент никогда
   не устанавливает и не запускает пакет. **Что получит агент** показывает задание целиком. Если агент не найден,
   нажмите **Скопировать проверку** и вставьте её своему агенту. Прочитайте отчёт агента и нажмите **Перейти к
   установке** или **Пропустить и установить** без проверки.
5. Второй вопрос: «Установить и запустить `@scope/name`? Его скрипты установки и первый запуск работают с вашими
   правами». Пакет ставит только кнопка **Установить и запустить**. **Назад** возвращает к проверке.
6. После установки WireCat проверяет, что программа описывает себя так же, как на экране проверки. Инструмент сразу
   появляется на странице «Инструменты» с меткой **Не проверен**. Перезапуск не нужен.

Подходит не любой пакет. У пакета должна быть область имён (`@scope/name`, но не `@wirecat/`), он написан на
TypeScript на [cli-base](https://github.com/WireCatLabs/cli-base) и содержит манифест `contracts/wirecat.json` —
файл, который описывает команды инструмента для WireCat. Программу из PATH или пакет без области имён добавить
нельзя. Как автору собрать такой инструмент, показано на странице
[Создайте свой CLI](../build-create-cli.md#подготовьте-его-для-wirecat-desktop).

### Экран проверки

Когда он открывается, ещё ничего не установлено. Сверху вниз:

- **Не проверен** рядом с названием инструмента.
- **Красное предупреждение**, верное для любого добавленного инструмента: он работает от вашего имени на этом
  компьютере, поэтому может прочитать всё, что хранит WireCat (ваши сообщения, почту, заметки и файлы). Если
  инструмент построен на cli-core, собственной библиотеке WireCat, предупреждение добавляет, что он открывает эти данные
  напрямую. Добавляйте его, только если полностью доверяете его авторам.
- **Издатель**, **Репозиторий**, **Версия** и **Где npm его собрал**. Каждое — ссылка, которая откроется в браузере:
  профиль издателя в npm, репозиторий, страница версии (**В npm**) и, если npm записал, где собрал пакет, **Коммит
  выпуска**, **Запуск сборки выпуска** и **Запись в журнале прозрачности**. «Нет записи о том, где npm его собрал»
  значит, что ничто не связывает пакет с открытым кодом.
- **Что стоит проверить**: каждый пункт с одной фразой о том, почему это важно. Пункты берутся из npm (впервые
  опубликован меньше 30 дней назад, мало версий, его публикует один аккаунт npm, нет записи о том, где npm его собрал),
  из репозитория на GitHub (создан недавно, давно не меняется, в архиве, мало звёзд, процессы сборки не запускают
  стандартные проверки WireCat), из того, использует ли он библиотеки WireCat, и из его кода (открывает сетевые
  соединения, называет серверы, которые не объявляет, может запускать другие программы, прячет вызовы или содержит
  машинный код в файлах `.node` или `.wasm`). Если GitHub недоступен или лимит проверок исчерпан, пункт пишет «Не
  удалось проверить его репозиторий на GitHub», и остальные проверки в силе. Если показать нечего, экран пишет «Ничего
  не бросилось в глаза. Это не значит, что он безопасен».
- **С какими серверами связывается**: серверы, которые объявляет инструмент, «Он говорит, что не связывается ни с
  какими серверами» или «Он не говорит». Сервер, который выбираете вы, например ваш почтовый сервер, тоже назван.
- **Что он, по его словам, делает**: таблица данных, с которыми работает инструмент (Contact, Deal…), с их полями, если
  инструмент их называет. Для каждого — **В** сервисе и **На этом компьютере**: **Читает**, **Меняет** или
  **Сохраняет**, либо **Ничего**. Затем что его синхронизация копирует в хранилище WireCat и **Стандартные команды
  WireCat** простыми словами (входит в аккаунт, проверяет, что всё работает, устанавливает инструкции для ИИ-агентов…).
  Точные команды свёрнуты под **Команды**; нажмите, чтобы раскрыть список.

Что это значит:

- **«Что стоит проверить» — сигналы, а не приговор.** Ни один пункт не мешает добавить инструмент, а пустой список не
  делает его безопасным. То, что WireCat находит в коде пакета, — «найдено в коде, не доказано»: библиотеки, которые
  пакет встраивает, пропускаются, а код можно написать так, чтобы он спрятался от такого чтения.
- **«Где npm его собрал» — не проверка безопасности.** npm записывает, какой репозиторий собрал пакет. Это показывает,
  откуда взят код, но не то, что он безопасен.
- **«Что он, по его словам, делает» — то, что инструмент сообщает о себе сам.** WireCat не может доказать, что он
  делает только это.
- **Установка запускает его код.** npm выполняет скрипты установки пакета с вашими правами. Поэтому сначала идёт
  проверка ИИ-агентом, а подтверждений два.

### Обновление

Кнопка **Обновить до** каждый раз заново открывает проверку для новой версии. Там же видно, что изменилось с версии,
которую вы подтвердили: репозиторий, место сборки в npm, издатели, новые команды, новый доступ на запись, новые или
изменённые части. Если что-то изменилось или инструмент не описывает, что он запрашивает, отметьте **Я принимаю эти
изменения**, иначе дальше не пройти. Потом идут проверка ИИ-агентом и второй вопрос, как для нового инструмента.

### Удаление

- **Убрать из WireCat** в сведениях об инструменте (нажмите на его название) удаляет его запись, и инструмент сразу
  исчезает со страницы «Инструменты». Перезапуск не нужен. Если программа установлена, вопрос предлагает **Сначала
  удалить программу**; иначе программа остаётся установленной, и страница «Инструменты» пишет, что осталось на
  компьютере.
- **Удалить** убирает программу. **Удалить вместе с данными** стирает ещё и собственные папки данных инструмента:
  только папки, названные по его пакету (`@scope/name` → `scope-name`). Общее хранилище ваших инструментов не
  удаляется никогда. Папка с таким именем, которая была ещё до того, как вы добавили инструмент, показана с пометкой
  «Эта папка была до того, как WireCat добавил инструмент, поэтому WireCat её не трогает» и не удаляется.

### Без интернета

Проверка, добавление и обновление пакета читают npm, поэтому им нужен интернет. Без него диалог пишет «Не удалось
связаться с npm». Уже добавленный инструмент остаётся на странице «Инструменты» и без сети: WireCat хранит его
запись на этом компьютере и при запуске npm не спрашивает. Работает ли без сети сам инструмент, зависит от
инструмента и его сервиса.

## Инструменты остаются инструментами командной строки

Приложение ставит те же пакеты npm, что и `npm install -g @wirecat/tg-cli`, и запускает собственные
команды инструментов для версий, проверок, входа и синхронизации. Инструмент, установленный приложением,
работает и в терминале, и с любым агентом, а инструмент, который вы поставили сами, виден в приложении.
Приложение никогда не выбирает аккаунт или профиль за вас: команда, которой он нужен, берёт тот, что
выбрали вы.

Ваши данные остаются там, где их хранят инструменты, — на этом компьютере. В сеть приложение выходит, чтобы
установить инструменты из npm, скачать Node.js, когда ставит свою копию, проверить на GitHub, нет ли его
новой версии, и отправить отчёт об ошибке, когда вы его отправляете.

## Обновление и удаление

В macOS, Windows и в AppImage приложение обновляется само: предлагает новую версию вверху окна, затем
устанавливает её и перезапускается. Копия из .deb или .rpm сама скачивает новый пакет и
открывает установщик программ системы и показывает команду `apt` или `dnf`. **Открыть в терминале** запускает
эту команду в вашем терминале: введите там пароль и перезапустите WireCat после установки. Ваши аккаунты и данные не удалятся.
[Обновления](/ru/download#updates) и [удаление](/ru/download#uninstall) на странице загрузки описывают
шаги для каждой системы. После удаления приложения инструменты и их данные остаются.

Удобнее в терминале? [Установите инструмент сами или с агентом](../installation.mdx).

## Частые проблемы

Найдите сообщение, которое видите, и сделайте то, что описано. Если ничего не подходит, кнопка [«Сообщить о проблеме»](#сообщить-о-проблеме) в приложении соберёт то, что нужно поддержке.

### Windows пишет «Система Windows защитила ваш компьютер»

Установщик подписан, но SmartScreen доверяет подписанному приложению, только когда его установит достаточно людей, а сертификат новый, поэтому Windows может попросить подтвердить первый запуск. Нажмите **Подробнее**, проверьте, что издатель **Open Source Developer Viacheslav Ptsarev**, затем нажмите **Выполнить в любом случае**. Если издатель другой или его нет, не запускайте файл: скачайте его заново на [странице загрузки](/ru/download). **Smart App Control** пропускает приложения с действительной подписью; старую неподписанную версию WireCat он блокирует. [Шаги первого запуска](/ru/download#first-launch) показывают, где нажать.

### AppImage пишет «AppImages require FUSE to run»

AppImage нужен FUSE 2. Установите его командой `sudo apt install libfuse2t64` в Ubuntu 24.04 и новее или `sudo apt install libfuse2` в более старых Ubuntu и Debian и откройте файл снова. То же сказано в [шагах первого запуска для Linux](/ru/download#first-launch).

### «Для установки инструментов WireCat нужен Node.js», «Node.js слишком старый» или «npm нужны права администратора»

Инструменты работают на Node.js 22.16 или новее в ветке 22.x, либо 24 и новее, вместе с npm. Сам WireCat Desktop работает без него. Нажмите **Установить Node.js за меня**: WireCat скачает Node.js, сверит его с контрольными суммами, которые публикует Node.js, и распакует в вашу пользовательскую папку, без прав администратора. Ваш Node.js остаётся как есть. Если хотите поставить его сами, выберите **Установлю самостоятельно**, а потом нажмите **Проверить снова**.

### Установленный инструмент не находится в терминале или в ИИ-приложении

Терминалы и ИИ-приложения, открытые до установки, увидят новые инструменты только после перезапуска. Если новый терминал всё равно не находит инструмент, а Node.js поставил WireCat, откройте запись Node.js в разделе **Ваш компьютер** и нажмите **Добавить в PATH**, затем откройте новый терминал. Для оболочки, которую WireCat не редактирует, то же окно показывает строку, которую нужно самому добавить в файл запуска оболочки. **Убрать из PATH** отменяет это.

### Установка инструмента не проходит: «Не удалось связаться с реестром npm»

WireCat ставит инструменты из npm, поэтому нужен интернет. Проверьте подключение или прокси и нажмите **Попробовать снова**. Установка дольше 15 минут останавливается; проверка та же. Если в сообщении сказано, что не удалось подтвердить, что выпуск собран WireCat, на компьютере ничего не изменилось: попробуйте позже.

### У инструмента написано «Установлен, но не запускается»

Лампа инструмента красная, а кнопка называется **Исправить**. Она открывает **Исправить с помощью ИИ-агента**: WireCat записывает, что пошло не так, в промпт и открывает с ним в терминале Claude Code, Codex или Gemini CLI. Агент объясняет, что нашёл, и спрашивает, прежде чем что-то менять. Когда он скажет, что проблема решена, нажмите **Попробовать снова**. Если WireCat не нашёл агента, скопируйте промпт и вставьте его в своего агента. На macOS, если Терминал не открывается, разрешите WireCat в Системных настройках: Конфиденциальность и безопасность, Автоматизация. Помешать может и вторая копия того же инструмента: **Управление** показывает копии и как убрать лишнюю.

### Вход не завершается

**Войти здесь** ждёт, пока вы закончите в браузере или на телефоне. Код и QR-код действуют несколько секунд, новый появляется сам; используйте последний. Мессенджеру может понадобиться минута, чтобы прислать историю: оставьте его открытым на телефоне или нажмите **Остановить и сохранить полученное**. Если сообщение говорит, что эта версия пока не умеет входить здесь, обновите инструмент на странице «Инструменты» или нажмите **Открыть терминал**. Если WireCat не нашёл программу терминала, выполните показанную команду сами и нажмите **Проверить вход**.

### «Проверить состояние» показывает сломанный файл настроек

Пропущенная или лишняя запятая, комментарий, одинарные кавычки или незакрытая скобка в файле настроек не дают инструменту прочитать настройки. В **Управлении** кнопка **Проверить состояние** называет проблему; нажмите **Исправить файл**. Инструмент сохраняет файл как был, говорит, что изменил, и не меняет того, что не может исправить безопасно. Если он отказывается, сообщение указывает строку, которую нужно поправить вручную в текстовом редакторе.

### Инструмент «не может прочитать хранилище»

Другой инструмент WireCat перевёл общее хранилище в более новый формат, чем читает этот. Обновите инструмент на странице «Инструменты»; [Хранилище](#хранилище) показывает, каким инструментам это нужно. Если более новой версии ещё нет, страница об этом скажет. Приложение проверяет это перед установкой или обновлением инструмента, поэтому обычно такое бывает только после **Всё равно обновить** или после обновления не из приложения, например через npm в терминале.

### «Не удалось установить обновление»

Нажмите **Попробовать снова** или скачайте WireCat на [странице загрузки](/ru/download). Если в сообщении сказано, что скачанный файл не прошёл проверку подписи WireCat, он не открыт и ничего не сохранено. Копия .deb или .rpm открывает установщик системы, который спросит пароль. Копия, которую WireCat не узнаёт, сама не обновится: установите новую версию так же, как эту. Ваши аккаунты и данные не удалятся. Подробнее: [Обновление и удаление](#обновление-и-удаление).

### «Список инструментов сообщества устарел»

**Появится в следующем выпуске WireCat Desktop.** Список [инструментов сообщества](#инструменты-сообщества), который
подписывает WireCat, истёк, а загрузить новый приложению не удалось. Пока это не получится, инструменты сообщества
нельзя установить или обновить. Установленные продолжают работать, ваши собственные инструменты это не затрагивает.
Проверьте интернет или прокси. Приложение пробует снова каждый день, и уведомление исчезает, как только придёт новый
список.

### WireCat не принимает инструмент, который вы добавляете

Когда вы [добавляете свой инструмент](#добавить-свой-инструмент), диалог называет проблему в заголовке, например
**Инструмент не найден**, а затем пишет, что не так и что делать. **Попробовать снова** возвращает к полю имени: имя
сохранено и выделено, его можно исправить. Если не удалось связаться с npm, пакет слишком большой или что-то пошло не
так, **Попробовать снова** читает то же имя ещё раз. До второго вопроса ничего не устанавливается, кроме двух
последних строк.

| Диалог пишет | Что делать |
| --- | --- |
| Инструмент не найден: в npm нет пакета … | Проверьте написание вместе с областью: `@scope/name`. |
| Здесь работают только имена с областью, например @scope/name. | Спросите у автора полное имя пакета в npm. |
| Это имя принадлежит собственным инструментам WireCat. | Инструменты WireCat уже есть на странице «Инструменты». Установите их там. |
| Этот инструмент не описывает себя для WireCat. | Вставьте его объект `desktop` из документации инструмента в поле под сообщением и нажмите **Проверить с этим объектом**. Или попросите автора выпустить версию с манифестом. |
| В описании инструмента для WireCat ошибка в «…»: … | В кавычках — часть описания, дальше — правило, которое она нарушает. Попросите автора исправить её и выпустить новую версию. |
| … уже использует имя, программу или папку данных этого инструмента. | Два инструмента не могут их делить. Попросите автора переименовать инструмент. |
| … из списка сообщества WireCat уже использует имя или папки этого инструмента. | Этот инструмент теперь есть в списке. Удалите свою запись, чтобы пользоваться инструментом из списка. |
| По данным npm он собран из …, а пакет называет …. | Не добавляйте его. Сообщите автору. |
| WireCat не смог связаться с npm. | Проверьте интернет или прокси и попробуйте снова. |
| Объект «…» больше, чем читает WireCat. | Попросите автора уменьшить пакет. |
| Не удалось прочитать npm: … | Попробуйте снова. Если повторится, сообщите о проблеме. |
| WireCat не может показать этот инструмент: … | Попросите автора исправить это и выпустить новую версию. |
| Пакет установлен, но WireCat его не добавил. | Программа не совпадает с проверкой. Нажмите **Удалить пакет**. |
| bun installed this tool, and bun cannot be told which registry your own tools come from. | Это сообщение приложение пока показывает только по-английски, при обновлении вашего инструмента, который установил bun. Удалите инструмент и добавьте его снова: WireCat поставит его через npm. |
