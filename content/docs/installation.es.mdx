Los CLI de Telegram y MAX se instalan como paquetes npm y funcionan en **Windows, macOS y Linux**.
Pide a tu agente local que compruebe tu ordenador, instale el CLI y te ayude a conectar tu cuenta,
o hazlo por tu cuenta en la terminal. Tras iniciar sesión, comprueba tu cuenta y los primeros chats
y pide al agente que resuelva una tarea útil.

## 1. Elige el mensajero

Abre **Telegram** o **MAX** abajo y copia la petición en tu agente local.
Sirve para Codex, Cursor, Claude Code, Gemini CLI y Hermes. Para instalarlo por tu cuenta,
abre **Instalar en una terminal** dentro del mensajero elegido.

<InstallationGuide />

Reserva unos cinco minutos para instalar e iniciar sesión. Descargar el historial es un paso
separado: elige los chats y la cantidad de mensajes después de configurar el CLI.

## 2. Inicia sesión en tu ordenador

Introduce los códigos y contraseñas en tu terminal local cuando los pida el CLI.

### Telegram

1. Ejecuta en tu terminal local:

   ```sh
   tg session start --app auto
   ```

2. La primera vez, el CLI obtiene las credenciales de la aplicación Telegram. Introduce el número y el código recibido en Telegram cuando se soliciten.
3. En el teléfono, selecciona la cuenta correcta. Abre Ajustes → Dispositivos → Vincular dispositivo de escritorio y escanea el QR del ordenador.
4. Introduce tu contraseña de dos pasos si se solicita y espera un acceso correcto.

Si falla el registro automático, usa:

```sh
tg session start --app browser
```

[Instrucciones de acceso a Telegram](./tg/sessions.md) explican las credenciales, el QR y el acceso por teléfono.

### MAX

1. Ejecuta:

   ```sh
   max setup --agent all
   ```

2. En el teléfono, abre MAX → Ajustes → Dispositivos. Escanea el QR del ordenador y confirma la conexión.
3. Sigue las indicaciones de la terminal. La configuración comprueba tu cuenta y cinco chats e instala los skills. Reutiliza una sesión existente; no descarga todo el historial ni inicia el servicio en segundo plano. Para iniciar sesión sin más pasos, usa `max session start qr`.

Consulta [el acceso a MAX](./max/sessions.md) para otros métodos o la [guía de bots](./max/bot.md) para conectar un bot.

### Comprueba la conexión

Ejecuta el comando de tu mensajero:

```sh
tg account show
```

```sh
max account show
```

La respuesta debe mostrar tu cuenta. Antes de iniciar sesión, el diagnóstico puede indicar que falta una sesión; es normal. Repite la comprobación tras acceder y consulta tus chats.

## 3. Conecta tu agente

[Conectar tu agente](./agents.md) explica los cinco clientes. Para Claude Desktop o MCP, sigue
con [MCP y documentación](./mcp.md).

```text prompt
Revisa los mensajes no leídos por chat y dime a quién debo responder.
```
En el CLI: `tg inbox --limit 5` o `max inbox --limit 5`.

Continúa con [las primeras tareas](./first-tasks.md): encontrar un acuerdo, preparar una reunión
y redactar una respuesta. En [cómo formular peticiones](./prompting.md) tienes ejemplos para copiar y límites útiles.

## Comandos para la terminal

Para instalarlo manualmente necesitas **Node.js 22.16 o posterior** con npm.
[Descarga Node.js](https://nodejs.org/en/download), abre una terminal nueva y comprueba las versiones:

```sh
node --version
```

```sh
npm --version
```

### Telegram

Instalar:

```sh
npm install -g @leemour/tg-cli
```

Versión:

```sh
tg --version
```

Diagnóstico:

```sh
tg doctor
```

Iniciar sesión:

```sh
tg session start --app auto
```

Cuenta:

```sh
tg account show
```

Primeros cinco chats:

```sh
tg chats list --limit 5
```

### MAX

Instalar:

```sh
npm install -g @leemour/max-cli
```

Versión:

```sh
max --version
```

Diagnóstico:

```sh
max doctor
```

Iniciar sesión:

```sh
max setup --agent all
```

Cuenta:

```sh
max account show
```

Primeros cinco chats:

```sh
max chats list --limit 5
```

### Windows

Ejecuta un único instalador de PowerShell para tu servicio:

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://wirecat.dev/install.ps1'))) -Tool tg -Agent all
```

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://wirecat.dev/install.ps1'))) -Tool max -Agent all
```

Instala el paquete npm, conserva las entradas de PATH del usuario, actualiza este PowerShell,
instala el skill y verifica que `tg` o `max` se ejecuta directamente. No necesitas editar PATH.
Funciona aunque npm omita los scripts de instalación. Conserva `.cmd` y elimina solo el shim
PowerShell generado por npm para este paquete; no cambia la política de ejecución.
`-Agent codex|cursor|claude|gemini|all|none` elige el skill; el valor predeterminado es `all`.
Un agente que ya está abierto actualiza su propio entorno antes de las siguientes llamadas.
El propietario sigue introduciendo los códigos o escaneando el QR localmente para iniciar sesión.
