Tres pasos, unos cinco minutos: **instala** el CLI, **inicia sesión** con el teléfono y **comprueba** que funciona.

Necesitas:

- un ordenador con Windows, macOS o Linux;
- tu teléfono, con Telegram o MAX abierto en la cuenta que quieres conectar.

Elige tu sistema y tu mensajero en las pestañas de abajo. La página recuerda tu elección.

### Inicia sesión con el teléfono

Al iniciar sesión, tu ordenador se añade como un dispositivo nuevo de tu cuenta, igual que Telegram
Desktop o MAX en el navegador. Tu teléfono lo aprueba. Ejecuta el comando en **tu propia terminal**,
no en el chat del agente: los códigos y las contraseñas solo deben escribirse en la terminal.

<Tabs groupId="messenger" persist items={["Telegram", "MAX"]}>
<Tab value="Telegram">

```sh
tg setup
```

La terminal te pide, en este orden:

1. **Número de teléfono** — en formato internacional, por ejemplo `+34600111222`.
2. **Código de Telegram para my.telegram.org** — Telegram lo envía como mensaje en la app de
   Telegram (en el chat llamado *Telegram*), no por SMS. Escríbelo en la terminal. El CLI lo usa
   para registrarse en Telegram por ti; esto solo ocurre en el primer inicio de sesión.

   <Screenshot alt="la app de Telegram con el mensaje que contiene el código de acceso a my.telegram.org" width={360} />

3. **Código QR** — la terminal muestra un código QR. En el teléfono, abre
   **Ajustes → Dispositivos → Vincular dispositivo de escritorio** y escanéalo con ese lector (no
   con la app de la cámara).

   <Screenshot alt="la terminal con el código QR de acceso a Telegram" />
   <Screenshot alt="Telegram en el teléfono: Ajustes → Dispositivos → Vincular dispositivo de escritorio" width={360} />

4. **Contraseña de verificación en dos pasos** — solo si la configuraste en Telegram. Los
   caracteres no se ven mientras escribes.
5. **Qué agente usas** — la configuración le enseña los comandos. Después muestra
   `Logged in as <your name>` y comprueba cinco de tus chats.

<Accordions>
<Accordion title="¿Por qué Telegram necesita un código para my.telegram.org?">

Telegram exige que todo programa que se conecta a una cuenta esté registrado primero. El registro
da al programa dos valores: un **app ID** y un **app hash**. Solo identifican el programa; por sí
solos no dan acceso a tus mensajes. Telegram permite un registro por número de teléfono, así que,
si ya tienes uno, el CLI lo reutiliza.

El código del paso 2 permite al CLI rellenar por ti ese formulario de registro en
[my.telegram.org](https://my.telegram.org). El escaneo del QR del paso 3 es el inicio de sesión
real.

</Accordion>
<Accordion title="¿Por qué escanear un código QR?">

El código QR vincula el CLI a tu cuenta como un dispositivo nuevo, igual que Telegram Desktop. Tu
teléfono demuestra que eres tú, así que el CLI nunca necesita tu contraseña. Tras iniciar sesión,
el CLI aparece en **Ajustes → Dispositivos**, donde puedes cerrar su sesión en cualquier momento.

</Accordion>
<Accordion title="¿Ha fallado el registro automático? Registra la app en el navegador">

Ejecuta:

```sh
tg setup --app browser
```

El comando abre [my.telegram.org](https://my.telegram.org). Después:

1. Escribe tu número de teléfono. Telegram envía un código a la app de Telegram. Escríbelo en el
   sitio.

   <Screenshot src="/screenshots/telegram/my-telegram-login.png" alt="formulario de acceso de my.telegram.org con el número de teléfono y el código de confirmación" />

2. Abre **API development tools**.

   <Screenshot src="/screenshots/telegram/my-telegram-api-tools.png" alt="menú de my.telegram.org con API development tools resaltado" />

3. Si aún no tienes una app, rellena el formulario: cualquier título y nombre corto, plataforma
   **Desktop**. Sáltate este paso si la página ya muestra una app.

   <Screenshot alt="formulario de my.telegram.org para crear una aplicación nueva, ya rellenado" />

4. Copia **App api_id** y **App api_hash** en la terminal cuando te los pida. El hash no se ve
   mientras escribes.

   <Screenshot src="/screenshots/telegram/my-telegram-credentials.png" alt="página App configuration de my.telegram.org con api_id y api_hash resaltados" />

5. Continúa con el código QR del paso 3 de arriba.

## Qué pueden hacer el CLI y tu agente con este acceso

El inicio de sesión da al CLI **el mismo acceso que tienes en la app**: leer tus chats, enviar,
editar y eliminar mensajes, gestionar grupos y contactos. Tu agente recibe ese acceso cuando ejecuta
comandos `tg` o `max`.

- **Solo actúa cuando un comando lo pide.** Leer no marca los mensajes como leídos, y no se envía
  nada si un comando no lo envía.
- **Por defecto, se permite enviar**, hasta 30 mensajes por hora. Eliminar mensajes necesita una
  confirmación adicional.
- **Tú decides qué puede hacer un agente.** Cada conexión de cuenta (un *perfil*) tiene sus propias
  reglas:

| Quieres | Configura | Más información |
|---|---|---|
| El agente solo lee y nunca cambia nada | un perfil de solo lectura | [Telegram](./tg/configuration.md#what-a-profile-may-do) · [MAX](./max/security.md#protección-de-envíos) |
| Una pregunta antes de cada envío | el nivel `ask` para enviar | [Telegram](./tg/configuration.md#a-question-before-a-change) |
| Envíos solo a los chats que elegiste | una lista de destinatarios | [Telegram](./tg/security.md#the-send-guard) · [MAX](./max/security.md#protección-de-envíos) |
| Menos mensajes por hora | `sendsPerHour` | [Telegram](./tg/security.md#the-send-guard) · [MAX](./max/security.md#protección-de-envíos) |

Estas reglas frenan a un agente al que ha engañado un mensaje que leyó. No frenan a un agente que
puede cambiar los ajustes por sí mismo, porque los ajustes son archivos y comandos normales de tu
ordenador. Para eso, fija el agente a un perfil con `TG_PROFILE_LOCK` o `MAX_PROFILE_LOCK` y no le
dejes ejecutar los comandos `config` ni `recipients`.
[Qué no pueden impedir los límites](./tg/security.md#what-the-guard-cannot-hold).

**Tu sesión se guarda en este ordenador.** Trata la sesión guardada como una contraseña: quien la
copie puede usar tu cuenta. Para cerrar sesión, ejecuta `tg session end` o `max session end`, o
cierra el dispositivo en **Ajustes → Dispositivos** en tu teléfono. Qué se guarda y dónde:
[seguridad de Telegram](./tg/security.md) · [seguridad de MAX](./max/security.md).

## Siguiente paso: pregunta a tu agente

La configuración ya enseñó los comandos a tu agente. Abre tu agente y pega:

```text prompt
Resume mis mensajes sin leer por chat y dime quién necesita una respuesta. Solo lectura: no envíes nada.
```

Después sigue con [las primeras tareas](./first-tasks.md). Si tu agente no conoce el comando `tg`
o `max`, consulta [Conectar tu agente](./agents.md).

## Solución de problemas

<a id="what-the-windows-installer-changes" />

### Qué cambia el instalador de Windows

npm pone el comando `tg` o `max` en su carpeta global. Windows solo encuentra comandos en las
carpetas que aparecen en PATH, y npm no siempre añade allí su carpeta. El instalador:

- instala el paquete npm;
- añade la carpeta de npm a tu PATH de usuario, conserva las entradas existentes y actualiza el
  PowerShell abierto;
- enseña los comandos a tus agentes (`-Agent codex|cursor|claude|gemini|all|none`, por defecto `all`);
- comprueba que `tg` o `max` se ejecuta por su nombre.

No cambia la política de ejecución de PowerShell. Un agente que ya estaba abierto cuando hiciste la
instalación debe reiniciarse, o actualizar su propio PATH, antes de poder encontrar el comando.

<Accordion title="Instalar sin el instalador de Windows">

```powershell

```

Si después no encuentra `tg`, ejecuta `npm.cmd prefix -g`, añade esa carpeta a tu PATH de usuario
y abre una terminal nueva. Para MAX, usa `max-cli` y `max`.
