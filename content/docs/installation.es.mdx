Los cli de Telegram y MAX se instalan con npm y funcionan en **Windows, macOS y Linux**.
Pide a un <DocTerm term="local-agent" lang="es" label="agente local" /> ayuda para instalar e iniciar sesión, o ejecuta los comandos en la terminal.

## 1. Elige el mensajero

Abre **Telegram** o **MAX** y copia el prompt a tu agente.

<InstallationGuide />

## 2. Inicia sesión en tu ordenador

Abre la guía de tu mensajero. Ten el teléfono a mano: tú autorizas el acceso a la cuenta y el agente te ayuda con los pasos.

- **[Iniciar sesión en Telegram](./tg/sessions.md)** — el cli obtiene primero las <DocTerm term="telegram-app" lang="es" label="credenciales de aplicación de Telegram" />; después confirmas el acceso con un QR o un código de Telegram. La guía explica ambos pasos, [my.telegram.org](https://my.telegram.org/apps) y cómo escanear el QR.
- **[Iniciar sesión en MAX](./max/sessions.md)** — escanea el QR en la aplicación MAX del teléfono y confirma la conexión. Los bots usan una [conexión por token](./max/bot.md) aparte.

Reserva unos cinco minutos para la configuración. Introduce los códigos y contraseñas en tu terminal local cuando el cli los pida. La descarga del historial es un paso aparte después de iniciar sesión.

## 3. Conecta tu agente y prueba una primera tarea

Un <DocTerm term="skill" lang="es" label="skill" /> enseña al agente a usar el cli. La [guía de conexión](./agents.md) explica cómo comprobar su instalación y conectar tu agente. Para Claude Desktop, usa [MCP](./mcp.md).

Prueba esta petición:

```text prompt
Revisa los mensajes sin leer por chat y dime quién necesita una respuesta.
```

[Primeras tareas](./first-tasks.md) incluye buscar acuerdos, preparar una llamada y redactar respuestas.

## Instalar en una terminal

Necesitas **Node.js 22.16+ (rama 22.x) o 24+** con npm. Si falta, [instala Node.js](https://nodejs.org/en/download) y abre una terminal nueva.

### Telegram

```sh
npm install -g @leemour/tg-cli
tg setup
```

### Comandos MAX

```sh
npm install -g @leemour/max-cli
max setup
```

`setup` guía el acceso y ofrece conectar un skill para tu agente.
Tras la configuración, ejecuta `tg doctor` o `max doctor` y sigue los pasos sugeridos.

### Windows

La referencia de cada cli explica problemas al ejecutar comandos, actualizaciones y ubicación de archivos: [instalación de Telegram](./tg/installation.md) e [instalación de MAX](./max/installation.md). También incluye ayuda para Windows si el comando no funciona después de instalarlo.
