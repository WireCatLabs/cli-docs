Подключите информацию, с которой должен работать ИИ-агент: переписку, заметки, почту, документы
или встречи. Выберите один инструмент ниже, установите его там, где агент сможет его запускать,
и проверьте небольшой результат. Для локальных файлов или скачанной расшифровки встречи аккаунт
мессенджера не нужен.

Всё уже установлено и подключено? [Подключите агента](./agents.mdx) и
[попробуйте первую задачу](./index.mdx#попробуйте-запрос). При пустом поиске сначала проверяют
доступные данные, а не переустанавливают инструмент.

Не хотите работать в терминале? [WireCat Desktop](/ru/download) — приложение для macOS, Windows и
Linux. Оно устанавливает и обновляет эти инструменты, ставит Node.js, если его нет, даёт агентам навыки
инструментов и открывает вход в аккаунт для каждого. [Что умеет приложение](./desktop/index.mdx).

учётных данных для всех инструментов нет.

## Настройте с помощью агента

Используйте <DocTerm term="local-agent" lang="ru" label="ИИ-агента" /> с доступом к терминалу на этом компьютере: например Claude Code, Codex, Cursor
или Gemini CLI. Назовите выбранный инструмент и источник, затем скопируйте запрос:

```text prompt
Помоги настроить выбранный инструмент WireCat по его инструкции. Сначала проверь Node.js и npm.
Подключи только выбранный аккаунт или папку; вход я подтвержу сам.
Установи инструкции для моего агента и подготовь немного данных.
Проверь один вопрос только для чтения, покажи источник и укажи, каких данных не хватает.
Объясни, где хранятся данные и как остановить запущенные фоновые процессы.
```

Агент подготовит программы и объяснит следующий шаг. Вы разрешаете доступ через вход самого
сервиса. Если вход запускает агент, он вставляет QR-код или ссылку для входа вам в чат: см.
[если вход запускает агент](./agents.mdx#agent-login). Действия с браузером или токеном бота описаны
в инструкции инструмента; пароли, токены и данные обратного вызова авторизации не отправляют в
обычный чат с агентом.

Для агента без терминала используйте [MCP](./mcp.mdx) или [доступ из браузера и с телефона](./browser-apps.mdx).
Инструмент всё равно должен работать на компьютере под вашим управлением.

## Настройте вручную

1. **Выберите компьютер.** Проще начать на своём компьютере с Windows, macOS или Linux. Сервер
   удобен для регулярной работы, но сеансы и файлы будут на нём. Папка ноутбука не появляется
   на сервере автоматически. Два компьютера сразу не нужны.
2. **Проверьте среду запуска** командами ниже. Затем выполните команду установки из инструкции
   выбранного инструмента. Инструмент командной строки, или CLI, — программа, которую агент
   запускает через терминал.
3. **Подключите источник.** Следуйте шагам входа или импорта файлов. Установка пакета не даёт
   доступ к аккаунту; вход также не загружает все его данные.
4. **Подключите агента.** [Установите skill или настройте MCP](./agents.mdx). Skill даёт инструкции
   агенту с терминалом; MCP открывает возможности инструмента совместимому агенту.
5. **Подготовьте первые данные и проверьте их.** Воспользуйтесь проверками ниже, прежде чем добавлять источники.

## Node.js, npm и доступность команды

<DocTerm term="nodejs" lang="ru" label="Node.js" /> запускает инструменты, npm устанавливает их.
Поддерживаются **22.16+ в ветке 22.x или 24+**; для tg в ветке 22.x нужен **22.19+**. Другие
варианты среды смотрите в инструкции выбранного инструмента. В терминале или PowerShell выполните:

```sh
node --version
npm --version
```

Если команды нет или версия устарела, попросите агента подготовить среду:

<NodeSetupPrompt lang="ru" />

После установки проверьте версию инструмента **в той же среде, где работает агент**. Глобальная
установка добавляет команды в PATH — список папок, где терминал ищет программы. Откройте терминал
заново или перезапустите уже работающего агента, если он не находит новую команду.

<a id="npm-install-scripts" />

### Предупреждение npm о скриптах установки

npm 11.17 и новее после первой глобальной установки `tg`, `max` или `memo` пишет
`install scripts not yet covered by allowScripts`. В нём названы скрипт настройки самого инструмента
и драйвер базы данных. В npm 11 оба скрипта всё равно выполняются и инструмент работает, поэтому
предупреждение можно не учитывать. npm 12 их блокирует. Выполните команду
`npm install -g --allow-scripts=…`, которую npm печатает под предупреждением: она разрешает только
названные пакеты и только один раз.

<a id="what-the-windows-installer-changes" />

### Windows и доступность команды

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd`. Может понадобиться и `.cmd`-команда
самого инструмента; смотрите его инструкцию для Windows. У Telegram и MAX также есть установщик,
который настраивает PATH и инструкции агента. Не считайте, что он подходит для любого инструмента.
Следуйте шагам для [Telegram](./tg/installation.md), [MAX](./max/installation.md),
[Drive](./drive/installation.md) или [Zoom](./zm/installation.md).

## Проверьте первый полезный результат

Попросите агента проверить выбранный аккаунт или папку, загрузить небольшой период либо
импортировать небольшую папку и ответить на один вопрос с источником:

- **Переписка:** показать несколько чатов, загрузить нужный период и найти известное сообщение.
  [История Telegram](./tg/archive.md) · [история MAX](./max/archive.md).
- **Файлы или почта:** импортировать выбранную папку или настроенный почтовый ящик и найти знакомую фразу.
  [Memo](./memo/index.md) · [почта](./email.mdx).
- **Drive:** импортировать одну выбранную папку и открыть документ из результата.
  [Первый импорт Drive](./drive/usage.md).
- **Встречи:** получить или импортировать одну расшифровку и прочитать фрагмент со ссылкой.
  [Первый результат Zoom](./zm/installation.md#check-your-first-result).

Успех — команда доступна, подключён нужный источник, сохранены полезные данные и агент может
на них сослаться. При пустом ответе проверьте даты и отсутствующие или непрочитанные файлы.
Сам по себе вход, установка skill или подключение MCP этого не подтверждает.

## Данные, обновления и фоновая работа

Сеансы и локальные данные остаются там, где работает инструмент. Агент может передавать прочитанные
материалы своему провайдеру ИИ согласно настройкам. Прежде чем разрешать изменения, изучите
[безопасность и движение данных](./security.mdx) и [разрешения](./permissions.mdx).

Установка не запускает постоянную синхронизацию или автоответы. Регулярным задачам нужен работающий
процесс или расписание; попросите агента объяснить, как остановить всё запущенное. Закрытие чата
не обязательно останавливает отдельный процесс. См. [регулярные задачи](./prompting.mdx#recurring-tasks).

Обновление и удаление описаны в инструкции выбранного инструмента. Удаление пакета, локальных
данных и отзыв доступа к аккаунту — разные действия. Когда первая проверка пройдёт,
[выберите следующую задачу](./index.mdx#попробуйте-запрос).
