Три шага, около пяти минут: **установите** CLI, **войдите** с телефона, **проверьте**, что всё работает.

Вам понадобятся:

- компьютер с Windows, macOS или Linux;
- телефон, на котором открыт Telegram или MAX с аккаунтом, который вы хотите подключить.

Выберите систему и мессенджер на вкладках ниже. Страница запомнит ваш выбор.

### Войдите с телефона

Вход добавляет ваш компьютер в аккаунт как новое устройство — так же, как Telegram Desktop или
веб-версия MAX. Телефон подтверждает вход. CLI задаёт вопросы в окне терминала, поэтому даже
когда настройку ведёт агент, обычно он просит вас запустить эту команду и ответить на вопросы самим.

<Tabs groupId="messenger" persist items={["Telegram", "MAX"]}>
<Tab value="Telegram">

```sh
tg setup
```

Терминал спросит, по порядку:

1. **Номер телефона** — в международном формате, например `+34600111222`.
2. **Код от Telegram для my.telegram.org** — Telegram присылает его сообщением в приложение Telegram
   (в чат *Telegram*), а не по SMS. Введите его в терминале. С этим кодом CLI сам регистрируется
   в Telegram; это нужно только при первом входе.

   <Screenshot src="/screenshots/telegram/code-message.jpg" alt="приложение Telegram с сообщением, в котором код входа на my.telegram.org" width={360} />

3. **QR-код** — терминал показывает QR-код. На телефоне откройте
   **Настройки → Устройства → Подключить устройство** и отсканируйте код этим сканером (не приложением камеры).

   <Screenshot alt="терминал с QR-кодом для входа в Telegram" />
   <Screenshot src="/screenshots/telegram/add-device.jpg" alt="Telegram на телефоне: Настройки → Устройства, кнопка подключения устройства" width={360} />

4. **Облачный пароль** — только если вы задали его в Telegram. Символы при вводе не видны.
5. **Какой агент вы используете** — настройка научит его командам. Затем она покажет
   `Logged in as <your name>` и проверит пять ваших чатов.

<Accordions>
<Accordion title="Зачем Telegram нужен код для my.telegram.org?">

Telegram требует, чтобы каждая программа, которая подключается к аккаунту, сначала была
зарегистрирована. Регистрация даёт программе два значения: <DocTerm term="telegram-app" lang="ru" label="app ID и app hash" />. Они только
обозначают программу; сами по себе они не дают доступа к вашим сообщениям. Telegram разрешает одну
регистрацию на номер телефона, поэтому если она у вас уже есть, CLI использует её.

Код на шаге 2 позволяет CLI заполнить за вас форму регистрации на
[my.telegram.org](https://my.telegram.org). Сам вход — это сканирование QR-кода на шаге 3.

</Accordion>
<Accordion title="Зачем сканировать QR-код?">

QR-код подключает CLI к вашему аккаунту как новое устройство, как Telegram Desktop. Телефон
подтверждает, что это вы. Если включена двухэтапная проверка, терминал также попросит её пароль. После входа CLI появится в
**Настройки → Устройства**, где вы можете в любой момент завершить его сеанс.

</Accordion>

### Проверьте, что всё работает

Настройка проверяет это сама, и агент, который ставил CLI, тоже. Запустите команду сами, если
агент пишет, что не находит команду, ваши чаты или сообщения:

<Tabs groupId="messenger" persist items={["Telegram", "MAX"]}>
<Tab value="Telegram">

```sh
tg chats list --limit 5
```

</Tab>
<Tab value="MAX">

```sh
max chats list --limit 5
```

</Tab>
</Tabs>

Вы увидите пять последних чатов.

- **«Не выполнен вход»** — запустите настройку ещё раз.
- **Команда не найдена** — откройте новый терминал или перезапустите агента; на Windows смотрите,
  [что меняет установщик](#what-the-windows-installer-changes).
- **Нет нужного чата или старых сообщений** — вход не скачивает историю. Попросите агента сначала
  загрузить историю этого чата.

## Что CLI и агент могут делать после входа

Вход даёт CLI **тот же доступ, что у вас в приложении**: читать чаты, отправлять, править и удалять
сообщения, управлять группами и контактами. Агент получает этот доступ, когда запускает команды
`tg` или `max`.

- **Он действует, только когда этого требует команда.** Чтение не отмечает сообщения прочитанными,
  и ничего не отправляется, если команда этого не делает.
- **По умолчанию отправка разрешена**, до 30 сообщений в час. Удаление сообщений требует
  дополнительного подтверждения.
- **Вы решаете, что можно агенту.** У каждого подключения аккаунта (*профиля*) свои правила:

| Вы хотите | Что настроить | Подробнее |
|---|---|---|
| Агент только читает и ничего не меняет | профиль только для чтения | [Telegram](./tg/configuration.md#what-a-profile-may-do) · [MAX](./max/security.md#защита-от-отправки-не-туда) |
| Вопрос перед каждой отправкой | уровень `ask` для отправки | [Telegram](./tg/configuration.md#a-question-before-a-change) |
| Отправка только в выбранные вами чаты | список адресатов | [Telegram](./tg/security.md#the-send-guard) · [MAX](./max/security.md#защита-от-отправки-не-туда) |
| Меньше сообщений в час | `sendsPerHour` | [Telegram](./tg/security.md#the-send-guard) · [MAX](./max/security.md#защита-от-отправки-не-туда) |

Эти правила останавливают агента, которого обмануло прочитанное сообщение. Они не останавливают
агента, который может сам поменять настройки: настройки — это обычные файлы и команды на вашем
компьютере. Для этого привяжите агента к одному профилю через `TG_PROFILE_LOCK` или
`MAX_PROFILE_LOCK` и не давайте ему запускать команды `config` и `recipients`.
[Чего не удержат ограничения](./tg/security.md#what-the-guard-cannot-hold).

**Вход сохраняется на этом компьютере.** Относитесь к сохранённой сессии как к паролю: кто её
скопирует, может пользоваться вашим аккаунтом. Чтобы выйти, выполните `tg session end` или
`max session end`, или завершите сеанс устройства в **Настройки → Устройства** на телефоне. Что где
хранится: [безопасность Telegram](./tg/security.md) · [безопасность MAX](./max/security.md).

## Дальше: спросите агента

Настройка уже научила агента командам. Откройте агента и вставьте:

```text prompt
Кратко перескажи мои непрочитанные сообщения по чатам и скажи, кому нужно ответить. Только читай: ничего не отправляй.
```

Затем переходите к [первым задачам](./first-tasks.md). Если агент не знает команду `tg` или `max`,
смотрите [подключение агента](./agents.md).

## Решение проблем

### Что меняет установщик Windows

Команды npm выше разрешают установочные скрипты пакетов. Они добавляют папку npm-команд в пользовательский PATH Windows, сохраняют прежние записи, оставляют рабочую обёртку `.cmd` и устанавливают skill для агента. Новый терминал находит `tg` или `max` по имени.

Уже открытый терминал или агент должен обновить своё окружение: дочерний процесс npm не может изменить PATH родительского процесса. Агент должен сделать это сам, не прося вас редактировать PATH. Политика выполнения PowerShell не меняется.

<Accordions>
<Accordion title="npm пропустил установочный скрипт или команда не находится">

Следуйте восстановлению из инструкции пакета: [установка Telegram](./tg/installation.md) или [установка MAX](./max/installation.md). Оно использует файлы установленного пакета и сохраняет прежние записи PATH.

Необязательный установщик PowerShell также обновляет запустивший его терминал, даже если npm пропускает скрипты пакетов. Для Telegram:

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://wirecat.dev/install.ps1'))) -Tool tg -Agent all
```

Для MAX укажите `-Tool max`. До входа агент должен прочитать `tg skill show` или `max skill show` и проверить, что установленный skill загружен.
