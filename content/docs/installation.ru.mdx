Работает на **Windows, macOS и Linux**. Попросите своего агента установить CLI —
он поможет настроить всё необходимое. Если предпочитаете делать это самостоятельно,
откройте инструкции для терминала.

## 1. Выберите мессенджер

Раскройте **Telegram** или **MAX** ниже и скопируйте запрос своему локальному агенту.
Он подходит для Codex, Cursor, Claude Code, Gemini CLI и Hermes. Для самостоятельной
установки откройте **Установить в терминале** внутри выбранного мессенджера.

<InstallationGuide />

На установку и вход заложите около пяти минут. Скачивание истории — отдельный шаг: после
настройки выберите нужные чаты и объём сообщений.

## 2. Войдите на своём компьютере

Коды входа и пароли вводите в локальном терминале, когда CLI их запросит.

**Telegram:** `--app auto` получает ID и hash приложения Telegram, затем запускает вход по QR.
Отсканируйте его в Telegram: Настройки → Устройства → Подключить устройство. Если шаг
с приложением не прошёл, выполните `tg session start --app browser` и следуйте подсказкам.
Другие способы входа и профили описаны в [сессиях Telegram](./tg/sessions.md).

**MAX:** отсканируйте QR в приложении MAX и следуйте подсказкам терминала.
Если нужен бот, используйте [руководство по ботам MAX](./max/bot.md).
Другие способы входа — в [сессиях MAX](./max/sessions.md).

`account show` должен показать ваш аккаунт. До входа `doctor` может сообщать об отсутствии
сессии; запустите его ещё раз после входа. Список чатов подтверждает связь с мессенджером.

## 3. Подключите агента

В [подключении агента](./agents.md) есть инструкции для всех пяти вариантов. Для Claude Desktop
или подключения по MCP перейдите в [MCP и документацию](./mcp.md).

Первый запрос: **«Разбери непрочитанные сообщения по чатам и скажи, кому нужно ответить».**
В CLI это `tg inbox --limit 5` или `max inbox --limit 5`.

## Команды для терминала

Для самостоятельной установки нужен **Node.js 22.16 или новее** с npm.
[Скачайте Node.js](https://nodejs.org/en/download), откройте новый терминал и проверьте версии:

```sh
node --version
```

```sh
npm --version
```

### Telegram

Установка:

```sh
npm install -g @leemour/tg-cli
```

Версия:

```sh
tg --version
```

Диагностика:

```sh
tg doctor
```

Вход:

```sh
tg session start --app auto
```

Аккаунт:

```sh
tg account show
```

Первые пять чатов:

```sh
tg chats list --limit 5
```

### MAX

Установка:

```sh
npm install -g @leemour/max-cli
```

Версия:

```sh
max --version
```

Диагностика:

```sh
max doctor
```

Вход:

```sh
max session start qr
```

Аккаунт:

```sh
max account show
```

Первые пять чатов:

```sh
max chats list --limit 5
```

### Windows

Если PowerShell блокирует `npm.ps1`, вызывайте `npm.cmd`, а установленную команду — через
`tg.cmd` или `max.cmd`. Если команда не находится на PATH, можно запустить пакет без изменения PATH:

```powershell
npm.cmd exec --yes --package=@leemour/tg-cli -- tg doctor
```

```powershell
npm.cmd exec --yes --package=@leemour/max-cli -- max doctor
```

С тем же префиксом запускайте `session start` и другие команды, пока исправляете PATH.
Для MCP нужна постоянная установка: `mcp config` не использует временный путь npm cache.
