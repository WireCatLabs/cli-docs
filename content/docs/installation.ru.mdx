CLI для Telegram и MAX устанавливаются как npm-пакеты и работают на **Windows, macOS и Linux**.
Попросите локального агента проверить компьютер, установить CLI и помочь подключить аккаунт —
либо выполните установку в терминале. После входа проверьте свой аккаунт и первые чаты,
затем дайте агенту полезную задачу.

## 1. Выберите мессенджер

Раскройте **Telegram** или **MAX** ниже и скопируйте запрос своему локальному агенту.
Он подходит для Codex, Cursor, Claude Code, Gemini CLI и Hermes. Для самостоятельной
установки откройте **Установить в терминале** внутри выбранного мессенджера.

<InstallationGuide />

На установку и вход заложите около пяти минут. Скачивание истории — отдельный шаг: после
настройки выберите нужные чаты и объём сообщений.

## 2. Войдите на своём компьютере

Коды входа и пароли вводите в локальном терминале, когда CLI их запросит.

### Telegram

1. Запустите в локальном терминале:

   ```sh
   tg setup --agent all
   ```

2. При первом входе CLI получит данные приложения Telegram. Введите номер и код, пришедший в Telegram, когда терминал их запросит.
3. На телефоне выберите нужный аккаунт Telegram. Откройте Настройки → Устройства → Подключить устройство и отсканируйте QR-код с компьютера.
4. Если включён облачный пароль, введите его по запросу терминала. Затем настройка проверит аккаунт и пять чатов и установит навыки агентов. Существующий вход используется повторно; историю скачивают отдельно. Для одного только входа используйте `tg session start --app auto`.

Если автоматическая регистрация не прошла, используйте:

```sh
tg session start --app browser
```

[Подробная инструкция входа в Telegram](./tg/sessions.md) объясняет данные приложения, QR и вход по телефону.

### MAX

1. Запустите:

   ```sh
   max setup --agent all
   ```

2. На телефоне откройте MAX → Настройки → Устройства. Отсканируйте QR-код с компьютера и подтвердите подключение.
3. Следуйте подсказкам терминала. Настройка проверит аккаунт и пять чатов, установит навыки агентов и повторно использует существующий вход. История целиком не скачивается, фоновый сервис не запускается. Для одного только входа используйте `max session start qr`.

Другие способы описаны в [инструкции входа в MAX](./max/sessions.md). Для бота откройте [руководство по ботам](./max/bot.md).

### Проверьте подключение

Выполните команду для своего мессенджера:

```sh
tg account show
```

```sh
max account show
```

В ответе должен быть ваш аккаунт. Диагностика до входа может сообщать об отсутствии сессии — это ожидаемо. После входа повторите проверку и откройте список чатов.

## 3. Подключите агента

В [подключении агента](./agents.md) есть инструкции для всех пяти вариантов. Для Claude Desktop
или подключения по MCP перейдите в [MCP и документацию](./mcp.md).

```text prompt
Разбери непрочитанные сообщения по чатам и скажи, кому нужно ответить.
```
В CLI это `tg inbox --limit 5` или `max inbox --limit 5`.

Продолжите с [первыми задачами](./first-tasks.md): поиск договорённости, контекст к созвону
и подготовка ответа. В [запросах агенту](./prompting.md) есть копируемые примеры и полезные ограничения.

## Команды для терминала

Для самостоятельной установки нужен **Node.js 22.16 или новее** с npm.
[Скачайте Node.js](https://nodejs.org/en/download), откройте новый терминал и проверьте версии:

```sh
node --version
```

```sh
npm --version
```

### Telegram

Установка:

```sh
npm install -g @leemour/tg-cli
```

Версия:

```sh
tg --version
```

Диагностика:

```sh
tg doctor
```

Вход:

```sh
tg setup --agent all
```

Аккаунт:

```sh
tg account show
```

Первые пять чатов:

```sh
tg chats list --limit 5
```

### MAX

Установка:

```sh
npm install -g @leemour/max-cli
```

Версия:

```sh
max --version
```

Диагностика:

```sh
max doctor
```

Вход:

```sh
max setup --agent all
```

Аккаунт:

```sh
max account show
```

Первые пять чатов:

```sh
max chats list --limit 5
```

### Windows

Выполните одну команду PowerShell для своего мессенджера:

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://wirecat.dev/install.ps1'))) -Tool tg -Agent all
```

```powershell
& ([scriptblock]::Create((Invoke-RestMethod 'https://wirecat.dev/install.ps1'))) -Tool max -Agent all
```

Установщик ставит npm-пакет, сохраняет прежние записи PATH пользователя, обновляет текущий
PowerShell, устанавливает навык агента и проверяет запуск `tg` или `max` по имени.
Редактировать PATH вручную не нужно. Это работает и при отключённых install scripts npm.
Установщик оставляет `.cmd` и удаляет только созданный npm PowerShell shim этого пакета;
политика выполнения не меняется. `-Agent codex|cursor|claude|gemini|all|none` выбирает навык;
по умолчанию — `all`. Уже запущенный агент сам обновляет окружение своего терминала перед
следующими командами. При входе код или QR по-прежнему подтверждает владелец локально.
