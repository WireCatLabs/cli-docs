cli для Telegram и MAX устанавливаются через npm и работают на **Windows, macOS и Linux**.
Попросите <DocTerm term="local-agent" lang="ru" label="локального агента" /> помочь с установкой и входом или выполните команды в терминале самостоятельно.

## 1. Выберите мессенджер

Раскройте **Telegram** или **MAX** и скопируйте промпт агенту.

<InstallationGuide />

## 2. Войдите на своём компьютере

Откройте инструкцию для своего мессенджера. Держите телефон под рукой: доступ к аккаунту подтверждаете вы, а агент помогает пройти шаги.

- **[Вход в Telegram](./tg/sessions.md)** — сначала cli получает <DocTerm term="telegram-app" lang="ru" label="данные приложения Telegram" />, затем вы подтверждаете вход QR-кодом или кодом из Telegram. В инструкции объяснены оба этапа, сайт [my.telegram.org](https://my.telegram.org/apps) и сканирование QR.
- **[Вход в MAX](./max/sessions.md)** — отсканируйте QR-код в приложении MAX на телефоне и подтвердите подключение. Для бота используется отдельное [подключение по токену](./max/bot.md).

На настройку заложите около пяти минут. Коды и пароли вводите в локальном терминале, когда cli их запросит. Скачивание истории чатов — отдельный шаг после входа.

## 3. Подключите агента и попробуйте первую задачу

<DocTerm term="skill" lang="ru" label="Skill" /> помогает агенту пользоваться cli. Как проверить его установку и подключить свой агент, описано в [инструкции подключения](./agents.md). Для Claude Desktop используйте [MCP](./mcp.md).

Попробуйте такой запрос:

```text prompt
Разбери непрочитанные сообщения по чатам и скажи, кому нужно ответить.
```

В [первых задачах](./first-tasks.md) есть поиск договорённостей, подготовка к созвону и помощь с ответом.

## Установка в терминале

Нужен **Node.js 22.16+ (ветка 22.x) или 24+** с npm. Если его нет, [установите Node.js](https://nodejs.org/en/download) и откройте новый терминал.

### Telegram

```sh
npm install -g @leemour/tg-cli
tg setup
```

### Команды MAX

```sh
npm install -g @leemour/max-cli
max setup
```

`setup` проведёт через вход и предложит подключить skill для вашего агента.
После настройки выполните `tg doctor` или `max doctor` и следуйте предложенным шагам.

### Windows

Проблемы с запуском команды, обновление и расположение файлов описаны в справке cli: [установка Telegram](./tg/installation.md) и [установка MAX](./max/installation.md). Там же есть особенности Windows и инструкции, если команда после установки не запускается.
