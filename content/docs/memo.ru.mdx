Memo помогает агенту находить сведения в файлах, заметках, письмах и сообщениях.
Используйте эту инструкцию, когда нужно найти прошлое решение или собрать контекст перед
разговором. Здесь описано, как установить Memo, выбрать источники и проверить найденное.

После чтения вы сможете:

- подключить папку текстовых файлов или хранилище Obsidian и искать по их содержимому;
- добавить почту и использовать её вместе со скачанной историей мессенджеров;
- попросить агента собрать справку с источниками и распознать недостающие данные.

## Перед началом

Используйте <DocTerm term="local-agent" lang="ru" label="локального ИИ-агента" /> на компьютере,
где хранятся файлы. Можно начать с одной папки заметок. Почта и история мессенджеров
необязательны; для сообщений [подключите Telegram или MAX](./installation.mdx) и скачайте
нужную историю. Memo читает эту локальную историю, но сам её не скачивает.

## Установите Memo

**Самый простой способ — попросить агента.** Скопируйте запрос в Claude Code, Codex, Cursor,
Gemini CLI или Hermes, как при установке Telegram или MAX:

```text prompt
Помоги установить Memo на этот компьютер командой npm install -g @leemour/cli-memo.
Сначала проверь Node.js и npm и помоги установить их, если нужно.
Прочитай memo --help и https://wirecat.dev/ru/docs/memo, чтобы узнать команды.
Проверь, что memo --help работает в твоём терминале, затем помоги подключить выбранную мной папку.
```

Агент устанавливает <DocTerm term="cli" lang="ru" label="CLI" /> и проверяет команду `memo`.
В самом Memo нет шага входа в мессенджер: папки вы выбираете, а почту настраиваете отдельно.

## Добавьте заметки

### Выберите папку

Папка — это каталог на компьютере, в котором лежат файлы. Memo читает выбранную папку
**и её подпапки**: это может быть обычная папка проекта, папка заметок или хранилище Obsidian.
Можно подключить несколько папок.

<DocTerm term="vault" lang="ru" label="Хранилище Obsidian (vault)" /> — обычная папка заметок,
которую Obsidian открывает как одно рабочее пространство. Заметки в ней — файлы
<DocTerm term="markdown" lang="ru" label="Markdown" />; Memo читает их напрямую, и держать
Obsidian открытым не нужно. Для работы с Memo пользоваться Obsidian необязательно.

### Какие файлы читает Memo

| Файлы | Распространённые расширения | Что ожидать |
| --- | --- | --- |
| Текст и заметки Markdown | `.txt`, `.md`, `.markdown` | Читаемый текст, включая заметки Obsidian. |
| Таблицы | `.csv`, `.tsv`, `.xlsx`, `.ods` | Текст и значения ячеек, с указанием места в источнике, где доступно. |
| Документы, презентации и книги | `.odt`, `.pptx`, `.epub` | Извлечённый читаемый текст, без исходного оформления. |
| PDF и документы Word | `.pdf`, `.docx` | Нужны дополнительные средства чтения: `unpdf` для PDF и `mammoth` для DOCX. |

Сканированный PDF содержит изображения страниц: перед импортом нужно распознать текст.
Старые `.doc` и `.xls` не поддерживаются; преобразуйте их в поддерживаемый формат.
Импорт сообщает о нечитаемых файлах и недостающих средствах чтения, а не считает их проверенными.

### Импортируйте выбранную папку

Замените `/path/to/notes` полным путём к **существующей папке** на компьютере.
Для обычной папки выберите формат Markdown:

```sh
memo folders add /path/to/notes --format markdown
memo notes import --no-embed
```

Для хранилища Obsidian замените `/path/to/vault` путём к его папке и выберите формат Obsidian:

```sh
memo folders add /path/to/vault --format obsidian
memo notes import --no-embed
```

Формат определяет, как Memo понимает ссылки и теги заметок. Markdown использует ссылки
вроде `[label](other-note.md)`; Obsidian также понимает `[[Note]]`. Если не указать `--format`,
используется Obsidian.

Регистрация выводит ID папки. Импорт копирует читаемое содержимое в локальное хранилище,
не меняя исходные файлы. Скрытые папки, например `.obsidian`, пропускаются.
`--no-embed` оставляет для первого импорта поиск по словам: для начала модель поиска не нужна.
Повторяйте `memo notes import --no-embed` после изменения или добавления файлов.

### Найдите сведения в файлах

Скажите агенту, какую тему нужно найти:

```text prompt
Используй Memo, чтобы найти заметки и файлы о бюджете в импортированных папках.
Покажи совпавший текст и исходный файл для каждого полезного результата. Скажи, какие файлы не удалось прочитать.
```

Для поиска вручную:

```sh
memo notes search 'budget' --json
```

В результатах указаны найденный файл, ссылка на источник и первая совпавшая строка.
Откройте файл, чтобы проверить сведения. Если ничего не найдено, попробуйте слово, которое
точно есть в одном из файлов, и изучите отчёт импорта: неимпортированный файл не попадёт в поиск.

## Добавьте почту

Memo читает почту через [Himalaya](https://github.com/pimalaya/himalaya) — отдельную почтовую
программу. Аккаунт настраивается в ней; Memo использует его имя и адрес, и ему не нужна
отдельная копия пароля от почты. Попросите агента помочь:

```text prompt
Помоги подключить выбранный мной почтовый аккаунт через Himalaya и добавить его в Memo.
Объясни настройку аккаунта, затем импортируй письма с выбранной мной даты.
Покажи результат импорта и скажи, нужен ли ещё один запуск, чтобы закончить этот период.
```

Перед импортом в Memo аккаунт должен работать в Himalaya. Для настройки вручную:

Добавьте `mail.accounts` в конфигурацию Memo, сохранив остальные настройки. Пути к файлу по умолчанию:

| OS | Файл конфигурации |
| --- | --- |
| Linux | `~/.config/cli-memo/config.json` |
| macOS | `~/Library/Preferences/cli-memo/config.json` |
| Windows | `%APPDATA%\cli-memo\Config\config.json` |

`MEMO_CONFIG_DIR` переопределяет папку; в Linux на путь по умолчанию также влияет `XDG_CONFIG_HOME`.
В примере аккаунт Himalaya называется `gmail`; замените имя и адрес своими.

```json
{
  "mail": {
    "accounts": [{ "name": "gmail", "address": "you@example.com" }]
  }
}
```

По умолчанию используется Gmail и импортируется All Mail. Для другого IMAP-провайдера
добавьте в запись аккаунта `"mode": "imap"` и `"folders": ["INBOX", "Archive"]`, указав
настоящие имена папок своего почтового ящика.

```sh
memo mail import --account gmail --since 2026-09-01 --json
```

Выберите начальную дату. По умолчанию за один запуск читается не более 200 новых писем.
Если результат сообщает о неполном импорте, повторите команду. Почтовый ящик используется
только для чтения: импорт не отправляет письма и не отмечает их прочитанными.
Импортированная почта хранится локально; повторный импорт может удалить из хранилища
текст писем, исчезнувших из источника.

Свяжите почтовый адрес с аккаунтом человека в мессенджере явно через `tg contacts link`
или `max contacts link`: совпадения имён недостаточно. Задачи с контактами описаны в
инструкции [о работе с людьми](./people.md).

## Попросите нужный контекст

Когда источники подключены, попросите контекст о человеке. Замените имя:

```text prompt
Используй Memo, чтобы собрать контекст о Rin Example перед встречей: последние сообщения,
письма, связанные заметки и открытые задачи. Добавь источники и скажи, каких данных не хватает.
```

Чтобы связать импортированную файловую заметку с человеком, замените имя и путь к файлу:

```sh
memo note telegram:"Rin Example" /path/to/notes/people/Rin.md
```

Файл уже должен быть импортирован. Имя в обычном тексте само по себе не создаёт связь:
укажите заметку явно или используйте поддерживаемую ссылку, например `[[Rin Example]]` в Obsidian.

Агент может собрать контекст о человеке или найти сведения в импортированных источниках:

```sh
memo context telegram:"Rin Example" --json
memo search 'budget' --all --json
```

`--all` явно включает все сохранённые аккаунты и импортированные заметки. Проверьте ссылки
на источники и охват данных, прежде чем полагаться на ответ. Недостающая история, письма
за пределами периода импорта и неразрешённые ссылки в заметках могут сделать результат
неполным. Добавьте `--account <id>` к `context`, если сохранено несколько аккаунтов
одного провайдера.

Можно также сохранить собственную заметку о человеке:

```sh
memo notes add 'Prefers morning meetings' --about telegram:'Rin Example'
memo notes list --about telegram:'Rin Example' --json
```

Эти заметки хранятся локально. Их создание не меняет импортированный файл;
`memo notes export` — отдельное явное действие для записи файлов.

## Проверьте результат

В полезном ответе указаны файлы, сообщения или письма, из которых взяты важные сведения.
Откройте источник, чтобы проверить договорённость или дату. Агент должен объяснить пробелы:
например, период почты ещё не импортирован, файл не прочитан или ссылка на человека не разрешена.
Отсутствие результата не доказывает, что договорённости не было.

## Если чего-то не хватает

- **Команда не найдена:** проверьте `memo --help` в терминале агента и откройте его заново после установки.
- **Заметки не найдены:** проверьте `memo folders list`, повторите `memo notes import --no-embed` и изучите результат импорта.
- **Нет почтового аккаунта:** проверьте, что `mail.accounts` ссылается на аккаунт, настроенный в Himalaya.
- **Не тот человек или неоднозначное имя:** укажите провайдера и точный ID; явно свяжите аккаунты.
- **Неполный контекст:** импортируйте нужные заметки и письма, а недостающую историю скачайте через tg или max.

Когда источники доступны, переходите к [подготовке к встрече](./meeting-brief.mdx).
Параметры команд можно посмотреть через `memo --help` или `--help` нужной подкоманды.
[Справка по командам Memo](https://github.com/leemour/cli-memo#readme)
также описывает задачи, связи, теги, локальные напоминания и подборки источников.
