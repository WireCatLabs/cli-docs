Договоры, отчеты и заметки лежат на Яндекс Диске, и ИИ-агент на вашем компьютере не может их прочитать, пока вы не
скачаете каждый файл и не вставите его в чат. Инструмент командной строки `ydisk` копирует на ваш компьютер текст
выбранных папок Диска. После этого агент находит файл, где упоминается бюджет, клиент или дата, цитирует его и
называет путь к файлу на Диске, даже без интернета. Когда нужно, тот же инструмент показывает, скачивает, загружает,
перемещает файлы на Диске и открывает к ним доступ по ссылке.

Для начала нужны Node.js 22.16 или новее в ветке 22.x либо 24 и новее и OAuth-токен Яндекса: ключ, с которым инструмент работает с вашим Диском.
Здесь вы узнаете, как устроена копия, как получить токен и как подключить первую папку.

<a id="how-it-works"></a>

## Как это устроено

- **Копия текста на вашем компьютере.** `ydisk` читает выбранные папки и сохраняет текст их файлов в локальном
  хранилище. Это один файл базы данных на вашем компьютере, общий для всех инструментов WireCat. Поиск читает эту
  копию, а не Диск.
- **Только выбранные папки.** Добавьте несколько папок, а не весь Диск. Яндекс Диск не сообщает, что изменилось,
  поэтому каждая синхронизация заново перечисляет все выбранные папки с вложенными и скачивает только измененные
  файлы.
- **Текст, а не копии файлов.** Инструмент читает Markdown, обычный текст, PDF с текстовым слоем, Word `.docx`, Excel
  `.xlsx`, CSV и TSV. Остальные файлы, например фото, сохраняются только по имени. Сами файлы остаются на Диске.
- **Профиль для каждого аккаунта.** Профиль - имя, которое вы даете одному аккаунту Яндекса, например `personal` или
  `work`. Каждая команда для аккаунта начинается с него: `ydisk personal search budget`.
- **Команды `files` меняют Диск.** Они работают с Яндексом напрямую. Удаление переносит файл в корзину Диска. В
  терминале инструмент спрашивает перед удалением, перезаписью или публичной ссылкой. По MCP спросить некого, поэтому
  для агента, которому это нельзя, поставьте этим правам `deny`.

<a id="install-and-sign-in"></a>

## Установка и вход

1. Установите инструмент из npm и проверьте его:

```sh
npm install -g @wirecat/yandex-disk-cli
ydisk --version
ydisk doctor
```

2. Получите токен. Яндекс выдает его приложению, которое вы регистрируете, а получить его можно по одной ссылке
   ([инструкция Яндекса](https://yandex.ru/dev/id/doc/ru/tokens/debug-token)):
   - Зарегистрируйте приложение на [oauth.yandex.ru](https://oauth.yandex.ru/client/new/). На шаге "Платформы
     приложения" укажите Redirect URI `https://oauth.yandex.ru/verification_code`.
   - Дайте ему доступы `cloud_api:disk.read`, `cloud_api:disk.info` и, чтобы менять файлы, `cloud_api:disk.write`.
   - Откройте `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>` с ClientID вашего
     приложения, нажмите "Разрешить" и скопируйте токен со страницы.

3. Войдите под именем профиля, которое выберете сами. Инструмент спросит токен скрытым вводом, проверит его у Яндекса и
   сохранит в системной связке ключей, а там, где ее нет, в закрытом файле.

```sh
ydisk personal session start
ydisk personal session status --check
```

Когда Яндекс перестанет принимать токен, снова выполните `session start` с новым токеном.

<a id="copy-a-folder-and-search-it"></a>

## Скопируйте папку и ищите по ней

`folders browse` показывает Диск по одному уровню, чтобы выбрать папку по ее пути:

```sh
ydisk personal folders browse
ydisk personal folders add /Documents
ydisk personal sync
ydisk personal search "quarterly budget"
```

Одна синхронизация проходит примерно до 10 000 элементов и запоминает, где остановилась. Запустите ее снова, чтобы
продолжить, а позже, чтобы получить изменения. `ydisk personal status` показывает последнюю синхронизацию и оставшуюся
работу. `documents show` выводит весь текст одного найденного файла.

<a id="connect-your-agent"></a>

## Подключите агента

Терминальный агент, например Claude Code, получает навык инструмента:

```sh
ydisk skill install
```

Дальше просите обычными словами:

```text prompt
Используй ydisk CLI с профилем personal. Найди в моих папках на Диске договор с Harbour Ltd.
Процитируй условия оплаты и назови путь к файлу на Диске. Ничего не меняй в файлах.
```

Сначала агент ищет в локальной копии. Файл вне выбранных папок он читает прямо с Диска. Приложение, которое
подключается к MCP-серверам, получает те же команды через `ydisk personal mcp serve`.

<a id="work-with-files-on-the-disk"></a>

## Работа с файлами на Диске

```sh
ydisk personal files list --folder /Documents
ydisk personal files download /Documents/plan.pdf --output ./plan.pdf
ydisk personal files upload ./notes.md --folder /Documents
ydisk personal files move /Documents/old.pdf --folder /Archive
ydisk personal files delete /Documents/old.pdf
ydisk personal files publish /Documents/plan.pdf
```

`files delete` переносит файл в корзину Диска, а `files restore` возвращает его. `files publish` создает ссылку,
которую может открыть любой, у кого она есть. В терминале инструмент спрашивает перед удалением, перезаписью с
`--replace` и публичной ссылкой. По MCP спросить некого, поэтому для агента, которому это нельзя, поставьте права
`files.delete=deny` и `files.share=deny`. `YDISK_READ_ONLY=1` запрещает любые изменения.

<a id="limits"></a>

## Ограничения

- В сканированных PDF и картинках нет текста для поиска.
- Выбранная папка, которую вы переименовали или перенесли на Диске, перестает синхронизироваться, и ее копии уходят из
  хранилища. Добавьте ее снова по новому пути.
- Вход только по вставленному токену. Входа через браузер пока нет.
