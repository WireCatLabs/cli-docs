Give your <DocTerm term="agent" lang="en" label="AI agent" /> access to the information you already
work with: chats, notes, email, documents or meeting transcripts. Ask what was agreed, who needs
an answer or what to prepare for a call. The agent uses connected sources and shows the passages
behind its answer. Start with one source; you do not need every tool.

## Get your first result

1. **[Choose where to install](./installation.mdx).** Use the computer or server where your agent
   can run the tools from a terminal (<DocTerm term="cli" lang="en" label="CLI" />). An agent can help with setup; the tool's guide also
   has manual steps. Login and app setup differ by source.
2. **[Connect your agent](./agents.mdx).** A <DocTerm term="skill" lang="en" label="skill" /> teaches a terminal agent the commands. <DocTerm term="mcp" lang="en" label="MCP" /> gives
   a compatible agent access to tools. Neither step imports history or authorizes an account.
3. **Prepare a small amount of data.** Follow the source guide to retrieve a chat period, import
   a folder or save one transcript. Confirm the account, folder and dates are the ones you chose.
4. **Ask one question and check its source.** Try a request below. If data is missing, the answer
   should say so; an empty search does not prove something was never discussed.

If you use an agent only in a browser or on a phone, follow [web and mobile access](./browser-apps.mdx).
The tool still runs on a computer you control.

## Try a request

For Telegram or MAX, start the request with **Use tg CLI** or **Use max CLI**, respectively:

```text prompt compact
Use tg CLI to find the delivery date agreed in the Atlas chat last week.
Show the supporting message and its surrounding context. Tell me if that period is missing.
```

For a meeting transcript you have already saved:

```text prompt compact
Use zm CLI to find the latest meeting about Research Example.
Show one supported decision and its cited passage, and list the information that is missing.
```

For notes or files you have imported into Memo:

```text prompt compact
Use memo CLI to find the project brief I imported.
Show the source and the agreed next step. Do not invent an answer if the files do not contain it.
```

A useful result includes the original source, enough context to check the conclusion and any
coverage limits. Once that works, try [first message tasks](./first-tasks.md),
[meeting context](./zoom.mdx) or [organizing sources](./organize.md).

## Decide what access to allow

The tools run where you install them and keep local data there. Your agent receives the content
it retrieves, and its own settings determine where that content is processed. Check
[security and data flow](./security.mdx) and [permissions](./permissions.mdx) before allowing writes
or background work. Reading, saving a note, drafting a reply and sending it are different actions.

Already connected? Go directly to [search](./search.md) or [meetings](./zoom.mdx); you do not need
to reinstall to try another question.
