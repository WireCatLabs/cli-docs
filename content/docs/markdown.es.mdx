Tus notas ya guardan tus planes, actas de reuniones y decisiones. Añade tu carpeta de notas o tu bóveda de Obsidian a
Memo, y tu agente de IA puede buscar en ellas en tu ordenador, junto a tus chats, correo y reuniones. Memo lee los
archivos y nunca los cambia.

Un agente con acceso a tus notas encuentra la nota donde se escribió una decisión, cita la línea y muestra las notas que
enlazan a ella. También puede escribir por ti una nota nueva sobre una persona o un proyecto, y volver a guardar tus
notas como archivos Markdown.

No hay una herramienta aparte para Markdown: `memo` lee carpetas de notas. Necesitas `memo` instalado
([instalación](./memo/installation.md)). No necesita cuenta ni inicio de sesión: tus notas ya están en tu ordenador.

## Versión corta

Los ejemplos usan la carpeta `~/Notes`, una carpeta de notas en tu carpeta personal. Usa la ruta de la tuya.

```sh
memo folders add ~/Notes
memo sync --only notes --no-embed
memo search notes 'budget'
```

El primer comando añade la carpeta y muestra su ID, por ejemplo `1`. La sincronización lee todos los archivos de la
carpeta y de sus subcarpetas, y dice cuántas notas encontró. La búsqueda muestra cada archivo que coincide y su primera
línea que coincide.

`--no-embed` omite la preparación para la búsqueda por significado, así que puedes empezar sin el modelo de búsqueda.
Deja de usar esa opción cuando tengas el modelo, y el agente también encontrará una nota por lo que significa.

O pídeselo a tu agente:

```text prompt
Usa memo CLI para añadir mi carpeta de notas ~/Notes e importarla.
Dime cuántas notas encontró y qué archivos no pudo leer.
```

## Carpeta Markdown o bóveda de Obsidian

Memo lee cualquier carpeta de archivos Markdown. Una bóveda de Obsidian es una carpeta de notas Markdown que Obsidian
abre como un solo espacio de trabajo. Memo averigua cuál tienes: una carpeta con la carpeta propia de Obsidian,
`.obsidian`, dentro de ella o en una carpeta superior, se lee como bóveda. No necesitas Obsidian para usar Memo, y
Obsidian no tiene que estar abierto.

Las dos se diferencian en cómo se escriben los enlaces y las etiquetas:

| | Carpeta Markdown | Bóveda de Obsidian |
|---|---|---|
| Enlaces a otras notas | `[label](other-note.md)` | `[[Other note]]` y `[[Other note\|label]]` |
| Etiquetas | el campo `tags:` al principio del archivo | el campo `tags:` y `#tags` en el texto |
| Otros nombres de una nota | | el campo `aliases:` |

Para elegir el formato tú mismo, añade `--format markdown` o `--format obsidian` a `memo folders add`. Memo omite las
carpetas ocultas como `.obsidian`.

## Qué te dice tu agente

Pregunta con tus propias palabras:

```text prompt
Usa memo CLI. Encuentra la nota donde decidimos el presupuesto de Harbour. Cita la línea con el nombre
del archivo y enumera las notas que enlazan a ella.
```

Para encontrar una nota junto con tus mensajes, correo y reuniones, el agente ejecuta `search all`:

```sh
memo search all 'Harbour budget'
memo notes show document:3
```

`notes show` abre una nota con sus etiquetas, las notas a las que enlaza y las notas que enlazan a ella. Una nota de
un archivo tiene una referencia como `document:3`. Copia la referencia de un resultado de búsqueda.

Una respuesta útil nombra el archivo y cita la línea. Una respuesta vacía no demuestra que la nota no exista: consulta
[Si falta una nota](#si-falta-una-nota).

## Archivos que Memo puede leer

Una carpeta puede tener más que Markdown. Memo también lee estos archivos:

| Archivos | Extensiones | Qué guarda Memo |
|---|---|---|
| Texto y Markdown | `.txt`, `.md`, `.markdown` | El texto, los enlaces y las etiquetas |
| Tablas | `.csv`, `.tsv`, `.xlsx`, `.ods` | Los valores de las celdas, con la hoja, la fila y la columna |
| Documentos, presentaciones y libros electrónicos | `.odt`, `.pptx`, `.epub` | El texto, sin el formato |
| PDF y Word | `.pdf`, `.docx`, `.doc` | El texto, con los números de página del PDF |
| Páginas web guardadas como archivos | `.html`, `.htm` | El texto principal y el título de la página |

Memo no puede leer PDF escaneados (imágenes de páginas, sin texto), archivos `.xls` antiguos ni archivos de más de
50 MiB. Guarda hasta 200 000 caracteres de cada archivo.

## Mantén tus notas al día

Vuelve a sincronizar después de añadir o editar archivos. Solo se leen los cambios:

```sh
memo sync --only notes
```

Para sincronizar con un temporizador, por ejemplo cada diez minutos:

```sh
memo jobs start --every 10m
```

Puedes añadir más de una carpeta. `memo folders list` las muestra todas. Una carpeta dentro o alrededor de otra que
Memo ya lee se rechaza, porque cada archivo compartido sería entonces dos notas.

Para dejar fuera algunos archivos, ponlos en `notes.ignore` en el
[archivo de configuración](./memo/configuration.md#notes). Una regla es una ruta dentro de la carpeta, una carpeta o un
patrón:

```json
{ "notes": { "ignore": ["Journal/Private.md", "Archive", "**/Private*"] } }
```

## Escribe notas y guárdalas como archivos

Tu agente también puede escribir una nota en Memo sobre una persona, un mensaje, un proyecto u otra nota. Escribirla no
envía nada a nadie.

```sh
memo notes add 'Prefers morning meetings' --subject telegram:'Kai Sample'
```

Para tener estas notas también en tu bóveda, exporta las notas como archivos Markdown:

```sh
memo notes export --output-dir ~/Notes/memo --format obsidian
```

Usa `--format markdown` para Markdown simple. Cada archivo lleva un `memo-id` y un `memo-hash` al principio, así que
importar esa carpeta no crea la misma nota dos veces. Si editaste tú un archivo exportado, Memo no lo sobrescribe y te
avisa.

Una nota de tus propios archivos se edita en el archivo, no en Memo. Edita el archivo como siempre y vuelve a sincronizar.

## Si falta una nota

1. **El archivo es nuevo o cambió.** Ejecuta `memo sync --only notes` de nuevo.
2. **El archivo no se leyó.** El informe de la sincronización enumera en cada ejecución todos los archivos que no pudo
   leer, y por qué, hasta que el archivo cambie:

   ```text
   notes /home/you/Notes: 41 notes, 2 changed, 0 moved, 0 gone, 1 not read
     not read: Archive/2009 budget.xls — this file type cannot be read
   ```

3. **No se encuentra un enlace o una etiqueta.** Puede que la carpeta se lea en el otro formato. Busca su ID con
   `memo folders list` y elige el formato: `memo folders update 1 ~/Notes --format obsidian`. La siguiente
   sincronización vuelve a leer todas las notas de esa carpeta.
4. **La búsqueda por significado no encuentra nada.** El modelo de búsqueda no está descargado, o la sincronización se
   ejecutó con `--no-embed`. Busca por palabras, o descarga el modelo como indica la
   [instalación](./memo/installation.md).
