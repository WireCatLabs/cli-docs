The `tg` and `max` command-line tools give your AI agent access to Telegram and MAX. Choose a task below and copy a request to try it.

The essentials:

- **Catch up on conversations:** important unread messages, unanswered questions and meeting context — [First tasks](./first-tasks.md).
- **Find what you need:** messages, agreements, people and text inside files — [Search](./search.md).
- **Prepare a reply:** a draft based on the conversation, sent after review — [Writing requests](./prompting.mdx).
- **Work with files and voice:** collect documents, choose versions and summarise recordings — [request examples](./prompting.mdx#files-and-voice).
- **Help with groups and bots:** member questions, moderation rules and bot messages — [groups](./group-admins.md) and [bots](./bot-api.mdx).

## A fuller overview

- **Messages:** read, reply, edit and forward; send files, react, create polls and schedule reminders.
- **Search and history:** download selected chats to <DocTerm term="local-archive" lang="en" label="a local archive" />, match word forms, filter by date and author, export history and gather summaries.
- **Documents and voice:** download attachments, extract text from supported formats, transfer a retained file to a remote agent and transcribe voice messages with <DocTerm term="speech-model" lang="en" label="a speech model" />.
- **People and accounts:** find contacts, recover conversation context, organise folders and use <DocTerm term="profile" lang="en" label="separate profiles" /> for multiple accounts.
- **Communities and bots:** manage members and invites with administrator rights, check moderation rules and use the Bot API. Forum topics are available in Telegram; bot comments under channel posts are available in MAX.
- **Access control:** allow reading, choose permitted changes and limit recipients and sending frequency. [Set permissions](./permissions.mdx).

## Try it on your task

If your account is connected, copy a request from the relevant section below. Otherwise, start with [installation and login](./installation.mdx). The [demo](./meeting-brief.mdx) shows an agent conversation without connecting an account. Expand the blocks below the examples for exact commands and additional capabilities.

Each tool works with one messenger: `tg` with Telegram, `max` with MAX. The requests name `tg`; for MAX, write `max` instead. Everything below works in both, unless a row says otherwise. The commands in the tables start with `tg` or `max`.

## Messages

Summarise a conversation or prepare a reply you can review before sending.

```text prompt
Use tg CLI. Read my conversation with Anna from today. What needs my answer? Draft a short reply without sending it.
```

Expect a draft and the messages it is based on. If the recipient is ambiguous, clarify the chat before sending.

<details>
<summary>Commands and additional capabilities</summary>

| What you can do | Commands |
|---|---|
| Read chats and message history | `messages list`, `messages show` |
| Send text and files, reply to a message | `messages send` |
| Edit, delete, forward and pin messages | `messages edit`, `delete`, `forward`, `pin` |
| Schedule a message — it goes out even when your computer is off | `messages send --at-time` |
| Download photos, documents and other attachments | `messages download` |
| React to messages | `reactions` |
| Create polls, vote, close your own | `polls` |
| Turn voice messages into text on your own computer | `messages transcribe` |
| Get a message locator and a messenger link when available | `messages link` |
| Mark chats as read — only when you ask | `chats mark-read` |

</details>

Guides: [Telegram usage](./tg/usage.md) · [MAX usage](./max/usage.md)

## Chats, contacts and account

Find a person and recover the context of your previous conversations.

```text prompt
Use tg CLI. Find the designer we discussed last month. Show who recommended them and what we have already agreed.
```

Expect a clearly identified person and supporting messages. Use separate profiles for work and personal accounts; [choosing an account](./profiles.md) explains how.

<details>
<summary>Commands and additional capabilities</summary>

| What you can do | Commands |
|---|---|
| List and search chats, filter by kind (people, groups, channels) | `chats list` |
| Create, change and delete chat folders | `chats folders` |
| Contacts: find, add, rename, block, import | `contacts` |
| Who someone is, what they wrote, whether the account looks like a bot | `contacts profile`, `context`, `check` |
| Auto-replies by your rules, to the audience you choose | `replies` |
| Update your profile; see every device logged in, end one | `account` |
| Several accounts, one *profile* each | `tg work …`, `max work …` |

</details>

Guides: [People](./people.md) · [Telegram login and profiles](./tg/sessions.md) · [MAX sessions and profiles](./max/sessions.md)

## Groups and channels

Review a group before changing its members, settings or moderation rules.

```text prompt
Use tg CLI. In my project group, list questions awaiting an administrator’s reply. Show sources; do not change anything.
```

Expect a list to review. Group changes require the relevant account rights. Moderation runs when started by you, your agent or a scheduled task.

<details>
<summary>Commands and additional capabilities</summary>

| What you can do | Commands |
|---|---|
| Create a group or a channel | `chats create` |
| Check where an invite link leads without joining | `chats inspect` |
| Join and leave; show or reset the invite link | `chats join`, `leave`, `link` |
| Add and remove members; make admins and set their rights | `chats members`, `chats admins` |
| See who joined, left or was removed | `chats events` |
| Find questions awaiting your or an administrator’s reply | `review --unanswered` |
| Change the title, description and settings | `chats update` |
| Moderation rules: links, invites, forwards, flooding, blocked people | `chats rules`, `chats moderate` |
| Forum topics: list, search, create, post into a topic — *Telegram* | `topics` |
| A moderation rule for new accounts — *MAX* | `chats rules` |

</details>

Moderation runs when you, your agent or your schedule starts it; nothing watches a group by itself.
Guides: [Telegram groups](./tg/groups.md) · [MAX groups](./max/groups.md)

## History, search and staying on top

Find an older agreement or collect the important unread messages.

```text prompt
Use tg CLI. Find what we agreed about the project deadline last month. Show the agreement and any later changes.
```

Expect the answer, sources and the period checked. By default, Telegram word searches and MAX word searches within one named chat can also query the messenger’s server. Topic search and counts use saved history; if the period is missing, [download the relevant chats first](./search.md#fetch-the-relevant-chat-history-first).

<details>
<summary>Commands and additional capabilities</summary>

| What you can do | Commands |
|---|---|
| Keep a local archive of the chats you choose | `store fetch` |
| Search by words, sender, date and chat; server search is available in Telegram and within one named MAX chat | `search messages` |
| Separate the threads of a busy group by replies and mentions | `conversations` |
| Export a chat as Markdown or JSON lines; back up the whole archive | `store export`, `store backup` |
| Unread messages from every chat in one list | `inbox` |
| Who is waiting for your answer, and what you are waiting for | `review` |
| Watch new messages as they arrive | `watch` |
| Keep the archive current in the background | `server` |

</details>

Guides: [Telegram archive](./tg/archive.md) · [Telegram search](./tg/search.md) ·
[MAX archive](./max/archive.md) · [MAX search](./max/search.md)

## Bots

Use a bot for customer messages, button responses or group tasks. It has its own identity and access.

```text prompt
Use tg CLI. Check the bot’s available messages and draft answers to unanswered questions. Show each draft to me before sending.
```

Expect drafts based on messages available to that bot. Your personal account’s history is separate. Start with [bot setup and capabilities](./bot-api.mdx).

A bot works with its own token, separate from your personal account.

<details>
<summary>Commands and additional capabilities</summary>

| What you can do | Commands |
|---|---|
| Every method of the official Bot API — all 185 for Telegram, all 33 for MAX | `bot api` |
| Send, edit, delete and pin messages | `bot messages` |
| Search messages available to the bot | `bot search messages` |
| Answer button presses; set the bot's command menu; manage webhooks | `bot callbacks`, `bot commands`, `bot webhooks` |
| Manage group admins and members | `bot chats admins`, `bot chats members` |
| Moderate a group by the same rules as your account | `bot chats moderate` |
| Give the bot to an agent over MCP | `bot mcp config` |
| Comments under channel posts — *MAX* | `bot comments` |

</details>

Guides: [Full Bot API](./bot-api.mdx) · [Telegram bots](./tg/bot.md) · [MAX bots](./max/bot.md)

## Built for agents

- <DocTerm term="skill" lang="en" label="A skill" /> gives your agent instructions for the commands and common tasks.
  [Connect your AI agent](./agents.mdx)
- <DocTerm term="mcp" lang="en" label="An MCP server" /> for Claude Desktop and other clients. It follows the profile’s permissions; choose read-only access or allow the actions needed. Confirmation prompts are controlled by your AI app.
  [MCP](./mcp.mdx)
- **Predictable output** — every command can return one JSON value, and each kind of failure has
  its own exit code, so scripts and agents can react to it.
- **Self-description** — `tg commands --json` lists every command and option, so an agent can look
  up what it needs instead of guessing.

## Limits you set

- **Permissions per profile** — read-only, ask before a change, or allow.
- **A recipient list** — the chats this profile may send to.
- **An hourly limit** on sends, 30 by default.
- **A send journal** — every send attempt, without the message text.
- **A profile lock** rejects commands selecting another profile. An agent that can change its environment can remove the lock; see [the control limits](./security.mdx#what-the-guard-cannot-hold).

[What the login allows and how to limit it](./installation.mdx) ·

## Not there yet

- **Telegram:** several photos in one message; muting a chat, privacy settings, call history, stickers and pressing buttons in a bot's message, which `max` already has.
- **MAX:** video notes, setting or removing the cloud password.

Current unsupported features and planned work are listed in the roadmaps for [Telegram](./tg/roadmap.md) and [MAX](./max/roadmap.md). A roadmap item is not an available capability.
