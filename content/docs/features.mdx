WireCat connects your messages and other sources to the AI agent you choose. Ask it to find an agreement, catch up on a chat or prepare a reply using your own history, with sources you can check. Messages are the starting point; notes, files and email can add context through Memo.

The key capabilities:

- **Your sources, your agent:** use command-line tools or MCP with an agent that supports them.
- **Messages with context:** find what was said, what changed and who needs an answer.
- **Search with evidence:** return matching sources and the surrounding messages.
- **People across accounts:** link identities you know belong to the same person.
- **Notes and files:** bring selected folders and your own notes into the same local context.
- **Bots and groups:** answer through a bot or help administer a community.
- **Control over access:** choose sources, permissions and how the tools run.

## Connect the agent you use

WireCat supplies tools and access to your sources. Your AI agent interprets your request and uses those tools to gather information or perform the actions you permit. You can change agents without starting your message archive or notes again.

Use a local agent with terminal access, or connect a compatible app through MCP. Available capabilities depend on the connected tool and account.

[Connect an AI agent](./agents.mdx) · [Use from web or mobile](./browser-apps.mdx)

## Messages

Catch up on unread messages, find questions awaiting an answer and prepare for a conversation using earlier messages. Ask the agent to show the source messages behind a summary or proposed reply, so you can check an agreement before acting on it.

A draft returned in your agent chat and a draft saved in the messaging app are different. The current personal-account tools return reply text for you to copy into the messaging app; they do not save it directly into the app’s draft field. Sending is a separate action with its own permissions.

## Search and sources

Find an older message by words, person, chat or date, or look for a topic by meaning when semantic search is configured. Open the surrounding messages to understand a result. Search can combine stored messages, imported notes and mail through Memo.

The local archive contains the history you downloaded. An empty result does not prove that a message never existed: check the period covered and import results. Word search can work locally without an AI provider; search by meaning needs additional setup.

## People across accounts

Keep context about a person together across the accounts you explicitly link. Use it to recall what you discussed, who introduced you or which notes you saved about them. Matching names alone do not merge people.

The answer depends on stored history and confirmed links; ask for evidence when the agent draws a conclusion about someone.

[People and linked accounts](./people.md)

## Notes, files and email

Use Memo to import selected folders, including Obsidian notes, search readable file contents and keep notes linked to people or messages. Imported files retain source references; notes you create can be edited and exported. Tags help you collect related sources without changing the originals.

Memo can also import mail from configured accounts. It reads already-downloaded messenger history; it does not connect to a messenger or download that history itself. Some document formats need optional readers, and scanned pages need text recognition first.

[Notes and files](./memo.mdx) · [Email](./email.mdx)

## Bots

Use a bot's own identity for messages, button responses and community workflows. An agent can help operate the bot through the supported Bot API commands. A bot's access differs from your personal account: it cannot read your private chats or assume your account's history.

Auto-reply rules and templates can handle selected incoming messages while their process is running, within the audience and limits you configure.

[Bot setup and capabilities](./bot-api.mdx) · [Auto-reply templates](./drafts-and-templates.mdx)

## Groups and channels

Ask your agent to review unanswered questions, help with members and invitations, or apply moderation rules. Changes require the account's administrator rights and tool permissions. Ongoing moderation needs a running process or a schedule; installing a tool does not start it automatically.

[Group administration](./group-admins.md) · [Telegram groups](./tg/groups.md) · [MAX groups](./max/groups.md)

## Your data and permissions

The tools keep history and notes on the computer or server where you run them. Local storage lets you search saved data without repeatedly downloading it. Background updates need that machine and the relevant process to stay running.

Choose the accounts, history and folders you make available, and set permissions for changes and sending. Local storage does not mean an agent's AI provider receives no data: retrieved content can enter the agent's request. CLI controls also do not constrain unrelated access an agent has to your machine.
