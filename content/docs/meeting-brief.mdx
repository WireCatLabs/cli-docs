## Read the decision in context

The two matches are message 13 (“I will send the final invoice after the review”) and message 12
(“deadline confirmed: Friday, October 9”). Their nearby context includes the earlier Tuesday
proposal and the reply rejecting Tuesday. A meeting brief should therefore report
**Friday, October 9 as the confirmed invoice deadline**, with sources 12 and 13; Tuesday was a
proposal, not the final agreement.

A useful brief separates confirmed decisions, unresolved questions and source messages. This
result does not establish that the final invoice was sent: message 13 describes a future action,
and the selected context is only a bounded window. The runner retrieves messages; the explanation
above is an interpretation of the displayed evidence.

## Use the workflow with your own archive

After [installation](./installation.mdx), login and a bounded history fetch
([Telegram](./tg/archive.md), [MAX](./max/archive.md)), ask your agent. Replace the chat name and
phrases with your task:

```text prompt
Use tg CLI. Prepare a brief for my meeting about the Atlas project. Search the "Atlas project" chat for the confirmed deadline and the final invoice, and read the messages around each match. Separate confirmed decisions from proposals and unanswered questions. Cite message sources, list the chats and time window checked, and say what the evidence cannot establish. Read only; do not send or mark anything read.
```

For MAX, write “Use max CLI” instead of “Use tg CLI”.

The agent may run a search with the same query syntax as the sample:

```sh
tg search messages 'chat:"Atlas project" AND ("deadline confirmed" OR "final invoice")' --json
```

```sh
max search messages 'chat:"Atlas project" AND ("deadline confirmed" OR "final invoice")' --json
```

`search messages` reads your saved history. Because the query names one chat, it also asks the
messenger's own search, which can find messages not yet downloaded; add `--backend archive` to
search saved history only ([Telegram](./tg/search.md#asking-telegram-too---backend),
[MAX](./max/search.md#search-the-max-server---backend)). Login alone does not download all
historical messages. Open the surrounding messages with `messages context` using source locators
returned by **your own** search; the `demo` locators above belong only to the sample. Options and
locators: [Telegram commands](./tg/commands.md) and [MAX commands](./max/commands.md).

Your saved history stays on your computer, while text passed to an AI agent follows that agent's
and model's configuration. See [security](./security.mdx) and [connecting an agent](./agents.mdx).

## Reproducibility and limits

The dataset and runner are versioned with the site, and an automated test checks the runner's
output. Record the repository commit when reproducing it. The example demonstrates query matching
and a bounded context window, not message-history completeness, a live command-line tool benchmark
or an AI model's accuracy. Nothing is sent by this walkthrough.
