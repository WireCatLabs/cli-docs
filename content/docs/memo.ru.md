Используйте Memo, когда нужный контекст разбросан по сообщениям, письмам и заметкам.
Он собирает сохранённые сведения о человеке со ссылками на источники, чтобы вы или ваш
ИИ-агент могли подготовиться к встрече или проверить договорённость. Сначала импортируйте
заметки и почту: Memo сам не скачивает историю Telegram и MAX.

Эта инструкция описывает **Memo 0.2.0**. Инструмент находится на ранней стадии развития
и доступен в пакете `@leemour/cli-memo`.

## Установите Memo

Нужны Node.js версии от 22.16 в ветке 22.x либо версии 24 и выше, а также npm.
Для контекста из мессенджера [установите Telegram или MAX](./installation.mdx) и скачайте
нужную историю соответствующим инструментом. Memo читает их общее локальное хранилище
на том же компьютере.

```sh
npm install -g @leemour/cli-memo@0.2.0
memo --version
```

Проверка версии должна вывести `0.2.0`. Агент с доступом к терминалу может запускать
`memo`, если команда доступна в его PATH. Дайте агенту эту инструкцию с командами ниже.

## Добавьте заметки

Выберите существующую папку заметок и замените `/path/to/vault` её полным путём.
По умолчанию используется формат Obsidian; для обычных ссылок Markdown добавьте
`--format markdown`.

```sh
memo folders add /path/to/vault
memo notes import --no-embed
memo search notes 'budget' --json
```

Первая команда выводит ID папки. Импорт копирует заметки в локальное хранилище,
не меняя исходные файлы. Поиск возвращает найденные заметки с их ссылками и совпавшим
текстом. `--no-embed` пропускает подготовку поиска по смыслу; поиск по словам работает.
Повторяйте импорт после редактирования файлов.

Чтобы связать импортированную заметку с человеком, замените имя и путь к файлу:

```sh
memo note telegram:"Rin Example" /path/to/vault/people/Rin.md
memo context telegram:"Rin Example" --json
```

Для другой учётной записи используйте `max:<name or id>` или `email:<address>`.
Заметка уже должна быть импортирована. Упоминание имени в обычном тексте само по себе
не создаёт связь: укажите заметку о человеке явно или используйте поддерживаемую ссылку,
например `[[Rin Example]]` в Obsidian.

## Добавьте почту

Memo читает почту через [Himalaya](https://github.com/pimalaya/himalaya). Сначала установите
Himalaya и настройте в нём почтовый аккаунт. Memo использует имя и адрес этого аккаунта;
ему не нужна отдельная копия пароля от почты.

Добавьте `mail.accounts` в конфигурацию Memo, сохранив остальные настройки. Пути к файлу по умолчанию:

| OS | Файл конфигурации |
| --- | --- |
| Linux | `~/.config/cli-memo/config.json` |
| macOS | `~/Library/Preferences/cli-memo/config.json` |
| Windows | `%APPDATA%\cli-memo\Config\config.json` |

`MEMO_CONFIG_DIR` переопределяет папку; в Linux на путь по умолчанию также влияет `XDG_CONFIG_HOME`.
В примере аккаунт Himalaya называется `gmail`; замените имя и адрес своими.

```json
{
  "mail": {
    "accounts": [{ "name": "gmail", "address": "you@example.com" }]
  }
}
```

По умолчанию используется Gmail и импортируется All Mail. Для другого IMAP-провайдера
добавьте в запись аккаунта `"mode": "imap"` и `"folders": ["INBOX", "Archive"]`, указав
настоящие имена папок своего почтового ящика.

```sh
memo mail import --account gmail --since 2026-09-01 --json
```

Выберите начальную дату. По умолчанию за один запуск читается не более 200 новых писем.
Если результат сообщает о неполном импорте, повторите команду. Почтовый ящик используется
только для чтения: импорт не отправляет письма и не отмечает их прочитанными.
Импортированная почта хранится локально; повторный импорт может удалить из хранилища
текст писем, исчезнувших из источника.

Свяжите почтовый адрес с аккаунтом человека в мессенджере явно через `tg contacts link`
или `max contacts link`: совпадения имён недостаточно. Задачи с контактами описаны в
инструкции [о работе с людьми](./people.md).

## Попросите нужный контекст

Дайте агенту такой запрос, заменив имя:

> Используй Memo, чтобы собрать сведения о Rin Example перед встречей: последние сообщения,
> письма, связанные заметки и открытые задачи. Добавь ссылки на источники и укажи, каких данных не хватает.

Агент может собрать контекст о человеке или найти сведения в импортированных источниках:

```sh
memo context telegram:"Rin Example" --json
memo search all 'budget' --json
```

`search all` ищет сразу в сообщениях, почте и заметках; `skipped` называет то, где искать не удалось. Проверьте ссылки
на источники и охват данных, прежде чем полагаться на ответ. Недостающая история, письма
за пределами периода импорта и неразрешённые ссылки в заметках могут сделать результат
неполным. Добавьте `--account <id>` к `context`, если сохранено несколько аккаунтов
одного провайдера.

Можно также сохранить собственную заметку о человеке:

```sh
memo notes add 'Prefers morning meetings' --about telegram:'Rin Example'
memo notes list --about telegram:'Rin Example' --json
```

Эти заметки хранятся локально. Их создание не меняет импортированный файл;
`memo notes export` — отдельное явное действие для записи файлов.

## Если чего-то не хватает

- **Команда не найдена:** проверьте `memo --version` в терминале агента и откройте его заново после установки.
- **Заметки не найдены:** проверьте `memo folders list`, повторите `memo notes import --no-embed` и изучите результат импорта.
- **Нет почтового аккаунта:** проверьте, что `mail.accounts` ссылается на аккаунт, настроенный в Himalaya.
- **Не тот человек или неоднозначное имя:** укажите провайдера и точный ID; явно свяжите аккаунты.
- **Неполный контекст:** импортируйте нужные заметки и письма, а недостающую историю скачайте через tg или max.

Когда источники доступны, переходите к [подготовке к встрече](./meeting-brief.mdx).
Параметры команд можно посмотреть через `memo --help` или `--help` нужной подкоманды.
[Исходная документация Memo 0.2.0](https://github.com/leemour/cli-memo/blob/v0.2.0/README.md)
также описывает задачи, связи, теги, локальные напоминания и подборки источников.
