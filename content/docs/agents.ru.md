Ваш ИИ-помощник может искать сообщения, собирать контекст и готовить ответы за вас. Здесь вы
проверите, видит ли он установленный инструмент для мессенджера, и подключите его, если нужно.

Начните с проверки ниже. Если агент показывает нужный аккаунт и несколько чатов, можно сразу
переходить к [первым задачам](./first-tasks.md). Повторять настройку не нужно.

Эти шаги подходят агенту с доступом к терминалу на вашем компьютере или сервере. Для ChatGPT
или Claude в браузере откройте [подключение браузерного ИИ-приложения](./browser-apps.mdx).

<a id="проверьте-подключение" />

## Проверьте, всё ли готово

Скопируйте запрос в своего агента. Для MAX замените `tg` на `max`:

```text prompt
Я установил tg для Telegram. Проверь, что ты можешь его запустить, и прочитай инструкцию через tg skill show. Затем покажи, какой аккаунт подключён, и выведи пять чатов. Только читай: ничего не отправляй и не отмечай прочитанным. Если чего-то не хватает, объясни следующий шаг.
```

**Если появились аккаунт и чаты, переходите к [первым задачам](./first-tasks.md).** Уже можно
попросить агента найти сообщение, пересказать переписку или подготовиться к встрече.

**Если агент не находит команду**, откройте [установку и вход](./installation.mdx).
Если команда работает в вашем терминале, но не у агента, попросите его проверить, что он
работает на том же компьютере и видит установленную программу.

**Если программа найдена, но агент не знает, как ей пользоваться**, подключите инструкцию ниже.
Если агент сообщает, что аккаунт не подключён, вернитесь к [входу](./installation.mdx).

## Подключите инструкцию

**Skill, или навык,** — файл, который объясняет агенту, как пользоваться `tg` или `max`.
Часто он уже установлен при настройке. Если агент его не нашёл, попросите:

```text prompt
Подключи инструмент Telegram tg к этому агенту. Проверь, откуда ты загружаешь навыки, прочитай tg skill show и установи эту инструкцию в подходящее место для своего окружения. Используй инструкцию из установленного инструмента. Сообщи, когда всё готово, чтобы я повторил проверку аккаунта и чатов.
```

Для MAX используйте `max` и `max skill show`. Агент может подобрать настройку для своего
окружения сам; знать расположение папок с навыками не требуется.

Или выполните команду своего мессенджера в терминале:

```sh
tg skill install
```

```sh
max skill install
```

Так инструкция попадает в стандартные папки для Claude Code, Codex, Cursor и Gemini CLI.
Если она не появилась, откройте новую беседу с агентом. У Hermes и OpenClaw также есть свои
папки навыков — они описаны ниже.

### Укажите агента при первом подключении

При первом входе настройка спрашивает, каким агентом вы пользуетесь. Его можно указать сразу:

```sh
tg setup --agent codex
max setup --agent codex
```

Выполните только команду своего мессенджера. Вместо `codex` можно указать `cursor`, `claude`
или `gemini`; `all` устанавливает инструкцию в обе стандартные папки. Если аккаунт уже подключён,
достаточно `skill install` выше — повторять настройку аккаунта не нужно.

## Подсказки для вашего агента

Откройте нужный раздел, если после общей установки агент ещё не видит навык.

### Codex

Выберите `$tg-cli` или `$max-cli` в беседе. Если навык не появился, откройте новую беседу
или перезапустите Codex. [Инструкция Codex](https://learn.chatgpt.com/docs/build-skills).

### Cursor

Используйте режим **Agent** с доступом к терминалу и попросите его воспользоваться `tg` или `max`.
Если навык не найден, попросите прочитать `skill show`.
[Инструкция Cursor](https://cursor.com/help/customization/skills).

### Claude Code

Вызовите `/tg-cli` или `/max-cli` в новой локальной сессии.
[Инструкция Claude Code](https://code.claude.com/docs/en/skills).

### Gemini CLI

Команда `gemini skills list` показывает доступные навыки. В уже открытой сессии обновите список
через `/skills reload`. [Инструкция Gemini](https://geminicli.com/docs/cli/skills/).

### Hermes

Попросите Hermes сохранить точный вывод `tg skill show` в
`~/.hermes/skills/tg-cli/SKILL.md`, а для MAX — вывод `max skill show` в
`~/.hermes/skills/max-cli/SKILL.md`. Начните новую сессию и повторите проверку в начале страницы.
[Инструкция Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/).

### OpenClaw

Попросите OpenClaw сохранить точный вывод `tg skill show` в
`~/.openclaw/skills/tg-cli/SKILL.md`, а для MAX — вывод `max skill show` в
`~/.openclaw/skills/max-cli/SKILL.md`. Проверьте, что навык доступен вашему агенту, и начните новую
сессию. Инструмент должен быть установлен на компьютере или сервере, где работает OpenClaw.
[Инструкция OpenClaw](https://docs.openclaw.ai/tools/skills).

## Переходите к первой задаче

Когда агент показывает аккаунт и чаты, откройте [первые задачи](./first-tasks.md).
Там можно скопировать запрос, чтобы разобрать входящие, найти договорённость или подготовить ответ.

Если агент не умеет запускать команды, подключите [MCP](./mcp.md) или дайте ему
[документацию в Markdown](./mcp.md#документация-для-агента).
