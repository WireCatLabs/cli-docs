В ваших заметках уже есть планы, записи встреч и решения. Добавьте папку с заметками или хранилище Obsidian в Memo, и
ваш ИИ-агент сможет искать по ним на вашем компьютере, рядом с чатами, почтой и встречами. Memo читает файлы и никогда
их не меняет.

Агент с доступом к заметкам найдет заметку, где записано решение, процитирует строку и покажет заметки, которые на нее
ссылаются. Он может и написать для вас новую заметку о человеке или проекте, а потом снова сохранить заметки в файлы
Markdown.

Отдельного инструмента для Markdown нет: папки с заметками читает `memo`. Нужен установленный `memo`
([установка](./memo/installation.md)). Ему не нужны аккаунт и вход: ваши заметки уже на вашем компьютере.

## Коротко

В примерах папка `~/Notes`: папка с заметками в вашей домашней папке. Укажите путь к своей.

```sh
memo folders add ~/Notes
memo sync --only notes --no-embed
memo search notes 'budget'
```

Первая команда добавляет папку и печатает ее ID, например `1`. Синхронизация читает все файлы в папке и во вложенных
папках и сообщает, сколько заметок нашла. Поиск показывает каждый подходящий файл и первую подходящую строку.

`--no-embed` пропускает подготовку к поиску по смыслу, так что можно начать без модели поиска. Когда модель скачана,
уберите этот флаг, и агент найдет заметку и по ее смыслу.

Или попросите агента:

```text prompt
С помощью memo CLI добавь мою папку с заметками ~/Notes и импортируй ее.
Скажи, сколько заметок нашлось и какие файлы не удалось прочитать.
```

## Папка Markdown или хранилище Obsidian

Memo читает любую папку с файлами Markdown. Хранилище Obsidian — это папка с заметками Markdown, которую Obsidian
открывает как одно рабочее пространство. Memo сам определяет, что у вас: папку, в которой или над которой есть служебная
папка Obsidian `.obsidian`, он читает как хранилище. Obsidian для работы с Memo не нужен, и держать его открытым тоже
не нужно.

Они различаются тем, как записаны ссылки и теги:

| | Папка Markdown | Хранилище Obsidian |
|---|---|---|
| Ссылки на другие заметки | `[label](other-note.md)` | `[[Other note]]` и `[[Other note\|label]]` |
| Теги | поле `tags:` в начале файла | поле `tags:` и `#tags` в тексте |
| Другие названия заметки | | поле `aliases:` |

Чтобы выбрать формат самому, добавьте к `memo folders add` флаг `--format markdown` или `--format obsidian`. Скрытые
папки, такие как `.obsidian`, Memo пропускает.

## Что расскажет агент

Спросите своими словами:

```text prompt
С помощью memo CLI найди заметку, где мы решили бюджет Harbour. Процитируй строку с именем файла
и перечисли заметки, которые на нее ссылаются.
```

Чтобы найти заметку вместе с сообщениями, почтой и встречами, агент запускает `search all`:

```sh
memo search all 'Harbour budget'
memo notes show document:3
```

`notes show` открывает одну заметку с ее тегами, заметками, на которые она ссылается, и заметками, которые ссылаются на
нее. У заметки из файла ссылка вида `document:3`. Копируйте ее из результата поиска.

Полезный ответ называет файл и цитирует строку. Пустой ответ не доказывает, что заметки нет: см.
[Если заметки нет](#если-заметки-нет).

## Какие файлы читает Memo

В папке может быть не только Markdown. Memo читает и такие файлы:

| Файлы | Расширения | Что сохраняет Memo |
|---|---|---|
| Текст и Markdown | `.txt`, `.md`, `.markdown` | Текст, ссылки и теги |
| Таблицы | `.csv`, `.tsv`, `.xlsx`, `.ods` | Значения ячеек с листом, строкой и столбцом |
| Документы, презентации и электронные книги | `.odt`, `.pptx`, `.epub` | Текст без оформления |
| PDF и Word | `.pdf`, `.docx`, `.doc` | Текст, у PDF с номерами страниц |
| Сохраненные веб-страницы | `.html`, `.htm` | Основной текст и заголовок страницы |

Memo не может прочитать сканы PDF (картинки страниц без текста), старые файлы `.xls` и файлы больше 50 МиБ. Из каждого
файла он сохраняет до 200 000 символов.

## Как держать заметки свежими

После того как вы добавили или изменили файлы, запустите синхронизацию снова. Читаются только изменения:

```sh
memo sync --only notes
```

Чтобы синхронизировать по таймеру, например каждые десять минут:

```sh
memo jobs start --every 10m
```

Папок может быть несколько. `memo folders list` показывает их все. Папку внутри или вокруг той, что Memo уже читает,
он не добавит: иначе каждый общий файл стал бы двумя заметками.

Чтобы не читать какие-то файлы, перечислите их в `notes.ignore` в [файле настроек](./memo/configuration.md#notes).
Правило — это путь внутри папки, папка или шаблон:

```json
{ "notes": { "ignore": ["Journal/Private.md", "Archive", "**/Private*"] } }
```

## Свои заметки и сохранение в файлы

Агент может и написать заметку в Memo о человеке, сообщении, проекте или другой заметке. Запись заметки ничего никому не
отправляет.

```sh
memo notes add 'Prefers morning meetings' --subject telegram:'Kai Sample'
```

Чтобы эти заметки были и в вашем хранилище, выгрузите их в файлы Markdown:

```sh
memo notes export --output-dir ~/Notes/memo --format obsidian
```

Для обычного Markdown укажите `--format markdown`. В начале каждого файла стоят `memo-id` и `memo-hash`, поэтому при
импорте этой папки та же заметка не появится дважды. Если вы сами изменили выгруженный файл, Memo его не перезапишет и
сообщит об этом.

Заметку из ваших файлов меняют в самом файле, а не в Memo. Измените ее как обычно и снова запустите синхронизацию.

## Если заметки нет

1. **Файл новый или изменен.** Снова запустите `memo sync --only notes`.
2. **Файл не прочитан.** Отчет синхронизации при каждом запуске перечисляет все файлы, которые не удалось прочитать, и
   причину, пока файл не изменится:

   ```text
   notes /home/you/Notes: 41 notes, 2 changed, 0 moved, 0 gone, 1 not read
     not read: Archive/2009 budget.xls — this file type cannot be read
   ```

3. **Не находится ссылка или тег.** Возможно, папка читается в другом формате. Узнайте ее ID через
   `memo folders list` и задайте формат: `memo folders update 1 ~/Notes --format obsidian`. Следующая
   синхронизация заново прочитает все заметки этой папки.
4. **Поиск по смыслу ничего не находит.** Модель поиска не скачана, или синхронизация шла с `--no-embed`. Ищите по
   словам или скачайте модель, как описано в [установке](./memo/installation.md).
