Guarda ajustes para las herramientas de línea de comandos y evita repetir las mismas opciones en cada ejecución, como cuántos resultados mostrar. Aprende dónde se guardan, cómo comprobarlos y cambiarlos, y dónde cada servicio de mensajería enumera todos sus ajustes. Los valores predeterminados sirven a la mayoría; cambia un ajuste cuando repites siempre la misma opción o quieres valores distintos para distintas cuentas.

Dos términos. El **archivo de ajustes** (`config.json`) guarda estos valores en tu ordenador. Un <DocTerm term="profile" lang="es" label="perfil" /> es una configuración con nombre para la conexión de una cuenta o bot, como `work`, con sus propios valores; los valores de `defaults` se aplican a todos los perfiles. Los datos de inicio de sesión nunca se guardan en este archivo, y lo que puede hacer tu agente se define en [Permisos](./permissions.mdx).

## Dónde está el archivo

La herramienta crea el archivo con valores habituales la primera vez que un comando lee los ajustes, y conserva un archivo existente tal como está.

| Sistema | Telegram | MAX |
|---|---|---|
| Linux | `~/.config/tg-cli/config.json` | `~/.config/max-cli/config.json` |
| macOS | `~/Library/Preferences/tg-cli/config.json` | `~/Library/Preferences/max-cli/config.json` |
| Windows | `%APPDATA%\tg-cli\Config\config.json` | `%APPDATA%\max-cli\Config\config.json` |

`config show` muestra la ruta real, que cambia si tu ordenador usa otro directorio. En PowerShell escribe `tg.cmd` o `max.cmd`.

## Comprobar y cambiar un ajuste

```sh
tg config show
tg config set limit 50
tg work config set limit 10
tg config set sendsPerHour 10 --defaults
tg config unset limit
```

`config show` enumera cada ajuste con su valor y de dónde viene. `config set` guarda un valor para el perfil actual, para un perfil con nombre como `work` o, con `--defaults`, para todos los perfiles. Comprueba el valor antes de escribirlo, así que un error tipográfico se rechaza en lugar de guardarse. `config unset` elimina un valor para que vuelva a aplicarse el predeterminado. Para MAX, escribe `max` en lugar de `tg`. También puedes editar el archivo a mano.

## ¿Qué valor gana?

Una opción del comando como `--limit 5` (<DocTerm term="flag" lang="es" label="un flag" />) cambia solo esa ejecución. Gana a una variable de entorno; después vienen el valor del perfil en el archivo, `defaults` y el valor integrado. Algunos ajustes no tienen opción ni variable; la referencia de cada servicio de mensajería indica cuáles existen.

## Un ejemplo

```json
{
  "defaults": { "limit": 20, "sendsPerHour": 30 },
  "profiles": { "work": { "limit": 50 } }
}
```

`tg work chats list` muestra 50 resultados, los demás perfiles 20, y `--limit 5` muestra cinco en un solo comando.

<details id="full-example" className="docs-disclosure">
<summary>Un ejemplo más completo con perfiles, bots y permisos</summary>

```json
{
  "defaultProfile": "personal",
  "defaults": { "limit": 20, "keepRunsForDays": 14, "updateCheck": true },
  "profiles": {
    "personal": { "limit": 50, "color": true },
    "work": { "limit": 10, "record": true, "permissions": { "messages": "readonly" } }
  },
  "personal": { "defaults": { "sendsPerHour": 30 } },
  "bot": { "profiles": { "shop": { "sendsPerHour": 200 } } }
}
```

- `defaultProfile` se usa cuando un comando no indica perfil.
- `defaults` se aplica a todos los perfiles; `profiles.<nombre>`, a uno.
- `personal` se aplica solo a los comandos de tu propia cuenta; `bot`, solo a los comandos `tg <nombre> bot …` y `max <nombre> bot …`.
- `work` guarda un registro de cada ejecución y solo puede leer mensajes.

</details>

## Todos los ajustes de Telegram y MAX

Las dos herramientas comparten la mayoría de los ajustes, como `limit`, `sendsPerHour`, `record` y `permissions`. Algunos existen solo en una: por ejemplo, `proxy` en Telegram y `serve` en MAX. Cada servicio de mensajería documenta los suyos:

- **Telegram:** [guía de configuración de Telegram](./tg/configuration.md) · [todos los ajustes de Telegram, sus valores predeterminados y variables de entorno](./tg/configuration-reference.md).
- **MAX:** [guía de configuración de MAX](./max/configuration.md) · [todos los ajustes de MAX, sus valores predeterminados y variables de entorno](./max/configuration-reference.md).

## Perfiles y bots

Pon el nombre del perfil antes del comando, como `tg work config show`. Añade `bot` después para trabajar como bot en lugar de con tu cuenta personal. [Perfiles y bots](./profiles.md) explica cómo elegirlos y cambiar entre ellos.
