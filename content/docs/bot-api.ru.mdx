Здесь вы узнаете, что доступно боту, как подключить его и проверить доступ перед первой задачей.
Бот — отдельный аккаунт со своим именем и правами. Он не получает доступ к вашей личной переписке.

Bot API — официальный способ управлять ботом Telegram или MAX из программы. С помощью инструментов командной строки `tg` и `max`
вы можете поручить это агенту или выполнить команды сами: отвечать от имени бота, публиковать
отчёты и помогать с задачами группы.

## Что умеет бот

- **Сообщения:** отправлять ответы и публикации, редактировать и удалять свои сообщения, добавлять кнопки.
- **Файлы и медиа:** отправлять и получать поддерживаемые мессенджером документы, фото и другие вложения.
- **Входящие события:** получать новые сообщения и нажатия кнопок для обработки агентом или вашей программой.
- **Группы и каналы:** работать с участниками, закреплениями и настройками там, где боту даны нужные права.
- **Настройка бота:** проверять его данные, задавать список команд и подключать получение событий.

Конкретные методы и типы вложений отличаются в Telegram и MAX. Бот видит только то, что ему разрешает мессенджер. Для непрерывных автоответов потребуется работающий обработчик событий; одна команда сама по себе его не запускает.

## Подключите бота

Сначала создайте бота по [инструкции Telegram](./tg/bot.md) или [MAX](./max/bot.md). Затем сохраните его <DocTerm term="bot-token" lang="ru" label="токен" /> в скрытом запросе терминала:

```sh
tg support bot auth set
max support bot auth set
```

`support` — выбранное вами имя профиля бота. Выполните команду своего мессенджера. Токен вводится локально; не отправляйте его агенту в сообщении. Проверка ниже покажет, какой бот подключён:

```sh
tg support bot me
max support bot me
```

Ожидайте имя и идентификатор именно вашего бота. Затем добавьте его в нужную группу или канал либо начните с ним личную беседу. Для Telegram пользователь должен сначала начать диалог с ботом, чтобы тот мог ему написать.

## Поручите агенту задачу

```text prompt
Используй подключённого бота support: проверь, кто он и какие события ему доступны. Предложи, как подготовить отчёт для моей группы. Покажи, какой чат выбран, и составь черновик. Пока ничего не отправляй.
```

Агент должен показать бота, выбранный чат и черновик. Вы проверяете текст и получателя, затем отдельно разрешаете отправку. Как узнать чат и отправить сообщение: [Telegram](./tg/bot.md) или [MAX](./max/bot.md).

## Когда нужен полный API

Для обычных задач есть удобные команды вроде `bot messages send`. Для более редких операций доступен весь нативный Bot API: 185 методов Telegram и 33 операции MAX в закреплённых схемах.

```sh
tg support bot api --help
max support bot api --help
tg support bot api get-me --json
max support bot api get-my-info --json
```

Справка метода объясняет его поля. Имена и параметры следуют API провайдера. Полный API доступен через командную строку; MCP даёт отдельные инструменты для типичных задач. Агент с терминалом может использовать оба интерфейса.

[Настройка и задачи Telegram-бота](./tg/bot.md) · [MAX-бота](./max/bot.md). Официальные методы: [Telegram](https://core.telegram.org/bots/api) и [MAX](https://dev.max.ru/docs-api).
