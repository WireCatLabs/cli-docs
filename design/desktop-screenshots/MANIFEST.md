# WireCat Desktop showcase screenshots

Captured 2026-11-02 at 1440×900 from the browser build with `?showcase` (PR WireCatLabs/wirecat-desktop#58), every
screen in en, ru and es, light and dark. Names: `wirecat-<screen>-<theme>-<lang>-1440x900`.

- All data is made up, and it is written in the screenshot's language: chats, messages, tasks, memory and the search
  query («Лиссабон», «Lisboa», "Lisbon").
- Tool versions are the ones on npm on 2026-11-02: tg 0.112.0, max 0.95.0, wa 0.23.0, zm 0.64.0, drive 0.55.0,
  memo 0.131.14. No update is offered.
- Tools: WhatsApp's details are open. en and es hide the MAX row (MAX is shown only to Russian visitors); ru keeps it.
  Other screens still name MAX where the app lists every tool (Agents skills, the connect step's buttons).
- PNG is lossless; WebP is quality 82. Suggested homepage hero: `tools`; gallery: `search-hit`, `tasks`, `memory`,
  `connect`.
