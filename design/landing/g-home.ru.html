Один день с агентом

Вы спрашиваете обычными словами. Агент запускает одну команду tg и возвращается с ответом, а не с перепиской.

08:00

Утренняя сводка

tg inbox --new

Настройте один раз по расписанию. Пока вы не открыли мессенджер, агент уже прочитал всё, что пришло за ночь, и написал вам одно сообщение.

Заглушённые группы не попадают в сводку, если вас в них не упомянули. Ничего не отмечается прочитанным, так что никто не видит, что вы заглядывали.

# Send later. Telegram delivers it on time, with your laptop shut.$ tg messages send me "Позвонить маме" --at-time 2h
# Everything else you do by hand. Replies, files, reactions, polls, edits, forwards, pins.$ tg messages send "Книжный клуб" "Протокол" --file minutes.pdf
# The bot's name is the first word. Keep several, each under a name you choose.$ tg bot list --check
# Tokens in the system keyring. Never printed, not even in an error.$ tg sales bot auth set
# Each bot has its own list of chats. It writes only there, and keeps a journal of what it sent.$ tg sales bot recipients add user:<id>
# Messages and files. Send, edit, delete and pin, to a chat or to a person.$ tg sales bot messages send "Команда" "Сборка готова" --file report.pdf
# On MAX, the whole Bot API. Members, admins, buttons, the command menu, webhooks and moderation.$ max sales bot api get-updates --limit 10
# A bot for your agent. An MCP server of its own, read-only by default.$ max sales bot mcp

Почему это работает так хорошо

Сделано в первую очередь для агентов и скриптов: быстро, предсказуемо и с журналом.

Быстро
Поиск идёт по копии чатов на вашем компьютере. Без сети и без ожидания.
tg messages search "договор" --offline
Всегда свежее
Фоновая служба держит копию в актуальном состоянии и догоняет пропущенное после перезапуска.
tg server install
Много аккаунтов и ботов
У каждого профиля и бота есть имя, и это имя — первое слово команды.
tg work inbox
Читает без следа
Чтение ничего не отмечает прочитанным. Собеседник ничего не видит, пока вы не решите.
tg chats mark-read
Не отправит дважды
Если связь оборвалась во время отправки, повторите команду. Telegram узнает её и отбросит копию.
--send-id
Журналы без ваших сообщений
Каждая отправка попадает в журнал, каждый вызов можно отследить — без текста, имён и номеров.
tg sends list · --trace
Секреты — в хранилище паролей
Ни пароль, ни код входа, ни номер телефона, ни токен не вводятся в командной строке.
tg session start
Сделано для агентов
Одно значение JSON в stdout, ошибки в stderr, свой код возврата для каждой ошибки.
--json
