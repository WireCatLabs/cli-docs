Conecta tu agente en una línea

Cada herramienta incluye una skill para agentes y un servidor MCP.

Claude Code · Codex · Gemini CLI

Instala la skill: qué comandos hay y cómo usarlos.

tg skill install

Claude Desktop · Cursor

Imprime la entrada MCP para tus ajustes. Incluye prompts listos:

/catch-up/review/reply/find
tg mcp config

# Group broadcasts. Ask your agent to send an announcement to the groups and channels you choose.$ max sales bot chats list
# Personalised messages. Let your agent tailor each message using the customer details you provide.$ max sales bot messages send user:4815162342 "Anna, your order is ready"
# Replies with context. Give your agent a knowledge base or conversation history to help it answer customer questions.$ max support bot messages list "Support" --limit 20
# Team notifications. Keep people informed about requests, results and changes, with the files they need.$ max sales bot messages send "Equipo" "La build está lista" --file report.pdf
# Buttons and clear choices. Help people choose an action, open a link or respond with a tap.$ max sales bot commands set start=Start help=Help
# Control what gets sent. Choose who the bot may contact and check which sends succeeded or need attention.$ max sales bot sends list
# Question monitoring. Find questions left without an answer so members get the help they came for.$ tg review --chat "Senderismo" --unanswered
# Analytics Who joined, left, was added or removed, and who did it.$ tg chats events "Senderismo" --since-time 7d
# Keep discussions on track. Ask your agent to flag spam, insults and conflicts so you can step in early.$ tg review --chat "Senderismo" --since-time 1d
# Moderation by your rules. Choose which violations to flag, which messages to delete and when to remove a participant.$ max chats check "Vecinos"
# Discussion summaries. Get the decisions, open questions and next steps without rereading the whole conversation.$ tg review --chat "Senderismo" --since-time 7d
# Group management. Delegate routine invitations, admin changes and invite-link updates to your agent.$ tg chats create "Senderismo 2027" @sofia

Funciona en todas partes
Windows, macOS y Linux con Node.js 22 o posterior. No necesitas compilar módulos nativos.npm i -g @leemour/tg-cli
Búsqueda potente
Encuentra mensajes incluso con erratas o palabras incompletas. Busca en chats y canales, filtra por autor o fecha y recupera el contexto de la conversación.tg messages search "contrato"
Almacenamiento local
El historial se guarda en una caché local en tu ordenador. Busca sin conexión, crea copias de seguridad y restaura el historial cuando lo necesites.tg store backup · tg store restore
Permisos flexibles
Tú controlas qué puede hacer el agente: solo leer, ejecutar comandos permitidos o pedirte permiso antes de actuar.permissions.messages.send · --confirm-send
Siempre al día
Un servicio en segundo plano mantiene el historial local al día y sincroniza los mensajes pendientes tras un reinicio.tg server install
Varias cuentas, varios bots
Cambia fácilmente entre cuentas y bots. Separa tus conversaciones personales de las de trabajo, o pide a tu agente que reúna contexto de varias cuentas.tg work inbox
Historial de acciones
Consulta los intentos de envío y registra las ejecuciones de comandos cuando lo necesites. Los registros incluyen identificadores, estados y tiempos, sin el texto de los mensajes.tg sends list · tg runs list · --record
Seguro
Los secretos se guardan en el almacén de contraseñas del sistema. Las contraseñas, los códigos de acceso, los números de teléfono y los tokens no se filtran a los registros ni al historial de comandos. La protección contra la inyección de instrucciones (prompt injection) ayuda a impedir que mensajes maliciosos controlen al agente.tg session start
