Who owes who

Your agent finds the payments in the chat and does the sums.

tg search messages "paid" --chat "Lisbon trip"

Settle Lisbon for me.

Ana paid €240, Ben €96, you €60. That's €132 each: you send Ana €72, Ben sends her €36. Post it in the chat?

Connect your agent in one line

Each tool ships with an agent skill and an MCP server.

Claude Code · Codex · Gemini CLI

Installs the skill: which commands exist and how to use them.

tg skill install

Claude Desktop · Cursor

Prints the MCP entry for your settings, with ready prompts: /catch-up, /review, /reply, /find.

tg mcp config
