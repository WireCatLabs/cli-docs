# WireCat homepage variants

Six English homepage explorations, preserving the WireCat type, palette and mark while varying the offer, section order and demonstrations. These files are independent of the production landing export.

```sh
node design/homepage-variants/build.mjs
node design/homepage-variants/serve.mjs 4325
```

Open http://localhost:4325 for the comparison index. Pages: `/direct`, `/memory`, `/context`, `/audiences`, `/workflow`, `/minimal`.

Interactive controls include keyboard-accessible example tabs, source disclosures, copied requests, a persisted theme choice, installation-provider selection and connected-workflow stages. Installation and reference links lead to public WireCat documentation. The preview server serves repository fonts locally and sends noindex headers. Stop it with Ctrl+C.

Product scope: tg/max are WireCat tools; email uses third-party Himalaya and notes use the user's Obsidian vault. Conversation semantic search needs builds and embeddings. Illustrative results demonstrate workflows rather than execute messenger operations.
