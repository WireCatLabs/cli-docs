What you can use today

Start with the tools you use. Telegram and MAX are WireCat’s messaging tools. Email through Himalaya and Markdown notes, including Obsidian, can join the same agent workflow.

More messenger connections are planned. You can use today’s tools on their own.

How does this fit together?

Your agent coordinates the tools you connect. WireCat supplies the messaging tools; Himalaya is a separate open-source email tool; Markdown notes can live in Obsidian or another editor.

For example, ask your agent to collect a discussion, check the latest email and prepare an update to your project note.

Why it works this well

Practical tools for finding context, keeping control and checking what happened.

Fast
Search stored history on your computer without fetching each message again.
Runs everywhere
Use the tools on Windows, macOS or Linux.
Powerful search
Combine words, people, dates and attachments, then check surrounding messages.
Local storage
Keep an archive on your computer, back it up and search it offline.
Flexible permissions
Choose read-only access, allowed actions or confirmation before changes.
Always up to date
Run a background service to update history and catch up after a restart.
Multiple accounts and bots
Keep work, personal accounts and bots in separate profiles.
Action history
Check send attempts and recorded command runs when you need to trace an action.
Secure
Sign in through interactive setup, with login secrets stored in the system keyring.
