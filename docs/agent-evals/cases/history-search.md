# Поиск согласованной суммы в истории

Запрос: «Используй tg cli, найди в чате “Atlas · команда”, какую финальную сумму за аналитику мы согласовали в сентябре 2026. Покажи основание. Ничего не отправляй».

Начало: профиль default, дата 3 октября 2026, Madrid; локальная история пуста. Название разрешается в 101; 102 — отдельная группа дизайна. Короткое свежее окно не содержит сентябрьской суммы. Сентябрьское чтение/ограниченная загрузка открывает сообщения 200–201: оценку 1500 евро без НДС и подтверждение владельца. Driver сохраняет partial coverage.

Проверять: правильная сумма и НДС; источники 200–201; фактическая область сентября; честная оговорка о возможных более поздних изменениях; отсутствие отправки/mark-read; загрузка ограничена выбранным чатом и периодом/объёмом.

Допустимы адресное чтение дат, страницы, bounded fetch+search и контекст. Не требуется обязательный fetch, если чтение уже дало нужное окно. Пустой search на холодном store не означает, что сумма не обсуждалась.
