# tg 0.62.0 tasks review

Reviewer: Claude. Portal base: `b3586e2`; final rebase recorded in the PR.
Reviewed runtime: tg `v0.62.0`, commit `4bb5ee11715997ee27731b15cf046c06b38fcfb4`,
Core `0.296.0`, Base `0.40.0`. Compared native guides and generated command reference
against `v0.61.0` (Core `0.292.0`). Other runtime pins remain unchanged: MAX stays at `v0.55.0`
(Core `0.288.0`) and Memo at `v0.45.0` (Core `0.293.0`), so the shared pages say which task
features only `tg` has.

Readers can now tell when an agent's close waits for them, how to confirm or refuse it, how a new
task about a recently closed one is linked, which categories the default list holds and how to find
tasks whose category left the list. Changed native prose was reviewed in RU/ES (the native guides
are English); the shared Tasks and How tasks work pages were revised in EN/RU/ES.

## Evidence and corrections

- tg tagged `docs/commands.md`, `docs/groups.md`, `CHANGELOG.md` and `package.json` between
  `v0.61.0` and `v0.62.0`: `tasks close --certainty/--as-owner`, the new `tasks reject`, the config
  keys `task_agent_close` and `task_agent_close_min`, follow-ups instead of a refusal for a closed
  candidate. Roadmap unchanged between the two tags and lists no task work.
- cli-core `CHANGELOG.md` 0.295.0 and 0.296.0 and `docs/dev/tasks-plan.md` (sections "Follow-ups and
  agent closes" and "A message linked to a task"): certainty threshold 0.8, store-wide settings,
  close suggestion fields, store version 17 columns, follow-up rule and 14-day window, the duplicate
  check's views of the source and 5 newest linked messages, the re-check after `tasks link`,
  `--into` and `merge`, Spanish stems and due dates. 0.293.0 and 0.294.0 have no task changes.
- cli-core `src/domain/task-categories.ts`: 59 default names and meanings, list cap 80; the How tasks
  work table copies the names in order and the meanings (translated in RU/ES).
- cli-core `src/cli/store-settings.ts`: a store without a saved list uses the opening tool's default
  list, so the shared pages say MAX and Memo still offer the earlier seven until they take the new
  core; a saved list is shared.
- `tg --help` of the npm `0.62.0` package, run with a throwaway HOME: `tasks close` lists
  `--certainty` and `--as-owner`, `tasks reject` exists, `tasks list` accepts `close:suggested`.
  `config set task_agent_close_min 0.9` and `config show` in that empty store printed the 59
  categories, `task_agent_close on` and the new threshold.
- The Tasks page no longer lists the linked-message check as not built; How tasks work drops it and
  the two open questions, both ruled by the owner on 2026-10-16.
