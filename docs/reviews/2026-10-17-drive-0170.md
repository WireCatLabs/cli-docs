# Drive database-copy review

Readers moving an existing Drive archive to the shared database can preview and copy document
context, then verify local notes and search without discarding their original database. The
existing recipes, import/storage guide, recovery guide and command reference own this workflow;
no new sidebar page or installation path is needed.

upgrades. These are synthetic temporary stores, with network and native credentials refused.
