# Memo 0.91.0 documentation review

Readers installing Memo or connecting an agent need the released commands, permission boundaries and current
roadmap in each language. This update advances the existing Memo integration from 0.90.0 to 0.91.0; the
roadmap route and translated roadmap already existed before this branch.

## Sources and scope

- [Released source](https://github.com/WireCatLabs/cli-memo/tree/v0.91.0), package `@wirecat/cli-memo@0.91.0`.
- [MCP implementation](https://github.com/WireCatLabs/cli-memo/pull/383) and
  [setup/readers implementation](https://github.com/WireCatLabs/cli-memo/pull/384), with synthetic runtime tests.
- [Release validation](https://github.com/WireCatLabs/cli-memo/actions/runs/40106292227).
- Site base: `1161ac2`, which already includes the Memo 0.90.0 roadmap review.

Reviewer: Codex. The changed English source and Russian/Spanish reader prose were compared with the release
behavior. Existing unchanged translations remain from the prior review. Generated operation descriptions in
command references and technical changelog entries remain English, as disclosed in those pages.

| Pages, all locales | Reader task | Review result |
|---|---|---|
| index, notes | Start and understand file changes | Describe explicit note editing/export; preserve existing destinations and examples |
| installation, troubleshooting | Install and repair | Explain npm 11.17 warning versus npm 12 blocking; point to Memo's own model download |
| mail, configuration | Add a selected account and limit agents | Explicit account/email match; local configuration check, no mailbox login; saved MCP levels and stricter overrides |
| mcp | Connect and open cited sources | Command coverage, legacy names, write permissions, runtime locks, delegated decisions and whole-record reads |
| memories, how-it-works, security, recipes | Review agent records | Keep proposed state, explicit delegation and annotation preview boundaries distinct |
| search | Search stored sources | Shared meeting selectors, explicit source, local stored reads and unverified future calendar times |
| commands | Look up syntax | Refresh the generated reference from the released tree; retain localized introduction and exact executable examples |
| changelog, roadmap | See what shipped and what remains | Import substantive 0.91.0 notes; remove shipped model/account/cited-read tasks from future work |
| compare | Choose a memory tool | Add Russian/Spanish prose; preserve native evidence links and feature marks; clarify remote language-model key versus local embeddings |

Portal corrections retain the immutable release source while correcting remaining broad owner-only meeting
wording in index/memories/recipes and the comparison's ambiguous model sentence. The supporting implementation
is linked in each correction. These should also be corrected in the native guides in a later documentation PR.
No runtime behavior or command contract was changed to satisfy a guide.

## Validation

- All Memo locale structures preserve headings, code blocks, inline literals and link destinations.
- Release-note/roadmap gate and exact released command captures passed.
- Strict guide check: 1,457 reference entries, no reference gaps and no invalid examples. The 147 syntax
  illustrations/manual-review cases are reported separately by the existing whole-site checker.
- 334 site unit tests, typecheck and repository lint passed.
- Initial browser verification exposed missing comparison-page descriptions; all three are now present and
  a focused metadata regression test covers the released route. The local dev server stopped under machine
  memory pressure, so full rendering/browser validation is delegated to the existing CI export suite.

This is a documentation review, not a declaration that Memo meets every shared CLI standard. The remaining
three-entry-tool MCP migration is tracked as MEMO-31 in Memo's backlog; individual and legacy tools remain in
this release. HTTP MCP and graph-engine benchmark results are not presented as shipped.
