# Memo document evidence and project review

Readers gathering a project's sources can inspect the paragraphs around cited documents, understand
which proposals an agent may decide and choose owner-only project decisions. This review updates
Memo from the portal's reviewed 0.81.0 to 0.82.0 without changing other tools' pins.

## Findings and corrections

- Native overview, security, explanation, memory and usage pages said agents could never decide
  anything through MCP. Fixed upstream: default project decisions may create accepted facts,
  numbered tasks or confirmed key documents; `agent_decisions: false` requires owner decisions.
  Direct memories/facts and outbound action proposals remain proposed; meeting findings are owner-only.
- Native memory prose named `accept` and `origin`, contradicting its command example and record shape.
  Fixed upstream to `memo facts confirm` and `source`; retired the portal's obsolete `accept` correction.
- The explanation promised nothing could access the network unless requested. Updated it to link the
  existing update/sender-domain policy; source-text analysis remains opt-in.
- Translation structure found a missing usage-to-project-review link. Added it in both locales and
  checked all ten updated prose-only translations before accepting their source fingerprints.
- The broader portal release update landed during preparation. Rebased on `6155c96`, preserving its
  tg0.77/MAX0.66/Zoom0.31/Drive0.19 pins and reviews. Memo-only conflicts retain the newer reviewed text.
