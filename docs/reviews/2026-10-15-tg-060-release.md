Readers can follow the existing search, archive, group-work and configuration paths with the
released syntax. Changed prose and examples were reviewed in EN/RU/ES, including surrounding
context, task openings and handoffs. Unchanged historical changelog prose and unchanged command

## Evidence and corrections

- TG tagged `docs/*.md`, `CHANGELOG.md` and `package.json`: permissions-only snake_case settings,
  Lucene-only message queries, shared flag vocabulary and task categories/claims/duplicate decisions.
- Core tagged `src/cli/envelope.ts` delegates JSONL framing to Base and emits item records followed
  by an end record. The old “items only” statements receive explicit portal corrections.
- Mail belongs to Memo. Removed obsolete TG-mail examples and stale cross-tool import advice;
  Memo remains pinned to its older reviewed release, so note import uses its existing syntax.
- Corrected provisional “next cli-core” changelog labels from the exact tagged package pins.
- Preserved removed configuration, query-mode and command anchors with explicit aliases.
- Restored the valid `allow` permission level after removing only the obsolete `allow` setting.
- Shared task examples use `--remind-time`; the report task chooses TG `--max-pages` or the
  separately pinned MAX `--budget`. The TG homepage example no longer selects a removed language.
- Category, claim and duplicate terminology now describes released capabilities rather than plans.

## Validation

Guarded command capture installs exact npm releases in temporary state with network/keyring
access blocked. No account or mailbox data is used. Localization, strict command examples,
release-note checks, lint, synthetic tests and the browser smoke suite run locally; complete
export, links, SEO and browser coverage remain CI responsibilities. Final counts and targeted
rendering checks are recorded in the PR after completion.

Local result: all five guarded release contracts captured; localization complete; 1,297 command
reference entries, zero gaps and zero invalid examples (141 unsupported/syntax cases retained
for manual review). All 305 synthetic tests and seven smoke tests passed. Lint passed with two
existing warnings. Targeted EN/RU/ES search, settings and command pages were checked at 390px
and 1280px; no page overflow. Mobile search screenshots exposed a stale mail promise in the
native opening; it now has an explicit correction in every locale. Existing Sidebar key warnings
in dev output remain outside this release documentation change.
