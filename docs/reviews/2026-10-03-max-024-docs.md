# MAX v0.24 documentation review

Published source: [MAX v0.24.0](https://github.com/leemour/max-cli/releases/tag/v0.24.0), compared with v0.23.0. Telegram stays at the previously reviewed v0.22.0. Review includes 17 MAX guides plus the changelog, English and Spanish translations, and the shared installation flow. Russian tool guides use the release's Russian source with reviewed portal corrections.

## User-facing changes

- Start with `max setup --agent all`: guided QR login, reuse of an existing session, account/five-chat checks, and agent skills. Setup neither backfills history nor starts the background service. Explicit QR reconnection remains available through `max session start qr`.
- A dedicated search page explains the strict Lucene default, fields and dates, local archive coverage, and `--language legacy` for forgiving search. MAX landing examples select legacy explicitly to preserve their demonstrated matching behavior.
- Personal moderation uses `max chats moderate`, `--since-time`, and `{chatId, rows}`. The preview/approval sequence remains in the demo. Bot and personal MCP tool names retain their own compatibility contracts.
- Group events use `--type`/`--since-time`; member lists are paginated unless `--all` is selected. Mutation results include `operationId`; updated guides explain the envelopes and partial/unknown outcomes.
- Removed `max cache clear` examples are replaced by the bounded `store clear --left` workflow. The guides distinguish the common archive from legacy profile files.

## Retained errata

The release still contains a shell example that negates the exit code before reading `$?`; the portal preserves the corrected `if/else` example in every language. Unix state-file permissions are distinguished from configuration permissions and Windows ACLs. Existing beginner definitions, Cursor terminal-access guidance, scheduled-send hour accounting, and QR reconnection guidance remain where applicable. Errata superseded by release changes are retired rather than layered over new text.

## Validation

Translations must pass source fingerprints, matching heading structure, unchanged code blocks and inline literals, and identical link destinations before publication. The installed npm v0.24.0 package's setup help and offline command contract were checked without logging in or reading messenger data. Publication also requires lint, unit tests, type checking, a production build, internal link checks, remote CI and Windows checks, plus live checks of all three locales and MAX search/setup/moderation examples.
