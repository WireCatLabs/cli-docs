# Drive 0.34.0 reviewed publication

Readers can look back at what a failed drive command did with `drive runs list` and `drive runs show`, and choose
which runs are kept. The portal targets published Drive 0.34.0, Core 0.422.0 and Base 0.53.0. Reviewer: Claude.

## Sources and boundaries

- [Published release](https://github.com/WireCatLabs/drive-cli/releases/tag/v0.34.0), commit `41922f9`, and
  [successful validation/publication](https://github.com/WireCatLabs/drive-cli/actions/runs/40209689235).
- Runs are [Drive PR 219](https://github.com/WireCatLabs/drive-cli/pull/219); help and MCP wording is
  [PR 224](https://github.com/WireCatLabs/drive-cli/pull/224). [PR 226](https://github.com/WireCatLabs/drive-cli/pull/226)
  moved PR 224's changelog line out of the released 0.33.0 section, so 0.33.0 matches its tag.
- `npm view @wirecat/drive-cli@0.34.0` names cli-core 0.422.0 and cli-base 0.53.0; an isolated install printed
  `0.34.0` for `drive --version`. `pnpm docs:contracts` captured the 0.34.0 command contract.
