# Documentation opening audit — 9 October 2026

The owner requires: page purpose → reader outcome → necessary terms/explanation → instructions.
The primary page openings were inspected by page job; this inventory records all three locale
files and the active HTML/Markdown presentation layer. Native text is not the effective opening
when a reader/orientation layer precedes it. Reference/history pages keep their own appropriate
scope rather than acquire artificial tutorials.

Reviewed 88 page homes and 264 locale files. Existing task openings remain;
weak native installation/query/migration/reference openings now have a localized purpose/outcome
layer. Agents, MCP, search and Bot API openings were revised directly. Product-action mentions
now name tg/max; project identity, real addresses and filenames are preserved.
