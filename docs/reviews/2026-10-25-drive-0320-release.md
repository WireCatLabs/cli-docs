# Drive 0.32.0 reviewed publication

Readers learn that Drive documents now sit in the store's own Google Drive account, named by the drive profile,
that `files list` takes the shared field query language, when a plain Markdown file in Drive is enough instead of a
mirror, and that local images stay as text in a mirrored Doc. The portal targets published Drive 0.32.0, Core 0.420.0
and Base 0.53.0, and covers 0.30.0 and 0.31.0, which were not published here. Reviewer: Claude.

## Sources and boundaries

- [Published release](https://github.com/WireCatLabs/drive-cli/releases/tag/v0.32.0), commit `098703c`, and
  [successful validation/publication](https://github.com/WireCatLabs/drive-cli/actions/runs/40195307566).
- `npm view @wirecat/drive-cli@0.32.0` names cli-core 0.420.0 and cli-base 0.53.0; `pnpm docs:contracts` captured
  the 0.32.0 command contract with the network disabled.
- The documents account appears in the released pages only in the changelog. `--source drive:<profile>` appears in
  recipes and search; no released guide names `google-drive:<principal>`, so RU/ES do not either.
