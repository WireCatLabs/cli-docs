# Zoom 0.48.0 reviewed publication

Readers find recorded runs where zm writes them, `~/.local/share/zoom-cli/runs`, and see the `files.problems` entry
named field by field. A bare `zm --version` answers faster; nothing else a reader types or reads changed. The portal
targets published Zoom 0.48.0 (Core 0.430.0, Base 0.57.0, the same as 0.47.0).
Reviewer: Claude (release update session, 26 October).

## Sources and boundaries

- Release: tag [v0.48.0](https://github.com/WireCatLabs/zoom-cli/releases/tag/v0.48.0); npm `@wirecat/zoom-cli@0.48.0`
  depends on `@wirecat/cli-core` 0.430.0 and `@wirecat/cli-base` 0.57.0, unchanged from 0.47.0.
- Commits since v0.47.0: zoom-cli#265 (CI), #266 (`--version` fast path), #267 (guides point recorded runs at
  `~/.local/share/zoom-cli/runs`), #268 (release).
- Native guide changes: configuration (`files.problems` fields), installation (paths table and uninstall list),
  troubleshooting (run log path). Changelog gains 0.48.0. No other page changed; the commands page is unchanged.
- Portal errata: all four zm entries (search, configuration, installation, sessions) still match exactly once; none
  are retired or added.

## Runtime evidence

The released 0.47.0 and 0.48.0 packages were installed with `--ignore-scripts` into scratch directories and run with
`env -i` and a scratch `HOME`, so no keyring or Zoom account was reachable.

| Claim | Evidence |
| --- | --- |
| No command, option or description changed | `zm commands --json` of 0.47.0 and 0.48.0 are byte-identical apart from `version` |
| `zm --version` prints the version | `0.48.0`, exit 0 |
| Recorded runs go to `~/.local/share/zoom-cli/runs` | after `zm personal config show --record` the scratch `HOME` holds `.local/share/zoom-cli/runs/<date>` |
| `files.problems` entries are `path`, `mode`, `want` | `config.json` at `0644` → `{ path, mode: "0644", want: "0600" }`; stderr `to make it private: chmod 600 '<path>'` |
| Windows paths `%LOCALAPPDATA%\zoom-cli\Data\` | source only: the native guide; not run on Windows |
