# Drive 0.14.0 review

This release keeps the existing user workflows while moving shared document behavior into Core.
The visible fix preserves picture checkpoint markers, avoiding repeated image downloads during
incremental sync. Readers continue using the existing install, import, search and knowledge guides.

## Source review

Core #1348 introduces a public document facade and separate domain/planning/sync/ingestion/knowledge/
extraction modules. Drive binds Google clients, conversion, metadata/identities, profile settings,
locks and filesystem I/O. No Google SDK moved into Core. Module import rules enforce these boundaries.
The document refactor adds no migration; Core 0.295.0 also includes main's separately developed task
store version 17, covered by Drive's prior-store upgrade checks.

Drive retains its explicit profiles, output envelopes, command tree, metadata keys, collection names
and checkpoint formats. The new optional picture marker is backward compatible. Google writes and
OAuth grants retain their existing controls. No provider account or real model was used in testing.
