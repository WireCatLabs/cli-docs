# Редакторский проход по всей документации

Проверены 87 адресов документации в EN/RU/ES: вступления, структура разделов, завершение,
необъяснённые термины и переходы к другим страницам. Для страниц с командами дополнительно
выполняется проверка контракта релиза. Это редакторский проход, а не доказательство каждого
описанного поведения на реальном аккаунте. Личные аккаунты не использовались.

Исходная рабочая версия: `6db1b09`, включающая main `e70b784`; TG v0.37.0 / MAX v0.36.0.
Общие страницы правятся здесь. Тексты мессенджеров импортируются из проверенных исходников;
для них сохранены владение исходником и ссылки на него.

## Что исправлено

- Подключение из браузера: конкретно ChatGPT/claude.ai, простой смысл MCP и публичного адреса, установка Tailscale через интерфейс, проверка соединения и вариант с сервером.
- Возможности: короткий список главного → полный обзор по задачам → запросы и точные команды.
- Запросы, настройки, права, профили, MCP, безопасность и администрирование: понятная задача и результат перед инструкциями; запрос администратора перед командами.
- Пояснения: значок без боковых отступов; терминал, публичный адрес, OAuth, профиль, локальный архив, речевая модель, параметр команды, токен бота, проверки агента и совместимость других агентов.
- Переходы: конкретные руководства вместо повторов «подробности в руководстве»; у технических страниц — ссылка к соответствующей пользовательской задаче, одинаковая в HTML и Markdown.
- Убраны обычный английский жаргон в русских задачах и неточное обещание подтверждения `ask` через MCP. Технические названия команд и полей сохранены.
- MAX определён как инструмент командной строки; его страница безопасности получила короткое название и прямое объяснение предмета.
- Карта задач обновлена после добавления интерактивных пояснений и дополнена уже существующими инструкциями по файлам/голосовым и отчётам групп. Новых публичных страниц ради покрытия не создано.

## Проверки

- 227 модульных тестов и 34 браузерные проверки прошли.
- Сборка: 542 адреса; проверка внутренних ссылок и SEO прошла.
- Markdown lint, проверка типов, форматирование, локализация и проверка записей релиза прошли.
- Контракты: 894 записи команд, без пропусков и некорректных примеров; 8 карт пользовательских задач. 108 сокращённых/шаблонных примеров явно остаются в очереди ручного разбора.
- Пять изменённых страниц просмотрены на ширине 390px: горизонтального переполнения нет, Markdown возвращается с кодом 200, компоненты пояснений раскрыты в текст.
- Размер значка пояснения проверен в браузере: 14px, внешний отступ 0px. Проверены наведение, клавиатура, Escape и касание на мобильном экране.
- В пояснении совместимости перечислены шесть агентов и общие требования для других; проверена ссылка на страницу агентов.
- Переход с ограничений MAX ведёт к восстановлению MAX. Восстановлено раскрываемое изображение сайта входа Telegram: вставка выполняется после уже существующего контекстного исправления, а не по старому исходному заголовку.

Полная локальная опись: `.docs-tooling/reports/editorial-pass/inventory.json` — содержит вступления, заголовки, окончания и количество переходов/пояснений для каждой языковой страницы. Это свидетельство объёма прохода, а не оценка качества по количеству ссылок.
