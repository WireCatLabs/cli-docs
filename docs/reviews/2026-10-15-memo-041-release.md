# Memo release review

Reviewer: Codex. Base: `9d2e44d`. Runtime source: Memo `v0.41.0`, commit
`acbc3fcec4b730b1c75bbd9d77a31f721c86f932`, Core `0.288.0`, Base `0.33.0`.
Compared native sources and generated help with `v0.21.0`. The npm registry and GitHub tag agree
on this release. Memo has no roadmap page; no roadmap review is invented. Other runtime pins stay.

The portal's existing install → notes/mail → search → review path is retained. Ordinary guide
prose is translated in RU/ES, preserving exact executable fences and literals. Existing English
agent-request fences remain as published. Generated command operation descriptions retain English
with localized reference orientation, as before. New changelog technical entries also retain exact
English body text under localized headings and an explicit language notice; historical translated
entries remain intact. This keeps API migration details exact while user-task instructions are localized.

## Review scope and evidence

Read the changed native guide passages, translated prose, surrounding opening/handoff and tagged
changelog; the previous review remains the baseline for unchanged paragraphs and historical entries.
This is a release-delta review rather than a claim to have re-audited all historical editorial copy.

- Native `docs/*.md`, `CHANGELOG.md` and `package.json` establish current names, progress boundaries,
  store-backed mail rules, Takeout and explicitly linked project key documents.
- Tagged `src/mail/import.ts` checks completed mbox size/mtime before reading; incomplete imports and
  `--rescan` scan again. Corrected the stale each-run claim in the portal, the native guide and skill.
- Core hit items no longer carry `tasks`; follow-up task queries are in `next`. The old `tasks.id`
  selector is replaced with supported compact hit fields. Projection preserves framing, not scan cost.
- `facts confirm` owns acceptance; corrected the old native `accept` literal in surrounding prose.
- Agent authorship is a label, with `--as-owner` able to bypass that label; it is not an access lock.
- Mail probe is read-only; opt-in RDAP discloses sender domains. Skip/envelope rules and cleanup remain
  owner decisions, with previews and retained mailbox state clearly distinguished.
- Context/project links do not infer identity or participation from names. Key documents are per-project,
  not global tags; missing sources retain an unavailable mark.
- Preserved retired install, mail and task section hashes as aliases. Updated affected shared email,
  separately pinned MAX import and Zoom meeting-knowledge examples; removed obsolete portal corrections.
- Replaced retired import with sync in the existing upkeep task mapping, retaining its task destinations.

Native corrections are merged in cli-memo PR207. The installed CLI is 0.41.0; its skill was refreshed
through `memo skill install --for all`, then both installed copies received only the reviewed mbox
paragraph correction. Unreleased mail-rule capabilities on native main were not copied into the
installed skill. A future reinstall from the unpatched package can replace this local correction.
