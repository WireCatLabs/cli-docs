# Telegram 0.106.0 reviewed publication

Readers can see who reacted to a message with `tg <profile> reactions list <chat> <message>`, and the people guide that
shows it now passes the strict example check. A person's profile is `contacts show` (`contacts info` is gone), phone
numbers are shown whole, and `--hide-phone` replaces `--show-phone`. The portal targets published tg 0.106.0
(Core 0.479.0, Base 0.65.0); max stays on 0.84.0. Reviewer: Claude.

The shared people guide in EN/RU/ES (#442) already described `reactions list`, `contacts show` and `--hide-phone`.
Against tg 0.104.0 its six `reactions list` lines were invalid examples, so every deploy since da1a074f failed at
`pnpm docs:quality --strict`. With this pin they are valid; no shared guide changes.

## Sources and boundaries

- [tg v0.105.0](https://github.com/WireCatLabs/tg-cli/releases/tag/v0.105.0) and
  [tg v0.106.0](https://github.com/WireCatLabs/tg-cli/releases/tag/v0.106.0): changelog, `docs/` diff from v0.104.0
  (commands, people, usage changed; roadmap unchanged since v0.92.0), and the npm contract captured by
  `pnpm docs:contracts` (isolated home, network and keyring sockets blocked).
- Run with `pnpm docs:cli` in a throwaway home with a fictional profile `work`, no login, no network, and no D-Bus
  session address:
  - `--version` → `0.106.0`.
  - `work reactions --help` lists `list [options] <chat> <message> [query...]`. `work reactions list --help` shows
    `--limit`, `--cursor`, the `reaction` field and the example `tg personal reactions list "Book club" 101
    reaction:🔥 --limit 20`. `commands info reactions list --json` → permission `reactions.list`, effects
    `remote: read`, `local: read`; rows are `person`, `reaction`, `reacted_at`.
  - `work reactions list "Book club" 101 reaction:🔥 --limit 20 --json` → `authentication_error` (no session), exit 4:
    the arguments parse; the Telegram call itself was not made.
  - `work contacts info @x` → `unknown command 'info'`, exit 2. `work account show --show-phone` →
    `unknown option '--show-phone'`, exit 2. `work contacts show --help` and `work account update --help` list
    `--hide-phone`. `--offline` is a global option.
  - `work mcp serve` answers `initialize` with `serverInfo` `tg 0.106.0`; `tg_tools_search` finds `reactions list` and
    nothing for `contacts info`.
