# Drive spreadsheet release review

The new release lets readers inspect and edit live spreadsheet cells, organize tabs and format
selected ranges while keeping import/search as a separate workflow. Review the source-owned
setup, recipes and reference before updating the portal from Drive 0.15.1. No page route or
installation distribution changes: users still install the npm package and connect through
WireCat's included app or an optional custom Desktop client.
