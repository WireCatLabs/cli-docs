# План: установка, агенты и навигация документации

## Задача и структура

Человек должен пройти путь «выбрать мессенджер → установить → войти → подключить агента →
проверить результат». Лендинг сохраняет утверждённый дизайн `design/landing/g-home*.html`, демо и все основные
секции; короткие CTA ведут в установку Telegram и MAX. Команды
установки skills и подробный запрос агенту живут только в документации.

Общие страницы принадлежат cli-docs; справка по командам и особенностям каждого мессенджера
по-прежнему приходит из его репозитория. Генерируемые `content/docs/{tg,max}` не редактируем.

| Страница | Что решает |
|---|---|
| `/{lang}/docs` | Стартовая точка: установка, подключение агента, MCP, документация Telegram и MAX |
| `/{lang}/docs/installation` | Требования, установка через агента или терминал, вход, проверка, Windows, следующие шаги; исходники `installation*.mdx` |
| `/{lang}/docs/agents` | Подключение Codex, Cursor, Claude Code, Gemini CLI, Hermes; skills, проверка, первая задача |
| `/{lang}/docs/mcp` | Польза MCP, выбор CLI/MCP, настройка клиентов, чтение документации агентами |
| `/{lang}/docs/{tool}/installation` | Существующая справка CLI с заметной ссылкой на общий пошаговый старт |
| `/{lang}/docs/{tool}/mcp` | Существующая подробная справка сервера с переходом к объяснению и настройкам клиентов |

## Решения

1. Верхняя панель документации видна на компьютере и телефоне: WireCat, Telegram / MAX,
   поиск, язык, тема, меню на телефоне. Переключение мессенджера сохраняет раздел, если он
   существует у второго; иначе ведёт на его главную. Язык сохраняет текущий URL страницы.
2. В боковом меню отдельная группа «Начало работы»; общие страницы доступны из каждого
   раздела мессенджера, а стандартные группы справки остаются прежними.
3. Установка через агента — копируемый запрос; установка вручную — последовательность
   команд и ожидаемый результат. Claude Desktop отдельно описываем как MCP-клиент.
4. Skills учат агента пользоваться командами; MCP предоставляет ему инструменты. Терминал
   уже есть у Codex, Cursor Agent, Claude Code, Gemini CLI и Hermes, поэтому MCP необязателен.
5. Проверенные CLI targets — `skill install --for claude` и `--for agents`. Codex, Cursor и
   Gemini используют общую `~/.agents/skills`; Hermes получает `skill show` в собственную
   директорию skills. Не выдумываем `--for cursor`, `--for hermes` или команду `setup`.
6. Оба CLI уже предлагают skill через общую реализацию `skillHint`: в окружении агента
   (`AI_AGENT` или `CLAUDECODE`), на stderr, максимум раз в сутки, если копия отсутствует
   или устарела. Это описываем в документации; расширение автоопределения агентов и мастер
   `setup` остаются следующей задачей CLI, а не обещанием существующего интерфейса.
7. MCP мессенджеров и MCP документации — разные подключения. Сайт сейчас отдаёт `/llms.txt`,
   `/llms-full.txt` и Markdown каждой страницы; собственного `/mcp` нет. Делаем эти способы
   доступными и объясняем их. Новый сервер требует отдельной реализации и размещения:
   текущий сайт — статический export.
8. Общие тексты и интерфейс — на английском, русском и испанском. Собственные страницы
   инструментов сохраняют свой исходный язык и существующую заметку об этом.

## Результат и проверка

Реализованы четыре общие страницы на трёх языках. Существующие страницы установки и MCP
обоих инструментов ссылаются на общий старт. При копировании Markdown общих руководств
сохраняется выбранный язык; основной `/llms.txt` по-прежнему содержит каждую страницу один раз.

- `pnpm sync`: релизы max v0.22.0 и tg v0.21.0, без preview из main.
- `pnpm lint`, `pnpm typecheck`, `pnpm test`: проходят; 8 тестов, включая сохранение раздела
  при переключении и переход на главную, если у второго инструмента раздела нет.
- `pnpm exec next build`: 170 статических страниц и ресурсов; `pnpm check:links`: проходит.
- Chromium: переход с лендинга раскрывает выбранный мессенджер; выбор Hermes меняет запрос;
  ручные команды раскрываются; Telegram / MAX сохраняет раздел, язык сохраняет URL;
  мобильное меню ведёт к общим руководствам; поиск находит Hermes.
- Проверены ширины 320, 375, 768, 1024 и 1440 пикселей. На 375 текст занимает доступную
  ширину. Ошибок JavaScript в браузере нет. Markdown новых страниц и его RU/ES-варианты доступны.

Исходники двух CLI не менялись: существующая подсказка skills проверена по коду и справке
релизов. Собственный MCP документации не добавлен; описаны реально доступные Markdown-ресурсы.

## Источники и границы

Проверяем пути skills и форматы MCP по официальным инструкциям агентов. Команды CLI — по
исходникам cli-core/cli-messaging/max-cli и синхронизированным страницам релизов. Установка,
вход и работа с реальными аккаунтами в ходе проверки сайта не выполняются.

Изменения сайта не требуют релиза CLI. Изменение их справки на портале делаем через общий
компонент перехода, без локальных правок файлов, которые следующий sync перезапишет.

## Сохранение лендинга после уточнения

Главная перенесена из утверждённых прототипов на трёх языках. Сохранены фон, логотип,
крупная типографика, пять демо-сценариев, Replay, копирование и все основные секции.
Удалены только переключатели дизайн-экспериментов и команды установки skills; ссылки
подключения ведут в общие доки. Шрифты локальные, CSS изолирован от документации.

## Уточнения 3 октября

- «Начало работы» выделено в верхнем и боковом меню на всех общих руководствах;
  Telegram/MAX продолжают выделяться только внутри своих разделов. Добавлены тесты этого состояния.
- В доках текстовое название заменено на SVG-логотип со спокойным оттенком и анимацией
  как на лендинге; при reduced motion анимация отключается.
- Для русских заголовков восстановлен Fira Sans Extra Condensed (900) из коммита b41b263.
  Генератор сохраняет выбор `data-ff` из каждого языкового прототипа.
- About вынесен на отдельные `/en/about`, `/ru/about`, `/es/about`. Добавлены описание
  проекта, кастомных чатботов и интеграций, порядок обсуждения задачи и подтверждённый
  владельцем контакт `hello@wirecat.dev`.

## Упрощение запроса установки

Запрос сокращён до установки, входа, подключения skill для окружения агента, проверки
и одной ссылки на локализованное руководство. Селектор агента удалён: он менял только
название в запросе. Один запрос используется во всех пяти агентах; конкретные пути skills
остаются в руководстве подключения.

## Порядок страницы установки

Страница начинается с Windows/macOS/Linux и выбора установки через агента или терминал.
Node.js остаётся в ручных инструкциях. Таблица удалена: внизу страницы отдельные блоки
с копированием каждой команды для Node/npm, Telegram, MAX и обхода проблем PowerShell/PATH.
Проверены порядок контента, копирование без форматирования, мобильная ширина и Markdown
на всех трёх языках.
