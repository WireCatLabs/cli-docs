Заметные изменения `@wirecat/asterisk-cli`. Один раздел на версию, новые сверху.

## 0.3.0 — 13.11.2026

### Изменено — может сломать вызовы

- Команда теперь называется `pbx` и устанавливается также как `wcat-pbx`. `asterisk` перекрывал собственную
  программу АТС на сервере, где стоят обе. Переменные начинаются с `PBX_` (`PBX_PROFILE`, `PBX_READ_ONLY`), запись MCP
  называется `pbx-<profile>`, а ее инструменты `pbx_read`, `pbx_write` и `pbx_tools_search`. Пакет, его настройки и
  сохраненные пароли сохраняют имя `asterisk-cli`, поэтому заново ничего настраивать не нужно.

## 0.2.0 — 13.11.2026

### Добавлено

- `files_from sftp` читает `Master.csv` и аудиозаписи на АТС по SFTP, только для чтения, через SFTP-клиент cli-core:
  повторы при обрыве соединения, тайм-ауты и каждый запрос в трассировке запуска. Ключ сервера закрепляется через
  `sftp_host_key` до отправки пароля или ключа, а первый `session start` показывает отпечаток для проверки.
  См. [подключите Asterisk](./asterisk.md#files-on-the-pbx-over-sftp).

### Исправлено

- `phone_region` теперь переводит номера в международный вид для любой страны, а не только для `ru`: правила взяты из
  cli-core (0.648.0).

## 0.1.0 — 13.11.2026

### Добавлено

- Создан из `@wirecat/cli-template` 0.23.0.
- Записи о звонках Asterisk становятся встречами в хранилище WireCat: `meetings sync` читает `Master.csv` или таблицу
  CDR в MySQL, MariaDB или PostgreSQL, только для чтения, одна встреча на строку CDR, поэтому плечи переадресованного
  звонка остаются отдельными.
- Аудиозапись звонка находится по столбцу FreePBX `recordingfile` или по `uniqueid` и связывается по пути. Файл,
  который еще пишется, ждет следующей синхронизации.
- `meetings transcribe` превращает аудиозаписи в текст локальной моделью распознавания речи, один раз для каждого
  неизмененного файла.
- `session start` проверяет источник и хранит пароль базы в связке ключей. Локальному `Master.csv` пароль не нужен.
- Внешние номера хранятся в международном виде с помощью `phone_region`, как их хранят другие инструменты WireCat.
- В `examples/` лежат выдуманный Master.csv и две короткие аудиозаписи.
