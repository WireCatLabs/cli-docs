---
title: "Если что-то не работает"
---

Команда не запускается, звонки не приходят, время сдвинуто или звонок не расшифровывается? Найдите свой симптом в
таблице. Рядом написано, что проверить и как это исправить. После исправления повторите команду, которая не
сработала.

Если это не помогло, напишите в поддержку. Сохраните для обращения код ошибки, причину из сообщения и имя профиля.
Профиль — это имя, которое вы дали подключению к АТС.

| Симптом | Что делать |
| --- | --- |
| Непонятно, что уже настроено | Запустите `pbx doctor`. Он не читает связку ключей (хранилище паролей системы) и не ходит в сеть. |
| `pbx` не найден | Откройте новый терминал. Проверьте, что глобальная папка npm есть в `PATH`, списке папок, где система ищет программы. |
| `pbx` запускает другую программу | Это имя занял другой инструмент. Набирайте `wcat-pbx`. |
| «name a profile» | Поставьте профиль первым словом, как в `pbx office meetings list`, или задайте `PBX_PROFILE`. |
| `source.not-configured` | Сообщение называет настройку и команду `config set`, которая её задаёт. |
| `cdr.unknown-columns` | В Master.csv столько столбцов, сколько модуль `cdr_csv` никогда не пишет. Назовите столбцы в `cdr_csv_columns`. |
| Время сдвинуто на несколько часов | Задайте в `cdr_timezone` часовой пояс АТС. Если в `cdr.conf` стоит `usegmtime=yes`, задайте `UTC`. Затем снова запустите `meetings sync --since-time`: записи о звонках обновятся, а не удвоятся. |
| «N call records could not be read» | В этих строках нет времени начала. Остальные звонки импортированы. |
| `db.refused` | База данных не приняла пользователя или пароль. Снова запустите `session start`. |
| `db.no-table`, `db.no-select` | Задайте `db_table` или дайте пользователю право `SELECT` на таблицу. |
| `network_error` от базы данных | Сервер базы недоступен с этого компьютера. Подключитесь к ней через SSH-вход АТС, как показано в разделе [база данных за SSH АТС](./installation.md#a-database-behind-the-phone-systems-ssh). |
| `sftp.host-key-missing` | Ключ сервера SFTP или SSH ещё не закреплён. Сравните отпечаток ключа из сообщения с выводом `ssh-keygen -lf` на сервере. Затем выполните команду `config set`, которую называет сообщение. |
| «this profile needs 2 passwords» | Введите каждый пароль, когда его спросят. Или передайте их по одному в строке, в том порядке, который называет сообщение. |
| `transcription.no-key` | Профиль расшифровывает через OpenAI, но ключа у него нет. Передайте ключ в `OPENAI_API_KEY` или выполните `config set transcribe_engine local`. |
| У звонка нет аудиозаписи | Проверьте `recordings_path`, затем `recordings_pattern`. Файл, изменённый в последние две минуты, ждёт следующей синхронизации. |
| `model.not-downloaded` | Запустите `pbx models download gigaam-v3` или скачайте модель, которую называет сообщение. |
| Звонок в WAV, GSM или M4A не расшифровывается | Установите `ffmpeg`, программу для работы со звуком. |
| Аудиозапись помечена как слишком длинная | Аудиозапись длиннее часа не расшифровывается. Файл MP3, Ogg или FLAC больше 64 МБ тоже. |
| `search meetings --model` или `meetings embed` говорит, что модели нет | Запустите `pbx models download embeddinggemma` или скачайте модель, которую вы назвали. |
| Файл настроек не читается | `doctor` перечисляет все проблемы файла в `config.issues`. Для каждой выполните `config unset`, который он предлагает. |

Никогда не вставляйте в обращение пароль, аудиозапись или расшифровку.
