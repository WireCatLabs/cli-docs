---
title: "Установка"
---

Установите `pbx` один раз на каждый компьютер, где с ним работаете вы или агент. Нужен Node.js 22.16 или более
новый 22.x, либо 24 и новее. Node 23 не поддерживается. Для расшифровки аудиозаписей WAV и GSM нужен `ffmpeg` в
`PATH`.

```sh
npm install -g @wirecat/asterisk-cli
pbx --version
```

Команда называется `pbx`, а `wcat-pbx` это тот же инструмент. Ни одно из имен не совпадает с `asterisk`, поэтому его
можно ставить и на саму АТС: собственная программа Asterisk не перекроется.

Проверьте установку:

```sh
pbx doctor
```

`doctor` не ходит в сеть и не открывает связку ключей. Он показывает версию, где лежат настройки, какие есть профили и
могут ли другие пользователи компьютера читать настройки. Дальше: [подключите Asterisk](./asterisk.md).
