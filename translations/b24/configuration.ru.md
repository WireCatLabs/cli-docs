Настройки лежат в одном файле, `config.json`, в папке, которую показывает `b24 doctor`. У каждого профиля своя
часть, а `defaults` действуют для всех профилей. Здесь описано, как их посмотреть и изменить.

```sh
b24 personal config show
b24 personal config set limit 50
b24 personal config unset limit
```

`config show` перечисляет каждую настройку и показывает, откуда она взялась: из файла, из переменной или по умолчанию.

## Права

`permissions` решает, что команда может делать для этого профиля: `allow`, `ask`, `readonly` или `deny`, для каждого
ключа прав. Через MCP спросить некого, поэтому `ask` разрешает команду. `B24_READ_ONLY=1` отклоняет любую запись,
что бы ни говорили права.

## Записи запусков

Команда, которая завершилась ошибкой, сохраняется как запуск для `b24 runs list` и `runs show`. Команда, которая
обращается к порталу, сохраняется и при успехе, вместе с отправленными запросами, если только `record` не равен
`false` (тогда сохраняются только ошибки) или она не запущена с `--no-record`. `record_input` решает, хранит ли запуск
введенные вами слова; он равен `true`, пока вы не зададите `false`. Секреты скрываются в любом случае; см.
[Безопасность](./security.md).
