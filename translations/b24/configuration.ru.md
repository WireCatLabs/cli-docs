Меняйте поведение `b24` для одного портала или для всех порталов на этом компьютере одной командой и смотрите,
откуда взялось каждое значение. Вы меняете только те несколько настроек, которые вам важны, а остальные сохраняют
значения по умолчанию или остаются незаданными.

Например, вы решаете, что может делать агент и копировать ли записи звонков. Ослабить право можете только вы: агенту,
который пытается это сделать, команда отказывает.

Настройки лежат в одном файле, `config.json`, в папке, которую показывает `b24 doctor`. У каждого профиля своя
часть, а `defaults` действуют для всех профилей. `b24 work config` показывает и меняет их.

## Посмотреть и изменить настройку

```sh
b24 work config show
b24 work config set limit 50
b24 work config unset limit
```

`config show` перечисляет каждую настройку и показывает, откуда она взялась: из файла, из переменной или по умолчанию.

## Права

`permissions` решает, что команда может делать для этого профиля: `allow`, `ask`, `readonly` или `deny`, для каждого
ключа прав. Через MCP `ask` ничего не спрашивает, и запись проходит. Ключи, их встроенные уровни и то, как оставить
записи агента под вашим контролем, описаны на странице [Права](./permissions.md).

## Звонки

`download_recordings` (`true` или `false`, по умолчанию `false`) скачивает запись каждого звонка при `meetings sync`
и хранит ее в папке состояния. `phone_region` (код страны, например `ru`, или несколько: `ru,kz`) задает страну
номера звонящего, который портал записывает без `+`. `sync_calls` (по умолчанию `true`) заставляет `sync` копировать
и звонки. `export_calls` (по умолчанию `false`) разрешает `calls export` записывать в Битрикс24 звонки из других
телефонных систем. Все четыре описаны на странице [Звонки](./calls.md).

## Связи в CRM

Две настройки общего хранилища, а не профиля, определяют, как синхронизация сохраняет связи:
`crm.bitrix24:<portal>.links` (`reported` или `review`) и `crm.bitrix24:<portal>.company-types` (что значит каждый
тип компании). Обе показаны в разделе [Кто есть кто](./usage.md#who-is-who).

## Записи запусков

Команда, которая завершилась ошибкой, сохраняется как запуск для `b24 runs list` и `runs show`. Команда, которая
обращается к порталу, сохраняется и при успехе, вместе с отправленными запросами, если только `record` не равен
`false` (тогда сохраняются только ошибки) или она не запущена с `--no-record`. `record_input` решает, хранит ли запуск
введенные вами слова. Он равен `true`, пока вы не зададите `false`. Секреты скрываются в любом случае. Подробнее на
странице [Безопасность](./security.md).
