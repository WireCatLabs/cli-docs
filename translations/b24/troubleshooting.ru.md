---
title: "Если что-то пошло не так"
---

Найдите симптом, выполните проверку, затем повторите команду. Для обращения в поддержку сохраните код ошибки и имя
профиля.

| Симптом | Что делать |
| --- | --- |
| Непонятно, что настроено | Запустите `b24 doctor`. Он не читает связку ключей и не обращается к сети. |
| `b24` не найден | Откройте новый терминал и проверьте, что глобальная папка npm есть в `PATH`. |
| «name a profile» | Поставьте профиль первым словом, как в `b24 personal config show`, или задайте `B24_PROFILE`. |
| Файл настроек не читается | `doctor` перечисляет все проблемы файла в `config.issues`. Выполните `config unset`, который предлагается для каждой, или исправьте файл вручную. |
| `doctor` показывает `files.problems` | Другие пользователи компьютера могут читать `config.json` или заходить в его папку. Выполните каждую команду `chmod`, которую `doctor` выводит после «to make it private:». Сам `doctor` права файлов не меняет. |
| «not signed in» | Запустите `b24 <profile> session start` и вставьте адрес вебхука. |
| Битрикс24 отклонил этот вебхук | Вебхук удален или изменен в Битрикс24, а изменение меняет его адрес. Создайте новый и снова запустите `session start`. |
| Нет scope для метода, или `ERROR_METHOD_NOT_FOUND` | Добавьте scope (`crm`, `user`, `catalog`) к вебхуку в Битрикс24. |
| `rate_limited` | Портал разрешает около 2 запросов в секунду на все свои приложения вместе. Короткое ожидание `b24` выжидает сам; о долгом он сообщает вам. |
| `outcome_unknown` при записи | Портал мог внести изменение. Сначала посмотрите запись (`sync`, затем `show`) и повторите ее с `--operation-id` из ошибки, только если ее там нет; см. [запись](./usage.md#write). |
| Запись отклонена | Ее запрещают права профиля или `B24_READ_ONLY`; см. [настройки](./configuration.md#permissions). |

Никогда не вставляйте в обращение в поддержку токен, пароль или личное содержимое.
