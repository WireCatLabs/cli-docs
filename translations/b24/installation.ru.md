---
title: "Установка"
---

Установите `b24` один раз на каждом компьютере, где им пользуетесь вы или агент. Нужен Node.js 22.16 или более
поздний 22.x, либо 24 и новее; Node 23 не поддерживается.

```sh
npm install -g @wirecat/bitrix24-cli
b24 --version
```

Проверьте установку, затем выберите имя профиля для своего аккаунта, например `personal`:

```sh
b24 doctor
```

`doctor` не нужна сеть, и он не открывает связку ключей. Он показывает версию, где лежат настройки, какие профили
есть и могут ли другие пользователи компьютера читать настройки. Дальше: [работа с инструментом](./usage.md).
