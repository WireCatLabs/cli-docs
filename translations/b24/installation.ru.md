За несколько минут `b24` заработает на вашем компьютере и подключится к порталу Битрикс24. Битрикс24 пускает программу
только через входящий вебхук или приложение, которое вы создаете на портале, и эта страница настраивает одно из них.

После этого агент на компьютере читает ваши сделки, лиды и клиентов и меняет их, когда вы попросите.

npm ставит `b24` как команду, а `b24 skill install` учит агента ею пользоваться. `b24 work setup` показывает, где
создать вебхук в Битрикс24 и какие права (scope) отметить, проверяет адрес вебхука на портале и хранит его в связке
ключей системы. `b24 doctor` показывает, что настроено, без сети. Нужен Node.js 22.16 или более поздний 22.x, либо 24
и новее. Node 23 не поддерживается.

## Установка инструмента

Установите `b24` один раз на каждом компьютере, где им пользуетесь вы или агент.

```sh
npm install -g @wirecat/bitrix24-cli
b24 --version
b24 skill install   # the agent skill, for Claude Code, Codex, Gemini CLI and OpenClaw
b24 doctor
```

Агент без терминала, например Claude Desktop, работает с `b24` через [MCP](./mcp.md). `doctor` не нужна сеть, и он
не открывает связку ключей. Он показывает версию, где лежат настройки, какие профили есть и могут ли другие
пользователи компьютера читать настройки. Затем выберите имя профиля для своего портала, например `work`.

## Вход

Быстрее всего войти через входящий вебхук. `b24 work setup` проводит вас по шагам, тем же, что показывает WireCat
Desktop. `b24 work session start` только спрашивает адрес. Шаги и права (scope), которые нужно отметить, описаны в
разделе [вход](./usage.md#sign-in).

С локальным приложением `b24` действует с правами сотрудника, который входит, а не того, кто создал вебхук. Создайте
приложение один раз на портале (Разработчикам → Готовые сценарии → Другое → Локальное приложение) в режиме **Серверное**. В поле **Путь
вашего обработчика** укажите `https://wirecat.dev/webhooks/apps/b24-callback`, поле **Путь для первоначальной
установки** и текст пункта меню оставьте пустыми, в правах доступа отметьте `crm`, `user_basic` и `department`,
а также `task` для задач, `telephony` для звонков, `disk` и `documentgenerator` для файлов и документов.
Затем выполните `session start` с адресом своего портала и кодом приложения (client_id), который показывает Битрикс24.
Здесь адрес `example.bitrix24.ru`, а код `local.0123abcd.45678901`, подставьте свои:

```sh
b24 work session start --portal example.bitrix24.ru --client-id local.0123abcd.45678901
```

Введите ключ приложения, когда команда его попросит. Шаги описаны в разделе [с локальным приложением](./usage.md#with-a-local-application).
