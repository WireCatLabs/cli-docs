---
title: "Установка"
---

Установите `b24` один раз на каждом компьютере, где им пользуетесь вы или агент. Нужен Node.js 22.16 или более
поздний 22.x, либо 24 и новее; Node 23 не поддерживается.

```sh
npm install -g @wirecat/bitrix24-cli
b24 --version
```

Проверьте установку, затем выберите имя профиля для своего аккаунта, например `work`:

```sh
b24 doctor
```

`doctor` не нужна сеть, и он не открывает связку ключей. Он показывает версию, где лежат настройки, какие профили
есть и могут ли другие пользователи компьютера читать настройки. Дальше: [работа с инструментом](./usage.md).

## Вход

Быстрее всего войти через входящий вебхук: `b24 work session start` спросит его адрес. Шаги описаны в разделе
[вход](./usage.md#sign-in).

С локальным приложением `b24` действует с правами сотрудника, который входит, а не того, кто создал вебхук. Создайте
приложение один раз на портале (Разработчикам → Готовые сценарии → Другое → Локальное приложение) в режиме **Серверное**. В поле **Путь
вашего обработчика** укажите `https://wirecat.dev/webhooks/apps/b24-callback`, поле **Путь для первоначальной
установки** и текст пункта меню оставьте пустыми, в правах доступа отметьте `crm`, `user_basic` и `department`.
Затем выполните `b24 work session start --portal example.bitrix24.ru --client-id <Application ID>` и введите ключ
приложения, когда команда его попросит. Шаги описаны в разделе [с локальным приложением](./usage.md#with-a-local-application).
