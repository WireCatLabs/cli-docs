Найдите договор, цифру или решение в папках Диска по тому, что написано в документе, даже если вы не помните его имя.
Поиск читает копию на вашем компьютере, поэтому отвечает без интернета и не тратит запросы к Яндексу. Он охватывает
папки, которые вы выбрали и синхронизировали. См. [папки и синхронизация](./usage.md).

```text prompt
Use ydisk CLI with profile personal. Find the document where we agreed the budget for the spring campaign.
Quote the passage and give me the file's path on the Disk.
```

## Поиск по словам

```sh
ydisk personal search "quarterly budget"
ydisk personal search "договор аренды" --limit 5
ydisk personal search "invoice 2026" --exact
```

Поиск находит другие формы слова: «договор» найдет и «договора», и «договоре», а «budgets» найдет «budget».
`--exact` ищет слова ровно так, как они написаны. У каждого результата есть id документа, его путь на Диске и
отрывок. Передайте id в `documents show`, чтобы увидеть весь текст.

Фильтр сужает результаты: `tag:` находит документы с вашим тегом, а `date:` ищет по дате последнего изменения на
Диске.

```sh
ydisk personal search "budget tag:follow-up"
ydisk personal search "budget date>=30d"
```

## Поиск по смыслу

Поиск по смыслу находит документ, который отвечает на вопрос другими словами. Например, на вопрос «о чем мы
договорились по расходам?» он найдет текст «бюджет утвержден на 2 миллиона». Для этого он использует текстовую модель
на вашем компьютере, общую для всех инструментов WireCat. Скачайте модель один раз командой `models` любого
инструмента WireCat, например [Memo](https://wirecat.dev/en/docs/memo), а затем проиндексируйте копию:

```sh
memo models download embeddinggemma
ydisk personal sync --embed
ydisk personal search "what did we agree to spend?"
```

Скачивание идет по сети. Индексация и поиск выполняются на вашем компьютере. Без модели поиск по словам работает как
раньше.

## Найдите файл по имени

`catalog` ищет по именам и типам файлов и папок, которые перечислила синхронизация, в том числе фото и другие файлы
без текста. `catalog import` кладет то, что перечислила синхронизация, в локальное хранилище. Запускайте его после
синхронизации:

```sh
ydisk personal catalog import
ydisk personal catalog search "passport"
ydisk personal catalog tree
```

Файл вне выбранных папок ищите прямо на Диске: `files list --folder /Documents` показывает содержимое папки
на Диске.

## Теги и заметки

Теги и заметки принадлежат вам и остаются на вашем компьютере. Диск их не видит. Они остаются с документом, когда
файл переносят.

```sh
ydisk personal tags add 1a2b3c follow-up
ydisk personal notes add 1a2b3c "Signed copy is with Anna"
ydisk personal documents context 1a2b3c
```

Id в примере выдуманный. Возьмите настоящий из `search` или `documents list`. `documents context` показывает
документ вместе с его тегами, заметками и записями памяти.

## По другим вашим источникам

Копия лежит в локальном хранилище, общем для других инструментов WireCat. С [Memo](https://wirecat.dev/en/docs/memo)
один поиск находит документ с Диска рядом с чатом Telegram или письмом, где его обсуждали.

## Если поиск ничего не нашел

Пустой результат значит, что в копии ничего не подошло, а не что такого файла нет на Диске. Проверьте по порядку:

1. `ydisk personal folders list`: выбрана ли папка с файлом?
2. `ydisk personal status`: закончилась ли синхронизация и не сохранен ли файл только по имени?
3. Если файл новый, запустите `ydisk personal sync`.
4. Поищите имя через `catalog search` или покажите папку напрямую через `files list`.

В отсканированном PDF нет текстового слоя, поэтому искать можно только по его имени.
