Находите любой документ на Яндекс Диске по тому, что в нем написано, и поручите ИИ-агенту читать, раскладывать и
отправлять файлы за вас. `ydisk` копирует на ваш компьютер текст выбранных папок Диска, поэтому поиск по словам «lease» или «договор аренды»
найдет PDF, даже если файл называется `scan_0042.pdf`, и даже без интернета. Когда нужен сам Диск, тот же инструмент
показывает, скачивает, загружает, переносит и раздает файлы там.

ИИ-агент с `ydisk` отвечает на вопрос «где договор с типографией и какие в нем условия оплаты?» цитатой и путем к
файлу на Диске. Он работает с Claude Code, Codex, Gemini CLI и другими агентами, которые запускают команды, с Claude
Desktop и Cursor через MCP, а с ChatGPT и Claude в браузере через ваш собственный туннель.

Нужны Node.js и токен OAuth Яндекса: ключ, который дает инструменту доступ к вашему Диску. Получить токен можно минут
за пять, один раз.

## Что вы получите

- **Поиск внутри файлов, а не только по их именам.** Ищется текст в PDF, Word (`.docx`), Excel (`.xlsx`), CSV, TSV,
  обычном тексте и Markdown. Поиск находит другие формы слова на русском и английском, а когда текст проиндексирован,
  находит документ и по смыслу.
- **Поиск без интернета.** Поиск читает копию на вашем компьютере, поэтому работает быстро и не делает запросов к
  Яндексу.
- **Весь Диск вживую.** Смотрите, читайте, скачивайте, загружайте, копируйте, переносите, удаляйте в корзину,
  восстанавливайте файлы и делитесь ими, не открывая браузер.
- **Агенту можно доверить.** В терминале инструмент спрашивает перед удалением, перезаписью и созданием публичной
  ссылки. Для агента каждый такой вопрос можно отключить или разрешить только чтение.
- **Один поиск по всем источникам.** Копия лежит в том же локальном хранилище, что и ваши Telegram, WhatsApp, почта,
  заметки и встречи из других инструментов WireCat, поэтому один поиск покрывает все.
- **Бесплатно и с открытым кодом.** Apache 2.0, macOS, Linux и Windows. Аккаунт WireCat и сервер WireCat не нужны:
  инструмент обращается к официальному API Яндекса прямо с вашего компьютера.

## Как это устроено

- **Профиль для каждого аккаунта.** Профиль: имя, которое вы выбираете для одного аккаунта Яндекса, например
  `personal` или `work`. Каждая команда, которой нужен аккаунт, начинается с него: `ydisk personal search budget`.
- **Копия текста, а не файлов.** `sync` читает выбранные вами папки и хранит их текст в локальном хранилище, это один
  файл базы данных на вашем компьютере. Сами файлы остаются на Диске. Фото и другие файлы без текста сохраняются
  только по имени.
- **Только выбранные папки.** Яндекс Диск не сообщает инструменту, что изменилось, поэтому каждая синхронизация
  заново перечисляет выбранные папки и скачивает только файлы с изменившимся содержимым. Выбирайте важные папки, а не
  весь Диск.
- **Команды для живой работы идут на Диск.** Команды `files` работают с Диском напрямую, синхронизация им не нужна.

## Попробуйте за пять команд

Сначала [установите инструмент и войдите](./installation.md):

```sh
ydisk personal folders browse
ydisk personal folders add /Documents
ydisk personal sync
ydisk personal search "quarterly budget"
ydisk personal files list --folder /Documents
```

Первая команда показывает папки верхнего уровня вашего Диска. Следующие две копируют текст из `/Documents`. Поиск
отвечает по этой копии, а последняя команда читает папку прямо с Диска.

## Спросите агента

Один раз установите навык инструмента командой `ydisk skill install` и просите обычными словами:

```text prompt
Use ydisk CLI with profile personal. Find the lease for the flat in my Disk folders.
Quote the notice period and give me the file's path on the Disk. Do not change any files.
```

Агент сначала ищет по копии, а файл вне выбранных папок читает прямо с Диска. Больше примеров запросов в
[рецептах](./recipes.md).
