Вход не удался, синхронизация остановилась, поиск ничего не находит: найдите свой случай здесь и исправьте его за
минуту-две. Каждая ошибка в своем сообщении говорит, что делать, а код выхода подсказывает скрипту, какой это был
сбой.

## Первая проверка

```sh
ydisk doctor
ydisk personal doctor --online
```

`doctor` не читает связку ключей и не ходит в сеть. Он показывает, что настроено и какие есть проблемы с файлом
настроек. `doctor --online` еще спрашивает Яндекс, работает ли токен профиля.

## По симптомам

| Симптом | Что делать |
| --- | --- |
| `ydisk` не найден | Откройте новый терминал и проверьте, что глобальная папка npm есть в `PATH`. |
| "name a profile" | Поставьте профиль первым словом, как в `ydisk personal status`, или задайте `YDISK_PROFILE`. |
| "refused the token", код выхода 4 | Токен неверный, отозван или истек. [Получите новый токен](./installation.md#get-a-yandex-token) и снова выполните `ydisk personal session start`. |
| Изменение завершается с кодом выхода 5 | У токена нет права `cloud_api:disk.write`, или его запрещают разрешения профиля или `YDISK_READ_ONLY`. Проверьте [настройки](./configuration.md#permissions). Чтобы получить право, зарегистрируйте приложение заново с ним и получите новый токен. |
| "the OS keyring did not answer" в Linux | Шина сеанса перезапустилась. Выйдите из системы и войдите снова или войдите через `session start --credential-storage file`. |
| "no such item, or this token cannot see it", код выхода 6 | Проверьте путь через `files list --folder` для его родительской папки. Путь на Диске начинается с `/`, как в `/Documents/plan.pdf`. |
| "asked to slow down", код выхода 8 | Яндекс получил слишком много запросов с этого аккаунта. Подождите минуту и повторите команду. |
| Синхронизация останавливается до конца | Одна синхронизация читает до 200 файлов. Запускайте `sync` снова, пока `status` не покажет, что работы не осталось. |
| Документы выбранной папки пропали | Папку переименовали или переместили на Диске. Добавьте ее снова по новому пути через `folders add`. |
| Поиск не находит файл, который точно есть | См. [когда поиск ничего не находит](./search.md#when-search-finds-nothing). |
| PDF находится по имени, но не по тексту | Это скан без текстового слоя или файл больше 50 МБ. `status` перечисляет такие файлы с причиной. |
| Загрузка не удалась, потому что Диск заполнен | Освободите место на Диске или очистите корзину. Повтор не поможет, пока нет места. |
| Большую загрузку отклоняют | Яндекс ограничивает размер одного файла по тарифу: 1 ГБ без тарифа Яндекс 360 и больше с ним ([ограничения Яндекса](https://yandex.ru/support/yandex-360/customers/disk/web/ru/uploading)). |
| Изменение завершилось с "outcome_unknown", код выхода 14 | Яндекс дал сбой во время изменения, поэтому оно могло пройти, а могло нет. Проверьте через `files show`, прежде чем запускать снова. |
| Агент изменил файл, который вы не хотели менять | По MCP уровень ask дает команде выполниться. Запретите `files.delete` и `files.share` или задайте `YDISK_READ_ONLY=1`. См. [подключение агента](./mcp.md#decide-what-the-agent-may-change). Удаленный файл лежит в корзине Диска: `files restore`. |
| Файл настроек не читается | `doctor` перечисляет каждую проблему файла в `config.issues`. Выполните `config unset`, который дан для каждой, или `config repair`, или поправьте файл вручную. |
| `doctor` перечисляет `files.problems` | Другие пользователи компьютера могут читать `config.json` или заходить в его папку. Выполните каждый `chmod`, который `doctor` печатает после "to make it private:". |

## Коды выхода

| Код | Что значит |
| --- | --- |
| 2 | Команда задана неверно: нет профиля, аргумента или параметра. |
| 3 | Настройки или связка ключей непригодны. |
| 4 | Яндекс отклонил токен. |
| 5 | Нельзя: права токена или разрешения профиля. |
| 6 | Нет такого файла или папки, или токен их не видит. |
| 7 | Изменение требует вашего подтверждения, а терминала для вопроса не было. |
| 8 | Яндекс просит снизить темп. |
| 14 | Изменение могло пройти, а могло нет. |

Все коды есть в [справочнике команд](./commands.md).

## Если не помогло

`ydisk runs list` показывает последние запуски, а `ydisk runs show` один из них со всеми шагами. Секреты скрыты.
`ydisk doctor reports create` записывает файл отчета для сообщения об ошибке и говорит, что в нем лежит. Создайте
обращение на [github.com/WireCatLabs/ydisk-cli/issues](https://github.com/WireCatLabs/ydisk-cli/issues) с кодом ошибки
и командой. Никогда не вставляйте в обращение токен или личное содержимое.
