---
title: "Настройки"
---

Меняйте поведение `ydisk` для одного профиля или для всех сразу: что агент может менять на вашем Диске, как долго
хранятся записи запусков и как поиск упорядочивает результаты. Настройки лежат в одном файле, `config.json`, в папке,
которую показывает `ydisk doctor`. У каждого профиля своя часть, а `defaults` действуют для всех профилей.

```sh
ydisk personal config show
ydisk personal config set limit 50
ydisk personal config unset limit
```

`config show` перечисляет каждую настройку и откуда она взялась: из файла, из переменной или из значения по
умолчанию.

## Разрешения

`permissions` решает, что команда может делать для этого профиля. У каждой команды свой ключ с ее именем, например
`files.move` или `files.upload`, и у каждого ключа один из четырех уровней:

| Уровень | Что происходит |
| --- | --- |
| `allow` | Команда выполняется. |
| `ask` | В терминале инструмент сначала спрашивает. Через MCP спросить некого, поэтому команда выполняется. |
| `readonly` | Чтение выполняется. Изменение отклоняется. |
| `deny` | Команда отклоняется с кодом выхода 5. |

Два ключа охраняют изменения, которые трудно отменить. Пока вы их не измените, у них уровень `ask`. Остальные ключи
`files` стоят на `allow`:

| Ключ | Что охраняет |
| --- | --- |
| `files.delete` | `files delete`, а также загрузку, копирование и перенос с `--replace`, которые перезаписывают файл. В группе `api`: удаление, очистку корзины и любую перезапись. |
| `files.share` | `files publish` и `files unpublish`: ссылку, которую откроет любой, у кого она есть. В группе `api`: операции с публичными ссылками. |

```sh
ydisk personal config set permissions.files.delete deny
ydisk personal config set permissions.files.share deny
ydisk personal config set permissions.files.upload deny
```

Команда `api`, которая делает то же, что команда `files`, проверяет и ключ той команды: `files.move` со значением
`deny` останавливает и `api resources-move`. `--dry-run` у любого изменения показывает каждый проверяемый ключ и его
уровень, но само изменение не делает.

`YDISK_READ_ONLY=1` отклоняет любое изменение, что бы ни говорили разрешения. Для одного MCP-сервера `--permission
files.delete=deny` делает ключ строже, но не мягче. См. [подключение агента](./mcp.md#decide-what-the-agent-may-change).

## Записи запусков

Команда, которая завершилась ошибкой, сохраняется как запуск, его показывают `ydisk runs list` и `runs show`. Команда,
которая обращается к Яндекс Диску, например `files list`, `sync` или `session status --check`, сохраняется и при
успехе, если только `record` не `false` (тогда сохраняются одни ошибки) или она не запущена с `--no-record`.
`record_input` решает, хранит ли запуск слова, которые вы набрали. По умолчанию `true`, пока вы не поставите `false`.
Секреты скрываются в любом случае. См. [безопасность](./security.md).

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| `record` | `true` | Сохранять каждый запуск. `false` сохраняет только неудачные. |
| `record_input` | `true` | Хранить слова, набранные в командной строке: `true`, `false` или `failed`. |
| `keep_runs_for_days` | `30` | Сколько дней хранится запуск. |
| `keep_successful_runs_for_days` | `7` | Сколько дней хранится успешный запуск. |
| `runs_size_limit_mb` | `200` | Сколько мегабайт могут занимать все запуски вместе. |

## Другие настройки

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| `limit` | `20` | Сколько элементов список показывает за раз. |
| `search_reranker` | `mmarco` | Модель, которая упорядочивает первые результаты поиска, или `off`. |
| `embedding_provider` | `local` | `local` или `openai`: чем текст превращается в векторы для поиска по смыслу. `openai` отправляет текст в OpenAI. |
| `update_check` | `true` | Раз в день проверять, нет ли новой версии. |
| `skill_hint` | `true` | Раз в день сообщать агенту, что `skill install` даст ему навык этого инструмента. |

## Переменные окружения

| Переменная | Что делает |
| --- | --- |
| `YDISK_PROFILE` | Профиль для команд, в которых он не назван. |
| `YDISK_READ_ONLY` | `1` отклоняет любое изменение. |
