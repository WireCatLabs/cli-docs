Настройки лежат в одном файле, `config.json`, в папке, которую показывает `slk doctor`. У каждого профиля своя
часть, а `defaults` действуют для всех профилей. Здесь описано, как их посмотреть и поменять.

```sh
slk personal config show
slk personal config set limit 50
slk personal config unset limit
```

`config show` перечисляет каждую настройку и откуда она взялась: из файла, из переменной или по умолчанию.

## Разрешения

`permissions` решает, что команда может делать для этого профиля: `allow`, `ask`, `readonly` или `deny`, для каждого
ключа разрешения. По MCP спросить некого, поэтому `ask` пропускает команду. `SLACK_READ_ONLY=1` запрещает любую
запись, что бы ни говорили разрешения.

## Записи запусков

Команда, которая не удалась, сохраняется как запуск для `slk runs list` и `runs show`. Команда, которую вы добавили и
которая делает работу в `context.run`, сохраняется и при успехе, если только `record` не равен `false` (тогда только
неудачи) или она не запущена с `--no-record`. Команды `api`, `session start`, `session status --check` и
`doctor --online` работают внутри запуска, поэтому `--record` их сохраняет. `record_input` решает, хранит ли запуск
введенные вами слова. Он равен `true`, пока вы не поставите `false`. Секреты маскируются в любом случае, см.
[Безопасность](./security.md).
