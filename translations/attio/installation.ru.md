Установите `attio` на свой компьютер и подключите его к своему пространству Attio примерно за пять минут. Attio
пускает программу по токену доступа, который создает администратор пространства, и эта страница проведет вас по
шагам.

После этого агент на этом компьютере читает ваши сделки, людей и компании, когда вы просите.

## Что нужно

- Пространство Attio и его администратор. Создать токен доступа может только администратор пространства. Если вы не
  администратор, попросите администратора создать для вас токен с правами из следующего раздела.
- Включенные сделки, если они вам нужны. Объект Deal есть в каждом пространстве Attio, но выключен, пока
  администратор не включит его в настройках объектов
  ([документация Attio](https://docs.attio.com/docs/standard-objects/standard-objects-deals)).
- Для командной строки: Node.js 22.16 или более поздний 22.x, либо Node.js 24 и новее. Node 23 не поддерживается.

## В WireCat Desktop

Добавьте Attio из списка инструментов и вставьте токен доступа, когда он попросит.
[Создайте токен доступа в Attio](#make-an-access-token-in-attio) показывает, как его получить.

## Установите инструмент

Установите `attio` один раз на каждом компьютере, где с ним работаете вы или агент.

```sh
npm install -g @wirecat/attio-cli
attio --version
attio skill install   # the agent skill, for Claude Code, Codex, Gemini CLI and OpenClaw
attio doctor
```

`doctor` не ходит в сеть и не открывает связку ключей. Он показывает версию, где лежат настройки, какие профили есть
и могут ли другие пользователи компьютера читать настройки.

Агент без терминала, например Claude Desktop или Cursor, работает с `attio` по [MCP](./mcp.md), а не через навык.

## Создайте токен доступа в Attio

Attio описывает эти шаги на своей странице помощи
[Generating an API key](https://attio.com/help/apps/other-apps/generating-an-api-key).

1. В Attio откройте меню рядом с названием пространства и выберите **Workspace settings**.
2. Откройте вкладку **Developers**.
3. Нажмите **New access token** и дайте токену имя, например `WireCat`.
4. Дайте токену чтение по этим правам:

   | Право | Для чего |
   |---|---|
   | `record_permission:read` | Сделки, люди и компании. |
   | `object_configuration:read` | Этапы сделок и собственные атрибуты вашего пространства. |
   | `user_management:read` | Участники пространства, ответственные за сделки. |

5. Сохраните и скопируйте токен, который покажет Attio.

С одними этими правами токен может читать и никогда ничего не меняет в Attio. У токенов Attio нет срока действия.
Они работают, пока администратор не удалит их там же.

## Вход

Профиль это имя, которое вы выбираете для одного пространства, например `work`. Это первое слово каждой команды,
которой нужен аккаунт. Ни одна команда не выбирает профиль за вас.

```sh
attio work session start
```

`attio` спрашивает токен, не показывая его, проверяет его в Attio и сохраняет в связке ключей системы. Токен, который
Attio отклонил, не сохраняется. На компьютере без связки ключей добавьте `--credential-storage file`, чтобы хранить
токен в закрытом файле. Агент или скрипт может передать токен через stdin. Токен никогда не принимается как
аргумент, поэтому он не попадает в историю оболочки.

## Проверьте, что все работает

```sh
attio work session status --check   # asks Attio which workspace the token belongs to
attio work sync                     # copies your deals and their people and companies
attio work deals list status:open
```

Первая синхронизация читает каждую сделку в пространстве и людей и компании из них, поэтому в большом пространстве
она идет долго. Если что-то не получилось, загляните в раздел
[если что-то не работает](./troubleshooting.md).

## Выход и смена токена

```sh
attio work session end
```

`session end` забывает токен на этом компьютере. Сам токен продолжает работать в Attio, пока администратор не удалит
его там: Workspace settings → Developers, меню рядом с токеном, **Delete**. Чтобы сменить токен, снова запустите
`session start` с новым.
