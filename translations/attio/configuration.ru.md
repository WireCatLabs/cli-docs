Меняйте, как `attio` работает для одного пространства или для всех пространств на этом компьютере, одной командой и
смотрите, откуда взялось каждое значение. Вы меняете только то немногое, что важно вам, а остальное остается по
умолчанию.

Вы решаете, например, что может делать агент, сколько записей показывает список и хранит ли запуск слова, которые вы
набрали. Ослабить разрешение можете только вы: агенту, который пытается это сделать, отказывают.

Настройки лежат в одном файле, `config.json`, в папке, которую показывает `attio doctor`. У каждого профиля своя
часть, а `defaults` действуют на все профили. `attio work config` показывает и меняет их.

## Посмотреть и поменять настройку

```sh
attio work config show
attio work config set limit 50
attio work config unset limit
```

`config show` показывает каждую настройку с ее значением и откуда она взялась: из файла, из переменной или по
умолчанию. Самые частые:

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `limit` | `20` | Сколько записей список показывает за раз. |
| `permissions` | не задано | Что может делать каждая команда. См. [Разрешения](#permissions). |
| `record` | `true` | Хранить каждый запуск. `false` хранит только неудачные запуски. |
| `record_input` | `true` | Хранить слова, которые вы набрали при запуске. |
| `keep_runs_for_days` | `30` | Сколько хранится запуск. |
| `update_check` | `true` | Раз в день проверять, нет ли новой версии. |

## Разрешения

`permissions` решает, что команда может делать для этого профиля: `allow`, `ask`, `readonly` или `deny`, для
каждого ключа разрешения. Через MCP `ask` не спрашивает: запись выполняется. Ключи, их встроенные уровни и то, как
оставить записи агента под вашим контролем, описаны на странице [Разрешения](./permissions.md).

```sh
attio work config set permissions.api readonly
```

## Переменные

| Переменная | Что делает |
|---|---|
| `WCATTIO_PROFILE` | Профиль для этой оболочки вместо первого слова. |
| `WCATTIO_TOKEN` | Токен доступа, который используется раньше связки ключей, для скрипта или контейнера. |
| `WCATTIO_READ_ONLY` | `1` отклоняет любую запись. |
| `WCATTIO_CONFIG_DIR`, `WCATTIO_STATE_DIR` | Переносят настройки или состояние в другую папку. |

`attio work session status` говорит, откуда взят токен: из переменной, из связки ключей или из файла, но никогда не
показывает сам токен.

## Записи запусков

Неудачная команда сохраняется как запуск для `attio runs list` и `runs show`. Команда, которая обращается к Attio,
например `sync`, операция `api` или `session status --check`, сохраняется и при успехе, если `record` не `false`
(тогда только неудачи) и она не запущена с `--no-record`. `record_input` решает, хранит ли запуск слова, которые вы
набрали. Секреты скрываются в любом случае. См. [Безопасность](./security.md#run-records).
