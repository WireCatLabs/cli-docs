Знайте, где стоит каждая сделка, не открывая Attio. `attio` дает ИИ-агенту, с которым вы уже работаете, например
Claude Code, Codex или Claude Desktop, копию ваших сделок Attio на вашем компьютере. Агент отвечает по этой копии,
даже без интернета. Людей и компании он ищет в Attio, когда вы о них спрашиваете.

Спросите, какие сделки застряли на этапе, что выиграно или проиграно на этой неделе или как выглядит ваша воронка
сегодня. Агент ответит со сделкой, ее суммой, компанией и ответственным. Нужно пространство Attio и администратор,
который может создать токен доступа.

## Что вы получаете

- **Ответ, а не поиск.** Спросите о сделке своими словами. Агент найдет ее с этапом, суммой, компанией и людьми,
  прочитав ее с вашего компьютера, без переходов по Attio.
- **Воронка одним взглядом.** Сколько сделок стоит на каждом этапе, их сумма в каждой валюте, сколько перешло на
  следующий этап и доля выигранных.
- **Что поменялось со вчерашнего дня.** Созданные, перемещенные, выигранные и проигранные сделки, списком или
  короткой утренней сводкой.
- **Люди и компании по запросу.** "Who is Anna at Example LLC?" читает Attio прямо в этот момент, с почтой,
  телефонами и компанией.
- **Выгрузка сделок одной строкой.** Любой список сделок, людей или компаний становится CSV-файлом для таблицы.
- **CRM рядом с вашими чатами.** Один поиск находит сделку рядом с сообщениями, письмами и встречами о ней, которые
  другие инструменты WireCat хранят на вашем компьютере.

## О чем новичок не догадается

- **Ваш ключ это токен доступа.** Attio пускает программу по токену, который администратор пространства создает в
  Workspace settings → Developers. Токен читает все пространство, а не только ваши записи.
  [Установка](./installation.md) показывает, куда нажать и какие права отметить.
- **`work` это имя, которое вы выбираете.** Оно называет одно пространство Attio и стоит первым словом в каждой
  команде. Ни одна команда не выбирает пространство за вас.
- **Команды сделок читают копию, команды людей читают Attio.** `sync` копирует сделки пространства и
  людей и компании из них вместе с этапами воронки сделок. `deals`, `pipelines` и `changes` отвечают по этой копии. `people`,
  `organizations` и `users` каждый раз спрашивают Attio, поэтому всегда показывают свежие данные, и им нужен
  интернет.
- **Любое изменение в терминале сначала спрашивает вас.** `deals create`, `update`, `move`, `close` и `delete`,
  `people create` и `update`, а также `activities create` и `close` для заметок и задач меняют Attio и сохраняют его
  ответ. В терминале каждая из них сначала спрашивает да или нет, как и любая запись через `api`. Новая сделка без
  `--owner` достается вам. Компании идут через `attio work api …`, который достает до любой операции API Attio,
  насколько это разрешают права токена и ваши [разрешения](./permissions.md).
- **Через MCP "ask" выполняется.** MCP это способ, которым приложения вроде Claude Desktop вызывают инструмент, и там
  никто не сидит у терминала, чтобы ответить на вопрос. Закройте группу `api`, прежде чем подключать такое
  приложение: [MCP](./mcp.md).

## Как это выглядит

```text
You:    Which deals are in Negotiation?
Agent:  (runs attio work deals list stage:Negotiation status:open)
        · "Example LLC renewal", 24 000 USD, owner Anna Example
        · "Sample Inc pilot", 6 500 USD, owner Bob Sample
You:    What did we win this week?
Agent:  (runs attio work changes list change:won "at>=7d")
        One deal: "Example Corp expansion", 12 000 USD, won on Tuesday.
```

*Сделки придуманы, вывод показан для примера.*

## Почему attio

- **Копия ваших сделок на вашем компьютере.** Списки, доска воронки и поиск отвечают по ней без запроса в Attio, в
  том числе без интернета.
- **Можно доверить агенту.** Любое изменение в Attio сначала спрашивает вас в терминале. У каждой команды и каждой
  операции API Attio есть свое разрешение: разрешить, спросить, только чтение или запрет. Одна строка закрывает от
  агента любую запись.
- **Токен остается в связке ключей системы.** Он никогда не попадает в вывод, ошибки или логи.
- **Бережно к Attio.** Большинству ответов запрос вообще не нужен, поэтому лимит запросов вашего пространства
  остается вашим другим приложениям.
- **Готов для любого агента.** Навык для агентов с терминалом, MCP-сервер для Claude Desktop и Cursor и защищенная
  ссылка для ChatGPT и Claude в браузере.
- **Бесплатно и с открытым кодом.** Apache 2.0.

## Что он умеет

- **Сделки:** список по этапу, статусу или компании, одна сделка с ее людьми и компанией, выгрузка страницы в CSV.
  [Работа с инструментом](./usage.md#deals)
- **Воронка:** каждый этап воронки сделок Attio с числом сделок и суммой и доля выигранных за выбранный вами период.
  [Работа с инструментом](./usage.md#the-pipeline)
- **Что поменялось:** созданные, перемещенные, выигранные и проигранные сделки и утренняя сводка.
  [Работа с инструментом](./usage.md#what-changed)
- **Люди, компании и участники:** поиск в Attio по имени или почте, одна запись, выгрузка списка.
  [Работа с инструментом](./usage.md#people-companies-and-members)
- **Ваши собственные атрибуты:** пользовательские атрибуты пространства у сделок, людей и компаний, с их значениями.
  [Работа с инструментом](./usage.md#your-own-attributes)
- **Поиск по всем инструментам:** сделки рядом с сообщениями, заметками, событиями и встречами из других
  инструментов WireCat. [Работа с инструментом](./usage.md#search-everything)
- **Любая операция API Attio** из терминала, с теми же проверками разрешений.
  [Работа с инструментом](./usage.md#the-attio-api)

## Как это работает

- **Копия на вашем компьютере.** `sync` кладет ваши сделки и людей и компании из них в локальное хранилище WireCat,
  один файл на вашем компьютере, общий для всех инструментов WireCat. Списки, воронка и поиск читают его, в том числе
  без интернета.
- **Вход по токену доступа.** Токен хранится в связке ключей системы, а на компьютере без нее в закрытом файле.
- **Сделан для скриптов и агентов.** `--json` дает ответ в JSON, а ошибка приходит с кодом, по которому можно
  ветвиться. [MCP](./mcp.md)
- **Что хранится и что уходит в сеть.** [Безопасность](./security.md)

## Начните за несколько минут

В WireCat Desktop установите Attio на странице **Инструменты** и войдите в разделе **Управление**, как
показано в [установке](./installation.md#in-wirecat-desktop). Или вставьте это своему
агенту:

```text prompt
Установи attio командой npm install -g @wirecat/attio-cli. Помоги мне создать токен доступа Attio и запустить attio work session start, чтобы подключить мое пространство, затем синхронизируй и покажи мои открытые сделки.
```

Или в терминале:

```sh
npm install -g @wirecat/attio-cli
attio skill install          # teaches Claude Code, Codex and Gemini CLI to use attio
attio work session start     # paste the Attio access token when it asks
attio work sync              # copy your deals and their people and companies
attio work deals list status:open
```

Нужен Node.js 22.16 или более поздний 22.x, либо Node.js 24 и новее. [Установка](./installation.md) показывает, как
создать токен.

## Ограничения

- Компании только читаются: у компании в Attio нет атрибута почты или телефона, который можно записать. Меняйте ее
  через `api`.
- Заметки и задачи видны в списке и на сделке, когда вы включаете настройку `activities`. У списков и
  пользовательских объектов пока нет своих команд. До них достает `attio work api`.
- Люди, компании и участники пространства каждый раз читаются из Attio, поэтому им нужен интернет.
- Attio не умеет отдавать только то, что поменялось с какого-то момента, поэтому каждая синхронизация заново читает
  все сделки. Большое пространство синхронизируется дольше.
- Создать токен может только администратор пространства, и токен читает все пространство.
