Дайте ваши сделки, людей и компании из Attio ИИ-агенту, который не может запускать команды, например Claude Desktop,
Cursor, ChatGPT или Claude в браузере. MCP (Model Context Protocol) это способ, которым такой агент спрашивает
программу, что она умеет, и потом вызывает ее. `attio` отдает свои команды именно так.

Тогда агент читает ваши сделки, воронку и изменения из копии на вашем компьютере, а людей и компании ищет в Attio, в
пределах разрешений профиля.

Агенту с терминалом, например Claude Code или Codex, так же хорошо подходят команды и навык
(`attio skill install`). Нужен профиль, в который вы вошли ([установка](./installation.md)), и сначала загляните в
[разрешения](./permissions.md): через MCP запись на уровне `ask` выполняется.

## Подключите attio к агенту

```sh
attio work mcp add claude-code --allow-writes   # or codex
attio work mcp check                            # the handshake and the tool list, as the client sees them
```

`--allow-writes` подтверждает, что вы знаете: профиль предлагает инструменты, которые пишут, то есть записи группы
`api`. Для Claude Desktop, Cursor или любого другого клиента `attio work mcp config` печатает запись, которую нужно
вставить в его настройки, с полными путями. Вручную для Claude Code:

```sh
claude mcp add attio -- attio work mcp serve
```

Один сервер может обслуживать несколько профилей: `attio mcp serve --profiles work,client` или `--profiles all`.
Тогда каждый вызов называет свой профиль, а агент спрашивает вас, если вы не сказали какой.

## Что видит агент

У сервера три инструмента:

- `attio_tools_search` находит команду по словам, с ее аргументами и видом ответа.
- `attio_read` запускает команду, которая только читает: `{ "command": "deals list", "arguments": { "query": "status:open" } }`.
- `attio_write` запускает команду, которая пишет, например операцию `api`, которая создает или удаляет запись.

Команда называется так же, как в командной строке, без профиля, и проверяет тот же ключ разрешения.

Текст из Attio приходит с пометкой `untrusted`: названия сделок, названия этапов, имена людей и названия компаний,
значения атрибутов и то, что находит `search all`. Агенту сказано, что это данные, а не инструкции.

## Записи остаются под вашим контролем

Команды сделок, людей и компаний только читают. Группа `api` достает до любой операции Attio, и ее записи по
умолчанию стоят на `allow`, а удаления на `ask`. Через MCP в терминале никого нет, чтобы ответить на `ask`, поэтому
удаление тоже выполняется.

Запись останавливают две вещи. Используйте хотя бы одну, прежде чем добавить сервер:

- **Права токена.** Токен только с тремя правами на чтение из раздела [установка](./installation.md) писать не
  может: Attio отклоняет запись.
- **Разрешения профиля.** Эта строка закрывает любую запись `api` от любого агента на этом профиле, а чтение
  продолжает работать:

  ```sh
  attio work config set permissions.api readonly
  ```

Чтобы один сервер был строже профиля, дайте ему свои уровни. Профиль они никогда не ослабляют:

```sh
attio work mcp add claude-code --allow-writes --permission api=readonly
attio work mcp serve --permission api.objects-records-delete=deny
```

Или включите подтверждение для инструмента `attio_write` в клиенте агента, чтобы клиент спрашивал вас перед каждой
записью.

## ChatGPT и Claude в браузере

Приложение в браузере подключается к серверу по HTTP через ваш собственный туннель, например Tailscale Funnel:

```sh
attio work mcp serve --http --public-url https://laptop.example.ts.net
```

Сервер слушает только `127.0.0.1`, порт 8765 (`--port` его меняет). Приложение в браузере входит по одноразовому
коду, который печатает команда. `attio work mcp revoke` завершает все входы.

`attio work mcp server start` запускает тот же сервер в фоне. `mcp server status` показывает его порт, код входа и
вошедшие приложения, а `mcp server stop` его останавливает.
