Пишите и проверяйте свой блог, не открывая wp-admin. `wordpress` дает ИИ-агенту, с которым вы уже работаете,
например Claude Code, Codex или Claude Desktop, копию постов и страниц вашего WordPress на вашем компьютере. Агент
отвечает по этой копии, даже без интернета. Он пишет черновики на вашем сайте и публикует их, когда вы это разрешите.

Спросите, что вы опубликовали в прошлом месяце, какие черновики ждут или что сейчас написано на странице. Отдайте
агенту свои заметки, и он сделает черновик с заголовком, отрывком и метками. Нужен свой сайт на WordPress, версии
5.7 или новее, открытый по https, и пользователь на нем.

## Что вы получаете

- **Ответ, а не поиск.** Спросите о посте своими словами. Агент найдет его по заголовку и тексту, с его статусом,
  метками и автором, прочитав их с вашего компьютера.
- **Все черновики и запланированные посты одним списком.** Отберите их по статусу, метке, автору или дню публикации.
- **Черновики из ваших заметок.** Файл Markdown становится черновиком на вашем сайте, с заголовком, отрывком и
  метками.
- **Публикация сейчас или позже.** Опубликуйте черновик сразу, запланируйте его или верните пост в черновики.
- **Корзина тоже.** Посты из корзины остаются в копии со своим статусом, так что выброшенное не пропадает из виду.
- **Ваши посты рядом с вашими чатами.** Они лежат в том же локальном хранилище, что и сообщения, письма и встречи,
  которые другие инструменты WireCat хранят на вашем компьютере.

## О чем новичок не догадается

- **Ваш ключ это пароль приложения.** WordPress пускает программу по паролю, который вы создаете в своем профиле,
  отдельно от пароля для входа. Он может то же, что ваш пользователь, и не больше. [Установка](./installation.md)
  показывает, куда нажимать.
- **`blog` это имя, которое вы выбираете.** Оно называет один сайт и одного пользователя и стоит первым словом в
  каждой команде. Ни одна команда не выбирает сайт за вас.
- **Чтение идет по копии, изменения идут на сайт.** `sync` копирует ваши посты и страницы. `posts list`,
  `posts search` и `posts show` отвечают по этой копии. `posts create`, `update`, `publish`, `unpublish` и `delete`
  меняют ваш сайт.
- **Что вы видите, решает ваша роль.** Администратор получает весь сайт. Редактор получает все посты и страницы, но
  не список пользователей. Автор или участник получает только часть, подробнее в [ограничениях](#limits).
- **Через MCP "ask" выполняется.** MCP это способ, которым приложения вроде Claude Desktop вызывают инструмент, и там
  никто не сидит у терминала, чтобы ответить на вопрос. Поэтому агент через MCP может публиковать. Если хотите
  публиковать сами, поставьте `posts.publish` в `deny`: [разрешения](./permissions.md).

## Как это выглядит

```text
You:    What did I publish in October?
Agent:  (runs wordpress blog posts list status:published "published:[2026-10-01 TO 2026-10-31]")
        · 38 "Release notes for version 2", published on 3 October
        · 40 "How we test with a fake WordPress", published on 17 October
You:    Schedule draft 63 for Monday 9:00.
Agent:  (runs wordpress blog posts publish 63 --at-time 2026-11-23T09:00:00Z)
        Draft 63 is scheduled for Monday, 23 November, 09:00 UTC.
```

*Посты выдуманы, вывод для примера.*

## Почему wordpress

- **Копия вашего сайта на вашем компьютере.** Списки и поиск отвечают по ней, без запроса к сайту, в том числе без
  интернета.
- **Можно доверить агенту.** У создания, изменения, публикации и удаления свое разрешение, и в терминале каждое из
  них сначала спрашивает. Одна строка оставляет публикацию за вами.
- **Бережные изменения.** Изменение останавливается, если пост поменяли на сайте после последней синхронизации. Пост
  с галереями или встраиваниями сохраняет свой текст, пока вы не скажете его заменить.
- **Пароль остается в связке ключей системы.** Он никогда не попадает в вывод, ошибки или логи.
- **Подходит любому агенту.** Навык для агентов с терминалом, MCP-сервер для Claude Desktop и Cursor и защищенная
  ссылка для ChatGPT и Claude в браузере.
- **Бесплатно и с открытым кодом.** Apache 2.0.

## Что он умеет

- **Посты и страницы:** список по статусу, типу, метке, автору или дате, поиск по словам, один пост с текстом в
  Markdown. [Работа с инструментом](./usage.md#read-posts-and-pages)
- **Метки, рубрики и авторы:** список с номерами, которые принимают другие команды.
  [Работа с инструментом](./usage.md#tags-and-authors)
- **Черновики:** новый черновик из файла Markdown, смена его заголовка, отрывка, меток или текста.
  [Работа с инструментом](./usage.md#write-a-draft)
- **Публикация:** опубликовать сейчас, запланировать, вернуть в черновики, отправить в корзину.
  [Работа с инструментом](./usage.md#publish)
- **Любая операция API WordPress** из терминала, с теми же проверками разрешений.
  [Работа с инструментом](./usage.md#the-wordpress-api)

## Как это работает

- **Копия на вашем компьютере.** `sync` кладет ваши посты и страницы с любым статусом, их метки, рубрики и авторов
  в локальное хранилище WireCat, один файл на вашем компьютере, общий для всех инструментов WireCat. Текст хранится
  в Markdown. Следующие синхронизации читают только изменения.
- **Вход по паролю приложения.** Пароль хранится вместе с адресом сайта в связке ключей системы, а на компьютере без
  нее в закрытом файле.
- **Сделан для скриптов и агентов.** `--json` дает ответ в JSON, а ошибка приходит с кодом, по которому можно
  ветвиться. [MCP](./mcp.md)
- **Что хранится и что уходит в сеть.** [Безопасность](./security.md)

## Начните за несколько минут

Вставьте это своему агенту:

```text prompt
Установи wordpress командой npm install -g @wirecat/wordpress-cli. Помоги мне создать пароль приложения в WordPress и выполнить wordpress blog session start --site blog.example.com --login anna, чтобы подключить мой сайт, затем синхронизируй и покажи мои черновики.
```

Или выполните сами:

```sh
npm install -g @wirecat/wordpress-cli
wordpress skill install          # teaches Claude Code, Codex and Gemini CLI to use wordpress
wordpress blog session start --site blog.example.com --login anna   # paste the application password
wordpress blog sync              # copy your posts, pages, tags and authors
wordpress blog posts list status:draft
```

Нужен Node.js 22.16 или более поздний 22.x, либо Node.js 24 и новее. [Установка](./installation.md) показывает, как
создать пароль.

## Ограничения

- Только свой WordPress с паролями приложений. Сайты на WordPress.com не поддерживаются.
- Пароль приложения вы вставляете сами. Вход через браузер есть в [планах](./roadmap.md).
- Автор или участник получает только свои посты и не получает страниц: WordPress не отдает обоим список страниц.
  Участник получает только свои черновики и посты на проверке. У обоих пост, который пропал из их доступа, остается
  в копии как был: удаленный навсегда или пост участника, который опубликовал редактор. Список пользователей получает
  только администратор. Синхронизация называет каждый такой пробел.
- Нет счетчиков просмотров. WordPress сам их не ведет, а статистика Jetpack не поддерживается. `posts stats`
  показывает только то, что есть в копии.
- У полей плагинов, например SEO-плагинов или плагинов произвольных полей, нет своих флагов. Группа `api` отправляет
  их в сыром `--body`.
- Изменения работают с постами. Комментарии и меню доступны через группу `api`. Группа `api` отправляет только JSON,
  поэтому загрузить файл в медиатеку она не может.
