Каждый сценарий — частая задача по шагам: какие команды выполнить, зачем нужна каждая и на что смотреть в ответе. Те же сценарии есть в терминале: `max guide` показывает список, а `max guide <name>` — один сценарий.

Команды, которые работают с аккаунтом, начинаются с профиля — имени, которое вы дали аккаунту при входе: `max <profile> …`.

<a id="agent-on-a-timer" />

## Агент читает MAX по расписанию

Каждое утро получайте сводку того, что ждёт вашего ответа, от агента, который не может отправлять.

1. ```sh
   max schedule command sync-chats --every 2h -- messages sync --all
   ```

   поддерживает историю всех чатов в локальном хранилище актуальной, чтобы агент читал её без сети

2. ```sh
   max schedule agent morning claude "run the daily follow-up review: max skill show follow-ups" --at 08:30
   ```

   запускает агента в 08:30 с MAX_READ_ONLY=1: он читает и готовит черновики, но никогда не отправляет

3. ```sh
   max schedule list
   ```

   когда сработает каждое расписание и как прошёл его последний запуск

На что смотреть:

- статус последнего запуска обоих расписаний
- сохранённый ответ агента и уведомление о том, что он готов

Агент работает под запретом изменений, поэтому любая его попытка отправки отклоняется ещё до обращения к MAX. Удалить расписание можно командой
`max schedule remove <name>`.

В терминале: `max guide agent-on-a-timer`

<a id="catch-up" />

## Наверстать упущенное за день

Узнайте, кто ждёт вашего ответа и что вы обещали, не открывая каждый чат.

1. ```sh
   max review 'date>1d' --unanswered 4h
   ```

   вопросы вам, на которые никто не ответил за четыре часа, во всех чатах

2. ```sh
   max inbox --new
   ```

   чужие сообщения, пришедшие после прошлой проверки, каждое по одному разу

3. ```sh
   max tasks list
   ```

   вопросы, просьбы и обещания, сохранённые обзором, начиная со старых

На что смотреть:

- кто спросил первым и как давно
- задачи, исходное сообщение которых — ваше обещание

`review` и `inbox` читают MAX и сохраняют прочитанное, поэтому `tasks list` и последующий поиск работают по локальному
хранилищу. Добавьте `--offline` к любой из них, чтобы читать только уже сохранённое.

В терминале: `max guide catch-up`

<a id="find-what-was-said" />

## Найти, что кто-то сказал

Верните сообщение, файл или голосовое, если помните только слово или человека.

1. ```sh
   max search all "invoice"
   ```

   сообщения, заметки, текст файлов и расшифровки голосовых одним поиском, лучшие совпадения первыми

2. ```sh
   max contacts timeline Anna
   ```

   всё, что написал человек или где его упоминали, начиная с новых, из хранилища

3. ```sh
   max messages context Team 1234
   ```

   сообщение, на которое указывает результат, вместе с соседними

На что смотреть:

- чат и время каждого результата
- указатель msg, чтобы сослаться на сообщение или открыть его

Поиск находит только то, что есть в хранилище. Выполните `max messages sync --all` один раз или `max schedule command` по таймеру,
чтобы старая история тоже находилась.

В терминале: `max guide find-what-was-said`

## Написать от имени бота

Отправьте сообщение в группу от имени бота через официальный Bot API MAX, а не со своего аккаунта.

1. ```sh
   max bot auth set
   ```

   проверяет токен бота в MAX и сохраняет его; введите токен в скрытом поле или передайте через stdin

2. ```sh
   max bot chats list
   ```

   чаты, которые бот видел на этом компьютере, чтобы выбрать, куда писать

3. ```sh
   max bot messages send Team "the release is out"
   ```

   отправляет сообщение от имени бота; без текста он читается из stdin

На что смотреть:

- какого бота называет `bot auth set`, до любой отправки
- id сообщения, который возвращает отправка, чтобы потом изменить или закрепить его

Боту нужен собственный токен от MAX; ваш личный вход не используется. `max bot recipients add` ограничивает чаты,
в которые бот может писать.

В терминале: `max guide post-as-a-bot`
