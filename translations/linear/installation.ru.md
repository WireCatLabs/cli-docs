---
title: "Установка"
---

Установите `linear` один раз на каждый компьютер, где с ним работаете вы или агент. Нужен Node.js 22.16 или более новый 22.x, либо 24 и новее. Node 23 не поддерживается.

```sh
npm install -g @wirecat/linear-cli
linear --version
```

Проверьте установку, затем выберите имя профиля для своего аккаунта, например `personal`:

```sh
linear doctor
```

`doctor` не ходит в сеть и не открывает связку ключей. Он показывает версию, где лежат настройки, какие профили
есть и могут ли другие пользователи компьютера читать настройки. Дальше: [как им пользоваться](./usage.md).
