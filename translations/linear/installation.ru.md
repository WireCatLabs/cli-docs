Подключите рабочее пространство Linear один раз, и дальше ИИ-агент отвечает о ваших тикетах, а вам не нужно
вставлять их в чат. Linear пускает программу только по персональному API-ключу, который вы создаете в настройках
Linear. Создать ключ, установить `linear` и войти можно примерно за пять минут.

Когда все готово, агент на этом компьютере читает копию ваших тикетов, проектов и комментариев, даже без интернета, и
меняет тикеты в пределах вашего ключа и ваших разрешений.

Все это можно сделать в [WireCat Desktop](https://wirecat.dev/en/docs/desktop), приложении, которое устанавливает инструменты за вас,
или в терминале через npm. В обоих случаях нужен один персональный API-ключ.

## Коротко

1. [Создайте ключ](#make-a-personal-api-key) на стороне Linear.
2. В WireCat Desktop: на странице **Инструменты** нажмите **Установить** в строке Linear, затем **Управление** и
   **Войти здесь**, и вставьте ключ.
3. Или в терминале установите инструмент, войдите с ключом и скопируйте данные:

```sh
npm install -g @wirecat/linear-cli
linear work session start
linear work sync
```

<a id="what-you-need" />

## Что нужно

- Рабочее пространство Linear, где вам можно создавать API-ключи. Администраторам можно всегда. Участникам можно, если
  администратор не отключил это в **Settings → Administration → API → Member API keys**.
- Для терминала: Node.js 22.16 или более новый 22.x, либо Node.js 24 и новее. Node 23 не поддерживается. WireCat
  Desktop ставит Node.js сам.

<a id="make-a-personal-api-key" />

## Создайте персональный API-ключ

Эти шаги Linear описывает на своей странице об [API и вебхуках](https://linear.app/docs/api-and-webhooks).

1. В Linear откройте [Settings → Account → Security & access](https://linear.app/settings/account/security).
2. Создайте новый персональный API-ключ и дайте ему имя, например `WireCat`.
3. Выберите доступ. Чтобы копировать пространство и искать по нему, хватит **Read**. Добавьте **Write**, если агент
   будет создавать и менять тикеты. Ключ можно ограничить несколькими командами.
4. Скопируйте ключ. Linear показывает его только один раз.

<a id="in-wirecat-desktop" />

## В WireCat Desktop

1. На странице **Инструменты** нажмите **Установить** в строке Linear.
2. Нажмите **Управление**, введите имя аккаунта, например `work`, и нажмите **Войти здесь**.
3. Вставьте ключ. Desktop проверяет его в Linear, прежде чем сохранить.

Desktop еще и дает вашим ИИ-агентам навык инструмента, так что остальную часть страницы можно пропустить.

<a id="in-a-terminal" />

## В терминале

Установите `linear` один раз на каждый компьютер, где с ним работаете вы или агент:

```sh
npm install -g @wirecat/linear-cli
linear --version
linear doctor
```

`doctor` не ходит в сеть и не открывает связку ключей. Он показывает версию, где лежат настройки, какие есть профили и
могут ли другие пользователи компьютера читать настройки.

Дайте терминальному агенту навык инструмента, короткое руководство по его командам. Приложение, которое подключается
к MCP-серверам, работает с инструментом по MCP, как показано в разделе [как пользоваться](./usage.md#agents).

```sh
linear skill install
```

<a id="sign-in" />

## Вход

Профиль - это имя, которое вы даете одному аккаунту Linear, например `work`. Оно идет первым словом в каждой команде
для аккаунта. Войдите в профиль с ключом:

```sh
linear work session start
```

Команда спрашивает ключ и не показывает его на экране, или читает его из stdin, но никогда не берет аргументом.
Сначала Linear проверяет ключ. Затем ключ попадает в связку ключей системы, а там, где она не работает, в закрытый
файл с `--credential-storage file`.

<a id="check-that-it-works" />

## Проверьте, что все работает

```sh
linear work session status --check
linear work sync
linear work issues list type:started
```

`session status --check` спрашивает у Linear, чей это ключ. `sync` копирует пространство, а `issues list` показывает
тикеты в работе из копии.

<a id="sign-out" />

## Выход

`linear work session end` забывает ключ на этом компьютере. Сам ключ в Linear остается действующим, пока вы не
отзовете его на той же странице настроек.
