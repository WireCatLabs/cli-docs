---
title: "Instalar"
---

Instala `linear` una vez en cada ordenador donde lo uses tú o un agente. Necesitas Node.js 22.16 o un 22.x posterior, o 24 o posterior. Node 23 no es compatible.

```sh
npm install -g @wirecat/linear-cli
linear --version
```

Comprueba la instalación y elige un nombre de perfil para tu cuenta, como `personal`:

```sh
linear doctor
```

`doctor` no usa la red ni abre el llavero. Muestra la versión, dónde están los ajustes, los perfiles que existen y si
otros usuarios del ordenador pueden leer los ajustes. Siguiente paso: [úsalo](./usage.md).
