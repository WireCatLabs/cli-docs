---
title: "Настройки"
---

Решите один раз, что агенту можно менять в Linear и сколько показывает одна команда. Настройки хранятся в одном
файле, `config.json`, в папке, которую показывает `linear doctor`. У каждого профиля своя часть, а `defaults`
действуют для всех профилей.

```sh
linear personal config show
linear personal config set limit 50
linear personal config unset limit
```

`config show` перечисляет каждую настройку и откуда она взялась: из файла, из переменной или по умолчанию.

## Разрешения

`permissions` решает, что команда может делать для этого профиля: `allow`, `ask`, `readonly` или `deny`, для каждого
ключа разрешения. По MCP спросить некого, поэтому `ask` пропускает команду. `WCLINEAR_READ_ONLY=1` запрещает любую
запись, что бы ни говорили разрешения.

## Записи запусков

Команда, которая не удалась, сохраняется как запуск для `linear runs list` и `runs show`. Если `record` равен
`false`, сохраняются только неудачи, а `--no-record` не сохраняет ничего. `session status --check` работает внутри
запуска, поэтому `--record` его сохраняет. `record_input` решает, хранит ли запуск введенные вами слова. Он равен
`true`, пока вы не поставите `false`. Секреты маскируются в любом случае, см. [Безопасность](./security.md).
