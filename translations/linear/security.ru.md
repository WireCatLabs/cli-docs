---
title: "Безопасность"
---

Общее для всех инструментов WireCat, например связка ключей, разрешения, MCP и то, что никогда не попадает в лог,
описано на [общей странице безопасности](https://wirecat.dev/en/docs/security). Здесь только то, что относится к
`linear`.

`linear` хранит настройки в `config.json`, а состояние в папках, которые показывает `linear doctor`. Группа `api`
обращается к API Linear. `session start` хранит токен сервиса в связке ключей системы или в закрытом файле, если
связка ключей не работает. Токен попадает только в заголовок Authorization запроса и никогда не попадает в адрес,
ответ, запись запуска или журнал отправок.

`linear personal mcp serve --http` слушает только `127.0.0.1`, для приложений в браузере, которые достают до него
через ваш собственный туннель. Каждое приложение входит по одноразовому коду, а сервер хранит хеш каждого выданного
входа в папке состояния, доступной для чтения только вам. `linear personal mcp revoke` забывает их все.

Запись запуска хранит командную строку так, как вы ее ввели, поэтому `linear runs show` говорит, что было запущено.
Секрет все равно сохраняется как `[redacted]`: параметр с именем вроде token или password, пароль в ссылке, длинная
непрозрачная строка. Номер телефона заменяется на `[redacted]` внутри введенного слова, в том числе в тексте
сообщения: номер, записанный с "+" и кодом страны, или от 11 до 15 цифр подряд, так что длинный id такой длины тоже
скрывается. Чтобы не сохранять ни одного введенного слова, выполните `linear personal config set record_input false`.

Секрет также узнается по виду, в записи запуска и в сохраненном сообщении об ошибке: токен известного формата
(GitHub, OpenAI, Slack, AWS, Stripe, npm и подобные), учетные данные `Bearer`, случайная на вид строка из 20 и более
символов и случайная на вид цепочка из 20 и более шестнадцатеричных символов в нижнем регистре, например
шестнадцатеричный ключ или полный хеш коммита. Значение после имени секрета тоже скрывается, идет ли оно после `=`,
`:` или пробела: `password=`, `API_TOKEN=`, `password hunter2`, `pin 1234`. Некоторые секреты похожи на обычные слова
и остаются: значение только из букв после имени секрета и пробела (`pin this message` остается), шестнадцатеричный
ключ в верхнем регистре, короткий хеш коммита или UUID, короткий пароль, введенный без имени секрета перед ним, и
секрет внутри ссылки или пути к файлу, если он не известного формата и не идет после имени секрета.

`config.json` сохраняется с доступом на чтение только для вас (`0600`), а его папка создается только для вас
(`0700`). Файл или папка, созданные старой версией, могут быть открыты другим пользователям компьютера:
`linear doctor` показывает каждый такой под `files.problems` и печатает `chmod`, который это исправляет. Windows не
проверяется. Об уязвимости сообщайте так, как сказано в
[SECURITY.md](https://github.com/WireCatLabs/linear-cli/blob/main/SECURITY.md).
