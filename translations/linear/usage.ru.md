Здесь объясняется, как устроена команда и как с инструментом работает агент. Прочитайте это до первой команды.

## Сначала профиль

Профиль это имя, которое вы выбираете для одного аккаунта. Это первое слово каждой команды, которой нужен аккаунт:

```sh
linear personal config show
```

`WCLINEAR_PROFILE=personal` делает то же для одного сеанса оболочки. Профиль никогда не подставляется сам, даже
единственный: команда без него останавливается с кодом выхода 2 и показывает профили на этом компьютере.

## Вывод для скриптов

Каждая команда, кроме `mcp serve` на stdin и stdout, принимает `--json` и печатает одно значение JSON в stdout.
Ошибки идут в stderr тоже в JSON, с кодом, по которому можно ветвиться. Коды перечислены в
[справочнике команд](./commands.md).

## Агенты

`linear skill install` кладет навык инструмента туда, где его ищут Claude Code, Codex, Gemini CLI и OpenClaw.
`linear skill install --for hermes` еще и добавляет эту папку в настройки Hermes Agent, поэтому простой `skill install`
Hermes не трогает. `linear personal mcp serve` отдает команды профиля по MCP, через stdin и stdout:

```sh
claude mcp add linear -- linear personal mcp serve
```

Сервер предлагает все команды, в том числе те, что пишут. Что из них выполнится, решают разрешения профиля, см.
[настройки](./configuration.md#permissions).

Для ChatGPT и Claude в браузере
`linear personal mcp serve --http --public-url https://laptop.example.ts.net` слушает `127.0.0.1` (порт 8765 или
`--port`) за вашим собственным туннелем. Приложение в браузере входит по одноразовому коду, который печатает команда.
`linear personal mcp revoke` завершает все входы. `linear personal mcp server start` запускает тот же сервер в фоне,
`mcp server status` показывает его порт, код входа и вошедшие приложения, а `mcp server stop` его останавливает.
