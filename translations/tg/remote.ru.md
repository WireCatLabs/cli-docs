---
title: "ChatGPT и Claude в браузере"
---

`tg mcp --http` предоставляет те же инструменты на `127.0.0.1`, за вашим HTTPS-туннелем. У HTTP-сервера
свой вход OAuth для одного владельца; отдельный прокси для проверки входа не нужен.
Локальное подключение через stdin/stdout работает как прежде. Настройка для браузера полностью от начала до конца не проверялась.

## Запустите туннель и сервер

Сначала настройте Telegram: `tg setup --agent none`. Пока пользуетесь коннектором, компьютер должен быть включён.
Например, установите [Tailscale](https://tailscale.com/download), включите
[Funnel](https://tailscale.com/kb/1223/funnel) и выполните:

```sh
tailscale funnel 8765
```

В другом терминале укажите HTTPS-адрес, который вывел Funnel, без пути:

```sh
tg mcp --http --public-url https://<device>.<network>.ts.net --port 8765
```

При необходимости поставьте профиль первым: `tg work mcp --http --public-url https://<device>.<network>.ts.net`.
Локальный порт по умолчанию — `8765`. Сервер выводит в терминал одноразовый код владельца.

## Подключите приложение

Добавьте адрес туннеля с `/mcp`, например `https://<device>.<network>.ts.net/mcp`, как удалённый
MCP-коннектор. Инструкции приложений:
[режим разработчика ChatGPT](https://developers.openai.com/api/docs/guides/developer-mode) или
[собственные коннекторы Claude](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).
Страница входа запрашивает код, выведенный в терминале. Он действует десять минут;
после каждого входа выводится новый код. После пяти неверных кодов вход заблокирован до перезапуска сервера.

Доступные инструменты по-прежнему определяют `permissions` профиля. Каждое изменение через HTTP требует подтверждения
в форме, даже с `allow`, `--yes` или `--allow-dangerous`. Клиент без форм такое изменение выполнить не может.
Для того, что коннектор не должен менять, выберите `readonly` или `deny`; см. [настройки](./configuration.md).

## Остановка и отзыв доступа

Нажмите Ctrl-C в обоих терминалах, чтобы остановить сервер и туннель. Выполненные в браузере входы сохраняются при обычном перезапуске сервера.
Чтобы забыть все входы из браузера для профиля:

```sh
tg mcp --revoke --json
```

Этим приложениям придётся войти снова. Ваша сессия Telegram при этом не завершается.

## Проверка подключения

`tg mcp doctor` проверяет локальное MCP-подключение и список инструментов; вход в Telegram и туннель он не проверяет.
Подключение к аккаунту проверяет явная сетевая команда, например `tg account show`.
Записи запусков доступны через `tg runs list`: успешные вызовы сохраняются, только если включена запись;
неудачные сохраняются по умолчанию, если запись не отключена явно.
