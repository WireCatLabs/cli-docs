---
title: "Профили и боты"
---

**Профиль** — это имя для одного входа `tg` на этом компьютере: аккаунт Telegram или бот, со своей сессией и собственными настройками. Без имени `tg` использует профиль `default`, поэтому с одной аккаунтом вам никогда не придется думать о профилях.

Прочтите эту страницу, если вам нужна вторая аккаунт, вы хотите, чтобы у вашего ИИ-агента было меньше прав, чем у вас, или вы хотите запустить бота. Вы узнаете, как выбрать профиль для команды, как задать профилю отдельные настройки и как переключиться на бота.

## Что позволяют профили

| Вы хотите | Как |
|---|---|
| Используйте две аккаунты Telegram на одном компьютере | Войдите один раз для каждого профиля: `tg work session start` |
| Дайте вашему агенту меньше прав, чем у вас есть | Профиль со своими [разрешениями](./permissions.md) |
| Оставьте агента в этом профиле | `TG_PROFILE_LOCK` ([профили в логине и сессиях](./sessions.md#profiles)) |
| Запустите бота Telegram рядом со своей аккаунтом | Профиль бота: `tg support bot api get-me` |
| Просмотреть все профили на этом компьютере | `tg account list` |

## Выберите профиль

Поместите имя профиля перед командой:

```sh
tg work config show
```

`tg account list` показывает все профили на этом компьютере и аккаунт, под которой выполнен вход; `tg work session end` завершает вход профиля `work`.

К этому профилю применяется параметр `profiles.work` в файле конфигурации; значения `defaults` применяются, когда он не имеет собственного значения. Правила для имен профилей и порядок, в котором `tg` выбирает профиль, находятся в [профили при входе и сессии](./sessions.md#profiles).

Профили не являются отдельными пользователями операционной системы: агент с неограниченным доступом к файлам все равно может получить доступ к другим данным на этом компьютере.

## Переключитесь на бота

Поставьте `bot` после имени профиля:

```sh
tg support bot api get-me --json
```

Для этих команд требуется уже подключенный профиль бота. Аккаунт и права бота берутся из Telegram, а не из вашего личного аккаунта. [Бот Telegram](./bot.md) объясняет, как подключить бота, с примерами.
