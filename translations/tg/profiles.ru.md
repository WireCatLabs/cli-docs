---
title: "Профили и боты"
---

Профиль задаёт имя и отдельные настройки для аккаунта или бота. Используйте его, если у вас несколько
аккаунтов, нужны отдельные разрешения для помощника или вы работаете с ботом.

## Выберите профиль

Укажите профиль перед командой:

```sh
tg work config show
```

Без имени инструменты используют профиль по умолчанию. Настройка в `profiles.work` относится к
этому профилю; значения в `defaults` применяются, если у профиля нет собственного значения.
Профили не являются отдельными пользователями операционной системы: помощник с неограниченным доступом к файлам
всё равно может получить другие данные на этом компьютере.

## Переключитесь на бота

Укажите `bot` после имени профиля:

```sh
tg support bot api get-me --json
```

Этим командам нужен уже подключённый профиль бота. Аккаунт и права бота определяются
мессенджером, а не вашим личным аккаунтом. Раздел [Боты](./bot.md) объясняет настройку и приводит примеры.

## Настройки и доступ

[Конфигурация](./configuration.md) объясняет сохранённые значения, переменные окружения и флаги.
[Разрешения](./permissions.md) определяют, что может делать каждый профиль.
Для входа используйте [руководство по входу](./sessions.md).
