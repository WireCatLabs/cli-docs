Несколько открытых инструментов уже подключают личный аккаунт Telegram к терминалу или ИИ-агенту. Здесь `tg` сравнивается с пятью из них, поэтому вы можете сразу увидеть, какой инструмент что делает, и выбрать тот, который подходит для вашей работы. Оценки берутся из собственной документации и исходного кода каждого проекта, проверено 23 октября 2026 года; инструмент может делать больше, чем указано в его документации.

Инструменты:

- **tg** — этот инструмент: командная строка и MCP-сервер для вашего аккаунта, с локальным архивом.
- **[tgcli](https://github.com/dapi/tgcli)** — командная строка с фоновой синхронизацией, локальным архивом и MCP-сервером (активно развиваемый форк [kfastov/tgcli](https://github.com/kfastov/tgcli)).
- **[tlgr](https://github.com/tlgrcli/tlgr)** — командная строка и фоновая служба, которые делают почти всё на сервере Telegram, с навыком для агентов.
- **[telegram-mcp](https://github.com/chigwell/telegram-mcp)** — самый популярный MCP-сервер для Telegram с большим набором действий.
- **[mcp-telegram](https://github.com/mcp-telegram/mcp-telegram)** — MCP-сервер примерно со 180 инструментами, запускается через `npx`.
- **[tdl](https://github.com/iyear/tdl)** — быстрый инструмент скачивания и отправки файлов и медиа.

✅ да · 🟡 частично · ❌ нет · ➖ нет в документации

У tg есть профиль только для чтения, список разрешенных получателей и почасовое ограничение на отправку.

## Когда другой инструмент подходит лучше

- **tdl** — вы в основном перемещаете файлы: массовые загрузки, выгрузки и пересылку на полной скорости из одного двоичного файла, который может установить большинство менеджеров пакетов.
- **tlgr** — вам сегодня нужны черновики и альбомы из командной строки или параллельные загрузки с возобновлением, а локальный архив не нужен.
- **telegram-mcp** — вам нужен самый широкий набор действий агента в Claude Desktop, установленный за один шаг и за которым стоит большое сообщество.
- **mcp-telegram** — вам нужен большой набор инструментов MCP, который запускается одной командой `npx`, без Python.
- **tgcli** — вы хотите, чтобы сервер MCP был внутри службы синхронизации, или ведёте заметки о чатах.

Если `tg` подходит, начните с [установки](./installation.md); о подключении агента без терминала см. [сервер MCP](./mcp.md).
