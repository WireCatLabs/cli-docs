Каждый сценарий — частая задача по шагам: какие команды выполнить, зачем нужна каждая и на что смотреть в ответе. Те же сценарии есть в терминале: `tg guide` показывает список, а `tg guide <name>` — один сценарий.

Команды, которые работают с аккаунтом, начинаются с профиля — имени, которое вы дали аккаунту при входе: `tg <profile> …`.

<a id="agent-without-send" />

## Дать агенту аккаунт, но не кнопку отправки

Агент читает ваш Telegram и готовит черновики, а любая отправка отклоняется.

1. ```sh
   tg mcp setup claude-code --permission messages.send=deny --allow-writes
   ```

   подключает этот профиль к Claude Code; его сервер отклоняет messages send, что бы ни разрешал профиль, а --allow-writes подтверждает, что другие инструменты могут что-то менять

2. ```sh
   tg schedule agent morning claude "run the daily follow-up review: tg skill show follow-ups" --at 08:00
   ```

   обзор каждое утро от агента, запущенного с TG_READ_ONLY=1: он готовит черновики и никогда не отправляет

3. ```sh
   tg sends list
   ```

   все попытки отправки, включая отклонённые, — видно, что пытался сделать агент

На что смотреть:

- отклонённые строки в sends list и команду, которая их запросила
- последний запуск расписания в tg schedule list

В терминале: `tg guide agent-without-send`

<a id="catch-up" />

## Наверстать упущенное за день

Узнайте, что изменилось, кто ждёт вашего ответа и что вы обещали, не открывая каждый чат.

1. ```sh
   tg review 'date>1d' --transcribe
   ```

   все сообщения со вчерашнего дня в изменившихся чатах, включая ваши, с голосовыми в виде текста

2. ```sh
   tg review --unanswered 4h
   ```

   вопросы вам, на которые никто не ответил четыре часа и дольше

3. ```sh
   tg tasks agenda
   ```

   задачи на сегодня, ответы, которые должны вы, и ответы, которых ждёте вы

На что смотреть:

- кто спросил первым и как давно
- обещания в ваших сообщениях, для которых ещё нет задачи

`review` читает локальное хранилище и изменившиеся чаты; по умолчанию ничего не отмечается прочитанным, это делает `--mark-read`.

В терминале: `tg guide catch-up`

<a id="find-what-was-said" />

## Найти, что кто-то сказал

Найдите сообщение, которое помните смутно, прочитайте его в контексте и поделитесь ссылкой.

1. ```sh
   tg search all invoice
   ```

   сообщения и заметки одним поиском, лучшие совпадения первыми; добавьте --offline, чтобы не выходить в сеть

2. ```sh
   tg messages context Team 1234
   ```

   сообщение и соседние сообщения по чату и id из результата

3. ```sh
   tg messages link Team 1234
   ```

   ссылка на сообщение, чтобы вставить её в заметку или задачу

На что смотреть:

- чат и время каждого результата
- ref нужного результата: его принимают следующие команды

В терминале: `tg guide find-what-was-said`

## Сделать файлы чата доступными для поиска

Ищите слова внутри PDF и документов, которые вам прислали, а не только в сообщениях.

1. ```sh
   tg messages sync Team
   ```

   обновляет историю чата в локальном хранилище

2. ```sh
   tg attachments extract --chat Team --download --output-dir tg-files
   ```

   сохраняет ещё не скачанные файлы и кладёт их текст в локальное хранилище

3. ```sh
   tg search all invoice --offline
   ```

   текст файлов теперь находится вместе с сообщениями, без запросов к Telegram

На что смотреть:

- файлы, текст которых не удалось прочитать; для сканов нужен --ocr
- курсор в ответе, если остались непрочитанные файлы

В терминале: `tg guide searchable-files`
