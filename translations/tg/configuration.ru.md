---
title: "Настройки"
---

`tg` можно настроить. Вы можете сохранить обычные настройки, изменить значение для одной команды
или выбрать другой профиль. Разрешения описаны отдельно в разделе [Разрешения](./permissions.md).

## Файл настроек

Инструменты создают начальный `config.json` с обычными значениями по умолчанию при первом запуске команды, которая
загружает настройки. Существующий файл сохраняется. Эти команды показывают путь к нему и текущие значения:

```sh
tg config show
```

Вы можете редактировать файл или использовать `config set` и `config unset`. Не храните в нём учётные данные входа;
вместо этого используйте команды входа и настройки провайдера моделей.

| Система | Telegram |
|---|---|
| Linux | `~/.config/tg-cli/config.json` |
| macOS | `~/Library/Application Support/tg-cli/config.json` |
| Windows | `%APPDATA%\tg-cli\config.json` |

В PowerShell используйте `tg.cmd`. Команды выше показывают фактическое расположение, если ваш
компьютер использует нестандартный каталог.

## Три способа задать значение

- **Файл:** значение сохраняется для следующих команд. `tg config set limit 50` сохраняет ограничение числа результатов.
- **Переменная окружения:** терминал может выбрать профиль или лимит времени команды для своей сессии.
  Например, `TG_PROFILE` выбирает профиль. Не у каждой настройки есть переменная.
- **Параметр команды:** флаг вроде `--limit 5` меняет только этот вызов.

## Какое значение имеет приоритет?

Параметр команды имеет приоритет над переменной окружения, затем идёт сохранённое значение выбранного профиля,
затем общие значения по умолчанию из файла, затем встроенное значение. Учитываются только поддерживаемые способы задания
именно этого значения. Справочник каждого мессенджера перечисляет их.

## Небольшая конфигурация

```json
{
  "defaults": { "limit": 20, "sendsPerHour": 30 },
  "profiles": { "work": { "limit": 50 } }
}
```

`tg work chats list` использует 50. Добавьте `--limit 5`, чтобы получить пять результатов для этой команды.
Удаление значения профиля снова позволяет применять общее значение по умолчанию.

## Что я могу настроить?

Обычные настройки включают число результатов, цвет, запись, ограничения отправки и провайдеров моделей.
Доступные значения и поддерживаемые переопределения описаны
в [справочнике настроек](./configuration-reference.md). После изменения используйте `config show`, чтобы проверить результат.

## Профили и боты

Профиль хранит настройки одного аккаунта или бота. Укажите его имя перед командой, например
`tg work config show`. Добавьте `bot`, чтобы работать от имени бота вместо личного аккаунта.
Раздел [Профили и боты](./profiles.md) объясняет их выбор и переключение.
