Все настройки, которые читает `zm`, и переменные среды, меняющие места хранения.

## Параметры

Установите значение через `zm config set <key> <value>`, просмотрите настройки через `zm config show`.

| Ключ | Значение |
|---|---|
| `zoom.clientId` | Public Client ID [вашего приложения Zoom](./zoom-app.md) |
| `account.profile` | метка [локального профиля](./sessions.md#select-a-local-profile), группирующая встречи |
| `source` | источник для `pull` и `watch`: `api` или `files` |
| `files.folder` | папка расшифровок для файлового источника и наблюдения |
| `files.timezone` | часовой пояс IANA в именах скачанных файлов, например `Europe/Madrid`; по умолчанию UTC |

Повреждённая конфигурация не мешает `--help` и `--version`; команды настроек сообщают об ошибке.

## Переменные среды

| Переменная | Действие |
|---|---|
| `ZM_CONFIG_DIR` | меняет каталог настроек и службу хранилища секретов для входа |
| `MESSAGING_STORE` | явный путь к общей базе для импорта, загрузки, наблюдения, чтения встреч и MCP |
| `OPENAI_API_KEY` | для явно выбранного OpenAI endpoint поиска по смыслу ([руководство](./topic-search.md)) |

Остальные каталоги следуют правилам платформы. Общая база по умолчанию — `wirecat.db`
([хранение встреч](./archive.md#where-meetings-are-stored)).
