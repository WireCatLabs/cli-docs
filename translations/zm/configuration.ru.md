---
title: "Настройки"
---

Измените приложение, источник или локальный профиль и проверьте настройки перед загрузкой или
сеансом агента. Открытые настройки выбирают приложение и пути данных; токены остаются в
системном хранилище секретов. Справочник перечисляет допустимые ключи и значения по умолчанию.

## Параметры

Установите значение через `zm config set <key> <value>`, просмотрите настройки через `zm config show`.

| Ключ | Значение |
|---|---|
| `zoom.client_id` | Public Client ID [существующего или нового приложения](./zoom-app.md); изначально не задан, нужен для API |
| `account.profile` | [Локальная метка](./sessions.md#select-a-local-profile) данных; изначально не задана, нужна для базы |
| `source` | Источник `meetings sync` и `watch`: `api` по умолчанию или `files` |
| `files.folder` | Папка для загрузки/наблюдения файлов; изначально не задана |
| `context.sources` | JSON-массив явно выбранных аккаунтов сообщений, почты или папок документов для этого профиля; по умолчанию пуст ([настройка ниже](#select-communications-for-preparation)) |
| `files.timezone` | Часовой пояс IANA имён файлов, например `Europe/Madrid`; по умолчанию UTC |

После изменения проверьте `zm config show`. Смена `account.profile` не меняет пользователя Zoom.
Другой ID клиента выбирает другую запись ключей: подтвердите приложение перед API. `ZOOM_CLIENT_ID`
не является настройкой установленной команды `zm`; используйте `zm config set zoom.client_id`,
а не переменную из инструмента разработчика.

Файл хранит эти настройки как `client_id`, `files_folder`, `files_timezone`, `account_profile` и `source`.
Настройки в JSON используют snake_case. Старый файл camelCase отклоняется и не переписывается.
Перед обновлением переименуйте `clientId` в `client_id`, `filesFolder` в `files_folder`,
`filesTimezone` в `files_timezone`, `accountProfile` в `account_profile`. Сохраните значения и закрытые
права доступа к файлу. Селектор команды `zoom.clientId` остаётся псевдонимом `zoom.client_id`,
но не поддерживается как ключ JSON.

Повреждённая конфигурация не мешает `--help` и `--version`; команды настроек сообщают об ошибке.

## Найти файл настроек

`zm config set` создаёт и изменяет `config.json` автоматически. В нём открытые настройки, а не
токены Zoom; файл не скачивается из Marketplace. `zm doctor --json` показывает фактический путь,
не проверяя сохранённый сеанс OAuth.

| Платформа | Стандартные открытые настройки |
|---|---|
| Linux и macOS | `~/.config/zm/config.json` или каталог `zm` внутри `XDG_CONFIG_HOME` |
| Windows | `%APPDATA%\zm\Config\config.json` |
| Явный путь | `config.json` внутри `ZM_CONFIG_DIR` |

Старое расположение macOS больше не переносится автоматически; doctor показывает используемый путь.
Открытые настройки приложения, токены хранилища секретов и база встреч — разные данные.

## Переменные среды

| Переменная | Действие |
|---|---|
| `ZM_CONFIG_DIR` | меняет каталог настроек и службу хранилища секретов для входа |
| `MESSAGING_STORE` | явный путь к общей базе для импорта, загрузки, наблюдения, чтения встреч и MCP |
| `OPENAI_API_KEY` | для явно выбранного OpenAI endpoint поиска по смыслу ([руководство](./topic-search.md)) |

Иначе каталоги следуют правилам платформы. Стандартная база — `wirecat.db`
([хранение встреч](./archive.md#where-meetings-are-stored)). Передавайте одинаковое окружение
в терминале и MCP; иначе они могут видеть разные профили или базы. В [сеансах](./sessions.md)
проверьте авторизацию отдельно от открытых настроек.

## Выберите источники для подготовки

Подготовка может искать в аккаунтах и папках, уже импортированных в общую базу. Сначала выберите
локальный профиль Zoom, затем сохраните до восьми источников для него. У каждого должны быть ID,
тип kind, провайдер provider и аккаунт account. Для сообщений и почты нужны точные сохранённые
значения провайдера и аккаунта: скопируйте их из настроек исходного инструмента или его ссылок
на источники. Отображаемое имя не заменяет идентификатор аккаунта.

```sh
zm config set account.profile research
zm config set context.sources '[{"id":"project-notes","kind":"document","provider":"folder","account":"notes:5"}]'
zm config show
```

В примере вымышленный ID папки. Выполните `memo folders list` и подставьте ID выбранной папки.
`notes:5` находит её сохранённый идентификатор; команда не создаёт и не импортирует папку.
Источник документов охватывает одну папку, сообщений — один аккаунт мессенджера, почты — один
почтовый аккаунт. Разрешение распространяется на весь выбранный аккаунт или папку: ограничений
по отдельному чату, отправителю или пути пока нет. Выбирайте только подходящую для вашей задачи область.

Настройка заменяет источники текущего профиля и сохраняет настройки остальных. Значение `[]`
отзывает выбор для текущего профиля. Повторяющиеся ID и идентификаторы, неизвестные поля и более
восьми записей отклоняются. В JSON-файле массив хранится в `context_sources`, с полем `profile`
у каждой записи. Меняйте его через `config set`, чтобы не редактировать этот формат вручную.

Только явно запрошенные источники разрешаются и просматриваются при подготовке. Недоступный
источник, который вы не запросили, не мешает остальным. Обычное чтение встреч не получает доступа
к другим аккаунтам. MCP-сервер сохраняет определения источников при запуске и закрепляет
идентификатор каждого запрошенного источника при первом использовании. После изменения или
отзыва выбора перезапустите сервер. Отсутствующий или несовпадающий идентификатор приводит к
ошибке; автоматического выбора источников нет.
