---
title: "Настройки"
---

Измените приложение, источник или локальный профиль и проверьте настройки перед загрузкой или
сеансом агента. Открытые настройки выбирают приложение и пути данных; токены остаются в
системном хранилище секретов. Справочник перечисляет допустимые ключи и значения по умолчанию.

## Параметры

Установите значение через `zm config set <key> <value>`, просмотрите настройки через `zm config show`.

| Ключ | Значение |
|---|---|
| `zoom.clientId` | Public Client ID [существующего или нового приложения](./zoom-app.md); изначально не задан, нужен для API |
| `account.profile` | [Локальная метка](./sessions.md#select-a-local-profile) данных; изначально не задана, нужна для базы |
| `source` | Источник `meetings sync` и `watch`: `api` по умолчанию или `files` |
| `files.folder` | Папка для загрузки/наблюдения файлов; изначально не задана |
| `files.timezone` | Часовой пояс IANA имён файлов, например `Europe/Madrid`; по умолчанию UTC |

После изменения проверьте `zm config show`. Смена `account.profile` не меняет пользователя Zoom.
Другой ID клиента выбирает другую запись ключей: подтвердите приложение перед API. `ZOOM_CLIENT_ID`
не является настройкой установленной команды `zm`; используйте `zm config set zoom.clientId`,
а не переменную из инструмента разработчика.

Повреждённая конфигурация не мешает `--help` и `--version`; команды настроек сообщают об ошибке.

## Найти файл настроек

`zm config set` создаёт и изменяет `config.json` автоматически. В нём открытые настройки, а не
токены Zoom; файл не скачивается из Marketplace. `zm doctor --json` показывает фактический путь,
не проверяя сохранённый сеанс OAuth.

| Платформа | Стандартные открытые настройки |
|---|---|
| Linux и macOS | `~/.config/zm/config.json` или каталог `zm` внутри `XDG_CONFIG_HOME` |
| Windows | `%APPDATA%\zm\Config\config.json` |
| Явный путь | `config.json` внутри `ZM_CONFIG_DIR` |

Старое расположение macOS переносится при возможности; doctor показывает реально используемый путь.
Открытые настройки приложения, токены хранилища секретов и база встреч — разные данные.

## Переменные среды

| Переменная | Действие |
|---|---|
| `ZM_CONFIG_DIR` | меняет каталог настроек и службу хранилища секретов для входа |
| `MESSAGING_STORE` | явный путь к общей базе для импорта, загрузки, наблюдения, чтения встреч и MCP |
| `OPENAI_API_KEY` | для явно выбранного OpenAI endpoint поиска по смыслу ([руководство](./topic-search.md)) |

Иначе каталоги следуют правилам платформы. Стандартная база — `wirecat.db`
([хранение встреч](./archive.md#where-meetings-are-stored)). Передавайте одинаковое окружение
в терминале и MCP; иначе они могут видеть разные профили или базы. В [сеансах](./sessions.md)
проверьте авторизацию отдельно от открытых настроек.
