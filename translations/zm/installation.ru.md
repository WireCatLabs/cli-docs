title: "Установка"
---

Установите `zm`, зарегистрируйте своё приложение Zoom, войдите и выберите локальный профиль.
После этого `zm pull` загрузит встречи, где вы были организатором, и агент сможет их прочитать.

## Что понадобится

- **Node 22.16 или новее в ветке 22.x либо Node 24 или новее.** Команда также работает на Bun.
- Linux, macOS или Windows. Автоматические ежедневные архивные задания устанавливаются только на Linux (пользовательские таймеры systemd).
- Системное хранилище секретов. Токены входа сохраняются только там; его отсутствие — ошибка. В конфигурационный файл токены не записываются.
- **Ваше собственное приложение Zoom** с Public Client OAuth — [руководство](./zoom-app.md) займёт несколько минут.
  Для корпоративного аккаунта может потребоваться одобрение администратора.

## Установить

```sh
npm install -g @wirecat/zoom-cli
zm --version
```

`--help` и `--version` работают без приложения и входа. `zm doctor` проверяет среду запуска
и публичные настройки без входа и открытия базы данных.

## Первый запуск

```sh
zm config set zoom.clientId <public-client-id>
zm login
zm config set account.profile personal
zm pull --lookback-days 7
zm meetings list
```

[Сеансы](./sessions.md) описывают вход и профили, [архив](./archive.md) — загрузку, импорт и записи.
Чтобы дать инструмент агенту, откройте [MCP и инструкции для агента](./mcp.md).

## Где хранятся файлы

Каталоги следуют правилам платформы. `ZM_CONFIG_DIR` меняет каталог настроек и тем самым службу
хранилища секретов для входа. Данные встреч находятся в общей базе WireCat (`wirecat.db`),
которую используют и другие инструменты; `MESSAGING_STORE` задаёт явный путь. См. [настройки](./configuration.md).

## Дополнение команд

`zm complete -- <words...>` отвечает на запросы дополнения оболочки и выводит её протокол,
если не выбран JSON. `zm commands --json` перечисляет аргументы, параметры и примеры команд.
