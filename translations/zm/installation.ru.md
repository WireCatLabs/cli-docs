title: "Установка и подключение Zoom"
---

Дайте ИИ-агенту доступ к сохранённым расшифровкам Zoom, чтобы находить обсуждения и показывать
фрагменты, подтверждающие ответ. Настройте всё с агентом или выполните команды сами. Если
расшифровки уже скачаны, можно начать без создания приложения Zoom и входа в аккаунт.

## Шаги

1. [Установите инструмент](#install) на компьютер, где работает агент.
2. [Выберите источник](#choose-how-to-connect): аккаунт Zoom или скачанные расшифровки.
3. [Подключите агента](#give-your-agent-access), чтобы он знал команды инструмента.
4. [Проверьте одну встречу](#check-your-first-result) и прочитайте подтверждающий фрагмент.

Встречи уже сохранены? Переходите к [поиску и источникам](./search.md).

## Настройте с агентом

Подойдёт агент, который запускает команды на этом компьютере: Codex, Claude Code, Cursor или
Gemini CLI. Скопируйте в его чат:

```text prompt
Use zm CLI: помоги подключить расшифровки встреч Zoom к моему ИИ-агенту на этом компьютере.
Следуй https://wirecat.dev/ru/docs/zm/installation и проверь необходимые программы перед установкой.
Спроси, хочу ли я подключить аккаунт Zoom или импортировать уже скачанные расшифровки.
Если выберу Zoom, помоги использовать моё приложение или создать новое и найти его Public Client ID.
Вход в браузере я подтвержу сам; не проси присылать токены или коды обратного вызова в этот чат.
Установи инструкции инструмента для агента, затем найди сохранённую встречу и покажи фрагмент со ссылкой.
Объясни, каких данных не хватает. Не создавай и не изменяй встречи в Zoom.
```

Агент подготовит инструмент и проверит результат. Вы выбираете приложение и аккаунт, разрешаете
доступ на экране Zoom и при необходимости завершаете обратный вызов входа. Если агент не может
держать открытым интерактивный терминал, выполните [первый запуск](#first-run) сами и вернитесь
к нему. Для агента без терминала откройте [MCP и skills](./mcp.md).

## Что понадобится

- **Node.js 22.16 или новее в ветке 22.x либо Node.js 24 или новее**, с npm. Проверьте
  `node --version` и `npm --version` в Terminal на macOS/Linux или PowerShell на Windows.
  Если команды нет, установите Node.js с [nodejs.org](https://nodejs.org/en/download), откройте
  терминал заново и повторите проверку. Инструмент также работает на Bun.
- Место для выбранных встреч на этом компьютере. Инструмент на сервере использует файлы
  и вход сервера, а не ноутбука.
- **Для доступа к аккаунту Zoom:** аккаунт, которому разрешена авторизация приложения, и системное
  хранилище паролей: Keychain на macOS, Credential Manager на Windows или сервис секретов рабочего
  стола на Linux. Организация может требовать одобрение администратора. Сервер без такого
  хранилища не сохраняет вход; импорт файлов его не требует.

## Установить

```sh
npm install -g @wirecat/zoom-cli
zm --version
zm doctor
```

Вы увидите номер версии и результат локальной диагностики. Эти команды не входят в аккаунт
и не читают встречи. Пакет называется `@wirecat/zoom-cli`, короткая команда — `zm`.

Если PowerShell на Windows блокирует `npm.ps1` или `zm.ps1`, используйте команды запуска:

```powershell
npm.cmd install -g @wirecat/zoom-cli
zm.cmd --version
zm.cmd doctor
```

Используйте `zm.cmd` и в остальных примерах, если этого требует терминал. Менять политику
исполнения PowerShell не нужно. Если команда не найдена, откройте терминал заново и проверьте,
что папка глобальных команд npm есть в PATH — списке папок поиска программ. Перезапустите
работающего агента, если он не видит установленную команду.

## Выберите способ подключения

| С чего начинаете | Что делать |
|---|---|
| Приложение Zoom уже создано | [Открыть его реквизиты](./zoom-app.md#use-an-app-you-already-created), включить Public Client OAuth и скопировать **Public Client ID** |
| Приложение предоставила команда, в том числе WireCat | Получить **Public Client ID** у владельца и проверить доступ своего пользователя Zoom; [использовать общее приложение](./zoom-app.md#use-a-wirecat-or-team-app) |
| Приложения нет | [Создать General app с управлением User-managed](./zoom-app.md#create-your-own-app), настроить обратный вызов и разрешения, затем вернуться сюда |
| Есть файлы расшифровок | [Импортировать без приложения Zoom](#import-without-a-zoom-app), пропустив вход в браузере |

**Файл учётных данных не нужен.** Приложение Zoom регистрирует разрешения, которые инструмент
может запросить. Это не ваш аккаунт и не приложение для звонков. Внутри него включите
**Use Public Client OAuth** и скопируйте **Public Client ID**. Обычные Client ID и Client Secret
не подходят. Создавать ещё один OAuth-клиент вне приложения не нужно.

Перед входом проверьте ту же среду Development или Production, к которой относится публичный ID:

| Настройка | Нужное значение |
|---|---|
| Тип приложения / управление | General app / User-managed |
| Use Public Client OAuth | Включено |
| OAuth Redirect URL и OAuth Allow Lists | В обоих точно `https://wirecat.dev/zoom-callback` |
| Scopes | Все пять [разрешений чтения встреч организатора](./zoom-app.md#what-the-manifest-asks-for) для синхронизации |

В [инструкции приложения](./zoom-app.md) есть шаги Marketplace и добавление доступа к записям.
Установка `zm` не выбирает общее приложение автоматически. Приложение в разработке может быть
доступно только аккаунту создателя; его ID не даёт доступ к чужим встречам.

## Первый запуск

Замените `<public-client-id>` публичным ID приложения, убрав угловые скобки. Выполняйте команды
по одной в обычном терминале и оставьте его открытым, пока подтверждаете вход в браузере:

```sh
zm config set zoom.client_id <public-client-id>
zm config set source api
zm session start
```

1. Войдите в аккаунт Zoom, чьи встречи организатора хотите получить, и проверьте разрешения.
2. Нажмите **Allow**. Zoom откроет страницу обратного вызова WireCat, которая передаст
   авторизацию ожидающему инструменту на этом компьютере.
3. Вернитесь в терминал. Успех — `logged_in: true` и приглашение командной строки.
   Одного одобрения в браузере недостаточно.
4. Если терминал ждёт, скопируйте со страницы `code=…&state=…` или полный URL обратного вызова,
   вставьте в **тот же ожидающий терминал** и нажмите Enter. Не отправляйте в чат агента
   и не выполняйте как команду оболочки. После пяти минут запустите новый вход.

Выберите **профиль** — локальную метку для сохранённых встреч, затем получите небольшой период:

```sh
zm session status --json
zm config set account.profile personal
zm meetings sync --lookback-days 7
zm meetings list --json
```

Статус должен показать сохранённый вход `logged_in: true`; он не обращается в Zoom для проверки
действительности доступа. Sync делает удалённые запросы и сохраняет доступные данные встреч
организатора. List читает локальную копию. Смена метки профиля не меняет подтверждённый аккаунт
Zoom. См. [сеансы и профили](./sessions.md#select-a-local-profile).

Если список пуст, проверьте аккаунт, даты и [наличие записей и расшифровок](./zoom-app.md#before-your-first-zm-meetings-sync).
Для встречи, где вы были участником, а не организатором, может понадобиться файл от организатора.
Ошибка отсутствующего разрешения называет его; сохраните изменения приложения и войдите заново.

## Импорт без приложения Zoom

Возьмите `.vtt`, скачанный с разрешения или полученный от организатора. Назовите файл, например,
`2026-10-01_1000_example-planning.vtt` и положите его прямо в папку. Имя задаёт дату, время и название встречи;
настройка часового пояса определяет, как интерпретировать время:

```sh
zm config set account.profile personal
zm config set files.timezone Europe/Madrid
zm meetings import ./downloaded-transcripts
zm meetings list --json
```

Укажите свою папку и часовой пояс. Импорт не обходит вложенные папки и не считает имена
говорящих списком участников. Приложение, вход в браузере и OAuth-токен не нужны.
Поддерживаемые имена и история исправлений описаны в [скачанных расшифровках](./archive.md#downloaded-transcripts).

## Дайте агенту доступ

**Skill** — инструкции инструмента для агента с терминалом:

```sh
zm skill install --for agents
```

Это устанавливает инструкции для Codex/Gemini. Для Claude Code используйте `--for claude`;
без `--for` устанавливаются оба варианта. Инструкции не авторизуют Zoom и не загружают встречи.
Для агента с MCP откройте [MCP и skills](./mcp.md); его инструменты встреч работают только на чтение.

## Проверьте первый результат

Возьмите ID из списка встреч и замените `<meeting-id>` без угловых скобок:

```sh
zm meetings show <meeting-id> --json
zm meetings transcript <meeting-id> --json
```

Вы увидите сохранённую встречу и расшифровку, если Zoom её предоставил или вы импортировали файл.
Встреча может не содержать текста; разрешение само его не создаёт. Попросите агента:

```text prompt
Use zm CLI: найди встречу, которую я только что импортировал или получил.
Покажи дату, действительно записанных участников, одно решение и подтверждающий фрагмент со ссылкой.
Если решение не подтверждается источником, скажи об этом. Укажи, есть ли расшифровка и сведения об участниках.
```

Полезный ответ содержит ссылку на источник, подтверждающие слова и указание на недостающие
данные. При отсутствии расшифровки или незавершённом входе откройте [решение проблем](./troubleshooting.md).
Когда проверка пройдёт, [найдите тему и прочитайте окружающий контекст](./search.md).

## Где хранятся файлы

При настройке создаётся публичный `config.json`; это не скачанный файл учётных данных.
`zm doctor --json` показывает его расположение. Токены остаются в системном хранилище паролей.
Встречи используют общее локальное хранилище `wirecat.db`; записи скачиваются в выбранную папку.
`ZM_CONFIG_DIR` меняет настройки и сервис ключей, `MESSAGING_STORE` — файл базы данных.
См. [конфигурацию](./configuration.md).

## Обновление и удаление

Для обновления повторите установку и проверьте версию:

```sh
npm install -g @wirecat/zoom-cli
zm --version
```

Для удаления команды:

```sh
npm uninstall -g @wirecat/zoom-cli
```

Удаление оставляет общую базу встреч и папки записей. Отзовите доступ приложения в Zoom
Marketplace, если хотите убрать авторизацию аккаунта. Команды выхода нет; см.
[сеансы](./sessions.md#remove-access). На Windows при необходимости используйте `.cmd`.

## Дополнение команд в оболочке

`zm complete -- <words...>` отвечает на запросы дополнения, но не устанавливает его в оболочку.
`zm commands --json` показывает команды и параметры агентам и скриптам.

После установки [найдите фрагмент встречи](./search.md) и проверьте источник, прежде чем сохранять выводы.
