---
title: "Вход, сеансы и профили"
---

Войдите со своим приложением Zoom, сохраните токен в системном хранилище секретов и выберите
локальную метку профиля для сохранённых встреч.

## Войти

Следуйте [руководству по приложению](./zoom-app.md). Используйте Public Client OAuth и адрес
`https://wirecat.dev/zoom-callback`. Настройте Public Client ID и войдите:

```sh
zm config set zoom.clientId <public-client-id>
zm login --browser firefox
```

Ответ возвращается слушателю на вашем компьютере. Если это не удалось, вставьте параметры
`code=…&state=…` со страницы обратного вызова. Вход проверяет state и PKCE, сохраняет токены только
в системном хранилище и возвращает состояние и фактически выданные разрешения. Отсутствие хранилища —
ошибка; в конфигурационный файл токены не записываются. Слушатель закрывается при успехе, ошибке
и истечении срока; входу по умолчанию даётся пять минут.

Для входа через браузер нужен терминал с вводом. В конвейере или JSON-режиме также нужен
`--interactive`; CI и терминалы без интерактивного ввода браузер не запускают. `--no-input` запрещает такой вход.

## Проверить сеанс

`zm session status` проверяет сохранённое состояние OAuth отдельно от локальных профилей данных,
без обновления токенов. `session status --check` явно обращается к Zoom и требует
разрешения чтения пользователя (`user:read:user`).

Ошибка отсутствующего разрешения называет его. Добавьте его в приложении Zoom и войдите снова:
старые токены не получают новые разрешения автоматически.

## Выбрать локальный профиль

Выберите метку сохранённых встреч:

```sh
zm config set account.profile personal
```

Метки содержат 1–64 буквы, цифры, точки, подчёркивания или дефисы и начинаются с буквы или цифры.
Метка группирует локальные данные; OAuth использует настроенный клиент и запись хранилища секретов.
Разные метки отделяют данные разных аккаунтов. Импорт файлов и API используют выбранный профиль.
Импорт папки не меняет курсор загрузки; при смене источника может понадобиться более ранний `--since`.

Импорт и загрузка регистрируют профиль при начале обработки. Команды чтения ищут существующий
профиль и не создают аккаунт; сначала импортируйте или загрузите встречи.
`MESSAGING_STORE` меняет путь базы для этих команд и MCP. Метаданные, справка, настройки и вход
базу не открывают.
