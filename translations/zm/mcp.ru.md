---
title: "MCP и инструкции для агента"
---

Дайте агенту сохранённые встречи Zoom: через skill — инструкции для агента, который запускает
команды в терминале, или через MCP-сервер только для чтения для приложений без терминала.

## Инструкции для агента

`zm skill show` показывает инструкции из пакета. `zm skill install` явно записывает копию с меткой
версии в `~/.claude/skills/zoom-cli/` для Claude Code и `~/.agents/skills/zoom-cli/` для Codex и Gemini CLI.
`--for claude` или `--for agents` выбирает одну группу; по умолчанию обе. При запуске обычной команды
инструкции автоматически не устанавливаются.

## MCP-сервер

`zm serve --mcp` использует stdio и предлагает семь инструментов только для чтения: список и просмотр
встреч, расшифровки, сводки, экспорт, поиск текста и участников. Обнаружение инструментов не открывает
базу. Каждое чтение использует выбранный аккаунт и закрывает соединение до ответа; вызывающий не может
сменить аккаунт. Запись файлов экспорта и удалённые изменения не доступны как инструменты.

MCP-клиент запускает `zm` с `["serve", "--mcp"]`. Для формата `mcpServers` в
[конфигурации Claude Desktop](https://modelcontextprotocol.io/docs/develop/connect-local-servers):

```json
{
  "mcpServers": {
    "zoom": { "command": "zm", "args": ["serve", "--mcp"] }
  }
}
```

Приложение может не видеть `PATH` вашего терминала; stdio-сервер наследует только часть среды
([отладка MCP](https://modelcontextprotocol.io/docs/tools/debugging)). Если сервер не запускается,
используйте полный путь из `which zm`. Если заданы `ZM_CONFIG_DIR` или `MESSAGING_STORE`, передайте
те же значения через `env`, иначе сервер прочитает другой профиль или базу.

Оставьте stdout для протокола: не добавляйте `--json`, `--jsonl` и `--fields`. `--max-output-bytes`
ограничивает результат каждого инструмента; ноль снимает ограничение. Перед чтением выберите профиль
и импортируйте или загрузите данные. Обнаружение инструментов доступно и без данных.

## Дополнительные инструменты

Флаги дополняют стандартный набор: `--meeting-context` добавляет источники, контекст человека и
предложения задач; `--unified-search` — общий поиск только по встречам; `--semantic --model <id>` —
один инструмент поиска по векторам. Для удалённого компонента нужны `--base-url` и `--dims`.
Сервер фиксирует компонент при запуске, профиль — при первом чтении. Перезапустите его, чтобы сменить
выбор; клиенты не могут это сделать. Генерация векторов и создание задач не являются MCP-инструментами.
