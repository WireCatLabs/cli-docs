---
title: "MCP и инструкции для агента"
---

Дайте агенту читать сохранённые встречи и отвечать с источниками. Выберите инструкции для
терминального агента или MCP для приложения, запускающего локальные инструменты. Skill — файл
инструкций; MCP — протокол вызовов. Ни один способ не выполняет вход и не загружает встречи.
[Сначала импортируйте или загрузите встречу](./installation.md#first-run), затем задавайте вопросы.

## Выберите подключение

| Ваш агент | Подключение | Результат |
|---|---|---|
| Codex или Gemini CLI на этом компьютере | `zm skill install --for agents` | Инструкции для команд |
| Claude Code на этом компьютере | `zm skill install --for claude` | Его инструкции для CLI |
| Локальное приложение с MCP | Добавить запись сервера ниже и перезапустить | Те же команды, как три инструмента |

Оба способа выполняют одни и те же команды с одними и теми же [разрешениями](./configuration.md#permissions) профиля.

## Инструкции для агента

`zm skill show` показывает инструкции из пакета. `zm skill install` явно записывает копию с меткой
версии в `~/.claude/skills/zoom-cli/` для Claude Code и `~/.agents/skills/zoom-cli/` для Codex и Gemini CLI.
`--for claude` или `--for agents` выбирает одну группу; по умолчанию обе. При запуске обычной команды
инструкции автоматически не устанавливаются.

## MCP-сервер

`zm personal mcp` предоставляет команды zm через stdio-протокол MCP как три инструмента, одни и те же в каждом CLI WireCat:

| Инструмент | Что делает |
|---|---|
| `zm_tools_search` | находит команду для задачи — «meetings list», «search», «prepare» — с её аргументами |
| `zm_read` | выполняет команду, которая ничего не меняет: `{ "command": "meetings list", "arguments": {} }` |
| `zm_write` | выполняет команду, которая что-то меняет, например `remote-meetings create`, или `search meetings`, который сначала обновляет индекс слов |

Вызов выполняет саму командную строку, поэтому отвечает и завершается ошибкой так же, как `zm personal <command> --json`.
Сервер работает от профиля, названного в его `args`; вызывающий не может его сменить. Вход, настройки, `watch` и
сам сервер не предлагаются.

То, что запрещают разрешения профиля, не предлагается и не выполняется, а `readonly` скрывает команды, которые что-то
меняют. Команда с уровнем `ask` выполняется без вопроса, потому что у терминала никого нет: встроенный `ask` для
`remote-meetings` позволяет агенту создавать, менять и отменять встречи Zoom. Чтобы агент этого не делал, задайте
профилю, которому он служит, `{"remote-meetings": "readonly"}`.

В формате `mcpServers`
[конфигурации Claude Desktop](https://modelcontextprotocol.io/docs/develop/connect-local-servers):

```json
{
  "mcpServers": {
    "zoom": { "command": "zm", "args": ["personal", "mcp"] }
  }
}
```

Настольное приложение может не видеть `PATH` вашего терминала, а stdio-сервер наследует лишь часть
окружения ([руководство по отладке MCP](https://modelcontextprotocol.io/docs/tools/debugging)). Если сервер не
запускается, укажите в качестве команды полный путь из `command -v zm` на Linux/macOS или `where.exe zm` на Windows.
Если вы задали `ZM_CONFIG_DIR` или `MESSAGING_STORE`, передайте те же значения в `env` записи, иначе сервер
прочитает другой профиль или базу. Оставьте stdout для сообщений протокола; не добавляйте `--json` и `--jsonl`.

### Обновление с версии 0.34 и ранее

`zm serve --mcp` и его флаги (`--meeting-context`, `--meeting-preparation`, `--semantic` и остальные) удалены;
`zm serve` теперь сообщает об этом. Каждый добавленный ими инструмент — команда, которую предлагает общий сервер:
`meetings context`, `meetings prepare`, `meetings projects scan`, `meetings scheduled`, `search all`,
`search meetings --model`. Замените `args` записи на `["personal", "mcp"]`.

## Проверьте подключение

После установки инструкций начните новый сеанс агента, если он их не обнаружил. После настройки
MCP перезапустите приложение и проверьте наличие инструментов Zoom. Попросите:

```text prompt
Покажи сохранённые встречи. Открой последнюю, покажи дату, доступную расшифровку и отрывок, подтверждающий главное решение. Скажи, если данных недостаточно.
```

Сравните выбранную встречу с `zm personal meetings list --json` в терминале. Если инструменты есть, а данных
нет, проверьте тот же профиль и путь, затем загрузите или импортируйте. Веб-чат не запускает локальную команду
без поддерживаемого соединения с компьютером.

## Выбранные источники в подготовке встречи

`meetings prepare` читает источники сообщений, почты и документов, настроенные для профиля
([выбор источников](./configuration.md#select-communications-for-preparation)); через MCP это та же команда,
поэтому действуют те же источники, а ненастроенный источник отклоняется. См.
[пределы и продолжение](./usage.md#include-selected-messages-mail-and-documents).
