---
title: "Поиск по смыслу"
---

Найдите обсуждение, даже если его слова отличаются от вопроса. Поиск по смыслу сравнивает
числовые представления текста — векторы, полученные выбранным компонентом. Нужны сохранённые
расшифровки и установленный локальный компонент либо явно заданный удалённый сервис.
Если он не настроен, сразу используйте [поиск слов](./search.md).

## Выберите место обработки текста

Локальный компонент обрабатывает текст на компьютере и должен быть установлен заранее. Удалённый
сервис получает расшифровки при построении векторов и вопрос при поиске. Явно выбирайте адрес,
идентификатор компонента и размерность. Инструмент не скачивает компоненты. Предпросмотр построения
не загружает их и не отправляет текст.

Примеры используют локальный `e5-small`. Проверьте установку до применения; одно имя ничего
не устанавливает. Для сопоставимости локальные и удалённые результаты должны использовать
тот же компонент и размерность, что сохранённые векторы.

## Искать по смыслу

Выберите уже установленный локальный компонент или явно укажите удалённый адрес и размерность:

```sh
zm personal search meetings "what did we decide about pricing?" --model e5-small --since-time 2026-09-01 --json
zm personal search meetings "example plan" --model example-model --base-url http://127.0.0.1:8080/v1 --dims 384 --json
```

Перед чтением поиск заново делит текущие расшифровки на фрагменты и создаёт векторы для тех,
у которых ещё нет вектора выбранного компонента. Первый поиск по большой базе занимает больше
времени, а удалённый компонент получает эти фрагменты. Продолжайте через `--cursor <next_cursor>`:
страницы продолжают один рейтинг.

Чтобы подготовить векторы заранее, просмотрите план и обрабатывайте порции:

```sh
zm personal meetings embeddings --model e5-small --json
zm personal meetings embeddings --model e5-small --yes --limit 100 --json
```

Первая команда показывает состояние фрагментов без открытия компонента, скачивания файлов и
вычисления векторов. `--yes` проверяет и открывает выбранный компонент, пересоздаёт фрагменты и
обрабатывает одну ограниченную порцию. Локальный компонент должен быть установлен заранее;
команда не скачивает его. Для OpenAI используется `OPENAI_API_KEY`. Удалённый сервис несовместим с `--offline`.

## Создать векторы

Обработка использует текущие версии расшифровок и снова проверяет хеши перед сохранением.
`--after-transcript-id` продолжает подготовку фрагментов; `--after-hash` — вычисление отсутствующих
векторов. Это разные курсоры. Общие кешированные векторы сохраняются для других ресурсов.
Подтверждённый результат завершённой обработки может быть выведен в короткий период завершения
после отмены, затем процесс выходит с кодом 130. При ошибке или отмене запроса такой квитанции нет;
заблокированный вывод может помешать её доставке.

## Искать

Команда сначала создаёт недостающие сохранённые векторы, затем выполняет два поиска по одним и тем же
встречам (фильтры по дате, встрече, серии, событию, человеку, проекту и тегу действуют на оба) и ранжирует
результаты вместе:

- **По словам**, как `search meetings` без `--model`. Вопрос (вопросительное слово в начале или `?` в конце)
  ищется по содержательным словам: «what did we decide about pricing?» — по «decide pricing». Другой текст
  разбирается как язык запроса; текст, который он отклоняет, всё равно ищется по смыслу, и `missing` сообщает об этом.
- **По смыслу**: каждый сохранённый вектор фрагмента выбранного компонента в этих встречах, до `--max-chunks`
  (по умолчанию 10000).

Строка, найденная обоими способами, ранжируется первой и цитируется своим `ref`; `by` показывает, как найден
каждый результат, `score` — сходство, а `passage` — первую и последнюю строку, совпавшие при поиске по смыслу.
При равенстве строка со словами выше фрагмента, который лишь похож на вопрос. `missing` сообщает, когда
`--max-chunks` остановил просмотр. Полнота индекса и архива остаётся неизвестной. `--max-rows` и
`--max-text-bytes` ограничивают чтение при построении и поиске. Через MCP та же команда работает только с
установленным компонентом: `--base-url` и `meetings embeddings` агенту не предлагаются.
[Измерение](https://github.com/WireCatLabs/cli-testing/tree/main/performance/search/meeting-hybrid)
сравнивает слова, смысл и оба способа на вымышленных встречах.

Откройте результат через [контекст встречи](./search.md#read-around-a-search-hit) и прочитайте
соседние строки: сходство указывает кандидата, а не доказывает решение. Если кандидатов нет,
проверьте профиль, компонент, наличие расшифровки и покрытие построения и просмотра, прежде чем
делать вывод об отсутствии обсуждения.
