## Что работает уже сейчас

`mail` читает почтовый ящик по IMAP в общее хранилище WireCat и никогда не меняет сам ящик. Сервер нового адреса он
находит сам: по встроенной таблице, по записи MX, по ISPDB Thunderbird и по файлу autoconfig домена. Вход выполняется по
паролю приложения, который хранится в хранилище ключей ОС; это работает для Яндекса, Gmail, iCloud, Mail.ru, Fastmail и
других провайдеров, которые выдают пароли приложений. Сохранённую почту вы ищете и читаете через `memo`. MCP-сервер даёт
ИИ-агентам те же команды. Все команды описаны в [справочнике команд](./commands.md).
