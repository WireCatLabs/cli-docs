Используйте эту страницу, если вам нужно точное имя, значение по умолчанию или область действия параметра или имя переменной среды. В нем перечислены все настройки, которые читает `wa`, и какое значение выигрывает.

Ни одна настройка не может хранить секрет: в файле нет поля для ключей устройства, номера телефона или идентификатора чата.

## Какое значение выигрывает

Для каждой настройки устанавливается первая из них:

1. опция в командной строке (`--limit 50`, `--record`, `--timeout 30s`)
2. переменная среды (`WA_PROFILE`, `WA_TIMEOUT`)
3. собственная запись профиля в файле конфигурации
4. `defaults` в файле конфигурации, общий для каждого профиля.
5. встроенный по умолчанию

`wa <profile> config show` печатает все действующие настройки и их происхождение.

## Файл

`~/.config/whatsapp-cli/config.json`. Никакая настройка не выбирает профиль: первое слово (`wa work …`) или `WA_PROFILE` называет его. В противном случае команда, использующая аккаунт, останавливается с кодом выхода `2` и выводит список профилей на этом компьютере. Файл, в котором все еще есть `default_profile` из более старого `wa`, также останавливает эту команду; `wa config unset default_profile` удаляет его.

| Настройка | По умолчанию | Что он делает | Переопределено для одного, управляемого |
|---|---|---|---|
| `limit` | `20` | строк на странице списка | `--limit` |
| `timeout_ms` | нет | как долго может ждать **один** запрос (в миллисекундах); для всей команды используйте `--timeout` | нет |
| `color` | из терминала | цвет в виде таблицы | никто; без настроек `NO_COLOR` отключает его |
| `sender_colors` | `false` | цвет для каждого отправителя в таблице сообщений | нет |
| `search_catch_up` | `false` | подготовить вновь сохраненные чаты для локального поиска: их график и, если они установлены, их векторы | `--catch-up`, `--no-catch-up` |
| `picture_search` | `false` | поиск сохраненных изображений по тому, что они показывают, после загрузки модели | нет |
| `record` | `false` | держать каждую пробежку | `--record`, `--no-record` |
| `keep_runs_for_days` | `30` | записанные прогоны старше этого удаляются при сохранении следующего | нет |
| `permissions` | разрешено все, кроме удаления и некоторых других изменений, спросите | что профиль может делать по команде | никто; `--yes` отвечает только на `ask` и никогда не поднимает `deny` |
| `sends_per_hour` | `30` | больше всего отправлений за час | нет |
| `requests_per_minute` | темп CLI | запрашивает минуту, разделяемую каждым процессом профиля; `0` отключает его | `WA_REQUESTS_PER_MINUTE` |
| `transcribe_with` | `auto` | кто превращает голос в текст: `auto`, `messenger` или `local` | `--local` или `--model` |
| `speech_model` | нет | который использует загруженную речевую модель `--local` | `--model` |
| `read_other_bots` | `false` | принимать сообщения, определенные как исходящие от других ботов; только профили ботов | нет |
| `update_check` | `true` | ежедневная строка «Существует более новая версия»; только под `defaults` | никто; `WA_NO_UPDATE_CHECK`, `NO_UPDATE_NOTIFIER` или `CI` выключить |
| `skill_hint` | `true` | линия не чаще одного раза в день для агента, у которого копия навыка отсутствует или устарела; только под `defaults` | нет |
| `embedding_provider` | `local` | местная модель или `openai` | `--embedding-provider` |
| `embedding_model` | провайдер по умолчанию | модель встраивания | `--model` |
| `embedding_base_url` | провайдер по умолчанию | встраивание конечной точки API | `--base-url` |
| `embedding_dims` | модель по умолчанию | целое число 1–65 536 | `--dims` |
| `analysis_provider` | `agent` | `agent`, `openai` или `anthropic` | `build --analysis-provider` |
| `analysis_model` | нет | модель анализа | `build --model` |
| `analysis_base_url` | провайдер по умолчанию | конечная точка API анализа | `build --base-url` |
| `models` | нет | внешние модели по назначению | `WA_MODELS_*` переменные |Настройки поиска, страны телефона, задачи и группы учетных записей (`search_stemmers.*`, `phone_countries`, `task_*`, `account_groups.*`) перечислены в разделе [`wa config set`](./commands.md#wa-config-set).

При первом создании файл записывается как `0600`. В этом нет никакой тайны.

## Профиль бота

Номер WhatsApp Business в облачном API Meta (`wa <profile> bot …`) сохраняет свои настройки под `bot` в файле: `wa <profile> config set --bot <setting> <value>`. Это идентификаторы со страницы настройки API панели управления приложениями, а не секреты; токен доступа находится в системной связке ключей ([номер WhatsApp Business в качестве бота](./bot.md)).

| Настройка | По умолчанию | Что он делает | Переопределено для одного, управляемого |
|---|---|---|---|
| `phone_number_id` | нет | бизнес-номер, о котором говорит каждая команда `bot` | `--phone-number-id` о командах `bot api` |
| `waba_id` | нет | аккаунт WhatsApp Business, содержащая шаблоны номеров | `--waba-id` о командах `bot api` |
| `graph_version` | `v23.0` | версию Graph API в каждом запросе | нет |

## Переменные среды

| Переменная | Что он делает |
|---|---|
| `WA_PROFILE` | профиль, когда первое слово не называет ни одного |
| `WA_PROFILE_LOCK` | закрепляет процесс в одном профиле; любому другому отказано |
| `WA_TIMEOUT` | то же, что `--timeout`: `500ms`, `30s` или `2m` для всей команды |
| `WA_REQUESTS_PER_MINUTE` | то же, что `requests_per_minute`, и побеждает его |
| `WA_CONFIG_DIR`, `WA_STATE_DIR`, `WA_CACHE_DIR` | переместить три каталога |
| `MESSAGING_STORE` | путь к файлу локального хранилища |
| `WIRECAT_STATE_DIR` | папка WireCat, совместно используемая каждым CLI: локальное хранилище и речевые модели |
| `WA_READ_ONLY` | `1` делает этот процесс доступным только для чтения: каждое изменение, включая привязку и отвязку устройства, отклоняется |
| `WA_ENGINE` | путь к программе движка, которую нужно запустить вместо установленной |
| `WA_ENGINE_LOG` | файл, в который движок добавляет свои предупреждения, замаскировав номера телефонов; не установлено, ничего не регистрируется |
| `WA_NO_UPDATE_CHECK` | `1` отключает ежедневную строку «Существует более новая версия» |
| `NO_COLOR` | нет цвета в виде таблицы |
| `WA_EMBEDDING_*`, `WA_ANALYSIS_*`, `WA_MODELS_*` | настройки модели |
