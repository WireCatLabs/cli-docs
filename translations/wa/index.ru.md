title: "WhatsApp"

`wa` подключает ваш аккаунт WhatsApp к терминалу и вашему ИИ-агенту (например, Claude Code, Codex, Cursor или Gemini CLI). Используйте его, когда хотите читать, искать и отвечать в чатах, не открывая WhatsApp, или передавать эту работу агенту в установленных вами пределах. Он привязывается к вашему аккаунту как устройство, как это делает WhatsApp Web.

На этой странице рассказывается, что может `wa`, как начать примерно за пять минут и какая страница отвечает на какой вопрос.

В руководствах используются три термина:

- **Терминал** (командная строка): окно, в котором вы вводите команды, например «Терминал» в macOS или PowerShell в Windows. `wa` — это одна из команд, которую вы там вводите.
- **ИИ-агент**: программа, которая выполняет за вас задачи и может запускать команды, например Claude Code или Codex. Он запускает для вас `wa`.
- **Навык**: короткий файл инструкций, который расскажет вашему агенту, как использовать `wa`. Программа установки установит его.

## Что он может сделать

| Вы хотите | Где |
|---|---|
| Читать свои чаты и непрочитанные сообщения других людей; ничего не помечено как прочитанное, если вы не спросите | [Использование wa](./usage.md) |
| Найдите то, что было сказано, по словам, людям, датам или меткам | [Поиск](./search.md) |
| Сохраняйте копии своих сообщений на этом компьютере и выполняйте поиск или экспортируйте их | [Локальное хранилище](./archive.md) |
| Отправляйте, сохраняйте и пересылайте фотографии и файлы, а также слушайте голосовые заметки в виде текста | [Вложенные файлы](./attachments.md) |
| Отвечать, редактировать, реагировать и удалять самостоятельно или через агента, а также удалять для всех самостоятельно, в пределах своих возможностей | [Использование wa](./usage.md), [Разрешения](./permissions.md) |
| Отключайте звук, архивируйте, закрепляйте или удаляйте чат и отмечайте сообщения на своих устройствах; установите свое имя и конфиденциальность | [Использование wa](./usage.md) |
| Посмотрите, на какие вопросы в ваших группах никто не ответил | [Группы](./groups.md) |
| Используйте WhatsApp из приложения без терминала или из чата в браузере | [Сервер MCP](./mcp.md), [Из браузера](./remote.md) |

Каждая команда выполняет одно действие и сохраняет форму ответа и имеет фиксированный код выхода для каждого типа сбоя. Поэтому скрипты и агенты могут обрабатывать ответы автоматически.

`wa` развивается; следующие задачи перечислены в [дорожной карте](./roadmap.md).

## Начать

```sh
npm install -g @wirecat/whatsapp-cli
wa personal setup                      # link by QR code, check five chats, install the agent skill
wa personal server install             # keep receiving in the background
wa personal inbox                      # other people's unread messages; nothing is marked read
```

Выделите около пяти минут на настройку: ваш телефон отправляет недавние чаты один раз, сразу после установления связи. Более старые сообщения чата можно будет запросить на телефоне позже, по 50 за раз ([старая история](./archive.md#older-history-from-your-phone)). Чтобы выбрать агента, который получит навык, укажите после `--agent` одно из значений `codex`, `cursor`, `claude`, `gemini` или `all`. `wa setup --help` показывает варианты связывания.

Для `wa` требуется Node 22.16 или новее ([установка](./installation.md)). Как работает связывание и почему одновременно может подключаться только одна команда `wa`: [связывание, устройства и профили](./sessions.md).
