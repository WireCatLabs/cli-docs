Держите сделки amoCRM или Kommo под рукой у своего ИИ-агента. Ваши сделки, их контакты и компании и история их
этапов копируются на ваш компьютер, и агент читает их даже без интернета. У amoCRM и Kommo нет своего MCP-сервера
для данных CRM, поэтому без такого инструмента агент видит сделки, только когда вы вставляете их в чат.

Спросите агента, какие сделки застряли на этапе, что поменялось в CRM вчера или как воронка переходит от этапа к
этапу. Агент может и перевести сделку на следующий этап, закрыть ее как проигранную с причиной или добавить контакт,
насколько это разрешают ваши настройки.

`amo` - инструмент командной строки WireCat для amoCRM (amocrm.ru) и Kommo (kommo.com). Он хранит копию в
локальном хранилище. Это один файл на вашем компьютере, общий для всех инструментов WireCat, поэтому поиск находит
сделку рядом с вашими чатами, почтой и встречами. Для начала администратор аккаунта один раз создает приватную
интеграцию в amoCRM или Kommo.

## Что вы получите

- **Сделки без интернета.** `sync` копирует сделки, где вы ответственный, воронки с историей этапов и только те
  контакты и компании, что есть в этих сделках. Сделки, воронки и этапы потом читаются из этой копии. Администратор
  может добавить коллег, чьи сделки тоже копируются.
- **Что поменялось со вчера.** Новые сделки, переходы по этапам, выигранные и проигранные, сделки с новым
  ответственным, новые и выполненные задачи. Утренняя сводка приходит уведомлением на компьютере, в Telegram или на
  почту через инструменты WireCat `tg` и `mail`.
- **Задачи и звонки по вашим сделкам.** Если включить настройку `activities`, `sync` копирует и задачи, комментарии и
  звонки по вашим сделкам за последние 90 дней. От звонка остается только направление, без номера телефона и записи.
- **Конверсия по этапам.** Сколько сделок стоит на каждом этапе, сколько дошло до него и пошло дальше и какая
  доля выиграна за период.
- **Изменения по вашим правилам.** У каждого действия свое разрешение: разрешить, спросить, только чтение или
  запретить. Действия, которые пишут клиентам, запускают Salesbot или добавляют пользователей, запрещены, пока вы их
  не разрешите. Любую запись можно сначала посмотреть с `--dry-run`, а `AMO_READ_ONLY=1` запрещает все записи.
- **Подключенный агент.** Установите навык инструмента для агента в терминале, например Claude Code, или подключите
  инструмент по MCP к приложению, которое работает с MCP-серверами.

Токен хранится в связке ключей системы, а где ее нет, в закрытом файле, и никогда не попадает в вывод или логи.
`amo` обращается только к вашему аккаунту. Подробнее в разделе [безопасность](./security.md).

## Подключите аккаунт и скопируйте сделки

1. [Установите `amo`](./installation.md#install) из npm.
2. Создайте приватную интеграцию в amoCRM или Kommo, как описано в разделе
   [создайте интеграцию](./installation.md#create-the-integration). Это делает администратор аккаунта, один раз.
3. Войдите с долгосрочным токеном интеграции. Это ключ, с которым инструмент действует с правами администратора,
   создавшего его. `work` - профиль, то есть имя, которое вы даете одному аккаунту. Токен инструмент спрашивает
   скрытым вводом.

```sh
amo work session start --host https://example.amocrm.ru
```

Чтобы каждый человек действовал со своими правами, войдите через интеграцию в браузере, как описано в разделе
[вход через интеграцию](./installation.md#sign-in-through-the-integration).

4. Скопируйте сделки и посмотрите открытые.

```sh
amo work sync
amo work deals list status:open
```

Запустите `sync` снова, чтобы обновить копию, или поручите это таймеру:

```sh
amo work schedule command crm --every 1h -- sync
```

5. Подключите агента. Агенту в терминале нужен навык:

```sh
amo skill install
```

Приложению с MCP нужен сервер, как описано в разделе [работа с инструментом](./usage.md#agents).

## Что читается напрямую и чего нет

- **Другие клиенты читаются из amoCRM.** Контакт или компания, которых нет ни в одной вашей сделке, не копируются.
  `people` и `organizations` находят их в amoCRM, пока есть интернет.
- **Не администратор видит меньше.** Со своими правами человек читает из копии только свои сделки, а телефоны и почту
  клиента другого пользователя видит не больше 100 раз в день.
- **Нет готовых команд для задач и примечаний.** Их можно записать только сырой командой `api call` в терминале,
  после того как вы разрешите ее ключ. Ни один инструмент MCP не дает `api call`.
- **Сделки не удаляются.** API amoCRM не умеет удалять сделку.
- **Без дополнения с фильтрами API sync медленнее.** Без платного дополнения amoCRM `sync` читает каждый контакт или
  компанию отдельным запросом.
