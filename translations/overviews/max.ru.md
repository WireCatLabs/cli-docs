Вы разбираете MAX за минуту, а не листаете каждый чат. `max` подключает ваш аккаунт MAX или вашего бота к ИИ-агенту,
которым вы уже пользуетесь, например Claude Code, Codex или Cursor. Он хранит копию чатов на вашем компьютере, поэтому
поиск по переписке MAX работает по всей истории, даже без интернета.

Агент скажет, кто ждет вашего ответа, что вы обещали на этой неделе и что Алиса сказала в голосовом. Он отвечает
сообщениями, которые нашел, и готовит ответ, который вы отправляете сами. Настройка занимает около пяти минут и один
QR-код.

## Что вы получите

- **Ни одного забытого ответа.** Один запрос показывает, кто ждет вашего ответа во всех чатах. Ничего не отмечается
  прочитанным.
- **Любое сообщение за секунды.** На вопрос "Когда мы договорились встретиться с Алисой?" агент дает дату и само
  сообщение, без интернета. Обсуждение можно найти и по смыслу, даже если вы не помните точных слов.
- **Голосовые как текст.** Голосовые сообщения превращаются в текст прямо на вашем компьютере, и по этому тексту
  тоже работает поиск.
- **Обещания под контролем.** "Что я обещал на этой неделе и чего жду от других?" дает один ответ по всем чатам.
- **Спокойные группы.** Проверка по вашим правилам ловит ссылки, приглашения в чужие чаты и флуд. По умолчанию она
  только отмечает, удаляет, когда вы разрешите. Видно, кто вступил и на какие вопросы никто не ответил.
- **Бот в том же инструменте.** Подключите бота по токену и вызывайте любую операцию официального Bot API MAX, рядом
  с готовыми командами для отправки и модерации.

## Что неочевидно с первого раза

- **Два вида подключения.** Личный аккаунт подключается как еще одно устройство, как web.max.ru. Бот работает по
  токену через официальный Bot API. Это разные профили.
- **`personal` - имя, которое вы выбираете сами** для одного аккаунта. С него начинается каждая команда. Ни одна
  команда не выбирает аккаунт за вас.
- **Чтение ничего не отмечает прочитанным**, и ничего не отправляется, пока команда этого не попросит.
- **Копия пополняется, пока вы читаете.** Чата, который вы не открывали и не скачивали, в ней нет. Поэтому пустой
  результат поиска без интернета не доказывает, что сообщения не было.

## Как это выглядит

```text
Вы:     Что я кому обещал за последние три дня?
Агент:  (запускает max personal review 'date>3d': 12 чатов, расшифровано 3 голосовых)
        Вы должны
        · Алиса Пример: прислать счет до пятницы. Личный чат, 24.09
        Ждете от других
        · Борис Образец: макет до 25.09. В чате "Дизайн" его пока нет
Вы:     Напомни Борису про макет.
Агент:  Черновик: "Борис, привет, как там макет?" Отправить?
Вы:     Да.
```

## Почему max

- **То, чего не описывает ни один другой инструмент для MAX в [сравнении](./compare.md).** Непрочитанное во всех
  чатах одним запросом, ответы, которые вы должны, поиск по смыслу и без интернета, расшифровка голосовых на вашем
  компьютере, утренняя сводка по расписанию.
- **Границы для агента задаете вы.** Только чтение, отправка только в чаты из вашего списка и не больше 30 сообщений
  в час по умолчанию. Перед отправкой `max` может спросить вас в терминале. Ни один другой инструмент в сравнении таких границ не
  описывает.
- **Никакого сервера WireCat.** `max` общается только с MAX, с вашего компьютера. Вход хранится в связке ключей
  системы.
- **Бережно к MAX.** У каждого профиля один темп запросов на все команды и всех агентов. Если MAX отвечает "слишком
  много запросов", `max` останавливается, а не повторяет запрос.
- **Бесплатно и с открытым кодом.** Лицензия Apache 2.0, работает на macOS, Linux и Windows.

Другой инструмент подойдет лучше, если нужны звонки и видеокружки (это приложение MAX) или официальный бот для
организации без установки на компьютер ([mcp-max-messenger](https://github.com/woyaxnini/mcp-max-messenger) на Bot
API).

## Что умеет max

- **Разобрать новое:** непрочитанное во всех чатах, обзор того, что изменилось, вопросы без ответа.
  [Повседневные команды](./usage.md)
- **Найти:** по человеку, чату, дате, файлу, ссылке и тегу, по смыслу, без интернета. [Поиск](./search.md)
- **Ответить:** отправить, ответить, переслать, изменить, закрепить, поставить реакцию, опрос, файл, отложенное
  сообщение. [Повседневные команды](./usage.md)
- **Вести группу:** проверка по вашим правилам, кто вступил, активность, итог недели. [Ваши группы](./groups.md)
- **Голосовые и файлы:** голосовые в текст, текст из сохраненных файлов.
  [Распознавание голосовых](./audio-recognition.md), [Вложения](./attachments.md)
- **Бот:** сообщения, кнопки и любая операция Bot API. [Боты](./bot.md)
- **Вместе с другими источниками:** свяжите аккаунты человека в MAX и Telegram, ищите сразу по сообщениям, почте и
  заметкам на этом компьютере. [Люди](./people.md)

## Как это устроено

- **Копия на вашем компьютере.** Сообщения, которые видел `max`, лежат в локальном архиве. Поиск, выгрузка и чтение
  без подключения отвечают из него. [Архив сообщений](./archive.md)
- **Вход по QR-коду.** Вы сканируете код в приложении MAX, и `max` становится еще одним устройством аккаунта. Бот
  входит по своему токену.
- **Для скриптов и агентов.** Одна операция на вызов, один JSON-ответ с `--json`, навык для агентов в терминале и
  MCP-сервер для приложений вроде Claude Desktop. [MCP](./mcp.md)
- **Что хранится и что уходит в сеть.** [Безопасность](./security.md)

## Начните за пять минут

Вставьте это в чат с агентом:

```text prompt
Используй max CLI. Установи его командой npm install -g @wirecat/max-cli, помоги мне пройти max personal setup и покажи, кто ждет моего ответа.
```

Или в терминале:

```sh
npm install -g @wirecat/max-cli
max personal setup     # вход по QR-коду и навык для агента
max personal inbox     # непрочитанное во всех чатах, ничего не отмечается прочитанным
```

QR-код вы сканируете в приложении MAX. Нужен Node.js 22.16 или новее в ветке 22, либо 24 и новее, либо Bun.
[Установка](./installation.md)

## Ограничения

- Для личного аккаунта `max` использует внутренний API MAX, тот же, что у веб-версии. MAX может изменить его без
  предупреждения. Пользовательское соглашение MAX не разрешает автоматические программы без согласия компании, и
  аккаунт могут ограничить. Как снизить риск, написано в разделе [безопасность](./security.md). Бот работает через
  официальный Bot API, и к нему это не относится.
- Звонки и видеокружки остаются в приложении MAX.
