`max` — инструмент командной строки, с которым ваш ИИ-агент может читать MAX, находить сообщения и помогать
отвечать. Можно пользоваться им и самому, через терминал. Работает на Windows, macOS и Linux.

Вы в разделе документации **MAX**. Инструкции для Telegram доступны через переключатель
мессенджера вверху страницы.

## Выберите, что подключить

- **Личный аккаунт** — ваши чаты, история и контакты, как на ещё одном устройстве. Начните с
  [установки и входа](/ru/docs/installation#max).
- **Бот** — сообщения и действия от имени бота, по его токену. Откройте
  [руководство по ботам](/ru/docs/max/bot).

Это разные способы подключения. Бот работает через официальный Bot API MAX; личный аккаунт —
через внутренний API, который может измениться без предупреждения. Ограничения и хранение
учётных данных описаны в [руководстве по безопасности](/ru/docs/max/security).

## Начните с личного аккаунта

### Подключить через агента

Откройте [установку через агента](/ru/docs/installation#max) и скопируйте короткий запрос.
Агент установит инструмент, поможет войти и проверит подключение. QR-код сканируете вы.

Затем выберите [инструкцию для своего агента](/ru/docs/agents): Codex, Claude Code, Cursor,
Gemini CLI или Hermes. Для приложений с MCP есть [руководство по MCP](/ru/docs/mcp).

### Начать самостоятельно в терминале

Откройте [пошаговую установку](/ru/docs/installation#max) и выберите инструкции для терминала.
После установки запустите настройку: она проведёт через QR-вход, проверит аккаунт и пять чатов и подключит навыки агентов. Существующий вход используется повторно; полная история не скачивается.

```sh
max setup
```

```sh
max chats list --limit 5
```

Способы входа и другие аккаунты — в [руководстве по входу и профилям](/ru/docs/max/sessions).

## Что попробовать после подключения

Попросите агента разобрать непрочитанное, найти сообщение, вспомнить договорённости или
подготовить ответ. Чтение **не отмечает сообщения прочитанными**. Отправка, удаление и другие
изменения выполняются отдельными командами; доступ агента можно ограничить.

Поиск по словам по умолчанию обращается к локальному архиву и мессенджеру (`--backend both`); для поиска только в архиве используйте `--backend archive`. Язык запроса по умолчанию — строгий Lucene; `--language legacy` возвращает прежнее сопоставление и исправление опечаток. Перед поиском только в архиве, подсчётами или рейтингами подготовьте историю и проверьте охват: пустой результат не доказывает отсутствие сообщения. Для серверного поиска MAX нужен один чат. Подсчёты, рейтинги и запросы, которые сервер не поддерживает, используют сохранённую историю. [Поиск](/ru/docs/max/search).
