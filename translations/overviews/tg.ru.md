`tg` — инструмент, с которым ваш ИИ-агент может читать Telegram, находить сообщения и помогать
отвечать. Он работает с **вашим личным аккаунтом** и его чатами. Можно пользоваться им и самому,
через команды в терминале. Работает на Windows, macOS и Linux.

Вы в разделе документации **Telegram**. Инструкции для MAX доступны через переключатель
мессенджера вверху страницы.

## С чего начать

### Подключить через агента

Если вы пользуетесь Codex, Claude Code, Cursor, Gemini CLI или Hermes, начните с
[установки через агента](/ru/docs/installation#tg). Скопируйте короткий запрос: агент установит
инструмент, поможет войти и проверит подключение. QR-код и подтверждение входа выполняете вы.

Затем откройте [подключение вашего агента](/ru/docs/agents). Для приложений, которым нужен
MCP-сервер, есть [руководство по MCP](/ru/docs/mcp).

### Начать самостоятельно в терминале

Откройте [пошаговую установку](/ru/docs/installation#tg) и выберите инструкции для терминала.
После установки войдите и посмотрите несколько чатов:

```sh
tg session start --app auto
```

```sh
tg chats list --limit 5
```

При первом входе понадобится приложение Telegram с my.telegram.org. Команда поможет его
зарегистрировать, затем предложит QR-код. Подробности и вход по номеру телефона — в
[руководстве по входу](/ru/docs/tg/sessions).

## Что попробовать после подключения

- **Разобрать непрочитанное.** Попросите агента показать, какие чаты ждут вашего ответа.
- **Вспомнить договорённости.** Спросите, что вы обещали за неделю и чего ждёте от других.
- **Найти сообщение.** Попросите найти нужную переписку, дату, ссылку или файл.
- **Помочь с ответом.** Дайте агенту контекст и попросите подготовить или отправить сообщение.

Чтение само по себе **не отмечает сообщения прочитанными**. Отправка, удаление и другие изменения
выполняются отдельными командами. Доступ агента можно ограничить: [доступ и безопасность](/ru/docs/tg/security).
