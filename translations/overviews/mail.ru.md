Вы находите счет с прошлой весны или переписку, где договорились о цене, просто спросив. `mail` хранит копию почтового
ящика на вашем компьютере, поэтому ИИ-агент, которым вы уже пользуетесь, например Claude Code или Codex, ищет по ней
даже без интернета. Работает с Gmail, Outlook, iCloud, Fastmail, Яндекс Почтой и любым другим почтовым сервером с
IMAP.

Агент скажет, на какие письма вы должны ответить, что написано в PDF из вложения, и разложит рассылки этой недели по
папкам. Перемещение и удаление можно отменить, а письмо кому-то кроме вас ждет вашего да.

## Что вы получите

- **Почта, с которой работает агент.** Просите письмо по тому, что в нем было, кто его прислал или что во вложении.
  Агент покажет письмо, которое нашел.
- **Короткий список того, что ждет вас.** В каких переписках новые письма, на какие вы должны ответить, какие ждут
  ответа от других.
- **Меньше рассылок и уведомлений.** Выберите, каких отправителей, рассылки или виды писем пропускать или хранить
  только кратко. До копирования можно посмотреть ящик по отправителям.
- **Порядок в ящике с отменой.** Перемещение, флаги и удаление происходят на почтовом сервере. Удаленное попадает в
  корзину, и перемещение или удаление можно отменить, пока письмо в корзине.
- **Черновики и ответы под вашим контролем.** Агент сохраняет черновик в папку Черновики вашего ящика, и его видно в
  любом почтовом приложении. Письмо кому-то кроме вас сначала спрашивает вас.
- **Почта рядом с чатами.** То же хранилище держит историю Telegram, MAX и WhatsApp, поэтому
  [Memo](/ru/docs/memo/mail) ищет по почте вместе с чатами и заметками.

## Что неочевидно с первого раза

- **Большинству провайдеров нужен пароль приложения.** Это пароль для одной программы, который можно отозвать. Outlook
  и Microsoft 365 вместо него используют вход через браузер. [Подготовка ящика](./providers.md)
- **Первая синхронизация читает последние 30 дней.** Добавьте дату начала, чтобы уйти дальше, или загрузите архив
  Google Takeout.
- **`personal` - имя, которое вы выбираете сами** для одного ящика. Ни одна команда не выбирает ящик за вас.
- **Текст письма написал кто-то другой.** Агент считает его данными, а не указанием.

## Как это выглядит

```text
Вы:     На какие письма за эту неделю я еще не ответил?
Агент:  (запускает mail personal review --unanswered 1d, потом mail personal messages show для каждого)
        · Анна Пример во вторник спросила, можно ли перенести счет на декабрь.
        · Борис Образец в среду прислал договор и просит замечания до пятницы.
Вы:     Набросай ответ Анне: да, декабрь подходит.
Агент:  Сохранил черновик в папке Черновики, в переписке с Анной. Ничего не отправлено.
```

## Почему mail

- **Одно хранилище с чатами.** Ни один почтовый инструмент из [сравнения](./compare.md) (Himalaya, mu, gog, Google
  Workspace MCP, Microsoft 365 MCP) не описывает хранение почты вместе с чатами, встречами и заметками и общий поиск
  по ним.
- **Отмена того, что изменено.** Ни один другой инструмент в сравнении не описывает отмену своих изменений на
  сервере.
- **Агент по MCP пишет только вам**, пока вы не разрешите больше. Удаление или изменение многих писем сначала
  спрашивает.
- **Пароль хранится в связке ключей системы.** `mail` общается только с почтовыми серверами вашего провайдера, по
  зашифрованному соединению.
- **Бесплатно и с открытым кодом.** Лицензия Apache 2.0.

Другой инструмент подойдет лучше, если в вашей организации IMAP выключен (Microsoft 365 MCP) или вы пользуетесь только
Gmail и хотите Календарь и Диск в том же инструменте ([gog](https://github.com/openclaw/gogcli)).

## Как это устроено

- **Копия на вашем компьютере.** `sync` читает почту в локальное хранилище, общее с другими инструментами WireCat.
  Поиск и чтение отвечают из него. Свежесть поддерживает запуск по таймеру. [Повседневная работа](./usage.md)
- **Изменения происходят на сервере.** Перемещение или удаление меняет ваш настоящий ящик, и это видно в любом
  почтовом приложении. Каждое изменение хранит все, что нужно для его отмены.
- **Для скриптов и агентов.** Одна операция на вызов, один JSON-ответ с `--json`, навык для агентов в терминале и
  MCP-сервер.
- **Что хранится и что отправляется.** [Доступ и безопасность](./security.md)

## Начало

Вставьте это в чат с агентом:

```text prompt
Используй mail CLI. Установи его командой npm install -g @wirecat/mail-cli, помоги подготовить мой ящик, войти через mail personal session start, синхронизировать последние 30 дней и показать, на какие письма я должен ответить.
```

Или в терминале. Сначала включите IMAP и создайте пароль приложения ([шаги для каждого провайдера](./providers.md)):

```sh
npm install -g @wirecat/mail-cli
mail personal session start          # спросит адрес, найдет сервер, спросит пароль приложения
mail personal sync                   # последние 30 дней
mail personal search messages счет
mail skill install                   # по желанию: инструкция для агента
```

Нужен Node.js 22.16 или новее в ветке 22, либо 24 и новее. [Установка](./installation.md)

## Ограничения

- `mail` читает почту по IMAP. Для ящика, доступного только через JMAP или Microsoft Graph, нужен другой инструмент.
- Удаленный черновик не вернуть, а Gmail очищает корзину через 30 дней, так что отмена работает только до этого.
