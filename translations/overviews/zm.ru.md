Сохраните отрывки встреч для агента, чтобы восстанавливать решения, проверять обещания и готовиться к звонку с источниками. Инструмент Zoom работает на компьютере как `zm`: читает доступные встречи организатора или импортирует файлы расшифровок.

## Выберите, с чего начать

| Ваша ситуация | Следующий шаг |
|---|---|
| Подключаете Zoom впервые | [Установить с агентом или вручную](./installation.md) |
| Приложение уже создано | [Найти его Public Client ID](./zoom-app.md#use-an-app-you-already-created), затем [завершить вход](./installation.md#first-run) |
| Есть скачанные VTT-файлы | [Импортировать без приложения и входа](./installation.md#import-without-a-zoom-app) |
| Встречи уже сохранены | [Найти фрагмент](./search.md); переустановка не нужна |

## Что можно сделать

- Прочитать доступные встречи, где вы были организатором, сеансы участников, расшифровки и сводки Zoom.
- Импортировать скачанные расшифровки и сохранять исправленные версии с историей.
- Архивировать доступные аудио, видео и расшифровки, проверять файлы и возобновлять поддерживаемые загрузки.
- Искать фрагменты по словам или через настроенный поиск по смыслу и сопоставлять их с заметками и проектами.
- Читать будущие встречи и приглашения; сначала просматривать простые изменения встреч, затем применять их.

Для API нужно настроенное приложение Zoom и выданные ему разрешения. Расшифровки должны быть доступны
вашему аккаунту; встречи, в которых вы участвовали, можно импортировать из скачанных файлов.

## Подключите данные

Начните с [установки и подключения](./installation.md). Там описаны уже созданное приложение, доступное вашему пользователю приложение WireCat/команды и создание своего. Нужны Public Client ID и подтверждение в браузере, а не файл учётных данных. Для файлов [импортируйте VTT](./archive.md#downloaded-transcripts) без приложения Zoom.

Когда первая встреча сохранена, [подключите агента](./mcp.md) через инструкции терминала или MCP для чтения. Подключение само не загружает данные.
