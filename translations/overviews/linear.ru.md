Пусть ИИ-агент читает ваши тикеты, проекты и комментарии в Linear, а вам не нужно вставлять их в чат. Инструмент
командной строки `linear` копирует рабочее пространство на ваш компьютер, и агент отвечает по этой копии, даже без
интернета. Если вы разрешите, тот же инструмент создает и меняет тикеты через API Linear.

Агент ответит, какие тикеты команды еще в работе, что написали в комментариях к ENG-12 и какие тикеты никто не
взял. Агент найдет их в локальной копии и назовет каждый тикет по его ключу. Тикет, который вы берете на себя,
становится [задачей](/ru/docs/tasks) в локальном хранилище, рядом с задачами из ваших чатов.

`linear` это сразу Linear CLI для терминала и MCP-сервер Linear для приложений вроде Claude Desktop,
а для ChatGPT через туннель, который вы запускаете сами. Нужен
персональный API-ключ Linear, его один раз создают в настройках Linear.

## Что вы получите

- **Тикеты без интернета.** Выводите тикеты по команде, проекту, статусу, исполнителю или метке, открывайте тикет с
  комментариями и находите тикеты, проекты и комментарии по словам.
- **Тикет становится вашей задачей.** `issues assign ENG-12` добавляет вам задачу со ссылкой на тикет и сроком, если вы
  его укажете. Текст тикета она не копирует и в Linear ничего не меняет.
- **Все остальное, что есть в Linear.** Создайте тикет, поменяйте его статус, добавьте комментарий, прочитайте циклы и
  документы через группу `api`. `api list` показывает все операции.
- **Вы решаете, что агент может менять.** Каждый профиль разрешает, спрашивает или запрещает каждый вид записи.
  Удалению и архивации нужно отдельное разрешение, `WCLINEAR_READ_ONLY=1` запрещает любую запись, а `--dry-run`
  показывает, что запись отправила бы, и ничего не отправляет. По MCP спросить некого, поэтому запись с уровнем ask
  выполняется. Чтобы это остановить, поставьте `permissions.api` в `readonly`. Подробнее в
  [настройках](./configuration.md#permissions).
- **Агент подключен.** Установите навык инструмента для терминального агента вроде Claude Code или Codex или отдайте
  инструмент по MCP приложению, которое подключается к MCP-серверам.

Ключ хранится в связке ключей системы или в закрытом файле, если связки ключей нет. Вы передаете его скрыто или через
stdin, никогда аргументом, поэтому он не попадает в историю оболочки. Подробнее в [безопасности](./security.md).

## Как это устроено

- **Копия на вашем компьютере.** `linear` хранит тикеты, проекты и комментарии вместе с командами, статусами и
  метками в локальном хранилище. Это один файл на вашем компьютере, общий для всех инструментов WireCat. Списки и поиск читают
  эту копию, а не Linear.
- **Копия ваша.** Linear показывает каждому участнику свой набор команд, поэтому в копии то, что видит ваш ключ, и
  ничего из закрытых команд других людей.
- **Синхронизация приносит изменения.** Первая синхронизация копирует все. Потом она читает только то, что
  изменилось, а раз в день замечает, что удалили в Linear. Архивные тикеты остаются в копии с пометкой.
- **Профиль для каждого аккаунта.** Профиль - имя, которое вы даете одному аккаунту Linear, например `work`. Каждая
  команда для аккаунта начинается с него: `linear work issues show ENG-12`.
- **Весь API в виде команд.** У каждого из 493 запросов и мутаций API Linear своя команда в группе `api`, со своими
  параметрами и справкой. Агент пользуется теми же командами, в терминале или по MCP.

## Создайте персональный API-ключ

В Linear откройте [Settings → Account → Security & access](https://linear.app/settings/account/security) и создайте
персональный API-ключ. Linear дает ключу полный доступ или только часть разрешений, например Read, и может
ограничить его несколькими командами. Чтобы копировать и читать рабочее пространство, хватит ключа только на чтение.
Чтобы создавать и менять тикеты через инструмент, добавьте Write. Если такого пункта нет, администратор пространства
отключил API-ключи для участников. Варианты описаны на [странице Linear об API и вебхуках](https://linear.app/docs/api-and-webhooks).

## Подключите и скопируйте рабочее пространство

1. [Установите `linear`](./installation.md) из npm.
2. Войдите. `work` - профиль, имя, которое вы даете одному аккаунту Linear. Инструмент спросит ключ скрыто и
   проверит его в Linear, прежде чем сохранить.

```sh
linear work session start
```

3. Скопируйте рабочее пространство и посмотрите тикеты, которые в работе.

```sh
linear work sync
linear work issues list type:started
linear work issues show ENG-12
```

Позже запустите `sync` снова, чтобы получить то, что изменилось.

4. Подключите агента. Терминальный агент получает навык:

```sh
linear skill install
```

Приложение, которое подключается к MCP-серверам, получает сервер, как описано в разделе
[как пользоваться](./usage.md#agents).

## Чего пока нет

- Общий поиск WireCat пока не читает тикеты Linear. Ищите их через `issues search`, а не вместе с сообщениями и
  заметками.
- Вход только по персональному API-ключу, без входа через браузер.
- Тикеты создаются и меняются через группу `api`, по одной операции Linear за раз.
