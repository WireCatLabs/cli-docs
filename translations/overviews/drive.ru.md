Предложения, бюджеты и записи встреч лежат в Google Docs, Sheets и PDF на Google Drive. Инструмент командной строки
`drive` копирует текст выбранных папок на ваш компьютер. Агент ищет по ним и берёт из них контекст, даже без
интернета.

Агент с доступом к вашим документам найдёт место, где записано решение, процитирует его и даст название документа и
ссылку на него в Google. Он может показать дерево папок, перечислить файлы, которые не удалось прочитать, и изменить
файл Google, если вы это разрешите.

`drive` хранит копию в локальном хранилище. Это один файл на вашем компьютере, общий для всех инструментов WireCat.
Там же лежат ваши чаты, почта и заметки, поэтому [Memo](/ru/docs/memo) найдёт документ вместе с перепиской о нём. Для
начала нужен аккаунт Google с доступом к папкам.

## Что вы получите

- **Поиск без интернета.** Находите фрагмент по словам, а после индексации и по смыслу. У каждого результата есть
  название и ссылка на оригинал в Google.
- **Только выбранные папки.** Вход ничего не копирует. Вы выбираете папки, и инструмент копирует их вместе с вложенными
  папками.
- **Свой контекст рядом с источником.** Добавляйте к документу или папке теги, заметки и записи памяти. Они остаются на
  вашем компьютере и сохраняются при переименовании и обычных изменениях.
- **Чтение напрямую, когда нужно.** Просматривайте папку или смотрите разрешения, комментарии и версии файла в Google,
  ничего не копируя.
- **Изменения только с вашего разрешения.** По умолчанию доступ только на чтение. Чтобы создавать и править Docs,
  заполнять Sheets, копировать или перемещать файлы, нужно отдельное право на запись.
- **Агент подключён.** Установите навык инструмента для агента в терминале, например Claude Code, или подключите
  инструмент по MCP к приложению, которое работает с MCP-серверами.

## Два слова, которые стоит знать

**Профиль** — имя одного подключённого аккаунта Google, например `personal` или `work`. Каждая команда для аккаунта
указывает его.

**Локальная копия** — текст, сведения о файлах и ваши заметки на компьютере, где работает `drive`. Она отделена от
файлов в Google. Поиск читает локальную копию. Синхронизация приносит новые правки.

## Подключите и скопируйте папку

1. [Установите `drive`](./installation.md) из npm.
2. Войдите. В примерах профиль называется `personal`, выберите своё имя. Откроется браузер, и вы разрешите чтение
   своего Google Drive.

```sh
drive personal session start
```

Google может отказать во входе через приложение WireCat или остановить его предупреждением. Тогда
[используйте своё приложение Google](./installation.md#google-shows-an-unverified-app-warning): это займёт несколько
минут и ничего не стоит.

3. Выберите папку. Откройте её в Google Drive и скопируйте адрес из браузера. Адрес ниже — пример, подставьте свой.

```sh
drive personal folders add https://drive.google.com/drive/folders/1a2B3c4D5e6F7g8H9i0JkLmNoPqRsTuVw
```

4. Скопируйте папку и ищите по ней.

```sh
drive personal sync
drive personal search 'budget' --exact
```

Одна синхронизация читает до 10 000 записей. `drive personal status` показывает, сколько работы осталось: запускайте
синхронизацию снова, пока ничего не останется, а потом, чтобы получить новые изменения.

5. Подключите агента. Агент в терминале получает навык:

```sh
drive skill install
```

Приложение на вашем компьютере, которое работает с MCP-серверами, запускает `drive personal mcp serve`; как его
добавить, показано в [командах](./commands.md). ChatGPT, Codex или Claude в браузере подключаются, как описано в
разделе [приложения в браузере](./remote.md).

Или попросите агента, когда `drive` установлен и вход выполнен:

```text prompt
С помощью drive CLI и профиля personal импортируй выбранную мной папку Google вместе с вложенными папками.
Найди решение по бюджету, покажи точный фрагмент и ссылку на оригинал в Google и перечисли пропущенные файлы.
Не меняй файлы Google.
```

## Что хранится в копии

| Что сохраняется | Что можно сделать без Google |
| --- | --- |
| Текст из Docs (все вкладки, таблицы и сноски), Sheets и поддерживаемых файлов | Искать фрагменты, читать источник и готовить ответ с доказательствами |
| ID в Google, название, тип, ссылка на оригинал, родительские папки и даты | Узнать источник и посмотреть его сведения на момент последней синхронизации |
| Владельцы и последний редактор, которых показывает Google | Увидеть, кто работал над документом |
| Папки и их дерево | Просматривать дерево папок, список папки, ставить папке теги и добавлять к ней заметки |
| Ваши теги, заметки, связи с людьми и проектами, записи памяти | Сохранять контекст между задачами |

Файлы, содержимое которых не читается, остаются в копии с именем и типом. `catalog search` находит их по имени, типу и
владельцу. Разрешения, история версий, комментарии и действия читаются из Google напрямую и не сохраняются.

## Что он читает

Инструмент индексирует Google Docs и Sheets, а также загруженные Markdown и простой текст, PDF с текстовым слоем,
Word `.docx`, Excel `.xlsx`, CSV и TSV. У сканов PDF, Slides, аудио и ярлыков нет текста для индекса. Изображения
находятся по имени или, если включить [поиск по картинкам](./search.md#search-images-by-what-they-show), по тому, что на
них изображено. В Docs не индексируются изображения, колонтитулы, комментарии и предложенные правки.
