title: "Настройки"

Настройте `hubspot` под себя для каждого аккаунта HubSpot: что может делать ваш ИИ-агент, копируются ли заметки,
звонки и задачи по вашим сделкам и что запуск сохраняет на потом.

Настройки лежат в одном файле, `config.json`, в папке, которую показывает `hubspot doctor`. У каждого профиля своя
часть, а `defaults` действуют на все профили. `hubspot work config show` показывает каждую настройку и откуда она
взялась: из файла, из переменной или по умолчанию.

## Посмотреть и поменять настройку

```sh
hubspot work config show
hubspot work config set limit 50
hubspot work config unset limit
```

## Разрешения

`permissions` решает, что команда может делать для этого профиля: `allow`, `ask`, `readonly` или `deny`, для каждого
ключа разрешения. Страница [Разрешения](./permissions.md) перечисляет каждый ключ, его встроенный уровень и что
действует через MCP.

```sh
hubspot work config set permissions.api readonly
```

## Активности

`crm.hubspot:12345678.activities` по умолчанию выключена. Подставьте id своего аккаунта вместо примера `12345678`:
`hubspot work session status` показывает его как `account`. Когда настройка включена, следующий `sync` копирует
заметки, звонки, письма, встречи и задачи по сделкам и их контактам и компаниям.
Команду показывает раздел [Активности и что изменилось](./usage.md#activities-and-what-changed). Задать ее можете
только вы, в терминале.

## Записи запусков

Команда, которая упала, сохраняется как запуск для `hubspot runs list` и `runs show`. Команда, которая обращается к
HubSpot, например `session status --check`, сохраняется и при успехе, если только `record` не равен `false` (тогда
только сбои) или она не запускалась с `--no-record`.
`record_input` решает, сохраняет ли запуск слова, которые вы набрали. Он равен `true`, пока вы не поставите `false`.
Секреты скрываются в любом случае, как показывает [безопасность](./security.md).
