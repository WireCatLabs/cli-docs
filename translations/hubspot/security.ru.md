## Ключ

`session start` читает сервисный ключ или токен приватного приложения скрытно или из stdin, но никогда не как
аргумент. Он спрашивает HubSpot, какому аккаунту принадлежит ключ (`GET /account-info/2026-03/details`), и только
потом хранит ключ вместе с id аккаунта в связке ключей ОС или, где связка ключей не работает, в файле, который можете
читать только вы. Ключ попадает только в заголовок `Authorization` запроса к `api.hubapi.com`, но никогда в адрес,
ответ, запись запуска или журнал отправок. `hubspot` никогда не отправляет его на адрес HubSpot для сведений о
токене, который принимает токен в адресе.

Ключ читает и меняет то, что разрешают его scope, во всем аккаунте: давайте ему scope на запись, только если вам
нужна запись. `hubspot` не может отозвать ключ.
`session end` и `account remove` забывают его на этом компьютере, а после утечки ключ удаляют или заменяют в HubSpot.

## Копия

`sync` хранит сделки, контакты и компании аккаунта, а когда вы их включите, и активности, в локальном хранилище
WireCat на вашем компьютере. [Условия HubSpot для разработчиков](https://legal.hubspot.com/developer-terms) просят
не хранить данные дольше, чем нужно:
`hubspot work account remove --delete-data` удаляет копию аккаунта и забывает ключ.

## Текст из аккаунта

Имена, значения свойств, заметки, адреса почты, номера телефонов и ссылки в ответе написаны другими людьми. Через MCP
они приходят к агенту с пометкой «недоверенные», и агент читает их как данные, а не как инструкции.

## MCP через HTTP

`hubspot work mcp serve --http` слушает только `127.0.0.1`, для браузерных приложений, которые доходят до него через
ваш собственный туннель. Каждое приложение входит по одноразовому коду, а сервер хранит хеш каждого выданного входа в
папке состояния, доступной для чтения только вам. `hubspot work mcp revoke` забывает их все.

## Записи запусков и файлы

Запись запуска хранит командную строку так, как вы ее набрали, а каждый секрет в ней заменен на `[redacted]`. Чтобы
не хранить ни одного набранного слова, выполните `hubspot work config set record_input false`.

`config.json` сохраняется с доступом только для вас (`0600`), а его папка создается только для вас (`0700`). `hubspot
doctor` показывает файл или папку, открытые другим пользователям, в `files.problems` и печатает `chmod`, который это
исправляет.
Об уязвимости сообщайте так, как написано в [SECURITY.md](https://github.com/WireCatLabs/hubspot-cli/blob/main/SECURITY.md).
