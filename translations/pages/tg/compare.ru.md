Несколько открытых инструментов подключают личный аккаунт Telegram к терминалу или ИИ-агенту. Эта страница ставит
`tg` рядом с пятью из них, строка за строкой, по задачам, которые решают люди: быть в курсе, отвечать, находить,
наводить порядок, вести группу и доверять аккаунт агенту. С её помощью выберите инструмент, который подходит для
вашей работы.

Каждая оценка проверена 24 октября 2026 года. Наши оценки взяты из ветки `main` инструмента `tg` и из его запуска.
Оценка другого инструмента взята из его собственной
документации или исходного кода, ссылки [под таблицей](#where-the-marks-come-from). Инструмент может делать больше,
чем говорит его документация.

✅ да · 🟡 частично · ❌ нет · ➖ нет в документации

Инструменты:

- **tg**: этот инструмент. Командная строка и MCP-сервер для вашего аккаунта, с локальной копией ваших чатов, в
  которой можно искать.
- **[tgcli](https://github.com/dapi/tgcli)**: командная строка с фоновой синхронизацией, локальным архивом и
  MCP-сервером (активно развиваемое ответвление [kfastov/tgcli](https://github.com/kfastov/tgcli)).
- **[tlgr](https://github.com/tlgrcli/tlgr)**: командная строка и фоновая служба, с навыком для агента.
- **[telegram-mcp](https://github.com/chigwell/telegram-mcp)**: MCP-сервер на Python для Claude Desktop, Cursor и
  других MCP-клиентов.
- **[mcp-telegram](https://github.com/mcp-telegram/mcp-telegram)**: MCP-сервер, который запускается через `npx`.
- **[tdl](https://github.com/iyear/tdl)**: быстрая программа для скачивания и загрузки файлов и медиа.

Что агент может делать, не спрашивая, как останавливается ошибочная отправка и что вы можете увидеть потом.

Пояснения к этим строкам:

- **Читать, но не отправлять.** tg позволяет сделать профиль доступным только на чтение для терминала и для MCP.
  telegram-mcp может открыть только свои инструменты чтения. tlgr может разрешить только те команды, которые вы
  перечислите.
- **Подтверждение отправки.** Задайте `messages.send: ask`, чтобы запрашивать подтверждение в терминале. Через MCP
  подтверждением управляет клиент, и он может разрешить вызов без повторного вопроса. Чтобы запретить запись,
  используйте разрешения deny или read-only. `reply` и `review` показывают черновики на проверку. tg требует явно
  выбирать аккаунт. tgcli поддерживает профили с профилем по умолчанию, а tlgr может требовать выбранный аккаунт через
  свою настройку strict-account.
- **Ограничения.** У tg есть список чатов, в которые он может отправлять, и по умолчанию 30 отправок в час.
  telegram-mcp ограничивает чаты, mcp-telegram ограничивает частоту запросов, у tdl есть пауза между запросами, tlgr
  ограничивает команды.
- **Повтор с тем же ID.** Для повтора отправки без расписания используйте тот же ID операции. Если исход неизвестен,
  проверьте журнал отправок и Telegram. Отложенные отправки нужно проверять, а не повторять вслепую. tlgr описывает
  отдельный код выхода для неизвестного исхода.
- **Ослабить собственные ограничения.** Через MCP tg показывает команды, которые меняют то, что сможет сделать
  следующий запуск (настройки, списки получателей, расписания), помечает их недоступными и называет разрешение,
  которое нужно задать из терминала.

## Настройка

| | tg | tgcli | tlgr | telegram-mcp | mcp-telegram | tdl |
|---|---|---|---|---|---|---|
| Установка | npm, pnpm, Bun | npm | pipx | git и uv, Docker, расширение Claude Desktop | npx, готовые файлы программы | один файл программы, Homebrew, Scoop, AUR, Nix, Docker |
| Лицензия и цена | Apache-2.0, бесплатно | MIT, бесплатно | MIT, бесплатно | Apache-2.0, бесплатно | MIT, бесплатно | AGPL-3.0, бесплатно |
| MCP | stdio, а также HTTP с собственным входом для приложений в браузере и на телефоне | HTTP | нет | stdio | stdio | нет |

**Сравнение с агентом в браузере.** Агент, который работает в веб-версии Telegram, нажимает кнопки на странице,
сделанной для людей. `tg` и другие инструменты здесь вызывают собственный интерфейс Telegram. Поэтому агент получает
тот же ответ, что и скрипт, в постоянном формате, а команда либо выполняется, либо объясняет, почему нет. Эта
страница не утверждает, что какой-то из способов быстрее: опубликованных измерений нет.

## Когда лучше подходит другой инструмент

- **tdl**: вы в основном перемещаете файлы. Массовое скачивание, загрузка и пересылка на полной скорости из одного
  файла программы, который ставится через большинство менеджеров пакетов.
- **tlgr**: вам нужно параллельное скачивание с продолжением после остановки из командной строки, а локальная копия
  для поиска не нужна.
- **telegram-mcp**: вам нужен самый широкий набор действий агента в Claude Desktop, установка в один шаг и большое
  сообщество.
- **mcp-telegram**: вам нужен большой набор инструментов MCP, который запускается одной командой `npx`, без Python.
- **tgcli**: вам нужен MCP-сервер внутри службы синхронизации или заметки о чатах.
