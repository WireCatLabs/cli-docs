На этой странице вы подключите аккаунт MAX к ИИ-агенту на своём компьютере. После этого агента можно просить читать чаты, искать сообщения и готовить ответы. Понадобится около пяти минут и телефон, на котором вы уже вошли в MAX.

## Шаги

1. [Установите max](#install). max — небольшая программа, которая даёт агенту доступ к вашему аккаунту MAX. Агент может установить её сам, или вы сделаете это вручную.
2. [Войдите в MAX](#log-in). Вы сканируете QR-код телефоном. Так компьютер становится новым устройством вашего аккаунта.
3. [Подключите агента](#connect-agent). Агент получает инструкции, чтобы пользоваться max.
4. [Проверьте, что всё работает](#check). Агент показывает ваш аккаунт и несколько чатов.

Если какой-то шаг не получается, загляните в [вопросы и ответы](#questions).

## 1. Установите max

Установить можно двумя способами. Результат одинаковый.

### С помощью агента

Подойдёт агент, который умеет запускать программы на этом компьютере, например Claude Code, Codex, Cursor или Gemini CLI. Если вы пользуетесь только чатом с агентом в браузере или на телефоне, откройте [подключение из веба или с телефона](/ru/docs/browser-apps).

Скопируйте этот запрос в чат с агентом. Он поможет установить инструмент и войти в аккаунт на вашем компьютере.

```text prompt
Помоги подключить мой аккаунт MAX к моему ИИ-агенту на этом компьютере.
Следуй https://wirecat.dev/ru/docs/max/installation: проверь нужные программы и помоги с установкой.
Покажи мне шаги входа, чтобы я сам подтвердил доступ к аккаунту.
Подключи инструкции инструмента к моему агенту. В конце покажи мой аккаунт и несколько чатов. Ничего не отправляй.
```

Агент проведёт вас по шагам:

1. **Проверит компьютер.** Для max нужен Node.js 22.16 или новее. Если его нет, агент объяснит, как его установить.
2. **Установит max.** Ваш аккаунт на этом шаге не затрагивается.
3. **Запустит вход.** Агент запускает `max personal setup` в окне терминала, и там появляется QR-код. Вы сканируете его телефоном, как описано в разделе [Войдите в MAX](#log-in). Если агент не может показать вам это окно, он попросит вас запустить `max personal setup` самостоятельно.
4. **Подключит себя к max.** Агент устанавливает себе инструкции max.
5. **Покажет результат.** Вы увидите имя аккаунта и несколько чатов. Агент ничего не отправляет.

Вход вы подтверждаете сами, на телефоне. Не вставляйте коды и пароли в чат с агентом.

### Вручную в терминале

Откройте «Терминал» в macOS или Linux либо PowerShell в Windows.

1. **Установите Node.js 22.16 или новее** (22.x или 24+) либо Bun 1.3+. См. [Node.js, npm и поиск команды](/ru/docs/installation#nodejs).
2. **Установите max:**

   ```sh
   npm install -g @wirecat/max-cli
   ```

   В Windows можно установить одной командой. Она ставит max, добавляет его в `PATH` (папки, в которых терминал ищет команды) и подключает все поддерживаемые агенты:

   ```powershell
   & ([scriptblock]::Create((Invoke-RestMethod 'https://wirecat.dev/install.ps1'))) -Tool max -Agent all
   ```

3. **Проверьте установку:**

   ```sh
   max --version
   ```

   Появится номер версии. Если терминал пишет, что команда не найдена, см. [max не находится после установки](#q-not-found).

4. **Запустите вход:**

   ```sh
   max personal setup
   ```

   Дальше — следующий шаг.

## 2. Войдите в MAX

Вход добавляет компьютер как новое устройство вашего аккаунта MAX — как приложение MAX для компьютера. Это устройство видно в MAX на телефоне, и его можно удалить в любой момент. Вход не скачивает историю чатов.

Вход показывает `max personal setup`. Его запускает агент или вы сами.

`personal` — имя этого входа на компьютере, оно называется профилем. Подойдёт любое имя. Следующие команды начинаются с того же имени, например `max personal doctor`.

1. Дождитесь, пока на компьютере появится QR-код для входа. Он появляется в терминале. Если окно слишком узкое, setup откроет код в браузере.
2. На телефоне откройте MAX, перейдите в «Настройки» → «Устройства» и выберите сканирование QR-кода. Разрешите доступ к камере, если MAX попросит.
3. Наведите сканер на код на компьютере. Нужен код входа из setup, а не QR-код вашего профиля для обмена контактами. Подтвердите вход в MAX, если он попросит.
4. Если setup попросит дополнительный пароль аккаунта, введите пароль, который вы задали в MAX. Терминал не показывает вводимые символы. Наберите пароль и нажмите Enter.
5. Дождитесь, пока setup подтвердит вход и проверит аккаунт и до пяти чатов.

<a id="connect-agent" />

## 3. Подключите агента

Чтобы пользоваться max, агенту нужны инструкции. Они называются навыком. Setup спрашивает, какой агент вы используете, и устанавливает навык для него. Глобальная установка через npm уже ставит навык для всех поддерживаемых агентов.

Чтобы установить навык заново или для другого агента:

```sh
max skill install --for all
```

После этого откройте новую сессию агента, чтобы он загрузил инструкции. Другие агенты и MCP-приложения описаны в разделе [Подключение агента](/ru/docs/agents).

<a id="check" />

## 4. Проверьте, что всё работает

Попросите агента:

```text prompt
Use max CLI. Покажи мой аккаунт MAX и пять последних чатов. Ничего не отправляй.
```

Проверьте, что имя и чаты относятся к аккаунту, который вы хотели подключить. Если да, max готов к работе.

Setup не скачивает всю историю чатов. Чтобы искать старые сообщения, попросите агента [скачать нужную историю](/ru/docs/max/archive).

Вручную: `max personal doctor` показывает, выполнен ли вход и где max хранит файлы. К MAX он не подключается.

## Вопросы и ответы

<a id="q-qr" />

### QR-код не сканируется

**С агентом:** попросите агента войти через браузер. Откроется отдельное окно браузера с web.max.ru. Отсканируйте его QR-код или выберите вход по номеру телефона и пройдите шаги на странице, включая капчу, если она появится.

**Вручную:** выполните одну из команд:

```sh
max personal setup --method qr-chrome   # web.max.ru в отдельном окне браузера
max personal setup --method sms         # то же окно, вход по номеру телефона
```

Для входа через браузер нужен Chrome, Chromium, Edge или Brave. Браузеры, установленные через snap, не подходят. Окно использует временный профиль, а не ваш, и закрывается после входа.

### QR-код истёк или setup прервался

**С агентом:** попросите запустить setup ещё раз и отсканируйте новый код.

**Вручную:** снова выполните `max personal setup`. Если вход уже выполнен, setup использует его и не спрашивает заново.

<a id="q-not-found" />

### max не находится после установки

**С агентом:** перезапустите агента или попросите его открыть новый терминал. Терминал, открытый во время установки, не видит новую команду. В Windows агенту в уже открытом терминале нужно обновить окружение и прочитать `max skill show` перед входом.

**Вручную:** откройте новый терминал и снова выполните `max --version`. Если не помогло, эта команда объяснит причину и подскажет, что выполнить:

```sh
npx @wirecat/max-cli doctor
```

В Windows npm иногда пропускает шаг, который добавляет max в `PATH`. Выполните это исправление в PowerShell. Другие записи `PATH` сохраняются:

```powershell
$maxNpmPrefix = (npm.cmd prefix -g).Trim()
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$maxNpmPrefix\node_modules\@wirecat\max-cli\install\windows.ps1" -RepairOnly -Prefix $maxNpmPrefix
$env:Path = "$maxNpmPrefix;$env:Path"
max skill install --for all
max --version
```

### После обновления max пишет, что профиль не назван

max никогда не выбирает аккаунт сам: каждая команда, которой нужен аккаунт, начинается с имени профиля.

**С агентом:** назовите агенту имя профиля. Если вы раньше настраивали max без имени профиля, он называется `default`.

**Вручную:** пишите имя первым словом (`max default chats list`) или задайте его один раз: `export MAX_PROFILE=default` в профиле оболочки. Если вы подключали max к MCP-приложению через `max mcp config`, выполните эту команду ещё раз.

### После обновления max останавливается и называет два файла архива

Обновление один раз переносит архив сообщений в папку WireCat. Если в старом и новом месте лежат разные копии, max останавливается с кодом 3 и называет оба файла. Оставьте нужный, уберите другой и запустите команду снова. Ничего не перенесено и не изменено.

### Куда вводить коды и пароли?

В терминал настройки или на странице web.max.ru, но никогда не в чат с агентом. Если не видите окно терминала, попросите агента его показать.

### Агент не может пользоваться max после настройки

**С агентом:** откройте новую сессию агента, чтобы он загрузил инструкции max. Если не помогло, откройте [Подключение агента](/ru/docs/agents).

**Вручную:** выполните `max skill install --for claude` для Claude Code, `--for agents` для Codex, Gemini CLI и других агентов, которые читают `~/.agents`, или `--for all`.

### Нет чата или старых сообщений

Setup проверяет только несколько чатов. Попросите агента скачать нужный чат и период: см. [Локальный архив](/ru/docs/max/archive). Пустой результат поиска не значит, что таких сообщений в чате нет.

### Можно попробовать max без установки?

Да: `npx @wirecat/max-cli --help`. Так max запускается один раз. Команда `max` не появляется, и агент не подключается.

### Где хранится вход?

В хранилище паролей операционной системы (ключнице), а не в файле. Если ключницы на компьютере нет, max сохраняет вход в файл рядом с настройками и сообщает об этом. См. [Безопасность](/ru/docs/security).

## Где хранятся файлы

| Что | Linux и macOS | Windows |
| --- | --- | --- |
| Настройки | `~/.config/max-cli/` | `%APPDATA%\max-cli\Config\` |
| Состояние: профили, боты, записи запусков | `~/.local/share/max-cli/` | `%LOCALAPPDATA%\max-cli\Data\` |
| Кэш | `~/.cache/max-cli/` | `%LOCALAPPDATA%\max-cli\Cache\` |
| Локальный архив сообщений, общий с tg | `~/.local/share/WireCat/wirecat.db` | `%LOCALAPPDATA%\WireCat\Data\wirecat.db` |
| Модели распознавания речи | `~/.local/share/WireCat/models/audio/` | `%LOCALAPPDATA%\WireCat\Data\models\audio\` |

`max personal doctor` показывает точные пути на вашем компьютере. `WIRECAT_STATE_DIR` переносит всю папку WireCat; он заменяет `CLI_COMMON_CACHE_DIR`. Как изменить эти папки и другие настройки, описано в разделах [Настройки](/ru/docs/configuration) и [справочник настроек max](/ru/docs/max/configuration).

Первый запуск после обновления со старого max один раз переносит сюда архив и модели из `~/.local/share/cli-messaging/` и `~/.cache/cli-common/models/`. Если в обоих местах лежат разные копии, max останавливается и называет оба файла: оставьте один и запустите снова.

## Обновление

```sh
max upgrade           # тем же менеджером пакетов, которым max установлен: npm, pnpm или bun
max upgrade --check   # только сообщает, есть ли новая версия
```

Если вы обновляетесь с версии, которая хранила сообщения в `messages.db`, сначала скопируйте заметки и метки, которые есть только на компьютере: старый файл удаляется, когда открывается новый архив. `max personal messages sync --all` скачает сообщения заново, но не локальные заметки и метки.

Обновляйте tg и memo вместе с max: у них общий архив сообщений, и старый инструмент создаст новый архив на прежнем месте.

max не обновляется сам. Раз в день он проверяет, есть ли новая версия, и пишет об этом одну строку в терминале. Вход после обновления сохраняется.

## Удаление

Удаление max убирает команду, но не ваши данные. Сначала выйдите из аккаунта, чтобы вход удалился и из ключницы:

```sh
max personal server uninstall          # только если ставили фоновую службу
max personal session end               # выйти и забыть вход
npm uninstall -g @wirecat/max-cli
rm -rf ~/.config/max-cli ~/.local/share/max-cli ~/.cache/max-cli
```

Если вы подключали ботов, выполните также `max <profile> bot auth remove` для каждого профиля бота. Удаляйте `~/.local/share/WireCat/` только если сохранённые сообщения больше не нужны другим инструментам, например tg.

## Из исходников

Устанавливайте из исходников, если меняете код или нужна ещё не выпущенная версия.

```sh
git clone git@github.com:WireCatLabs/max-cli.git
cd max-cli
pnpm install
pnpm build
pnpm link --global      # команда max становится доступной
```

Запуск без привязки: `node dist/bin/max.js --help`. Обновление: `git pull && pnpm install && pnpm build`.
