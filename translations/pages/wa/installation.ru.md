Подключите свой WhatsApp к ИИ-агенту на компьютере. После настройки агент сможет читать сохранённые чаты, искать сообщения и готовить ответы. Держите рядом телефон с открытым WhatsApp и отведите около пяти минут на получение недавней истории.

## Шаги

1. [Установить wa](#install): инструмент командной строки и движок WhatsApp.
2. [Привязать аккаунт](#log-in): отсканировать QR-код в WhatsApp на телефоне.
3. [Подключить агента](#connect-agent): установить инструкции для него — навык.
4. [Проверить результат](#check): увидеть выбранный аккаунт и несколько сохранённых чатов.

Это неофициальный клиент. Перед привязкой прочтите [безопасность](./security.md) и [ограничения](./limits.md): WhatsApp может ограничить или заблокировать аккаунт, использующий неофициальный клиент.

## 1. Установить wa

### С помощью агента

Используйте агента с доступом к терминалу на этом компьютере, например Codex, Claude Code, Cursor или Gemini CLI. Для чата только в браузере откройте [доступ из браузера или с телефона](/ru/docs/browser-apps).

```text prompt
Используй wa CLI. Помоги подключить мой WhatsApp к ИИ-агенту по https://wirecat.dev/ru/docs/wa/installation. Проверь необходимые программы и установи инструмент. Спроси, какой аккаунт и имя профиля я хочу; personal — пример. Я сам подтвержу привязку устройства на телефоне. Установи навык и покажи мой аккаунт и несколько чатов. Ничего не отправляй и не запускай работу в фоне без вопроса.
```

### Вручную в терминале

Откройте «Терминал» в macOS или Linux либо PowerShell в Windows. Нужен Node.js 22.16 или новее в ветке 22.x либо 24 или новее, вместе с npm; см. [подготовку компьютера](/ru/docs/installation#nodejs).

```sh
npm install -g @wirecat/whatsapp-cli
wa --version
wa doctor
```

Оставьте необязательные пакеты включёнными: npm устанавливает движок WhatsApp для вашей системы и процессора. Менеджер пакетов может сообщить о заблокированных сценариях установки; проверьте результат командами ниже. Если движка нет, откройте [устранение неполадок](./troubleshooting.md#whatsapp-engine-is-not-installed). В Windows откройте новый терминал, если команда не найдена.

## 2. Привязать аккаунт WhatsApp

В примерах personal — имя профиля: одного привязанного аккаунта на этом компьютере. Выберите любое имя и повторяйте его в следующих командах. Инструмент не выбирает аккаунт за вас.

```sh
wa personal setup
```

1. Запустите настройку в терминале. Она проверит папки и начнёт привязку устройства; уже привязанный профиль используется повторно.
2. На телефоне откройте WhatsApp → Настройки → Связанные устройства → Привязать устройство. Отсканируйте QR-код из настройки сканером внутри WhatsApp.
3. Оставьте WhatsApp открытым, пока приходит недавняя история. Настройка проверит аккаунт и до пяти сохранённых чатов, затем предложит установить навык агента.

Так добавляется связанное устройство, как в WhatsApp Web. Его можно в любой момент отключить в разделе связанных устройств на телефоне. Для кода сопряжения вместо QR используйте `wa personal setup --method phone`; номер вводится в терминале. Подтверждайте доступ сами. Старая история приходит по [отдельному запросу к телефону](./archive.md#older-history-from-your-phone).

<a id="connect-agent" />

## 3. Подключить агента

Навык — короткий файл инструкций, который объясняет терминальному агенту, как использовать wa. Настройка может установить его для выбранного агента. Отдельная установка:

```sh
wa skill install --for all
```

Приложение без терминала может использовать [MCP](./mcp.md). Сначала выберите [разрешения](./permissions.md) профиля: MCP предоставляет как команды чтения, так и команды изменения данных.

<a id="check" />

## 4. Проверить результат

```sh
wa personal account show
wa personal chats list --limit 5
```

Аккаунт должен совпадать с выбранным на телефоне. Список чатов берётся из сохранённой истории и не отправляет уведомлений о прочтении. Пустая или неполная история не доказывает отсутствие сообщений; см. [полноту истории](./archive.md).

Чтобы получать новые сообщения, запустите `wa personal serve` в терминале; Ctrl-C остановит его. Связанное устройство допускает только одно соединение. Перед другой командой с подключением прочтите [правило соединения](./sessions.md#one-connection-per-device).

<a id="questions" />

## Вопросы и ответы

### QR-код не виден

Попросите агента показать терминал или вставить текстовый QR-код в чат. Используйте сканер WhatsApp. Если терминал слишком узкий, расширьте его и дождитесь следующего QR-кода. Другие проблемы привязки — в [устранении неполадок](./troubleshooting.md).

## Из исходного кода

Вместо этого, чтобы запустить `wa` из локальной копии репозитория:

```sh
git clone https://github.com/WireCatLabs/whatsapp-cli.git
cd whatsapp-cli
pnpm install
pnpm build
pnpm engine:build   # needs Go
node dist/bin/wa.js --version
```

<a id="shell-completion" />

## Завершение оболочки

Вкладка завершает команды, параметры и их значения. Там, где ожидается чат, он предлагает чаты из локального хранилища. Добавьте одну строку в файл запуска вашей оболочки:

```sh
echo 'source <(wa complete zsh)' >> ~/.zshrc      # zsh
echo 'source <(wa complete bash)' >> ~/.bashrc    # bash
wa complete fish | source                         # fish, in config.fish
```

PowerShell: `wa complete powershell | Out-String | Invoke-Expression` в вашем профиле.

Tab никогда не подключается к WhatsApp. Пока нет локального хранилища, выполняются только команды и параметры.


<a id="upgrade" />

## Обновление

```sh
wa upgrade            # with the package manager that installed wa
wa upgrade --check    # only say whether a newer version exists; installs nothing
```

`upgrade` запрашивает npm, поэтому `--offline` отклоняется с кодом выхода `2`. `upgrade --check` работает под управлением `WA_READ_ONLY`; `upgrade` без него не обходится.

После обновления `wa upgrade` перезапускает каждый работающий фоновый `serve`, поэтому старый код не продолжает выполняться. Движок поставляется в виде пакета `wa`, поэтому он обновляется вместе с ним. Раз в день `wa` сообщает в stderr, когда существует более новая версия; `WA_NO_UPDATE_CHECK=1` или `update_check: false` в настройках отключает это.

Из исходного кода: `git pull && pnpm install && pnpm build && pnpm engine:build`.


<a id="uninstall" />

## Удалить

Удаление команды оставляет ваши данные. Сначала отсоедините, пока `wa` еще здесь:

```sh
wa personal server uninstall         # if you installed the background unit; stop it first
wa personal session end              # unlinks the device on WhatsApp's side and deletes its keys here
npm uninstall -g @wirecat/whatsapp-cli
rm -rf ~/.config/whatsapp-cli ~/.local/share/whatsapp-cli ~/.cache/whatsapp-cli
```

Повторите `session end` для каждого профиля. Локальная база данных используется совместно с другими инструментами WireCat. Удалите `~/.local/share/WireCat/`, только если его больше никто не использует: он содержит сообщения, которые сохранил каждый из них.
