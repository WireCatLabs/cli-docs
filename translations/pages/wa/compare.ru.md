Несколько открытых инструментов подключают личный аккаунт WhatsApp к терминалу или ИИ-агенту, а у Meta есть
официальный API для бизнес-номеров. Эта страница ставит `wa` рядом с пятью из них и сравнивает по задачам, которые
решают люди: разобрать накопившееся, ответить, отправить файлы, найти нужное, вести группы и передать аккаунт агенту.
По ней можно выбрать инструмент, который подходит для вашей работы.

Каждая отметка проверена 24 октября 2026 года. Наши отметки взяты из ветки `main` в `wa` и из запуска его сборки.
Некоторые команды не проверялись на реальном аккаунте, а в разделе [использование wa](./usage.md#not-in-wa-yet)
перечислено, чего `wa` не умеет. Отметка для другого инструмента взята из его собственной документации или исходного
кода, ссылки [под таблицей](#where-the-marks-come-from). Инструмент может уметь больше, чем говорит его документация.

✅ да · 🟡 частично · ❌ нет · ➖ нет в документации · n/a неприменимо

Инструменты:

- **wa**: этот инструмент. Командная строка и MCP-сервер для вашего собственного аккаунта WhatsApp, с локальной копией
  ваших чатов, по которой можно искать.
- **[wacli](https://github.com/openclaw/wacli)**: командная строка с локальной копией ваших чатов, поиском и
  синхронизацией в фоне. MCP-сервера у неё нет.
- **[whatsapp-mcp](https://github.com/verygoodplugins/whatsapp-mcp)**: MCP-сервер для WhatsApp с локальной копией
  ваших чатов, его поддерживает Very Good Plugins. Это форк
  [lharries/whatsapp-mcp](https://github.com/lharries/whatsapp-mcp). Последнее изменение было 20 октября 2026 года.
- **[mudslide](https://github.com/robvanderleek/mudslide)**: командная строка, которая отправляет сообщения из
  скриптов. В её README сказано, что она только для отправки.
- **[WhatsApp Channel](https://github.com/Rich627/whatsapp-claude-plugin)**: плагин для Claude Code, с которым агент
  отвечает в чатах от вашего аккаунта. Он также работает как обычный MCP-сервер.
- **[WhatsApp Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api/overview)**: официальный API Meta.
  Он работает с бизнес-номерами телефонов, а не с личным аккаунтом.

## Установка, лицензия и цена

| | Установка | Лицензия | Цена |
|---|---|---|---|
| wa | `npm install -g @wirecat/whatsapp-cli` | Apache-2.0 (CLI), GPL-3.0-only (движок) | бесплатно |
| wacli | `brew install openclaw/tap/wacli` или архив выпуска | MIT | бесплатно |
| whatsapp-mcp | клонировать, затем запустить мост на Go и сервер на Python | MIT | бесплатно |
| mudslide | `npm install -g mudslide` или `npx mudslide` | ISC | бесплатно |
| WhatsApp Channel | `claude plugin install` | Apache-2.0 | бесплатно |
| Cloud API | аккаунт разработчика Meta и бизнес-номер | официальные условия | Meta берёт плату за каждое сообщение, см. её [страницу с ценами](https://developers.facebook.com/documentation/business-messaging/whatsapp/pricing) |

Все инструменты, кроме Cloud API, привязываются к вашему аккаунту так же, как WhatsApp Web. Условия WhatsApp
запрещают неофициальные клиенты и позволяют заблокировать аккаунт, который ими пользуется. Прочитайте
[ограничения](./limits.md), прежде чем разрешить агенту отправку.

## Когда другой инструмент подходит лучше

- **Бизнес, который отвечает клиентам**: Cloud API. Он официальный, работает с бизнес-номером, и номер не рискует
  блокировкой. `wa` работает с вашим личным аккаунтом.
- **Сохранить контакт в адресную книгу телефона**: wacli. В нём есть `contacts save`. WhatsApp хранит изменения
  адресной книги на телефоне, поэтому `wa` читает синхронизированную адресную книгу и не меняет её.
- **Старые сообщения**: wacli. `history backfill` запрашивает у телефона старые сообщения чата. `wa messages sync`
  делает то же самое по 50 за раз, но `wa` новее, поэтому на реальных аккаунтах он проработал меньше, чем wacli.
- **Скрипт, который только отправляет**: mudslide. Он маленький, отправляет одной командой, и настроить его можно за
  минуту.
- **Сессия Claude Code, которая просыпается на каждое входящее сообщение**: WhatsApp Channel. Он сделан именно для
  этого. `wa` никогда не отвечает сам.

## Сравнение с агентом, который управляет WhatsApp Web

Браузерный агент открывает WhatsApp Web и нажимает кнопки. Ему нужен браузер, в котором сохранён вход, он читает
экран, и у него нет способа ограничить то, что он отправляет. `wa` и другие инструменты на этой странице общаются с
WhatsApp как связанное устройство, без браузера, и возвращают данные, а не экраны. Мы не измеряли скорость и
стоимость по сравнению с браузерным агентом, поэтому эта страница ничего не утверждает ни о том, ни о другом.
