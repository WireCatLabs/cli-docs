Подключите рабочее пространство Notion один раз, и дальше ИИ-агент находит любую вашу страницу и отвечает со ссылкой
на нее. Notion хранит страницы в своем облаке и пускает программу только по токену, который вы создаете в Notion. Создать
токен, установить `notion` и войти можно примерно за пять минут.

Когда все готово, агент на этом компьютере ищет по выбранным страницам и берет из них контекст, даже без интернета.

Все это можно сделать в [WireCat Desktop](/ru/docs/desktop), приложении, которое устанавливает инструменты за вас,
или в терминале через npm. В обоих случаях нужен один токен Notion.

## Что нужно

- Рабочее пространство Notion, где вы полноправный участник. Гость токен создать не может.
- Для терминала: Node.js 22.16 или более новый 22.x, либо Node.js 24 и новее. Node 23 не поддерживается. WireCat
  Desktop ставит Node.js сам.

<a id="make-a-notion-token" />

## Создайте токен Notion

В Notion есть два вида токенов. Создайте один из них.

**Личный токен доступа** действует с вашими правами и видит то же, что и вы
([инструкция Notion](https://developers.notion.com/guides/connections-and-tokens/personal-access-tokens)):

1. Откройте [notion.so/developers/tokens](https://www.notion.so/developers/tokens) и нажмите **New token**.
2. Дайте ему имя, например `WireCat`, и выберите срок действия. Если Notion спросит рабочее пространство, выберите
   свое.
3. Нажмите **Create token** и скопируйте токен. Notion показывает его только один раз.

На тарифе Free такой токен создают только владельцы пространства. На Business и Enterprise владельцы решают, кому это
можно, в **Settings → Connections**.

**Токен внутреннего подключения** видит только страницы, которыми вы поделились с этим подключением. Выберите его,
чтобы дать инструменту несколько страниц и больше ничего
([инструкция Notion](https://developers.notion.com/guides/connections-and-tokens/internal-connections)):

1. Откройте [портал разработчика](https://app.notion.com/developers/connections) и нажмите **New connection**.
2. Дайте подключению имя, в **Authentication method** выберите **API token** и нажмите **Create connection**.
3. На вкладке **Configuration** скопируйте **API token**. Включите чтение содержимого и пункт «Read user information
   including email addresses» ([возможности подключения](https://developers.notion.com/reference/capabilities)). Без
   данных пользователей синхронизация хранит автора страницы только по id Notion и не может сопоставить его с людьми,
   которых вы знаете по адресу почты. Если агент будет писать в Notion, включите еще изменение и добавление
   содержимого.
4. Поделитесь страницами: на каждой верхней странице в Notion откройте меню **•••**, выберите **Connections**, затем
   **+ Add connection** и свое подключение. Вложенные страницы откроются вместе с ней.

<a id="in-wirecat-desktop" />

## В WireCat Desktop

1. На странице **Инструменты** нажмите **Установить** в строке Notion.
2. Нажмите **Управление**, введите имя аккаунта, например `personal`, и нажмите **Войти здесь**.
3. Вставьте токен. Затем выберите страницы и базы данных для копирования. Пока ничего не выбрано, инструмент копирует
   все, что видит токен.

Desktop еще и дает вашим ИИ-агентам навык инструмента, так что остальную часть страницы можно пропустить.

<a id="in-a-terminal" />

## В терминале

Установите `notion` один раз на каждый компьютер, где с ним работаете вы или агент:

```sh
npm install -g @wirecat/notion-cli
notion --version
notion doctor
```

`doctor` не ходит в сеть и не открывает связку ключей. Он показывает версию, где лежат настройки, какие есть профили и
могут ли другие пользователи компьютера читать настройки.

Дайте терминальному агенту навык инструмента, короткое руководство по его командам. Приложение, которое подключается
к MCP-серверам, работает с инструментом по MCP, как показано в разделе [использование](./usage.md#agents).

```sh
notion skill install
```

<a id="sign-in" />

## Вход

Профиль - это имя, которое вы даете одному аккаунту Notion, например `personal`. Оно идет первым словом в каждой
команде для аккаунта. Войдите в профиль с токеном:

```sh
notion personal session start
```

Команда спрашивает токен и не показывает его на экране, или читает его из stdin. Сначала Notion проверяет токен. Затем
токен попадает в связку ключей системы. Там, где связка ключей не работает, добавьте `--credential-storage file`,
чтобы хранить токен в закрытом файле.

<a id="check-that-it-works" />

## Проверьте, что все работает

```sh
notion personal session status --check
notion personal sync
notion personal search "квартальный план"
```

`session status --check` спрашивает у Notion, чей это токен. `sync` копирует страницы, а `search` находит их в копии.
Как копировать только часть страниц, описано в разделе
[подключите и скопируйте страницы](./index.md#подключите-и-скопируйте-страницы).

<a id="sign-out" />

## Выход

`notion personal session end` забывает токен на этом компьютере. Сам токен в Notion остается действующим, пока вы не
удалите его там же, где создали.
