Каждый сценарий — частая задача по шагам: какие команды выполнить, зачем нужна каждая и на что смотреть в ответе. Те же сценарии есть в терминале: `memo guide` показывает список, а `memo guide <name>` — один сценарий.

<a id="decision-trail" />

## Что мы решили про X — по всем источникам

Найдите решение по одной теме и доказательства в заметках, почте, сообщениях, встречах и документах, затем запишите его один раз.

1. ```sh
   memo facts list kind:decision project:HRB
   ```

   решения, уже записанные по проекту, каждое со своими доказательствами

2. ```sh
   memo search all venue
   ```

   сообщения, письма и заметки с упоминанием темы в общем рейтинге

3. ```sh
   memo search meetings venue
   ```

   что говорили об этом на встречах, с фрагментом для цитаты

4. ```sh
   drive personal search venue
   ```

   документы Drive на эту тему

5. ```sh
   memo answers create "what did we decide about the venue?" --all
   ```

   доказательства с источниками одним набором — для вас или вашего агента

6. ```sh
   memo facts add "The team day is at the harbour venue" --kind decision --evidence msg:telegram/1/77/42 --project HRB
   ```

   сохраняет решение с источником, чтобы следующий поиск нашёл его первым

На что смотреть:

- самое новое решение и кто его принял
- более поздние сообщения или встречи, которые его отменяют
- ссылается ли записанное решение на найденный вами источник

В терминале: `memo guide decision-trail`

<a id="person-brief" />

## Один человек во всех инструментах

Узнайте всё об одном человеке перед звонком — сообщения в tg и MAX, почту, заметки, встречи и документы Drive — с источником для каждой строки.

1. ```sh
   memo context telegram:Kai
   ```

   его сообщения, письма, заметки и открытые задачи в одном ответе, каждое со ссылкой на источник; email:kai@example.com находит человека по адресу

2. ```sh
   memo facts list subject:"person:42"
   ```

   решения, обещания и вопросы, уже записанные о нём; ссылку на человека даёт ответ context

3. ```sh
   memo memories list subject:"person:42"
   ```

   сохранённые предпочтения и сводки о нём

4. ```sh
   memo search meetings Kai
   ```

   встречи, где его упоминают, с фрагментом для цитаты

5. ```sh
   tg personal contacts context Kai
   ```

   общие чаты Telegram, последние сообщения в обе стороны и где его упоминали другие

6. ```sh
   max personal contacts context Kai
   ```

   то же для MAX

7. ```sh
   zm personal meetings context person:42
   ```

   что о нём говорят сохранённые встречи Zoom, через связанные с ним идентичности

8. ```sh
   drive personal search Kai
   ```

   документы Drive, где он назван

9. ```sh
   memo answers create "what is open with Kai?" --all
   ```

   один набор доказательств с источниками по всем аккаунтам и заметкам, готовый для агента

На что смотреть:

- открытые задачи и обещания с обеих сторон
- последний контакт в каждом канале и кто написал последним
- записанные о нём решения и всё более новое, что им противоречит
- документы, которые стоит перечитать перед звонком

memo объединяет то, что уже есть в хранилище; другие инструменты добавляют то, что читают только они. Каждый шаг только читает — ничего
не отправляется и не меняется.

В терминале: `memo guide person-brief`

<a id="prepare-meeting" />

## Подготовиться к встрече

Приходите на регулярную встречу, зная, что говорили в прошлый раз, что ещё не решено и что сказано в документах проекта.

1. ```sh
   memo meetings prepare 85012345678 --source zoom --project HRB
   ```

   прошлые встречи серии, их реплики и связанные сообщения и письма, каждое с источником

2. ```sh
   memo meetings actions list status:proposed --source zoom
   ```

   дальнейшие действия по прошлым встречам, которые никто не проверил

3. ```sh
   memo projects context HRB
   ```

   сначала ключевые документы проекта, затем его заметки, находки и открытые задачи

4. ```sh
   memo answers create "what is still open for the Harbour kickoff?" --all
   ```

   один набор с источниками по всем аккаунтам и заметкам, из которого агент составит повестку

На что смотреть:

- обещания с прошлой встречи и выполнены ли они
- открытые задачи без ответственного
- время следующей встречи: подготовка его не проверяет

В терминале: `memo guide prepare-meeting`

<a id="set-up" />

## Настроить memo

Загрузите заметки и почту в локальное хранилище, поддерживайте его актуальным и дайте агенту его читать.

1. ```sh
   memo folders add ~/notes
   ```

   присваивает папке с заметками id; memo никогда не меняет файлы

2. ```sh
   memo sync --only notes
   ```

   импортирует заметки сейчас; почтовые аккаунты берутся из настройки mail.accounts

3. ```sh
   memo jobs start
   ```

   с этого момента синхронизирует заметки и почту каждые 5 минут

4. ```sh
   memo doctor
   ```

   где memo хранит файлы и что требует внимания; никуда не подключается

5. ```sh
   memo skill install --for all
   ```

   учит Claude Code, Codex и Gemini CLI пользоваться memo

На что смотреть:

- что, по словам doctor, требует внимания
- включён ли поиск по смыслу или только по словам

В терминале: `memo guide set-up`

<a id="start-the-day" />

## Начать день

Узнайте, что ждёт вас сегодня и что агенты сделали за ночь, не читая каждый чат и ящик.

1. ```sh
   memo jobs status
   ```

   синхронизировал ли таймер заметки и почту недавно; неудачный запуск будет назван здесь

2. ```sh
   memo tasks agenda
   ```

   просроченные и текущие задачи, чаты, где ответ должны вы, и чаты, где ждёте вы

3. ```sh
   memo actions list status:proposed
   ```

   ответы и приглашения, предложенные агентами и ждущие вашего «да» или «нет»

4. ```sh
   memo facts list status:proposed
   ```

   факты, записанные агентами и ещё не подтверждённые вами

5. ```sh
   memo agents list --limit 20
   ```

   каждый вызов инструмента агентом, никогда — с аргументами

На что смотреть:

- самый старый чат без ответа
- задачи на сегодня
- предложения, которые нужно подтвердить или отклонить, прежде чем агент начнёт на них опираться

В терминале: `memo guide start-the-day`
