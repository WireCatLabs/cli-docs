Эта страница поможет подключить Memo к приложению ИИ без терминала, например к Claude Desktop или Cursor.
MCP (Model Context Protocol, протокол контекста модели) — это способ, которым такие приложения
используют программу на вашем компьютере. После подключения приложение может читать ваши сообщения,
почту, заметки и архивные встречи, а также то, что Memo знает о человеке. Ещё оно может сохранять память, записывать
факты и предлагать действия. Всё, что оно сохраняет, ждёт вашей проверки.

## Что приложение может делать через MCP

| Приложение может | Приложение не может |
|---|---|
| Искать и читать сохранённые сообщения, почту и заметки | Отправить сообщение или письмо |
| Читать контекст одного человека по мессенджерам и почте | Изменить ваши заметки, почту или сообщения |
| Добавлять, показывать списком, открывать и искать память | Подтвердить запись памяти |
| Добавлять, показывать списком и открывать факты | Принять факт |
| Предлагать действия и показывать их списком | Одобрить или отклонить действие |
| Читать журнал агентов | Удалить что-либо |
| Находить проекты, теги и темы по названию и видеть, какие задачи готовы | Создавать или связывать задачи |

Записывают только три инструмента: `memories_add`, `facts_add` и `actions_add`. То, что они добавляют,
ждёт как предложение, пока вы его не подтвердите, а действие никогда не отправляется. Остальные
инструменты не меняют исходные записи; поиск по встречам может обновить локальный текстовый индекс. Подключайте Memo только к приложению, которому доверяете читать ваши
сообщения, почту и заметки.

## Подключите приложение

Добавьте Memo в настройки MCP приложения. Большинство приложений используют такой файл:

```json
{ "mcpServers": { "memo": { "command": "memo", "args": ["mcp"] } } }
```

Добавьте запись `memo` рядом с серверами, которые уже есть в файле:

| Приложение | Файл настроек |
|---|---|
| Cursor | `~/.cursor/mcp.json` |
| Claude Desktop, macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Claude Desktop, Windows | `%APPDATA%\Claude\claude_desktop_config.json` |

Сохраните файл и перезапустите приложение. Memo должен быть установлен на том же компьютере, что и
приложение. Если приложение не находит `memo`, замените `"memo"` полным путём. Его покажет команда
`which memo` (macOS и Linux) или `where.exe memo` (Windows).

Затем проверьте:

```text prompt
Use the memo tools to list the memories waiting for my review.
```

## Инструменты

| Инструмент | Действие |
|---|---|
| `search_all` | Поиск сообщений всех мессенджеров, почты и заметок вместе; только чтение |
| `search_messages`, `search_mail`, `search_notes` | Поиск одного вида источников со всеми полями; только чтение |
| `search_meetings`, `meeting_passage` | Поиск по сохранённым встречам в одном явно выбранном аккаунте-источнике и чтение процитированных фрагментов расшифровки |
| `person_context` | Человек в мессенджерах и почте, со связанными заметками и задачами; только чтение |
| `memories_add`, `memories_list`, `memories_show`, `search_memories` | Запись и чтение памяти |
| `facts_add`, `facts_list`, `facts_show` | Запись и чтение фактов |
| `actions_add`, `actions_list`, `actions_show` | Предложение и чтение действий |
| `agents_log` | Чтение журнала агента |
| `vocabulary_list`, `vocabulary_show`, `vocabulary_check` | Просмотр проектов, тегов и тем; только чтение |
| `vocabulary_inspect` | Проверить два выбранных тега перед объединением: счётчики, пересечения и ограниченные примеры; ничего не объединяет |
| `tasks_relations`, `tasks_status`, `tasks_list` | Зависимости задач; только чтение |

Всё, что добавляет приложение, сохраняется под именем агента `memo-mcp` и ждёт со статусом «предложено».
Вы проверяете это командой `memo memories list status:proposed` и командами со страницы
[Память и факты](./memories.md).

## Журнал агентов

Каждый вызов приложения записывается в журнал агентов:

```sh
memo agents log agent:memo-mcp --limit 20
```

Журнал показывает инструмент, результат и время, но никогда не показывает, что отправило приложение.

О доказательствах из встреч см. [поиск по встречам](./search.md#search-stored-meetings). Пакеты выводов по встречам
сейчас создаются из командной строки (`memo meetings actions add`), а не пакетным инструментом MCP.

Дальше: [проверьте, что сохранило приложение](./memories.md).
