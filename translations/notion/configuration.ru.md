title: "Настройки"

Настройки хранятся в одном файле, `config.json`, в папке, которую показывает `notion doctor`. У каждого профиля своя
часть, а `defaults` действуют для всех профилей. На этой странице описано, как посмотреть и поменять настройки.

```sh
notion personal config show
notion personal config set limit 50
notion personal config unset limit
```

`config show` перечисляет все настройки и откуда взято каждое значение: из файла, из переменной или по умолчанию.

## Разрешения

`permissions` решает, что команде можно делать в этом профиле: `allow`, `ask`, `readonly` или `deny`, для каждого
ключа разрешения. Через MCP спросить некого, поэтому `ask` пропускает команду. `WCNOTION_READ_ONLY=1` отклоняет любую
запись, что бы ни говорили разрешения.

## Записи запусков

Команда, которая завершилась ошибкой, сохраняется как запуск для `notion runs list` и `runs show`. Команда, которую вы
добавили и которая делает свою работу в `context.run`, сохраняется и при успехе. Это не так, если `record` равно
`false` (тогда сохраняются только ошибки) или команда запущена с `--no-record`. `documents`, `databases` и
`session status --check` работают внутри запуска, поэтому `--record` сохраняет и их. `record_input` решает, хранит ли
запуск слова, которые вы набрали. Оно равно `true`, пока вы не зададите `false`. Секреты скрываются в любом случае,
см. [Безопасность](./security.md).
