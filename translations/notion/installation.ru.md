---
title: "Установка"
---

Установите `notion` один раз на каждый компьютер, где с ним работаете вы или агент. Нужен Node.js 22.16 или более
новый 22.x, либо 24 и новее. Node 23 не поддерживается.

```sh
npm install -g @wirecat/notion-cli
notion --version
```

Проверьте установку, затем выберите имя профиля для своего аккаунта, например `personal`:

```sh
notion doctor
```

`doctor` не ходит в сеть и не открывает связку ключей. Он показывает версию, где лежат настройки, какие есть профили и
могут ли другие пользователи компьютера читать настройки.

## Вход

Выполните вход в профиль с токеном Notion:

```sh
notion personal session start
```

Команда спрашивает токен и не показывает его на экране, или читает его из stdin. Подходит токен любого из двух видов:

- [персональный токен доступа](https://developers.notion.com/guides/connections-and-tokens/personal-access-tokens),
  который действует с вашими собственными правами.
- токен внутреннего подключения, который видит только страницы, открытые этому подключению.

Для подключения включите в его [возможностях](https://developers.notion.com/reference/capabilities) пункт
«Read user information including email addresses» (чтение данных пользователей вместе с адресами почты). Без него
синхронизация хранит автора и редактора страницы только по id Notion и не может сопоставить их с людьми, которых вы
знаете по адресу почты.

Сначала Notion проверяет токен. Затем токен попадает в связку ключей ОС. Там, где связка ключей не работает, добавьте
`--credential-storage file`, чтобы хранить токен в закрытом файле. `notion personal session end` забывает токен на
этом компьютере. Сам токен в Notion остается действующим.
