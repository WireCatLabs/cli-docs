## 0.1.0 — 2026-10-11

- Рекурсивный импорт выбранных папок Google, включая все вкладки Google Docs и загруженные Markdown/TXT.
- Локальное хранение текста для поиска, идентичности источников, выбранных метаданных, снимков Markdown/JSON и контрольных точек для продолжения синхронизации.
- Поиск по словам и локальным тегам, дополнительная подготовка локальных эмбеддингов и чтение импортированных источников без Google.
- Локальные теги, заметки, идентичности редакторов, связи с людьми и проектами, записи памяти с доказательствами.
- Предпросмотр дополнительного извлечения памяти через общего провайдера ИИ, проверка подтверждающих цитат и устаревание памяти после изменений источника.
- Чтение и управление файлами, папками Drive и Google Docs через официальные клиенты, 68 генерируемых методов API и дополнительная история действий.
- Явный выбор профиля аккаунта, разделение OAuth и прав команд, структурированный вывод, режимы без сети и предварительной проверки, дополнение и локальный MCP.
- Установка скомпилированного JavaScript через npm; общие проверки WireCat, приёмка пакета и соглашения процесса выпуска MAX.

- Вход через включённое Desktop-приложение Google от WireCat либо собственный OAuth-клиент через файл или окружение; приватные токены пользователя остаются в локальном хранилище учётных данных.
