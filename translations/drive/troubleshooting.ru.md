---
title: "Исправить подключение или пустой поиск"
---

Восстановите работу, если Drive недоступен, Google отклоняет вход или сохранённый документ
не находится. Начните с симптома ниже, проверьте нужный шаг и убедитесь в результате перед
большим импортом или изменением разрешений. Сохраните код ошибки и имя профиля для поддержки.

| Симптом | Что делать |
| --- | --- |
| `drive` не найден | Откройте терминал/агента заново; проверьте каталог команд npm в PATH и повторите [установку](./installation.md). |
| Google блокирует вход | Проверьте показанную ошибку Google и правила Workspace. Для своего клиента также проверьте API, экран согласия и тестовых пользователей. |
| `google-api.disabled` | Владелец OAuth-проекта должен включить нужный API; см. [настройку API](#google-api-is-disabled). Повторный вход или разрешение записи не включает API. |
| Вход истёк | Повторите `drive personal session start`. Добавляйте `--client-file` только для собственного приложения. Разрешения External Testing обычно истекают через семь дней. |
| Нет системного хранилища ключей | Повторите вход с явным `--credential-storage file`, если подходит приватное файловое хранение. |
| Поиск пуст | Выполните `status`, проверьте корни через `folders list`, затем `sync`. Попробуйте известное слово с `search --exact`. |
| Файл пропущен | Проверьте тип и разрешение на скачивание. Импортируются Docs, Sheets, Markdown/TXT, PDF, `.docx`, `.xlsx` и CSV; сканированные PDF, Slides и ярлыки не читаются. |
| Синхронизация остановилась с ошибками | Повторите её: ожидающая работа возобновится. Частичный импорт не означает полное покрытие. |
| Для смыслового поиска нет компонента | Подготовьте общий кеш по руководству [поиска](./search.md#search-by-meaning) или используйте `--exact`. |
| Цель связи не найдена | Используйте ссылку из выбранной базы. Перед связями с людьми/проектами мессенджера проверьте, что все инструменты используют одинаковый MESSAGING_STORE. |

```sh
drive personal status --json
drive personal folders list --json
drive personal sync --json
drive personal search 'known word' --exact --json
```

При обращении за помощью передайте обезличенный код ошибки и команду. Не прикладывайте
JSON клиента, токены или приватный текст. Когда источник появился, вернитесь к [поиску](./search.md).

## «Choose a profile explicitly»

Выполните команду как `drive personal …` либо `drive --profile personal …`, заменив `personal`
выбранным именем аккаунта. Ошибка перечисляет настроенные профили. Ни `DRIVE_PROFILE`, ни прежний
сохранённый профиль не заменяют явный выбор. Для первого входа см.
[подключение](./installation.md#connect-your-account). `drive personal session list` показывает все имена.

## Непонятна настройка Google Cloud

Включение API не создаёт OAuth-клиент. Настройте **Google Auth platform → Branding**,
добавьте аккаунт в **Audience → Test users**, затем создайте **Clients → Desktop app** и скачайте JSON.
Следуйте [инструкции по консоли](./installation.md#prepare-google-sign-in).
Нужен Desktop JSON, а не ключ API или сервисного аккаунта.

## Приложение Google опубликовано, но нужен вход

Публикация приложения не разрешает доступ к вашему аккаунту и компьютеру. Выполните
[подключение аккаунта](./installation.md#connect-your-account) и подтвердите доступ в браузере
Google. При включённом клиенте WireCat обычным пользователям не нужно повторять настройку
Google Cloud. Собственный Desktop клиент остаётся альтернативой. Google ещё не закончил проверку
приложения WireCat, поэтому показывает предупреждение «непроверенное приложение» и ограничивает его
100 новыми пользователями всего; см. [предупреждение](./installation.md#google-shows-an-unverified-app-warning).
Правила Workspace тоже могут ограничивать доступные аккаунты и разрешения.

## Google API отключён

Подключение может быть действительным, пока API отключён в Google Cloud проекте приложения.
Например, импорт Sheets через XLSX-экспорт Drive может работать, а актуальные команды `sheets` —
завершаться ошибкой. `google-api.disabled` отличает эту проблему настройки приложения от доступа
к файлу или отсутствующего OAuth-разрешения. Ошибка не подтверждает существование таблицы.

Для включённого приложения WireCat сообщите WireCat команду и очищенную ошибку; пользователям
не нужно создавать своё приложение, чтобы исправить проект WireCat. Со своим приложением выберите
его проект в Google Cloud Console, откройте **APIs & Services → Library**, найдите API и нажмите
**Enable**. Для актуальных операций Sheets откройте
[страницу Google Sheets API](https://console.cloud.google.com/apis/library/sheets.googleapis.com).
Проверьте выбор проекта перед включением. См. официальные
[инструкции по настройке API](https://developers.google.com/workspace/guides/enable-apis).

Дайте настройке время примениться, затем повторите чтение, например `sheets info`, для выбранной
таблицы с тем же явным профилем. Включение API не предоставляет доступ к файлу или право записи;
сама эта ошибка не означает, что нужно повторно входить с более широкими разрешениями.

## Локальное содержимое отличается от Google

Проверьте последнюю синхронизацию и незавершённую работу через `drive personal --offline status --json`.
Сохранённые данные относятся к этой версии. Обновите их онлайн с `drive personal sync --json`,
затем повторите поиск. Актуальные метаданные, комментарии и история требуют доступа к Google
и запрещены с `--offline`; импортированный источник читается через `documents show`.

## Неизвестен результат изменения Google

Если после тайм-аута или прерванного ответа команда сообщает неопределённый результат,
проверьте файл в Google перед повтором. Повторное создание документа или копирование может
дублировать уже успешное действие. Ошибки объясняет [справочник команд](./commands.md); в запрос
поддержки добавьте очищенный код ошибки, а не ответы SDK или приватное содержимое.

## При обновлении хранилища найдены аннотации

Drive сохраняет предыдущую базу, если теги, заметки, память, факты или связи остались бы за
пределами нового хранилища. Задайте в `MESSAGING_STORE` путь к предыдущему файлу, чтобы продолжить
пользоваться аннотациями. Используйте тот же путь в других инструментах WireCat, если они должны
искать в этой базе. Не удаляйте предыдущий файл и не сбрасывайте контрольную точку для обхода
защиты. Чтобы скопировать контекст, выполните `drive personal status --json`: прежняя база указана в
`store.checkpoint`. Затем следуйте [сценарию переноса](./recipes.md#keep-notes-when-changing-databases).
`store check` показывает количества и конфликты без изменения файлов. `store import` требует
fingerprint этого просмотра и меняет контрольную точку только после сохранения копии. Сохраните
оригинал. Для отсутствующих проектов/задач нужны явные соответствия ссылок; противоречия в
содержимом, людях или псевдонимах меток надо разрешить до переноса. Прерванную неизменённую копию
можно повторить без дублирования аннотаций.

Схему источника ниже версии 2 сначала обновите в отдельной копии; перенос не обновляет оригинал.
Эту копию можно указать явно, если хеши документов совпадают с кешем профиля. Слишком большой граф
отклоняется без частичного копирования. На время перехода остановите другие записи в исходную
базу: операция не синхронизирует два хранилища.

Если ошибка говорит об отсутствующем снимке, выполните `drive personal sync --rescan`,
чтобы снова скачать выбранное дерево папок. Защита аннотаций при этом продолжает действовать.
