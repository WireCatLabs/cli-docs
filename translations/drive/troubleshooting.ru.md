---
title: "Исправить подключение или пустой поиск"
---

Восстановите работу, если Drive недоступен, Google отклоняет вход или сохранённый документ
не находится. Начните с симптома ниже, проверьте нужный шаг и убедитесь в результате перед
большим импортом или изменением разрешений. Сохраните код ошибки и имя профиля для поддержки.

| Симптом | Что делать |
| --- | --- |
| `drive` не найден | Откройте терминал/агента заново; проверьте каталог команд npm в PATH и повторите [установку](./installation.md). |
| Google блокирует вход | Проверьте Desktop-клиент, API, экран согласия и тестовый аккаунт. Используйте добавленный в приложение аккаунт. |
| Вход истёк | Выполните `session start` снова с клиентским файлом. Разрешения External Testing обычно истекают через семь дней. |
| Нет системного хранилища ключей | Повторите вход с явным `--credential-storage file`, если подходит приватное файловое хранение. |
| Поиск пуст | Выполните `status`, проверьте корни через `folders list`, затем `sync`. Попробуйте известное слово с `search --exact`. |
| Файл пропущен | Проверьте тип и разрешение на скачивание. Поддерживаются Google Docs и Markdown/TXT; PDF, Office, Sheets, Slides и ярлыки не импортируются. |
| Синхронизация остановилась с ошибками | Повторите её: ожидающая работа возобновится. Частичный импорт не означает полное покрытие. |
| Для смыслового поиска нет компонента | Подготовьте общий кеш по руководству [поиска](./search.md#search-by-meaning) или используйте `--exact`. |
| Цель связи не найдена | Используйте ссылку из выбранной базы. Перед связями с людьми/проектами мессенджера проверьте явное общее хранение. |

```sh
drive personal status --json
drive personal folders list --json
drive personal sync --json
drive personal search 'known word' --exact --json
```

При обращении за помощью передайте обезличенный код ошибки и команду. Не прикладывайте
JSON клиента, токены или приватный текст. Когда источник появился, вернитесь к [поиску](./search.md).

## «Choose a profile explicitly»

Выполните команду как `drive personal …` либо `drive --profile personal …`, заменив `personal`
выбранным именем аккаунта. Ошибка перечисляет настроенные профили. Ни `DRIVE_PROFILE`, ни прежний
сохранённый профиль не заменяют явный выбор. Для первого входа см.
[подключение](./installation.md#connect-your-account). `drive personal session list` показывает все имена.

## Непонятна настройка Google Cloud

Включение API не создаёт OAuth-клиент. Настройте **Google Auth platform → Branding**,
добавьте аккаунт в **Audience → Test users**, затем создайте **Clients → Desktop app** и скачайте JSON.
Следуйте [инструкции по консоли](./installation.md#prepare-google-sign-in).
Нужен Desktop JSON, а не ключ API или сервисного аккаунта.

## Приложение Google опубликовано, но нужен вход

Публикация приложения не разрешает доступ к вашему аккаунту и компьютеру. Выполните
[подключение аккаунта](./installation.md#connect-your-account) и подтвердите доступ в браузере
Google. При включённом клиенте WireCat обычным пользователям не нужно повторять настройку
Google Cloud. Собственный Desktop клиент остаётся альтернативой. Правила Workspace и проверка
разрешений Google могут ограничивать доступные аккаунты и разрешения.

## Локальное содержимое отличается от Google

Проверьте последнюю синхронизацию и незавершённую работу через `drive personal --offline status --json`.
Сохранённые данные относятся к этой версии. Обновите их онлайн с `drive personal sync --json`,
затем повторите поиск. Актуальные метаданные, комментарии и история требуют доступа к Google
и запрещены с `--offline`; импортированный источник читается через `documents show`.

## Неизвестен результат изменения Google

Если после тайм-аута или прерванного ответа команда сообщает неопределённый результат,
проверьте файл в Google перед повтором. Повторное создание документа или копирование может
дублировать уже успешное действие. Ошибки объясняет [справочник команд](./commands.md); в запрос
поддержки добавьте очищенный код ошибки, а не ответы SDK или приватное содержимое.
