title: "Настройки"
---

Управляйте расположением локальной копии Drive, разрешёнными действиями профиля и провайдером ИИ
для дополнительного извлечения памяти. Откройте руководство, чтобы сохранить выбор для следующих
запусков или изменить поведение одного аккаунта. Вы узнаете, где лежит файл, как изменить значение
и чем сохранённые настройки отличаются от переменных окружения и параметров команды.

**Настройка** — сохранённое значение в `config.json`. **Профиль** — именованная конфигурация одного
аккаунта Google. **Переменная окружения** передаётся терминалом или процессом агента; **параметр**
действует в одном запуске команды. Это разные способы управления инструментом.

## Где лежат файлы

| Система | Файл настроек | Локальные данные и снимки |
| --- | --- | --- |
| Linux | `~/.config/drive-cli/config.json` | `~/.local/share/drive-cli/` |
| macOS | `~/Library/Preferences/drive-cli/config.json` | `~/Library/Application Support/drive-cli/` |
| Windows | `%APPDATA%\drive-cli\Config\config.json` | `%LOCALAPPDATA%\drive-cli\Data\` |

Это стандартные пути системы; переменные ниже позволяют их изменить. Конфигурация содержит ID
выбранных папок, идентичность аккаунта и настройки, но не токены OAuth. Токены лежат в системной
ключнице, если при входе явно не выбрано файловое хранение. База по умолчанию в Linux — `~/.local/share/WireCat/wirecat.db`; снимки и контрольные точки находятся в `profiles/PROFILE_NAME/`. Перед переносом
или удалением прочитайте о [локальном хранении](./usage.md#disk-use-index-without-an-export-directory).

Файлы со старыми именами настроек в camelCase автоматически переходят на snake_case при первом
успешном чтении. Права доступа к файлу сохраняются; повторное чтение без изменений его не
перезаписывает. Имена профилей, пути разрешений и названия назначений моделей не меняются.
Конфликтующие старые и новые значения отклоняются.

## Сохранённые настройки

| Ключ | Что регулирует | Область |
| --- | --- | --- |
| `read_only` | Запрещает локальные и удалённые изменения, включая синхронизацию и добавление заметок | Профиль или `defaults` |
| `permissions` | Уровни доступа команд: `deny`, `readonly`, `ask` или `allow` | Профиль или `defaults` |
| `max_text_chars` | Предел текста одного файла; значение по умолчанию и максимум `2000000`, предел читателей документов | Профиль или `defaults` |
| `picture_search` | `true` включает поиск изображений по содержимому: sync скачивает изображение до 25 МБ, а поиск возвращает `pictures`; по умолчанию `false` | Только профиль |
| `models.memories.provider` | Провайдер ИИ для явно запрошенного извлечения памяти | Профиль или `defaults` |
| `models.memories.model` | Идентификатор модели провайдера | Профиль или `defaults` |
| `models.memories.base_url` | Дополнительный адрес сервиса выбранного провайдера | Профиль или `defaults` |

Сведения аккаунта меняют отдельные команды: `session start` сохраняет идентичность и способ
хранения учётных данных, а `folders add`/`folders remove` меняют выбранные корни. Не кладите токены
доступа и ключи провайдеров в файл настроек.

## Изменить и проверить значение

```text prompt
Use drive CLI with profile personal. Show the saved settings and explain which actions they allow.
Set remote file operations to read-only, keeping local indexing and notes available.
Show the saved change; do not change Google files.
```

Вручную:

```sh
drive personal config show --json
drive personal config set permissions.files '"readonly"'
drive personal config set permissions.documents '"readonly"'
drive personal config show --json
```

Эти разрешения ограничивают группы команд для файлов и Google Docs. Для локальной синхронизации
и заметок используются отдельные ключи. `read_only true` действует шире: запрещает и локальные
изменения, поэтому не включайте его для импорта и тегов. Перед выбором более широких правил
проверьте [справочник команд](./commands.md) и [разрешения](./security.md).

`config set` меняет выбранный профиль, если не добавлен `--defaults`. Например:

```sh
drive personal config set read_only true --defaults
drive work config set read_only false
drive personal config show --json
```

`drive personal config set picture_search true` включает поиск изображений только для `personal`.
Сначала подготовьте общую локальную модель `clip-b32` (около 160 МБ), затем пишите запросы по-английски.
Агент с доступом к терминалу может использовать проверенный установщик моделей из установленного SDK:

```text prompt
Prepare WireCat's local CLIP image model for Drive profile personal using the installed shared SDK.
Use its verified model installer and the same WIRECAT_STATE_DIR as Drive. Download only model files;
do not connect to Google or change my source files. Then enable picture_search for personal.
```

Публичный SDK экспортирует `modelsCommand` из `@wirecat/cli-core/cli`; агент может изучить этот
API для подготовки модели. Drive предоставляет настройку и поиск, а модель устанавливается
через общий SDK или инструмент WireCat с поддержкой подготовки моделей изображений.

Первая строка меняет общее значение, вторая переопределяет его для `work`. Последняя команда
печатает оба раздела конфигурации, а не объединённый список действующих значений. Отсутствие
профиля — ошибка: `DRIVE_PROFILE` и прежнее сохранённое значение по умолчанию его не выбирают.

`drive personal config set max_text_chars 500000` ограничивает длину текста: более длинный файл
пропускается с причиной и читается при следующем sync после повышения предела.

## Переменные окружения

Эти значения действуют для процесса Drive; `config set` их не сохраняет.

| Переменная | Назначение |
| --- | --- |
| `DRIVE_CONFIG_DIR` | Перенести `config.json` и связанное пространство учётных данных |
| `DRIVE_STATE_DIR` | Перенести снимки и контрольные точки |
| `DRIVE_CACHE_DIR` | Перенести кеш инструмента; снимки документов остаются в каталоге данных |
| `MESSAGING_STORE` | Выбрать файл общей базы вместо стандартной базы WireCat |
| `WIRECAT_STATE_DIR` | Перенести папку WireCat с общей базой и поисковыми моделями; по умолчанию `~/.local/share/WireCat/` |
| `DRIVE_GOOGLE_CLIENT_ID`, `DRIVE_GOOGLE_CLIENT_SECRET` | Использовать своё Desktop OAuth приложение вместо включённого WireCat; перед secret укажите ID |
| `DRIVE_MODELS_MEMORIES_PROVIDER`, `DRIVE_MODELS_MEMORIES_MODEL`, `DRIVE_MODELS_MEMORIES_BASE_URL` | Переопределить параметры извлечения памяти для процесса |
| `DRIVE_OPENAI_API_KEY`, `DRIVE_ANTHROPIC_API_KEY` | Передать ключ выбранного провайдера; соответствующая переменная без префикса тоже принимается |

Используйте одинаковые пути при входе и последующих командах: их изменение может сменить запись
ключницы, которую видит CLI. Если задан `WIRECAT_STATE_DIR`, подготовка модели и создание
эмбеддингов должны использовать тот же каталог.

## Параметры одного запуска

| Параметр | Действие в этом запуске |
| --- | --- |
| `--profile NAME` или первое слово `NAME` | Явно выбрать профиль аккаунта Google |
| `--offline` | Запретить Google, синхронизацию и извлечение ИИ; отвечать из локальной копии |
| `--read-only` | Запретить локальные и удалённые изменения |
| `--permission KEY=LEVEL` | Временно переопределить разрешение команды |
| `--dry-run` | Проверить и показать поддерживаемое действие без выполнения |
| `--json`, `--jsonl` | Структурированный вывод; `--json=id,title` оставляет только эти поля; ответы MCP явно показывают управляющие символы |
| `--timeout DURATION`, `--max-output-bytes N` | Ограничить время команды и размер буферизованного вывода |

Это не настройки файла. Параметры конкретных команд, например `search --limit` и `sync --limit`,
описаны рядом с командами. Временные разрешения важнее разрешений профиля, затем идут общие
значения. Сохранённое `read_only true` остаётся ограничением даже при разрешении `allow`. Переменные
ИИ важнее выбора провайдера и модели в профиле или общих настройках.

## Дополнительное извлечение ИИ

Один раз настройте извлечение и просмотрите результат перед сохранением памяти:

```sh
drive personal config set models.memories.provider '"openai"'
drive personal config set models.memories.model '"YOUR_MODEL_ID"'
drive personal config show --json
```

Замените `YOUR_MODEL_ID` идентификатором провайдера. Передайте ключ через окружение, а не в чат
агента. Извлечение отправляет выбранный сохранённый текст этому провайдеру. Поиск по словам и
локальные эмбеддинги — отдельные операции, которым ключ API ИИ не нужен. Проверка и сохранение
объясняются в [извлечении памяти](./recipes.md#remember-a-source-backed-decision).

## Общие документы и сообщения

Drive использует ту же базу WireCat, что Memo, Telegram и MAX. Импортированные документы доступны
в их локальном поиске с Google-ссылкой и временем последнего изменения в Google. Успешная
синхронизация записывает выбранный профиль Drive рядом с его коллекцией документов. Поиск Drive
читает выбранный аккаунт Google, а общий поиск других инструментов может охватывать несколько
сохранённых источников. Снимки и контрольные точки остаются в `DRIVE_STATE_DIR`, а
`MESSAGING_STORE` выбирает базу. Общее хранение не объединяет входы и разрешения Google.

При переходе со старой отдельной базы Drive восстанавливает ссылки на документы из локальных
снимков и сохраняет исходный файл. Прерванное восстановление можно повторить. Если снимков
не хватает, выполните `drive personal sync --rescan`, чтобы снова скачать выбранные источники.

Drive останавливается, если в предыдущей базе есть аннотации, которые остались бы за пределами
новой базы. Чтобы продолжить пользоваться ими, задайте в `MESSAGING_STORE` путь к предыдущему
файлу; не удаляйте его. `DRIVE_STORE` больше не поддерживается и вызывает ошибку, а не молча
выбирает другой файл. Автоматического переноса пользовательских аннотаций между базами нет.

Далее — [связи документов с людьми и проектами](./recipes.md#link-a-document-to-a-person-or-project).
