---
title: "Импортировать и организовать"
---

Выберите папку проекта, импортируйте поддерживаемые документы и сохраняйте локальный контекст
рядом с источниками. Каждый результат поиска содержит ссылку на Google для проверки оригинала.

## Импортировать папку

Скопируйте URL папки из Google Drive и замените `FOLDER_ID`:

```sh
drive folders add https://drive.google.com/drive/folders/FOLDER_ID
drive sync --json
drive status --json
drive documents list --json
```

Синхронизация включает вложенные папки. Проверьте пропуски и ошибки в отчёте: папка с PDF
или таблицами не становится полностью доступной для поиска. После изменений выполните
`drive sync` снова. Прерванная работа возобновляется; автоматического фонового наблюдения нет.

`drive folders list` показывает выбранные корни, а не интерактивное дерево. Содержимое удалённой
папки можно посмотреть через `drive files list --parent FOLDER_ID`. Имена могут повторяться;
используйте возвращённые идентификаторы.

## Добавить локальный контекст

Замените `DOC_ID` на Google ID импортированного документа:

```sh
drive tags add DOC_ID budget follow-up
drive notes add DOC_ID 'Ask Rin to confirm the revised totals'
drive search 'tag:follow-up' --exact --json
drive documents context DOC_ID --json
```

Теги и заметки не редактируют документ Google. Они сохраняются при обычном переименовании и
повторной синхронизации. `documents context` собирает теги, заметки, связи, записи памяти и
наблюдаемых редакторов.

Создайте предложенную запись памяти для полезного факта и проверьте её перед подтверждением:

```sh
drive memories add DOC_ID 'The launch budget is approved' --scope work
drive memories list DOC_ID --json
drive memories confirm DOC_ID memory:MEMORY_ID
```

Замените `MEMORY_ID` возвращённой ссылкой. Изменение или удаление источника делает связанные
активные записи памяти устаревшими. Сохранённая запись не доказывает правильность источника;
сохраняйте документ, который её подтверждает.

## Экспортировать или прекратить импорт

```sh
drive documents export DOC_ID --out ./decision.md
drive folders remove FOLDER_ID
drive sync --json
```

Экспорт записывает локальный Markdown и не перезаписывает существующий файл. Удаление выбранного
корня обновляет локальную копию при следующей синхронизации; файлы, включённые через другой корень,
остаются в области импорта. Оригиналы Google не удаляются. Продолжите с [поиском](./search.md)
или [сценариями](./recipes.md).
