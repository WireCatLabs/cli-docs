## 0.1.0 — 2026-10-11

- Importación recursiva de carpetas Google elegidas, incluidas todas las pestañas de Docs y Markdown/TXT subidos.
- Texto para búsqueda, identidad de fuentes, metadatos seleccionados, copias Markdown/JSON y puntos de control reanudables guardados localmente.
- Búsqueda por palabras y etiquetas, preparación opcional de embeddings locales y lectura de fuentes importadas sin Google.
- Etiquetas, notas, identidades de editores, vínculos con personas/proyectos y recuerdos con evidencia locales.
- Vista previa de extracción opcional de recuerdos con el proveedor de IA compartido, validación de citas y marcado de recuerdos obsoletos tras cambios de fuente.
- Lectura y gestión de archivos, carpetas Drive y Docs mediante clientes oficiales, con 68 métodos API generados e historial de actividad opcional.
- Perfiles de cuenta explícitos, permisos OAuth separados de los comandos, salida estructurada, modos sin conexión y de vista previa, autocompletado y MCP local.
- Instalación de JavaScript compilado con npm; validación compartida WireCat, aceptación del paquete y convenciones de publicación MAX.

- Acceso con la aplicación Google Desktop incluida de WireCat o tu propio cliente OAuth mediante archivo o entorno; los tokens privados permanecen en el almacén local de credenciales.
