---
title: "Если что-то не работает"
---

Верните `amo` в рабочее состояние по сообщению, которое он показывает. У истекшего токена, профиля, пропущенного в
команде, и аккаунта amoCRM, который перестал отвечать, свое сообщение и свое исправление.

Найдите свой симптом в таблице, выполните проверку, которую она дает, и повторите команду. Если не помогло, у вас уже
готовы код ошибки и имя профиля для обращения в поддержку. Ваш агент может сделать то же самое: каждая ошибка
называет свою причину, например `session.expired`, поэтому агент знает, что случилось.

`amo doctor` показывает, что настроено, без сети и без связки ключей. `amo work session status --check` спрашивает у
аккаунта, от имени какого пользователя действует вход.

## Первые проверки

```sh
amo doctor                         # the version, the settings, the profiles, without the network
amo work session status --check    # the account and the user the sign-in acts as
amo work store status              # how far each kind's sync is, and when it last ran
```

## Симптомы и что делать

| Симптом | Что делать |
| --- | --- |
| Непонятно, что настроено | Запустите `amo doctor`. Он не читает связку ключей и не ходит в сеть. |
| `amo` не находится | Откройте новый терминал и проверьте, что глобальная папка npm есть в `PATH`. |
| "name a profile" | Поставьте профиль первым словом, как в `amo work config show`, или задайте `AMO_PROFILE`. |
| Файл настроек не читается | `doctor` перечисляет все проблемы файла в `config.issues`. Выполните `config unset`, который дан для каждой, или исправьте файл вручную. |
| `doctor` показывает `files.problems` | Другие пользователи компьютера могут читать `config.json` или заходить в его папку. Выполните каждую команду `chmod`, которую `doctor` печатает после "to make it private:". Сам `doctor` права файлов не меняет. |
| "not signed in" (`session.missing`) | Запустите `amo work setup` или `amo work session start --host` с адресом аккаунта, как показано в разделе [установка и подключение](./installation.md#sign-in-with-a-key). |
| "amoCRM refused the token" (`session.expired`) | Срок долгосрочного токена закончился, его отозвали, или `--host` указывает на другой аккаунт. Создайте новый токен и снова запустите `amo work session start` с адресом аккаунта, как показано в разделе [установка и подключение](./installation.md#sign-in-with-a-key). |
| Вход через браузер перестал работать | `amo` не запускался больше 3 месяцев, и refresh-токен amoCRM истек. Войдите снова, как показано в разделе [вход через интеграцию](./installation.md#sign-in-through-the-integration). |
| "another profile here already signs in to this account as this user" (`session.duplicate`) | Используйте тот профиль или удалите его командой `amo <profile> account remove --keep-data` и войдите снова. |
| Синхронизация копирует чужие сделки или не все ваши | Синхронизация копирует сделки пользователя, который вошел, или пользователей, которых выбрал администратор. Найдите id через `users list`, затем задайте их, как показано в разделе [какие сделки копирует синхронизация](./configuration.md#which-deals-sync-copies). |
| Контакта или компании нет в копии | Копия хранит только клиентов из ваших сделок. Любого другого читайте напрямую через `people list` или `organizations list`. |
| "the account has no API filter add-on" (`amo.filters-off`) | Список контактов или компаний из аккаунта фильтруется по ответственному или времени только с платным дополнением amoCRM с фильтрами API. Вместо этого ищите по словам, например `amo work people list "Anna"`. |
| На сегодня телефоны и почта закончились (`crm.foreign-contacts-spent`) | Пользователь, который не администратор, видит их не больше чем у 100 других контактов и компаний в день. Счет начинается заново на следующий день (UTC). |
| "the token's user may not do this in amoCRM" (`amo.access-denied`) | Это запрещают права самой amoCRM. Администратор дает этому пользователю право в amoCRM, или в профиль входит сам администратор. |
| "only an amoCRM administrator …" (`employee.delete`, `employee.clear`, `employee.unbind`) | Удаление, очистка поля и отвязка записей требуют входа администратора. См. [разрешения](./permissions.md#checks-that-hold-whatever-the-permissions-say). |
| `rate_limited` (код выхода 8) | `amo` держится в пределах 5 запросов в секунду и сам пережидает короткий отказ. Подождите минуту и запустите команду еще раз. |
| `outcome_unknown` (код выхода 14) на записи | amoCRM могла сделать изменение. Запустите `sync`, посмотрите запись через `show` и пишите снова, только если изменения там нет. |
| "the amoCRM subscription has ended" (`amo.subscription-ended`) | Продлите подписку в amoCRM. Запись останавливается сразу, а чтение через 30 дней. |
| "amoCRM blocks every request" (`amo.blocked`) | Остановите все команды `amo` для этого аккаунта и проверьте его в amoCRM: слишком много запросов или адрес не в списке разрешенных. |
| Запись отклонена | Ее останавливают разрешения профиля или `AMO_READ_ONLY`. См. [разрешения](./permissions.md). |

## Как попросить помощи

Сохраните код ошибки и имя профиля. `amo doctor reports create` записывает отчет о проблеме в файл и говорит, куда
его отправить. Спросите в [Discord](https://discord.gg/DebENqbRrJ) или откройте issue в
[репозитории amo-cli](https://github.com/WireCatLabs/amo-cli/issues).

Никогда не вставляйте в обращение токен, пароль или личное содержимое.
