---
title: "Если что-то не работает"
---

Начните с симптома, выполните проверку и повторите команду. Для обращения в поддержку сохраните код ошибки и имя
профиля.

| Симптом | Что делать |
| --- | --- |
| Непонятно, что настроено | Запустите `amo doctor`. Он не читает связку ключей и не ходит в сеть. |
| `amo` не находится | Откройте новый терминал и проверьте, что глобальная папка npm есть в `PATH`. |
| "name a profile" | Поставьте профиль первым словом, как в `amo work config show`, или задайте `AMO_PROFILE`. |
| Файл настроек не читается | `doctor` перечисляет все проблемы файла в `config.issues`. Выполните `config unset`, который дан для каждой, или исправьте файл вручную. |
| `doctor` показывает `files.problems` | Другие пользователи компьютера могут читать `config.json` или заходить в его папку. Выполните каждую команду `chmod`, которую `doctor` печатает после "to make it private:". Сам `doctor` права файлов не меняет. |
| "amoCRM refused the token" (`session.expired`) | Срок долгосрочного токена закончился, его отозвали, или `--host` указывает на другой аккаунт. Создайте новый токен и запустите `amo work session start --host <address>`. |
| "the amoCRM subscription has ended" (`amo.subscription-ended`) | Продлите подписку в amoCRM. Чтение останавливается через 30 дней после записи. |
| "amoCRM blocks every request" (`amo.blocked`) | Остановите все команды `amo` для этого аккаунта и проверьте его в amoCRM: слишком много запросов или адрес не в списке разрешенных. |
| Запись отклонена | Ее останавливают разрешения профиля или `AMO_READ_ONLY`, смотрите [настройки](./configuration.md#permissions). |

Никогда не вставляйте в обращение токен, пароль или личное содержимое.
