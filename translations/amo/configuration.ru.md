Настройки лежат в одном файле, `config.json`, в папке, которую показывает `amo doctor`. У каждого профиля своя
часть, а `defaults` действуют на все профили. Здесь описано, как их посмотреть и поменять.

```sh
amo work config show
amo work config set limit 50
amo work config unset limit
```

`config show` показывает каждую настройку и откуда она взялась: из файла, из переменной или по умолчанию.

## Разрешения

`permissions` решает, что команда может делать для этого профиля: `allow`, `ask`, `readonly` или `deny`, для каждого
ключа разрешения. По MCP спросить некого, поэтому `ask` пропускает команду. `AMO_READ_ONLY=1` запрещает все записи,
что бы ни говорили разрешения.

## Записи запусков

Команда, которая завершилась ошибкой, сохраняется как запуск для `amo runs list` и `runs show`. Добавленная вами
команда, которая работает в `context.run`, сохраняется и при успехе, если только `record` не `false` (тогда только
ошибки) или она не запущена с `--no-record`. `api call` и `session status --check` работают в запуске, поэтому
`--record` их сохраняет. `record_input` решает, хранит ли запуск слова, которые вы набрали. Он `true`, пока вы не
поставите `false`. Секреты скрываются в любом случае, смотрите раздел [безопасность](./security.md).
