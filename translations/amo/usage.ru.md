title: "Работа с инструментом"

Здесь описано, как устроена команда и как с инструментом работает агент. Прочитайте это перед первой командой.

## Сначала профиль

Профиль - это имя, которое вы выбираете для одного аккаунта. Это первое слово каждой команды, которой нужен аккаунт:

```sh
amo work config show
```

`AMO_PROFILE=work` делает то же самое для одного сеанса оболочки. Профиль никогда не подставляется сам, даже
единственный: команда без него останавливается с кодом выхода 2 и показывает профили на этом компьютере.

## Вход

Создайте приватную интеграцию аккаунта и войдите в профиль, как описано в разделе
[установка и подключение](./installation.md): по ключу или через интеграцию в браузере.
`amo work session status --check` показывает аккаунт и пользователя, от имени которого действует профиль.

## Первая синхронизация

`sync` копирует в локальное хранилище WireCat сделки, где вы ответственный, и сделки коллег, которых выбрал
администратор, а также только те контакты и компании, что есть в этих сделках. Команды вроде `deals list` потом
читают эту копию без интернета:

```sh
amo work sync
amo work deals list status:open
```

Других клиентов читают напрямую из amoCRM командами `people` и `organizations`. Запустите `sync` снова, чтобы
обновить копию. `amo work schedule command crm --every 1h -- sync` делает это по таймеру.

## Вызов API

`amo work api list` перечисляет все операции amoCRM API v4 с именами вида `<HTTP verb> <path>`, их ключами
разрешений и страницами справки. `api call` отправляет одну операцию, параметры запроса и тело передаются в JSON:

```sh
amo work api call "GET /api/v4/leads" --params '{"limit":5,"with":"loss_reason"}'
amo work api call "PATCH /api/v4/leads/42" --body '{"price":1000}' --dry-run
```

`--dry-run` показывает все разрешения, которые проверяет вызов, и ничего не отправляет.

## Вывод для скриптов

Каждая команда, кроме `mcp serve` на stdin и stdout, принимает `--json` и печатает в stdout одно значение JSON.
Ошибки идут в stderr тоже в JSON, с кодом, по которому можно ветвиться. Коды перечислены в
[справочнике команд](./commands.md).

## Агенты

`amo skill install` кладет навык инструмента туда, где его ищут Claude Code, Codex, Gemini CLI и OpenClaw.
`amo skill install --for hermes` еще и добавляет эту папку в настройки Hermes Agent, а простой `skill install`
Hermes не трогает. `amo work mcp serve` отдает команды профиля по MCP, на stdin и stdout:

```sh
claude mcp add amo -- amo work mcp serve
```

Сервер предлагает все команды, в том числе те, что пишут. Что выполнится, решают разрешения профиля, смотрите
[настройки](./configuration.md#permissions).

Для ChatGPT и Claude в браузере
`amo work mcp serve --http --public-url https://laptop.example.ts.net` работает на `127.0.0.1` (порт 8765, или
`--port`) за вашим собственным туннелем. Приложение в браузере входит одноразовым кодом, который печатает команда.
`amo work mcp revoke` завершает все входы. `amo work mcp server start` запускает тот же сервер в фоне,
`mcp server status` показывает его порт, код входа и подключенные приложения, а `mcp server stop` его
останавливает.
